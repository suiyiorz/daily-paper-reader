## 摘要
潜在世界-动作模型通过在特征空间中预测与动作相关的视觉子目标来避免渲染未来像素。LaWAM确立了这一表述，但其原始呈现方式将世界模型、多模态骨干网络和部署检查点紧密耦合。我们引入AcrossWAM1.0，这是对这一潜在世界-动作栈的模块化与扩展研究。我们并非将潜在子目标作为新算法提出，而是明确模块边界：策略适配器产生潜在动作与动作生成上下文；保留的潜在世界解码器将预测的转移扎根于当前场景；流匹配专家生成连续动作块。我们进一步将仅用于训练的教师模块从推理图中分离，并提供可验证的部署导出。在2,000个配对的LIBERO回合中，将Qwen3-VL-2B骨干替换为Qwen3.5-0.8B，成功率为97.45%，而2B模型为98.00%（差异为-0.55个百分点；精确McNemar检验p=0.266）。这并不能证明等价性，但满足预设的两点保留标准。紧凑的、可推理检查点包含1,472.6M个唯一参数，比原始2B策略少42.4%，且所有保留的张量与源检查点逐位相同。此外，通过MiniCPM-V适配器冒烟测试检查了跨家族执行；闭环跨家族迁移仍是一个开放评估问题。因此，AcrossWAM1.0为紧凑的潜在世界-动作策略贡献了一个可审计的软件与评估边界，区别于LaWAM的原始潜在子目标贡献。

## Abstract
Latent world-action models avoid rendering future pixels by predicting an action-relevant visual subgoal in feature space. LaWAM established this formulation, but its original presentation left the world model, multimodal backbone, and deployment checkpoint tightly coupled. We introduce AcrossWAM1.0, a modularization and scaling study of this latent world-action stack. Rather than presenting latent subgoals as a new algorithm, we make the module boundary explicit: a policy adapter produces latent-action and action-generation contexts; a retained latent world decoder grounds the predicted transition in the current scene;and a flow-matching expert generates continuous action chunks. We further separate training-only teachers from the inference graph and provide a verifiable deployment export. On 2,000 paired LIBERO episodes, replacing a Qwen3-VL-2B backbone with Qwen3.5-0.8B yields 97.45% success versus 98.00% for the 2B model (a-0.55percentage-point difference; exact McNemarp=0.266). This does not prove equivalence, but it meets a prespecified two-point retention criterion. The compact, inference-reachable checkpoint contains 1,472.6M unique parameters, 42.4% fewer than the original 2B policy, while all retained tensors are bitwise identical to the source checkpoint. Cross-family execution is additionally checked with a MiniCPM-V adapter smoke test; closed-loop cross-family transfer remains an open evaluation. AcrossWAM1.0 therefore contributes an auditable software and evaluation boundary for compact latent world-action policies, distinct from LaWAM's original latent-subgoal contribution.

- 先前工作LaWAM证明了这种预测无需渲染像素图像：通过逆动力学潜在变量可解码为空间视觉子目标，并用于条件化动作专家。**然而，LaWAM的原始实现将世界模型、多模态骨干网络与部署检查点紧密耦合**——在图上模块化不等于在代码中模块化，更换骨干网络会牵涉 token 约定、隐藏维度、图像调用签名、检查点可达性等一系列问题。

## 2. 论文提出的方法论：核心思想与关键技术细节

### 2.1 整体架构与模块边界

**问题形式化。** 策略建模如下联合分布：

p(a, ĥ_{t+Δ}, z_t | o_t, ℓ, s_t) = p_θ(z_t | o_t, ℓ) · p_ω(ĥ_{t+Δ} | h_t, z_t) · p_η(a | c_θ, h_t, ĥ_{t+Δ}, s_t)

其中：o_t为多视角视觉观测，ℓ为语言指令，s_t为可选本体感受状态；z_t∈R^{32}为潜在动作，ĥ_{t+Δ}为预测的潜在视觉子目标，h_t=f_ψ(o_t)为冻结DINOv3的patch表征。该分解使预测的场景变化成为显式的中间变量。

**系统分两阶段：**

### 2.2 阶段一：学习动作相关的潜在世界模型（继承自LaWAM）
- **冻结特征空间**：使用冻结的DINOv3编码器为每个转移对(o_t, o_{t+Δ})产生patch token，维持目标空间稳定。
- **逆动力学Q-Former**：编码器q_ϕ用单查询注意力处理成对的时序 token，输出32维高斯后验潜在动作 z_t = μ_ϕ + σ_ϕ ⊙ ε。
- **潜在世界解码器D_ω**：12层Transformer，每个块用自适应层归一化（AdaLN）将 z_t 调制到各 token 的变换上，将当前特征 h_t 解码为预测的未来特征 ĥ_{t+Δ}，以平滑L1损失匹配冻结的未来特征。
- **损失函数**：L_S1 = L_future + λ_s L_state + β_KL D_KL，其中状态接地损失通过类别特定预测器将(z_t, s_t)映射到状态位移，防止潜在变量仅编码外观变化；KL项使潜在空间规则化，便于后续策略模仿。
- 阶段一结束后，q_ϕ成为**仅训练用教师**，f_ψ与D_ω组成可复用的世界模块。

### 2.3 阶段二：预测潜在动作与动作生成
- **骨干与查询布局**：策略骨干（VLM/VAM）接收指令、主视图图像和可选辅助视图。两组不相交的查询embedding分别服务不同目的：**8个潜在动作查询（ACT queries）**收集推断转移所需的多模态上下文；**8个流查询（flow queries）**向连续动作专家暴露上下文。骨干适配器返回上下文token、两组查询切片及图像处理参数。
- **潜在动作预测**：潜在动作查询处隐藏状态经单查询交叉注意力映射器 M_ρ 压缩为预测潜在动作 ẑ_t；用冻结的阶段一教师提取的目标 z*_t 做蒸馏（L_distill = ‖ẑ_t − z*_t‖²₂），赋予潜在动作查询明确的动态语义。
- **潜在视觉子目标**：用保留的世界模型解码 D_ω(h_t, ẑ_t) 得到 ĥ_{t+Δ}，以L_subgoal匹配真实未来特征。子目标保持与当前DINOv3特征相同的空间token结构，能指定哪些图像区域应如何变化，而不只是一个全局潜在向量。
- **流匹配动作专家（Flow-DiT）**：条件扩散Transformer，一条条件流携带骨干上下文（含流查询状态），另一条携带当前与预测视觉token拼接(h_t, ĥ_{t+Δ})。采用flow matching目标——给定真实动作块a₁和高斯噪声a₀，构造线性插值a_τ，专家网络回归条件向量场 u_τ = a₁ − a₀：L_flow = E‖v_η(a_τ, τ|c_θ, h_t, ĥ_{t+Δ}, s_t) − u_τ‖²₂。测试时用ODE求解器从噪声积分出动作块（H=50步/1.2秒，10步积分）。
- **总损失**：L_S2 = L_flow + λ_p L_subgoal + λ_d L_distill（λ_p = λ_d = 0.1）。

### 2.4 推理边界与证据层级
- 推理图仅包含：骨干预测ẑ_t → 潜在世界解码器单次前向产生ĥ_{t+Δ} → 流匹配专家从噪声积分动作块。逆动力学编码器、状态接地头和未来帧均不在推理图中。

## 6. 论文的主要结论与发现

1. **模块化基础成立**：显式的骨干/世界/动作合约在一个框架内同时容纳2B与0.8B骨干并做配对闭环评估，证据表明模块边界在骨干缩放中存活。
2. **紧凑骨干保留了闭环性能**：Qwen3.5-0.8B策略在2,000回合LIBERO上达到**97.45%**成功率，Qwen3-VL-2B为**98.00%**，差值为−0.55个百分点。不一致计数2B独赢46回合、0.8B独赢35回合，精确McNemar p=0.2664——该评估未检测到配对差异，满足预设两百分点保留标准。
3. **部署压缩显著**：原始0.8B原始策略含1,883.8M唯一参数（较2B减少26.3%）；导出后的推理可达检查点仅含**1,472.6M唯一参数，较2B减少42.4%**，且所有保留张量逐位一致（1,078个保留、321个训练键移除、718个别名去重）。
4. **跨家族适配器执行可行但存在失败模式**：MiniCPM-V冒烟测试通过，但暴露了其词表无未使用嵌入行用于placeholder查询的问题，需显式处理resize与冻结规则。
5. **语言接地仍是弱点**：传统策略在冲突指令中仅27.4%按陈述方向放置物体；语言CFG变体改善到50.3%但以非冲突指令崩溃率从1%升至10%为代价。
6. **本论文不声称的功能**：统计等价性、闭环MiniCPM-V表现、跨骨干家族的冻结世界解码器迁移、紧凑模型的延迟/存储优势、对LaWAM算法与基准结果的归属。

- **训练方差未知**：每个骨干仅一个训练检查点，无法衡量重复训练的种子间波动。
- **部署验证不完整**：虽在状态字典和CPU加载层面验证了导出文件，但加速器+模拟器的完整闭环冒烟测试尚未完成；未见紧凑模型延迟、峰值内存等关键工程指标。
- **语言接地诊断初步且暴露折衷**：仅两个RoboTwin任务；CFG改进指令遵循的同时增加了非冲突指令下的崩溃，说明语言接地与任务完成之间存在未被解决的张力。
- **不是新算法贡献**：论文自身定位为模块化、缩放与部署研究，而非提出新的潜在子目标学习算法；依赖LaWAM作为技术根基，若根基方法本身存在不足则本工作也无法弥补。
- **算力信息和训练成本缺失**，不利于读者评估复现门槛与能耗代价。

## 总结

AcrossWAM1.0的贡献不是一个新的潜在子目标算法，而是将LaWAM的计算转化为一套具有显式接口、清晰模块边界和可审计导出的“软件+评估合约”。在2

在2B与0.8B骨干的配对闭环评估中，紧凑策略在2,000回合LIBERO上达到97.45%成功率，相对2B骨干的98.00%仅差0.55个百分点，McNemar精确检验未检测到显著差异，满足预设“不超过2个百分点”的保留标准。更重要的是，这一结论带有明确的范围边界：它只支持同家族、同合约下的骨干缩放，并不构成跨家族冻结传输的证据——因为在紧凑训练中，世界解码器仍然参与优化，而不是被冻结复用。这种“模块合约存在”与“模块可整体冻结复用”之间的区分，正是本文在方法论层面最值得留存的见解。

将这一主旨延伸到工程层面，导出验证进一步表明模块化不只是概念上的：推理可达检查点仅保留1,472.6M唯一参数（较2B减少42.4%），1,078个张量与源检查点逐位一致，321个训练专有键被剔除，718个别名键可从保留张量逐位重建。也就是说，策略、世界模型、动作专家之间的解耦最终落到了可加载、可校验、可追溯的检查点事实之上，而非仅停留于架构图的模块框。

总体而言，AcrossWAM1.0交付的是一个自觉受限的贡献：作者不声称提出新算法、不声称跨家族迁移、不声称紧凑模型的延迟与存储收益、也不把转述而来的RoboTwin数字当成自测结果。其真正价值在于以较严格的证据纪律证明了一件事——在显式模块化合约之下，紧凑骨干能够保持闭环操作性能，大量训练后期不可达状态也可以被安全地排除在推理图之外。但这份证据的覆盖范围仍然有限：仅单一基准、单一训练检查点、无训练种子方差、无真实机器人验证、无算力与能耗披露，语言接地诊断也暴露了指令遵循与任务完成之间的未解折衷。若后续工作能在跨家族冻结迁移、多随机种子统计、真实硬件闭环与延迟/内存指标上补足证据，该模块化框架的通用性与实用性才会得到更完整的检验。
