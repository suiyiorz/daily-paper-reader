## 摘要
多智能体机器人操作任务需要智能体之间进行协调，以满足任务层面的时间、逻辑和安全约束。最近，扩散策略已被用于执行此类任务。然而，在需要多智能体同时或顺序交互的任务中，它们仍然存在失同步、动作顺序错误和协调失败的问题。因此，提出了 LTLDiff 作为一个框架，将有限线性时序逻辑（LTLf）规范学习与通过扩散策略进行学习相结合，同时用于演示生成和策略学习。每个任务都有特定的 LTLf 公式，该公式使用大规模语言模型从一组自然语言指令中学习得到。为了能够对从语言模型学习到的规范进行固定维度向量嵌入，LTLf 使用抽象语法树表示方案。这种逻辑嵌入作为以下两项的条件：(i) 逻辑引导的数据收集和 (ii) 基于扩散的策略训练，从而鼓励生成与期望的顺序和协调要求一致的轨迹。在多智能体 LTLDiff 操作任务上的实验表明，与基线相比，任务成功率有所提高。总之，这些贡献证明了 LTLDiff 在协调多智能体操作中的有效性。

## Abstract
Multi-agent robotic manipulation tasks require coordination among agents to satisfy task-level temporal, logical, and safety constraints. Recently, diffusion policies have been used to perform the task. However, they still suffer from desynchronization, incorrect action ordering, and coordination failures in tasks that require simultaneous or sequential multi-agent interaction. Therefore, LTLDiff is proposed as a framework that combines Finite Linear Temporal Logic (LTLf) specification learning for both the generation of demonstrations and learning via diffusion policies. Each task has a specific LTLf formula that is learned from a set of natural language instructions using a large-scale language model. To enable a fixed-dimensional vector embedding of the learned specification from the language model, LTLf uses an abstract syntax tree representation scheme. This embedding of logic serves as a condition for (i) logic-guided data collection and (ii) diffusion-based policy training, encouraging trajectories that are consistent with the desired ordering and coordination requirements. Experiments on multi-agent LTLDiff manipulation tasks demonstrate improved task success rates compared to the baseline. Together, these contributions demonstrate the effectiveness of LTLDiff for coordinated multi-agent manipulation.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：多智能体机器人操作任务要求多个智能体在共享环境中协同工作，同时满足任务层面的**时序约束**（如"先抓取后抬升"）、**逻辑约束**（如"两个智能体都抓取后才能抬升"）和**安全约束**（如"始终避免碰撞"）。
- **现有方法的两难困境**：
  - **基于规则的方法**（A*、LTL-based 规划）：能严格保证安全与时序要求，但灵活性差，难以适应新任务和环境变化。
  - **基于学习的方法**（行为克隆、离线强化学习、扩散策略）：灵活性强，但缺乏满足关键安全与时序要求的机制。
- **扩散策略的痛点**：在多智能体同时或顺序交互任务中，容易出现**失同步**、**动作顺序错误**和**协调失败**。
- **RoboFactory 的局限**：虽然通过组合式逻辑、空间、时序约束来生成多智能体数据，但这些约束**未纳入策略训练**，导致执行阶段仍缺乏显式协调与时序推理。
- **LTLDiff 的定位**：介于规则方法与学习方法之间——用扩散策略实现任务适应，同时将 **有限线性时序逻辑（LTLf）规范**作为结构化条件输入，实现逻辑引导的数据生成与策略学习。

## 2. 方法论

### 2.1 核心思想
将任务的自然语言描述转化为 LTLf 公式，经抽象语法树（AST）编码为固定维度向量，该逻辑嵌入同时作为**(i) 离线演示数据生成**和 **(ii) 扩散策略训练**的条件信号，从而在软梯度引导下（非硬约束）生成符合时序与协调要求的轨迹。

### 2.2 关键技术细节

- **LTLf 生成器**：
  - 使用大规模语言模型 **Qwen**，从任务描述与目标条件生成 LTLf 公式。
  - 每个任务生成 **10 个候选公式**，再由 Qwen 回看任务描述，选择最合适的公式。
  - 输出为 JSON 结构，包含任务名、原子命题集合和 LTLf 公式。
  - 支持的时序算子：`F`（eventually）、`G`（globally）、`U`（until）、`X`（next）；逻辑算子：`&`、`|`、`->`、`!`。

- **LTLf 编码器**：
  - **分词与解析**：将算子、命题、括号显式分离，解析为 AST 以保留层次结构。
  - **AST 递归编码**：
    - 叶节点（原子命题）编码为 one-hot 向量：`hv = OneHot(p)`。
    - 内部节点编码为算子 one-hot 与子节点嵌入均值的拼接：`hv = [OneHot(ov) || (1/|C(v)|) Σ hu]`。
    - 根节点嵌入经零填充得到固定维度 `zφ ∈ R^128`。

- **LTLf 引导的离线数据生成**：
  - 数据生成分为多个"阶段"（phase），由原子命题和 LTLf 时序结构决定。
  - 原子命题作为高层语义与底层运动执行的接口；逻辑嵌入值决定运动规划参数（速度、加速度平滑度、物体位置等）的调制幅度与方向。
  - 生成"轨迹 + LTLf 公式"配对数据集：`D = {(τ(k), φ)}`。

- **LTLMAG：多智能体 LTLf 引导算法**（算法 1）：
  - 从高斯噪声开始，通过条件扩散策略迭代反向去噪。
  - 单一 LTLf 规范在所有智能体间共享，同时输入条件扩散策略 `πθ(τ|zφ)` 和学习到的回归器网络 `gφ`。
  - **回归器损失**：`Lreg = ||gφ - g*||²₂ + 0.01·max(0, ||gφ||₂ - 1)² + 0.1·Lsat`，其中 `g*` 为目标 LTLf 满足梯度，`Lsat` 为辅助二分类交叉熵损失。
  - **引导权重**：`ξi` 为时间变化引导权重，默认 0.1，采用线性调度（早期 2ξi，后期 0.1ξi）。
  - **两阶段多智能体更新**：每个扩散步内先进行各智能体局部去噪，再对拼接的联合轨迹施加回归器引导，以强制跨智能体时序与协调约束。
  - 相比 **LTLDOG-R** 的三点改进：① 使用条件扩散策略而非无条件策略；② 用前馈网络（MLP）替代图卷积网络作为回归器；③ 从单智能体扩展到多智能体。
