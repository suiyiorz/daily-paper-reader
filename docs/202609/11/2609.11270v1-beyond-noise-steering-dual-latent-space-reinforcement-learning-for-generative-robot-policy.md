## 摘要
预训练的生成式机器人策略从演示中学习富有表现力的动作先验。然而，现有强化学习方法仅引导噪声空间，却无法在生成过程中调节中间动作表示，导致性能下降和效率低下。为解决这一局限，我们提出了一种新颖的双潜在空间强化学习（DLSRL）框架，该框架通过冻结生成器内部的表示级控制来补充初始噪声引导。具体而言，我们的 Actor 网络预测两个不同的潜在变量：一个用于引导行为生成的初始噪声潜在变量，以及一个用于中间特征调制的动作表示潜在变量。此外，该表示潜在变量被映射为适配器特征，并通过残差连接巧妙地注入到中间动作 token 的隐藏状态中。我们的双控制设计能够在不更新基础策略的情况下直接调整动作表示。在生成式策略架构和机器人操作任务上的实验表明，DLSRL 有效加速了在线机器人策略适应，并取得了有竞争力的性能。我们的代码可在 https://github.com/xianchaoxiu/DLSRL 获取。

## Abstract
Pretrained generative robot policies learn expressive action priors from demonstrations. However, existing reinforcement learning methods only steer the noisy space but fail to modulate intermediate action representations during the generation process, resulting in performance degradation and inefficiency. To address this limitation, we propose a novel Dual-Latent Space Reinforcement Learning (DLSRL) framework, which complements initial-noise steering with representation-level control inside the frozen generator. Specifically, our actor network predicts two distinct latent variables: an initial-noise latent variable that steers behavior generation, and an action-representation latent variable for intermediate feature modulation. Moreover, this representation latent variable is mapped to adapter features and ingeniously injected into the hidden states of intermediate action tokens via residual connections. Our dual-control design enables direct adjustment of action representations without updating the base policy. Experiments across generative policy architectures and robotic manipulation tasks show that DLSRL effectively accelerates online robot policy adaptation and achieves competitive performance. Our code is available at \href{https://github.com/xianchaoxiu/DLSRL}{https://github.com/xianchaoxiu/DLSRL}.

- **现有方法的共同瓶颈**：保持基座策略冻结、仅学习外部引导机制的强化学习方案（如 DSRL 学习初始噪声策略、Residual RL 学习残差动作、DynaGuide 引导去噪轨迹等）均只在**动作生成的边界**上干预：

- **核心问题**：缺少一种强化学习机制，能够同时实现**全局行为模式选择**与**生成器内部中间动作表征的直接调制**。

## 二、方法论：DLSRL 框架

### 核心思想
- 在冻结的生成器内部引入**第二个 RL 控制接口**，与初始噪声引导互补，形成"双潜在空间"控制。
- 双潜在 Actor 从当前观测同时预测两个潜在变量：初始噪声潜变量 $z_t$（引导行为生成模式）和动作表征潜变量 $u_t$（调制中间特征）。
- 基座策略参数 $\phi$ 全程冻结，仅更新 Actor 参数 $\theta$ 与适配器映射参数 $\omega$。

### 关键技术细节
- **双潜在 Actor**：$(z_t, u_t) \sim \pi_\theta(\cdot \mid o_t)$，动作生成变为 $a_t = G_\phi(o_t, z_t, f_t)$。
- **适配器特征映射**：$f_t = A_\omega(u_t)$，$f_t$ 与动作 token 隐藏状态形状对齐（$f_t \in \mathbb{R}^{N_a \times d_h}$）。
- **动作 token 隐状态调制**：在第 $l$ 个冻结 Transformer 块输出上做残差注入：
  - $\tilde{H}^{(l)}_{t,k} = H^{(l)}_{t,k} + \delta_t$，其中 $\delta_t = \lambda_{inj} f_t$
  - $\lambda_{inj}$ 为全局注入强度；同一 $f_t$ 在所选块与各生成步之间共享；仅注入动作 token 位置，不改动视觉、语言、本体感受等上下文 token；不引入额外可训练层。

### 双潜在策略优化（算法流程）
- **动作空间 Critic** $Q^{act}_\psi(o_t, a_t)$：用在线交互数据以标准 off-policy TD 学习训练。
- **潜在空间 Critic** $Q^{lat}_\nu(o_t, z_t, f_t)$：通过值蒸馏从动作 Critic 学习：
  - $\mathcal{L}_{distill} = \mathbb{E}[(Q^{lat}_\nu(o_t, \hat{z}_t, \hat{f}_t) - \text{sg}[Q^{act}_\psi(o_t, \hat{a}_t)])^2]$，梯度只回传至 $\nu$，避免穿过冻结生成过程。
- **Actor 更新**：最小化熵正则化目标
  - $\mathcal{L}_{actor} = \mathbb{E}[\alpha \log \pi^z_\theta(z_t \mid o_t) - Q^{lat}_\nu(o_t, z_t, f_t)]$
  - 熵正则仅施加于初始噪声分支，但潜在价值的梯度会同时回传至两个 Actor 分支与适配器映射器。
- **交替训练**：动作 Critic → 潜在 Critic → 双潜在 Actor + 适配器映射器，循环迭代（Algorithm 1）。
- **部署阶段**：仅保留双潜在 Actor 与适配器映射器，丢弃两个 Critic。

## 六、主要结论与发现

- DLSRL 在 RoboMimic 三个任务上均表现出**更快的早期与中期性能提升**；在 Can 任务后期达到约 99% 成功率，而 DSRL 约为 90%；在 Square 上提升更快更稳定。
- 优势主要体现在**适应速度**而非一致更高的最终性能——Lift 任务上 DSRL 后期可逼近相近成功率。
- 在 LIBERO 六个流匹配 VLA 任务上，DLSRL 普遍更快达到饱和性能，且在全部六个任务上取得更短的平均回合长度，相对 DSRL 降低 **15.27%–25.40%**。
- 消融表明：仅靠动作 token 隐状态调制（DLSRL-Rep）即可将成功率从约 27% 提升至 52%，说明表征级控制可独立改善冻结基座策略，也解释了双接口组合为何能加速适应。
- 注入强度存在权衡：$\lambda_{inj}=0.09$ 初期提升快但后期波动大；$\lambda_{inj}=0.03$ 稳定但缓慢；$\lambda_{inj}=0.06$ 在适应速度与稳定性间取得最佳平衡，最终达到 100% 成功率。

## 七、优点与亮点

- **方法创新性**：首次将初始噪声引导与动作 token 隐状态调制统一在同一 RL 框架中，把控制接口从采样初始化阶段延伸到生成器内部中间表征阶段。
- **轻量且架构无关**：适配器特征与动作 token 形状对齐，残差注入无需新增可训练层、无需修改基座网络结构、无需更新基座参数，适用于扩散与流匹配两类生成式策略。
- **训练机制巧妙**：采用动作-潜在值蒸馏，避免梯度穿过冻结生成过程，训练稳定且部署时仅保留 Actor 与映射器，推理开销低。
- **实验覆盖较广**：跨两个基准、两种生成范式、九个任务验证，并辅以表征调制独立性与注入强度两组消融，论证链条较完整。
