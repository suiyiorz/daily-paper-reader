## 摘要
长时程机器人操作需要记忆，但不一定需要将记忆置于动作策略内部。为解决此类任务，当前的智能体系统常将 VLA 与规划器和几何工具结合，有时还会使用额外深度或标定几何。这些系统混淆了归因：性能提升可能来自更丰富的观测或替代性运动工具，而失败则可能源于策略，也可能源于未充分指定的语言接口。我们通过一种刻意受限的设计来分离这一问题：减少工具广度，但增大接口带宽。2AM 让多模态 Agent 成为任务记忆的唯一持有者，并让单个基于 RGB、按回合无状态的动作模型成为任务相关运动的唯一执行者。Agent 将交互历史编译为子任务语言，以及可选的 2D 抓取、放置和移动提示，这些提示在不同时间尺度上绑定其物理意图。为了教会 VLA 这种可引导性，我们用结构化提示标签增强演示数据，并在条件 dropout、空间噪声和时间抖动下训练，以容忍不完美的 Agent 输出。在 LIBERO-Mem 上，在不使用深度、在线几何或基于规划器的物体运动的情况下，2AM 达到 76.3% 的平均完成率，相比已报告的最强基线 14.8% 提升 61.5 个百分点，同时取得 63.0% 的宽松成功率和 11.8% 的严格成功率。这些结果表明，任务记忆可以保留在 Agent 侧。它们进一步表明，动作模型的能力不仅取决于策略学到了什么，还取决于 Agent 能多精确地引导它。

## Abstract
Long-horizon robot manipulation requires memory, but not necessarily inside the action policy. To address such tasks, current agentic systems often combine VLAs with planners and geometric tools, sometimes using additional depth or calibrated geometry. These systems confound attribution: gains may come from richer observations or alternative motor tools, while failures may stem from either the policy or an under-specified language interface. We isolate this question through a deliberately constrained design: less tool breadth, but greater interface bandwidth. 2AM makes a multimodal Agent the sole holder of task memory and a single RGB-based, episodically stateless Action Model the sole executor of task-relevant motion. The Agent compiles interaction history into subtask language and optional 2D grasp, place, and move hints that bind its physical intention at different time scales. To teach this steerability to the VLA, we augment demonstrations with structured hint labels and train under condition dropout, spatial noise, and temporal jitter to tolerate imperfect Agent outputs. On LIBERO-Mem, without depth, online geometry, or planner-based object motion, 2AM reaches 76.3% average completion, a 61.5-point improvement over the strongest reported baseline of 14.8%, together with 63.0% relaxed and 11.8% strict success. These results show that task memory can remain Agent-side. They further show that Action Model capability depends not only on what the policy has learned, but on how precisely the Agent can steer it.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：长时程机器人操作需要“记忆”，但当前主流做法往往把记忆直接嵌入动作策略内部（如视觉历史、循环状态、学习式记忆），或将 VLA 与规划器、几何工具、深度/标定几何混合使用。
- **核心问题**：现有 agentic 系统存在**归因混淆**——性能提升可能来自更丰富的观测（深度、掩码、物体位姿）或替代性运动工具（规划器、专用控制器），而非策略本身；失败也可能源于策略，或仅仅源于语言接口未充分指定实例、目的地或运动参数。
- **关键洞察**：仅用语言调用 VLA 并非中立的“能力证据”，因为可引导策略（steerable policies）表明，通用运动能力可能被信息不足的接口所掩盖。
- **研究定位**：论文刻意选择**相反的设计点**——限制感知（仅 RGB）与工具广度（无深度、无在线几何、无规划器），但**增大接口带宽**。目标是隔离并回答：任务记忆能否完全留在 Agent 侧，而动作模型仅作为无状态执行器？

## 2. 方法论

### 核心思想
- **双模型分解 + 显式契约**：多模态 Agent 是任务记忆的唯一持有者与决策者；单个基于 RGB、**按回合无状态（episodically stateless）** 的 Action Model 是任务相关运动的唯一执行者。
- **Steering Command（引导命令）**：Agent 将交互历史编译为一条组合式命令，承载“记忆的当前后果”，但不携带历史本身。

### 关键技术细节

- **问题设定**：长时程操作耦合快速局部控制状态（外观、夹爪构型、接触）与慢速任务状态（实例、目的地、重复次数、语义阶段）。论文研究“事件尺度物体操作”，即历史改变任务状态，但其当前后果可被当前 RGB 观测接地。
- **形式化**：
  - Agent 输出：`ck = AM_agent(g, I^a_k, H_k)`，其中 `g` 为回合指令，`I^a_k` 为当前 agent-view RGB，`H_k` 为有限整合历史记录（保留物体身份、目的地、计数、阶段）。
  - Action Model 输出：`â_{t:t+L-1} = AM_action(I^a_t, I^w_t, s_t, c_k)`，接收 agent-view、wrist-view、机器人状态与命令，预测 L 步绝对末端执行器动作。
  - **无状态含义**：Agent 每短动作块更新一次；Action Model 在每个块内执行，无持久回合状态，但并非对当前运动/本体状态“盲”。
- **组合式引导契约**：
  - `ck = (ℓ_k, q^grasp_k, q^place_k, q^move_k)`，其中 `ℓ_k` 为局部语言指令，其余为归一化 2D 提示（当前 agent-view 图像坐标，左上原点，[0,1000] 范围）。
  - 缺失字段直接省略，而非用特殊点表示；可用性本身随阶段变化。
  - **三种提示的时间尺度**：
    - `q^grasp`：绑定下一个物体实例，接触前最有用，物体被持住或阶段变化后消失。
    - `q^place`：保留较长承诺，跨运输阶段维持目的地显式。
    - `q^move`：近期线索，指示未来若干步的有用夹爪位置，被解释为局部方向提示，而非必须到达的路径点。
  - 三者互补而非同一目标的不同编码，可组合使用（如接近阶段用语言+抓取+移动，运输阶段去掉抓取保留放置+移动）。
- **训练监督恢复（无需模型教师）**：
  - 从演示轨迹中确定性提取子任务、活动物体实例、目的地及各提示有效区间。
  - 抓取/放置监督：对可见物体框 `(x,y,w,h)`，使用归一化中心 `q = 1000 * ((x+w/2)/W, (y+h/2)/H)`，为语义目标而非最优接触点。
  - 移动监督：采样 `Δ ∼ U{10,...,20}`，`q^move_t = robot_xy_{t+Δ}`，索引在回合边界裁剪；窗口采样避免模型将某一固定时间偏移视为定义。
  - 动作标签沿用原 VLA 对齐方式，窗口可在子任务边界跨越，保持抓取、抬升、释放附近运动连续。
- **面向不完美引导的训练**：
  - 用 `v_t ∈ {0,1}^4` 标记各字段语义可用性，掩码 `m_t ∼ p_mask(m|v_t)`，满足 `m_t ⪯ v_t` 且 `||m_t||_0 ≥ 1`（非空条件约束），生成仅语言、仅点、混合命令。
  - 对保留点加各向同性高斯噪声并裁剪：`q̃ = clip_[0,1000]²(q + ε)`，`ε ∼ N(0, σ²I₂)`。
  - 三类扰动覆盖主要接口错误：**遗漏、定位误差、时间错位**。
- **模型实现**：Qwen3-VL-4B 骨干 + flow-matching Action Expert；无独立抓取/放置/移动控制器。
- **闭环执行**：每个动作块后 Agent 观察新 RGB、更新 `H_{k+1}`、可修订子任务或任意提示；不暴露基准状态或完成预言机。

## 6. 主要结论与发现

- **核心结果（LIBERO-Mem 聚合）**：
  - 2AM：严格成功率 11.83%、宽松成功率 63.00%、完成率 76.29%。
  - 复现 π0：严格 12.25%、宽松 37.42%、完成 70.79%。
  - 已报告最佳基线（SlotSSM）：完成率 14.80%，严格成功率为 0。
  - 相比对齐 π0 复现，2AM 完成率提升 **5.50 个百分点**，宽松成功率提升 **25.58 个百分点**，严格成功率相当但略低。
- **语言-only 消融**：严格 7.25%、宽松 19.42%、完成 53.72%；加入接地提示后分别提升 **4.58、43.58、22.57 个百分点**，其中宽松成功率增益最显著。
- **任务级模式**：2AM 在全部 10 个任务上宽松成功率更高，在 7 个任务上完成率更高；复现 π0 在 T1–T6 严格成功率更高，2AM 在关系与遮挡更重的 T7–T10 更强。
- **关键发现**：
  - 任务记忆可以完全保留在 Agent 侧，无需内嵌于动作策略。
  - 动作模型能力不仅取决于策略学到了什么，还取决于 Agent 能多精确地引导它。
  - 接地引导主要帮助 Agent 将记忆意图贯穿整个有序进程，但**精确停止**（semantic termination）仍是独立未解瓶颈（63.0% 宽松 vs 11.8% 严格的巨大差距）。
  - 鲁棒训练可容忍遗漏、定位误差、时间错位，但无法纠正已编码错误高层意图的子任务或物体绑定错误。

## 7. 优点

- **问题隔离设计巧妙**：通过“少工具广度、大接口带宽”的受控设计，将性能归因于 Agent–Action Model 之间的契约，而非特权观测或替代运动路径。
- **单一执行器 + 无状态策略**：所有任务相关运动必须经过同一 Action Model，避免多组件重叠授权；无状态设计使 Agent 可在不继承失败轨迹潜变量的情况下重试。
- **组合式接口**：语言 + 三个独立可选 2D 提示，字段按阶段可用/缺失，缺失或噪声仅退化某一角色而非使整条命令失效。
- **监督来源无需模型教师**：从演示中确定性恢复结构化标签，避免 VLM 叙述轨迹引入的噪声与不可控性。
- **面向部署鲁棒性的训练**：条件 dropout、空间噪声、未来窗口采样分别对应遗漏、定位误差、时间错位三类真实接口错误，训练与推理接口一致。
- **公平的对齐比较**：主动指出已发表基线被低估，并构建同骨干复现 π0 作为主参照，同时用语言-only 消融直接量化接口带宽贡献。
- **诚实的结论表述**：明确承认严格成功率未提升、单一基准局限，不夸大结论。

## 8. 不足与局限

- **实验覆盖有限**：仅单一模拟基准 LIBERO-Mem，任务记忆的当前后果可被 RGB 接地；不能作为通用长时程能力的证据。
- **接口表达能力受限**：2D 接口无法暴露隐藏几何、力/接触状态、连续运动历史；对需要时序状态、精确时机或轨迹模仿的任务可能不适用。
- **严格终止未解决**：宽松与严格成功率差距巨大，说明“到达意图状态”与“精确停在该状态”是不同问题，当前接口未解决语义终止。
- **消融不完整**：未隔离 grasp/place/move 各自贡献，未比较更强 Agent 骨干，未测量引导频率与延迟的权衡。
- **Agent 错误无法被训练纠正**：子任务选择错误、目的地绑定错误等高层次意图错误会直接通过接口进入 Action Model，鲁棒性训练无法修复。
- **算力信息缺失**：未报告 GPU 型号、数量、训练时长，难以评估可复现性与实际开销。
- **潜在偏差风险**：复现 π0 与 2AM 共享骨干、输入与块长，但仍可能存在实现细节差异；已发表基线数字被作者认为严重低估，跨论文比较需谨慎。
- **应用限制**：依赖 Agent 的推理能力与延迟；真实机器人验证尚未进行，仿真到现实的迁移性未知。
