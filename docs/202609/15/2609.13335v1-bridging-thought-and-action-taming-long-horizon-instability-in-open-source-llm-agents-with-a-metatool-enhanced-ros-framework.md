## 摘要
大语言模型（LLM）使更自然的人机交互成为可能，但开源模型在部署到智能体式机器人框架中时，常表现出不稳定的长时程推理和低效的动作执行。本文提出了一种基于 ROS-Agent 的增强架构，可利用开源 LLM 提升智能体式机器人系统的任务可靠性与执行效率。所提出的系统引入了一种新颖的中间机制，称为 MetaTool，它在动作执行之前强制进行结构化规划。给定自然语言命令后，MetaTool 会引导 LLM 生成预期工具调用的伪代码计划，该计划被存储在 ROS-Agent 的 scratchpad 中，并在整个执行过程中持续存在。通过显式地将规划与执行分离，所提方法减少了执行循环并提升了确定性行为。该架构在一个具有多模态感知与运动控制能力的定制移动机器人平台上进行了验证。真实世界交互任务的实验结果表明，任务完成度和上下文一致性均得到提升，在复杂任务上相比基线框架可获得高达约 24% 的提升。

## Abstract
Large Language Models (LLMs) have enabled more natural human-robot interaction, but open-source models often exhibit unstable long-horizon reasoning and inefficient action execution when deployed in agentic robotic frameworks. This paper presents an enhanced ROS-Agent based architecture that improves task reliability and execution efficiency for agentic robotic systems using open-source LLMs. The proposed system introduces a novel intermediate mechanism, termed the MetaTool, which enforces structured planning prior to action execution. Given a natural-language command, the MetaTool induces the LLM to generate a pseudo-code plan of intended tool invocations, which is stored in the ROS-Agent's scratchpad and persists throughout execution. By explicitly separating planning from execution, the proposed approach reduces execution loops and improves deterministic behavior. The architecture is validated on a custom mobile robotic platform with multimodal perception and motion control capabilities. Experimental results on real-world interactive tasks demonstrate improved task completion and contextual consistency, with up to ~24% gains on complex tasks compared to the baseline framework.

## 1. 核心问题与研究动机

- **背景**：LLM 使自然语言驱动机器人交互成为可能，将 LLM 与机器人中间件（ROS）耦合的"智能体式框架"成为主流路径；其中 NASA JPL 的 **ROS-Agent（ROSA）** 提供了将 LLM 推理与 ROS 原生工具对接的结构化接口，支持任务分解与执行。
- **核心痛点**：开源 LLM 部署到智能体式机器人管线中时，**长时程（long-horizon）多工具调用推理不稳定**，表现为：
  - 冗余/重复动作、执行循环（execution loops）；
  - 任务推进不一致、指令漂移（instruction drift）、上下文遗忘；
  - 工具调用幻觉与超时。
- **动机**：闭源模型（如 GPT-4o）行为更稳定，但成本高、可及性受限，因此作者选择**从架构层面**而非模型层面提升开源 LLM 的鲁棒性。
- **整体含义**：提出一种"把规划从执行中显式剥离"的架构原语，使开源 LLM 在真实机器人长时程任务中具备可预测、可约束的执行行为。

## 2. 方法论

### 2.1 核心思想
- 在 LLM 与 ROS 执行层之间插入一个**中间智能体算子 MetaTool**，在**任何任务相关工具被执行之前**，先强制生成结构化的伪代码工具调用计划。
- 该计划写入 ROS-Agent 的 **scratchpad**，并在整个"观测—推理—动作"循环中**持久存在**，从而条件化后续每一次工具调用。
- 关键重构：把 baseline 中作为"无约束对话记忆"的 scratchpad，重新定义为**可强制执行的执行契约（enforceable execution contract）**。

### 2.2 关键技术细节
- **基础范式**：沿用 ROS-Agent 的 ReAct 式认知架构，用户查询 + 预置系统提示（编码机器人具身形态与可用工具集）共同送入 LLM，再由 ROS-Agent 桥接语言意图与硬件执行。
- **计划生成**：给定自然语言指令 $q \in Q$ 与工具集 $A=\{a_1,\dots,a_m\}$，MetaTool 诱导 LLM 生成有序符号计划 $P=\langle a_{i_1}, a_{i_2}, \dots, a_{i_n}\rangle$，$a_{i_k}\in A$。
- **策略形式化**：常规智能体为 $\pi(a_t \mid s_t)$；MetaTool 替换为**计划条件策略** $\pi_{\text{meta}}(a_t \mid s_t, P)$，并施加硬约束：
  - $\pi_{\text{meta}}(a_t \mid s_t, P) = 0,\ \forall a_t \notin A_P(t)$，其中 $A_P(t)=\{a_{i_t}\}$ 为计划在该步指定的工具，除非显式触发重规划。
  - 因 $|A_P(t)| \ll |A|$，该约束压缩了无结构的动作分支，抑制递归循环与指令漂移。
- **记忆机制**：计划持久保存；每次工具输出追加至 scratchpad，与初始计划共同构成连贯的执行轨迹，驱动工具链从头到尾一致推进。
- **动作空间**：ROS-Agent 原生系统工具（如 `rosnode`、`rostopic`）+ 自定义任务工具：
  - `describe image`（视觉—语言理解）、`RAG query`（向量库知识检索）、`face expression`（情感状态发布）、`follow me`（基于姿态关键点的人体跟随）、`get goal odometry`（目标条件里程计）、`set goal`（目标定义与存储）、`publish twist to move base`（导航目标下发）、`stop uh v1`（急停与目标取消）。
- **可迁移性**：作者将 MetaTool 定位为可被同类框架"即插即用"（drop-in）的架构原语。

## 6. 主要结论与发现

- **持久规划的价值（C1→C3）**：提升最一致。GPT-OSS-20B 在 T3 从 30%→35%，GPT-OSS-120B 在 T3 从 40%→50%，说明伪代码计划持久化可缓解开源模型的多步执行上下文遗忘。
- **对开源模型收益更大（C2→C3）**：GPT-OSS-20B 在 T1 从 60%→70%，Kimi-K2 在 T1 从 75%→85%，体现"意图外化"减少了递归调用与过早执行失败。
- **执行约束的必要性（C3→C4）**：在最难任务上收益显著。T3 上 GPT-OSS-20B 35%→55%、GPT-OSS-120B 50%→70%、Kimi-K2 65%→70%；T2 上 GPT-OSS-120B 80%→90%。说明将工具调用严格约束到计划对长时程导航收敛至关重要。
- **真机效率与稳定性（GPT-OSS-120B，40 次试验）**：
  - 重复工具调用：19.0% ± 5.7 → **6.1% ± 2.2**；
  - 无效/失败调用：21.7% ± 6.5 → **8.1% ± 2.9**；
  - 执行时间：89.51 s ± 16.48 → **84.23 s ± 9.71**（方差显著下降）。
- **Token 分析**：baseline ROSA 的 token 用量方差高（同一查询产生分歧的工具序列），MetaTool 呈低方差紧凑分布，说明其稳定生成结构化可执行计划，对小模型抑制递归调用尤为明显。
- **失败模式对比（40 次真机试验）**：MetaTool 成功率 **75.0%（30/40）**，优于 ROSA 57.5%（23/40）、CaP 50.0%（20/40）、ReAct 42.5%（17/40）；工具不可用/超时降至 **3/40**（ROSA 为 17/40）。
- **总体**：复杂任务相较基线最高约 **24%** 提升；显式分离规划与执行能提升推理稳定性、任务协调性与执行可靠性。

## 7. 优点

- **架构层面而非提示层面的解法**：把长时程不稳定性问题转化为动作空间的硬约束问题，具有可解释性与可复用性。

- **开源模型池覆盖偏窄**：仅选用 GPT-OSS-20B/120B 与 Kimi-K2，**未涵盖 Llama、Qwen、Mistral、DeepSeek 等更广泛的开源生态**，"对开源 LLM 普遍有效"的泛化性论断证据不足。
- **缺乏成本量化**：虽通过 Groq API 调用且报告 token 分布，但**未给出 API 调用次数、单次任务 token 成本、端到端任务耗时的成本换算**，无法直接支撑"低成本替代闭源模型"的经济性主张。
- **人机交互维度评估缺失**：真机涉及人体跟随与情感显示等 HRI 场景，但**未报告用户主观体验、安全性评估或社会可接受度**指标，任务成功率的提升是否伴随交互体验改善未知。

## 9. 启示与未来方向

- **架构原语的可迁移性**：MetaTool 被定位为"drop-in"组件，其"显式计划 + 持久 scratchpad + 执行约束"三元结构**原则上可移植到 MCP、LangChain、AutoGen 等通用智能体中间件**，为更广泛的工具调用场景提供稳定性约束范式。
- **规划—执行分层契约**：将 scratchpad 从"对话记忆"重新定义为"可执行契约"，为分层智能体设计提供了新的接口语义——高层负责计划、低层受约束执行，中间以结构化伪代码作为契约载体。
- **自适应约束松弛**：未来可引入**失败触发或不确定性触发的动态重规划**，在"刚性约束保稳定"与"柔性松弛保适应"之间取得平衡，避免错误计划被固化。
- **统计更严格的评估协议**：建议以更大规模试验、置信区间、显著性检验与多种子重复，替代当前 20/40 次的指示性规模。
- **扩展验证维度**：向多任务类别、多机器人平台、大规模工具库、真实动态非结构化环境推广，并与微调式（RoboGPT）、符号规划式（LLM+PDDL）方法做同基准实证对比。

## 10. 总体评价

本文的核心贡献在于**将"长时程不稳定"这一模型能力问题，转化为一个架构可约束问题**：通过 MetaTool 这一中间算子强制"先规划、后执行"，并以计划条件策略对动作空间施加硬约束，使开源 LLM 在 ROS 机器人管线中的重复调用、无效调用与执行方差显著下降。其形式化表述简洁、消融设计干净（C1→C4 逐组件叠加）、并辅以真机验证与多维度指标，方法学价值明确。但受限于试验规模小、统计不严谨、真机覆盖单一任务与单一模型、基线为重实现版本，以及缺少与主流规划式方案的实证对比，其结论目前**更适合作为"有前景的架构方向"而非"已验证的普适结论"**。若能在更大规模、多平台、多模型与更严格统计框架下复现，该方法有望成为开源 LLM 机器人智能体的一项通用稳定性原语。
