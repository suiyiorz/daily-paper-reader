## 摘要
自动驾驶问答需要对结构化场景信息进行推理，然而现有的视觉语言方法在很大程度上将异构的推理操作交由单一的神经推理过程完成。我们认为，这种统一策略忽视了一个根本区别：有些查询存在精确的符号解，而另一些查询则需要语义解释。我们提出了一种查询自适应的神经符号推理框架，根据查询的性质显式分配计算。其核心是一个分层时空场景图（STSG），它将持久对象身份与帧特定状态分离，并将空间关系和时间转换表示为显式的有向结构。给定一个查询，符号执行器首先尝试通过精确的图操作来求解；只有当符号执行弃权时，才调用 LLM 进行语义推理。对于这些未解决的查询，查询条件图检索和证据过滤保留关系方向、时间局部性和对象语义，为 LLM 提供紧凑且经过验证的任务相关证据。这种设计将 LLM 的角色从通用推理引擎转变为有针对性的语义推理器，同时使确定性计算能够被精确且高效地处理。我们在 oracle 感知设置下，对 nuScenes v1.0-mini 全部十个场景中的 5,916 个 NuScenes-QA 问题评估了该框架。完整系统在使用 GPT-5.4-mini 时达到 80.63% 的总体准确率，相比对应的仅 LLM 配置提高了 5.48 个百分点；使用 DeepSeek-V4-Flash 时，提升达到 6.64 个百分点。最大增益出现在计数问题上，分别提高了 10.20 和 12.61 个百分点。这些结果表明，选择性推理同时提高了准确率和推理效率。

## Abstract
Autonomous-driving question answering requires reasoning over structured scene information, yet existing vision-language approaches largely delegate heterogeneous reasoning operations to a single neural inference process. We argue that this uniform strategy overlooks a fundamental distinction: some queries admit exact symbolic solutions, while others require semantic interpretation. We introduce a query-adaptive neuro-symbolic reasoning framework that explicitly allocates computation according to the nature of the query. At its core is a hierarchical Spatiotemporal Scene Graph (STSG) that separates persistent object identities from frame-specific states and represents spatial relations and temporal transitions as explicit directed structures. Given a query, a symbolic executor first attempts to resolve it through exact graph operations; only when symbolic execution abstains is an LLM invoked for semantic reasoning. For these unresolved queries, query-conditioned graph retrieval and evidence filtering preserve relation direction, temporal locality, and object semantics, providing the LLM with compact and verified task-relevant evidence. This design shifts the role of the LLM from a universal reasoning engine to a targeted semantic reasoner, while allowing deterministic computation to be handled exactly and efficiently. We evaluate the framework on 5,916 NuScenes-QA questions across all ten scenes of nuScenes v1.0-mini under an oracle-perception setting. The complete system achieves 80.63 percent overall accuracy with GPT-5.4-mini, improving over the corresponding LLM-only configuration by 5.48 percentage points; with DeepSeek-V4-Flash, the improvement reaches 6.64 points. The largest gains occur on counting questions, with improvements of 10.20 and 12.61 points, respectively. These results show that selective reasoning improves both accuracy and inference efficiency.

## 1. 核心问题与整体含义

- **研究背景**：自动驾驶系统正从单纯感知走向对周围世界的结构化推理，需要回答诸如"某区域内是否存在某物体""有多少物体满足空间约束""哪个物体与自车存在特定关系"等关系型问题。nuScenes 与 NuScenes-QA 等数据集让此类推理任务变得可评测。
- **核心问题**：现有视觉语言方法（VLM/LLM）大多把**异构的推理操作统一交给单一神经推理过程**。作者认为这种"一刀切"策略忽视了一个根本区别——**部分查询存在精确的符号解（如存在性判定、计数、空间约束过滤），另一些查询则需要语义解释（如语义歧义、组合式理解）**。
- **关键论点**：把确定性语义问题强行交给 LLM 用自由生成复现，会引入不必要的**不确定性**与**额外计算**；反之，语义模糊问题也难以被固定符号规则覆盖。由此产生一种"计算的不对称性"。
- **整体含义**：核心挑战不是"让语言模型去推理驾驶场景"，而是**如何把不同推理操作分配给最适合的计算机制**。论文据此把基于 LLM 的驾驶场景问答形式化为**查询自适应推理问题**，引入**基于弃权（abstention）机制的选择性推理**，让符号组件不只是 LLM 的辅助工具，而是决定"是否需要神经推理"的**门控**。

## 2. 方法论

### 2.1 核心思想
- 构建显式的结构化记忆（分层时空场景图 STSG），先尝试**确定性符号执行**；仅当符号求解器**弃权**时，才调用**检索增强的 LLM**进行语义推理。
- 对未解决查询执行**查询条件图检索 + 证据过滤**，为 LLM 提供紧凑、已验证、保留关系方向与时间局部性的证据。
- 设计目标：将 LLM 从"通用推理引擎"转变为"定向语义推理器"。

### 2.2 分层时空场景图（STSG）
- 图表示为 G = (V, E)，提供跨序列的**共享身份层**，同时保留各时间戳的状态与空间构型。
- **节点集**：持久实体节点 V_ent、时间状态节点 V_state、自车参考节点 v_ego；即 V = V_ent ∪ V_state ∪ {v_ego}。
- **边集**：空间关系 E_spat、实体–状态层级关系 E_hier、时间转移 E_temp；即 E = E_spat ∪ E_hier ∪ E_temp。
- **持久实体节点**：表示场景序列中身份稳定的物理实例，提供跨帧稳定标识符。
- **时间状态节点**：v_state_{i,t} = (i, t, a_{i,t})，其中 a_{i,t} 为帧特定语义与物理属性（类别、运动状态等）。分离身份与状态可避免同一物体的重复观测被当成独立实体。
- **空间关系边**：以 BEV 中心差计算相对位移 Δp_{i|j,t} 与方位角 θ_{i|j,t} = atan2(Δy, Δx)，采用 NuScenes-QA 的六种自车对齐方向谓词 φ(θ)，得到有向关系 e_spat = (v_state_{i,t}, φ(θ), v_state_{j,t})；参考对象为自车时替换为 v_ego。**主–参考约定使边方向显式化**，降低关系反转风险。
- **层级边**：e_hier = (v_ent_i, HAS STATE, v_state_{i,t})，使物体既可按持久实例引用，也可按帧特定状态引用。
- **时间转移边**：对同一实体相邻观测连接 e_temp = (v_state_{i,t(k)}, NEXT STATE, v_state_{i,t(k+1)})，形成显式状态轨迹，支持运动演化、时序排序与跨帧比较推理。

### 2.3 结构化图投影与索引
- 完整图 G 作为符号引擎的结构化记忆；为检索派生出检索导向视图 G_R = Π_R(G)。
- Π_R 将相关图元素映射为规范化节点/关系记录，**保留实体标识、关系方向与时序引用**，并插入基于 LightRAG 的图–向量索引。
- 该结构化插入**绕过"图转文档 + LLM 再抽取"的中间环节**，每条记录保留原子级主–谓–宾语义。
- 主实现中，持久实体层、HAS STATE 与 NEXT STATE 边保留在完整图中供符号推理使用，检索投影聚焦于当前帧特定问答所需的记录。

### 2.4 神经符号双引擎问答
- **保守的符号优先路由**：a_sym = Φ_sym(Q, G, t_q) ∈ Y ∪ {⊥}。符号求解器在帧特定状态节点上执行精确集合运算：判定存在性、对计数问题统计**唯一持久身份**数量、在答案唯一时返回类别或运动状态。查询模式不受支持或存在多个可能答案时返回 ⊥ 而非强行预测。比较类问题与组合歧义问题因此被下放给神经回退。
- **查询条件检索（神经回退）**：H0_Q = R(Q ⊕ h(t_q); G_R)，即用问题加帧锚文本检索候选证据。
- **证据过滤**：H_Q = F_filter(H0_Q; t_q, C_q, R_q, Q)，含四条确定性约束：①帧约束（移除非查询帧记录）；②语义约束（移除无关类别；泛化词如 thing/object 时放宽；路障与锥桶仅在显式提及时保留）；③方向约束（仅保留与问题空间表达匹配的方向谓词；无空间约束时移除空间关系记录）；④自车引用约束（仅在问题提及 me/ego/my car 时保留自车相关记录）。
- **最终路由**：若 a_sym ≠ ⊥ 则直接采用符号答案；否则 â = Φ_llm(Q, H_Q)。过滤后的证据序列化为**问题类型专用提示词**交给 LLM。
- **答案归一化**：输出 JSON 格式 {"answer": "value"}；存在性/比较为 yes/no，计数为非负整数，物体为支持类别之一，状态为支持运动状态标签之一；对大小写、标点、空格、下划线及别名归一化（如 traffic cone → trafficcone，person → pedestrian），并按类别约定约束状态标签。

- **总体判断**：神经符号推理在结构化驾驶场景中的收益**并非来自处处组合两个模块**，而是来自**按查询性质选择性分配计算**；该设计无需任务特定微调，同时提升准确率与推理效率。

## 7. 优点

- **问题定位清晰且有原则性**：把"符号 vs 神经"的选择问题重新表述为**计算分配问题**，并提出用**弃权机制**作为门控，思路简洁且具有可推广性。
- **图表示设计扎实**：STSG 显式分离**持久身份**

与帧特定状态**，使同一物体在跨帧引用时既有稳定标识符、又能携带帧级属性；HAS STATE 与 NEXT STATE 边进一步把"实例—状态—时序"三个层次解耦，支持身份级、帧级与时序级三类查询而不互相污染。
- **检索表示的设计避免了常见的信息损耗**：结构化投影 Π_R 直接生成规范化的节点/关系记录，绕过"图转自然语言文档、再由 LLM 重新抽取"的迂回流程，使每条证据保持原子级主–谓–宾语义与关系方向，减少语义漂移与方向反转。
- **符号求解器的"保守弃权"是稳健性的关键**：符号组件只在答案唯一时输出，遇到不支持模式或多候选即返回 ⊥，把不确定性显式外化给神经回退，而非以高置信错误污染最终答案。这一设计使符号模块的引入只可能"锦上添花"，降低了组合系统的下行风险。
- **证据过滤规则具体、可复现、可审计**：帧、语义、方向、自车四条约束均为确定性操作，规则边界（如泛化词放宽、路障/锥桶仅在显式提及时保留、无空间约束时移除空间记录）写得清楚，便于复现与后续改进。
- **受控比较做得干净**：两后端之间固定图事实、嵌入模型、检索配置、过滤规则、提示策略与归一化，唯一变量是 LLM，使 Full vs LLM-only 的差异可较可信地归因于符号路由。
- **对自身结论的限定诚实**：主动声明 Symbolic-only 因规则集更广而非严格消融，主动指出比较类问题上 Full 与 LLM-only 的差异不可归因于符号执行，这类自我约束在同类工作中并不常见。
- **效率口径透明**：明确界定计时起点（图与索引加载完成后）、终点（最后一道题解析结束）、包含项（符号执行、检索、过滤、生成、解析、网络等待、重试）与排除项（图构建、索引、嵌入、序列化），并强调同后端配对比较才是效率结论的主依据。

## 8. 局限性与批判性评价

- **感知设定脱离真实部署**：全程使用 oracle 3D 框、类别、实例身份、属性与自车位姿，隔离了感知误差。这意味着论文验证的是"给定完美结构化输入时的推理分配"，而实际自动驾驶中感知噪声会同时影响符号求解的精确性（如计数、存在性判定）与检索证据的质量，收益是否保持尚未可知。
- **规模与覆盖面有限**：仅在 nuScenes v1.0-mini 的 10 个场景、404 个关键帧、5,916 道题上评测，场景多样性、长尾情形与语言变体覆盖不足，结论的泛化性有待更大规模验证。
- **时序能力"设计了但未验证"**：STSG 的核心卖点之一是 NEXT STATE 边支撑运动演化与跨帧比较，但评测问题全部为帧特定问题，时序边对推理的实际贡献没有实验支撑，属于"声称能力大于验证证据"。
- **符号求解器依赖手工规则，可扩展性存疑**：模板感知解析 + 固定执行规则意味着新增问题类型或语言表达需人工扩展；论文未给出符号覆盖率、弃权率与各路由占比，读者无法判断系统对神经回退的依赖程度，也无法评估过滤规则的敏感性。
- **路由是硬门控且阈值机制未详述**：符号弃权判定（何时"存在多个可能答案"）的具体准则与容差未充分展开，门控的稳定性与鲁棒性难以独立评估。
- **神经回退仍受限于单一 LLM 与 API 行为**：效率数字高度依赖后端服务延迟、网络与重试；不同时间、不同负载下复现可能偏离。缺少本地模型或不同提示策略的对照。
- **统计严谨性不足**：未报告多次运行的方差或显著性检验，主结论（如 +5.48 / +6.64 点）建立在单次结果上，随机性影响无法排除，尤其对比较类问题作者自己已提示这一风险。
- **证据过滤可能引入"过严"风险**：确定性过滤在减少噪声的同时也可能删除有用上下文（例如问题隐含空间约束但未显式表述时），论文未做过滤强度消融。

## 9. 启示与延伸方向

- **"计算分配"而非"模块堆叠"的视角具有迁移价值**：把符号与神经的选择形式化为按查询性质分配计算，并用弃权作为门控，可推广到机器人操作、具身问答、表格/数据库问答等一切"部分可判定、部分需语义"的任务。
- **结构化记忆可成为两类引擎的共享底座**：STSG 同时服务符号执行与检索投影，说明好的中间表示能让符号与神经"说同一种语言"，避免各自维护独立知识源带来的不一致。
- **可验证性应成为设计目标**：符号路径天然可审计，神经路径则通过紧凑、已验证的证据约束生成空间，这种"能算就算、不能算才问"的架构在安全关键场景中比端到端生成更易获得信任。
- **待补的实验方向**：在真实感知噪声下评测、扩展到 nuScenes 全量或更长时间序列、构造跨帧/时序推理基准、报告弃权率与路由占比、做过滤规则与符号规则覆盖度的消融、引入多次运行方差与显著性检验。

## 10. 总体评价

该论文的核心贡献不在于提出新的网络结构，而在于给出一个**有原则的计算分配框架**：以分层时空场景图为共享结构化记忆，以保守弃权的符号求解器为门控，仅在必要时以查询条件检索增强的 LLM 做语义推理。方法设计自洽、图表示与检索投影有实质工程考量，实验在两个 LLM 后端上呈一致方向，且作者对结论边界做了诚实限定。其主要短板在于评测规模小、oracle 感知设定、时序能力未被验证以及缺少统计严谨性与敏感性分析。作为"何时该用符号、何时该用神经"这一问题的实证回答，论文提供了清晰且可复现的证据，但距离真实自动驾驶部署仍有明显的验证缺口。
