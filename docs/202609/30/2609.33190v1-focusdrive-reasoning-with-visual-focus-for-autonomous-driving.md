## 摘要
驾驶决策既取决于关注何处，也取决于如何对所看到的内容采取行动。有效的驾驶推理必须确定哪些物体重要、它们位于何处，以及它们如何为预期动作提供信息。基于文本的理由可以描述驾驶响应，但其与特定视觉证据之间的对应关系仍是隐含的。视觉焦点通过识别场景中重要的内容及其位置，为这种联系提供了具体的起点。我们提出 FocusDrive，一个结构化的多模态推理框架，它围绕显式视觉焦点组织端到端规划。它将决策相关对象的描述与图像块引用配对，把显式视觉焦点引入生成驾驶规划和轨迹的推理中。我们首先通过驾驶员注视预测评估这种焦点表示，然后利用现有 NAVSIM 训练场景中的驾驶焦点标注，考察其在规划推理中的作用。在 W3DA 和 NAVSIM 上的实验展示了有竞争力的注视预测和端到端规划性能，其中 FocusDrive 优于基于文本的思维链。这些结果表明，视觉焦点是连接场景理解与驾驶行动的有效纽带。

## Abstract
Driving decisions depend on both where to focus and how to act on what is seen. Effective driving reasoning must establish which objects matter, where they are, and how they inform the intended action. Text-based rationales can describe a driving response while leaving its correspondence to specific visual evidence implicit. Visual focus provides a concrete starting point for this connection by identifying what matters in the scene and where it is. We propose FocusDrive, a structured multimodal reasoning framework that organizes end-to-end planning around explicit visual focus. It pairs descriptions of decision-relevant objects with image-patch references, bringing explicit visual focus into the reasoning that generates driving plans and trajectories. We first assess this focus representation through driver gaze prediction, then investigate its role in planning reasoning using driving-focus annotations within existing NAVSIM training scenes. Experiments on W3DA and NAVSIM demonstrate competitive gaze prediction and end-to-end planning performance, with FocusDrive improving over text-based chain-of-thought. These results support visual focus as an effective link between scene understanding and driving action.

## 2. 论文提出的方法论

### 核心思想
- 围绕**显式视觉焦点**组织端到端规划：将对象描述（object description）与图像块引用（patch reference）配对，形成"焦点跨度"（focus span），再依次生成动作计划（action plan）和未来轨迹（waypoints）。
- 采用 PaDT 的动态视觉引用接口，把图像网格单元映射为 VLM 隐藏空间中的原型（prototype），使引用 token 既作为输出选择、又作为输入嵌入。

### 关键技术细节

- **视觉焦点的表示**：
  - 视觉骨干对输入图像 $I$ 产生空间嵌入 $E(I) = [e_1, \dots, e_N]^\top \in \mathbb{R}^{N \times d}$，每个网格单元称为一个图像块。
  - 视觉引用投影器通过层归一化 + 低秩残差映射（瓶颈宽度 $r=64$）将 $e_j$ 变换为原型 $p_j$，形成 $P(I) = [p_1, \dots, p_N]^\top$。
  - 输出头扩展为文本词表 $W_{\text{text}}$ 与图像相关引用集 $P(I)$ 的联合打分，文本与引用在同一 softmax 分布中归一化，实现自回归序列中文本与视觉引用的混合生成。
  - 生成引用 $v_j$ 时，其原型 $p_j$ 作为该 token 位置的输入嵌入，供后续解码使用。

- **驾驶焦点标注**：
  - 在 NAVSIM 的 Navtrain 场景中构建：基于风险线索（TTC、安全场、交互风险评估）+ VLM（Qwen3.7-Plus）候选对象筛选 + 人工审核选择最终焦点。
  - 每个标注配对对象描述 $d_o$ 与人工选择的图像位置 $u=(u_x,u_y) \in [0,1]^2$。
  - 标注覆盖 13.1% 的 Navtrain 场景；其余 86.9% 仍保留计划与轨迹监督。
  - 焦点对象类别分布：车辆 84.43%、交通灯 7.18%、停止标志 5.32%、行人 2.92%、自行车 0.10%、其他 0.04%；89.2% 的焦点标注场景涉及减速。

- **从视觉引用到注视预测**：
  - 在引用 token 前的位置 $t^\star$，用最终层隐藏状态 $h_{t^\star}$ 与原型矩阵相乘得到 patch 分数 $z_{t^\star} = P(I) h_{t^\star} \in \mathbb{R}^N$。
  - 通过注视适配器 $f_\phi$（z-score 归一化 + 5 层卷积 + 双线性上采样）解码为密集注视热图 $\hat{G}$。
  - 训练损失：语言建模损失 + 热图损失（BCE + KL 散度），$\lambda_g=3$，$\lambda_{KL}=0.5$。

- **从视觉焦点到端到端规划**：
  - 序列组织：$[d_o, v_j] \rightarrow a \rightarrow w$，即视觉焦点 → 动作计划 → 航点文本。
  - **三阶段训练**：
    1. **视觉引用 token（VRT）预热**：在 Navtrain 上构建更广泛的对象引用标注（对象描述 + 相对位置 + patch 引用），训练模型联合描述与引用对象。
    2. **规划 SFT**：token 级交叉熵，监督焦点跨度、动作计划和航点文本。
    3. **GRPO 强化微调**：对同一观测采样 $G$ 个完成，解析轨迹并用 PDMS 作为奖励，计算组内相对优势 $A_i = (r_i - \bar{r})/(\sigma_r + \delta)$，优化策略损失并加 KL 正则约束偏离 SFT 参考策略。
  - 规划输出为 8 个航点（4 秒、0.5 秒间隔），格式为 $[x_k, y_k, \theta_k]$。

## 6. 论文的主要结论与发现

- **注视预测**：FocusDrive 在 Normal、Safety、Accident 三类场景中多数指标领先，KLdiv、CC、AUC 全面最优；在安全关键场景中相对 DualGaze-VLM 的相关性提升最大，表明其能有效定位驾驶员焦点。

- **焦点推理优于文本 CoT**：
  - SFT 阶段：+1.3 PDMS、+1.4 EPDMS。
  - RL 阶段：+0.9 PDMS、+1.0 EPDMS。
- **表示形式的影响**：
  - Patch 引用优于 Text-2D 坐标（无预热 +0.4，有预热 +0.6）。
  - 引用预热进一步提升 +0.3 PDMS、+0.2 EPDMS。
  - 图像条件 patch 原型优于学习式 ID 嵌入，再提升 +0.3 PDMS/EPDMS，说明引用不仅传递位置，还携带当前图像的视觉语义。
- **总体结论**：视觉焦点是连接场景理解与驾驶动作的有效纽带，显式焦点推理能提升规划的安全性与合规性。

## 7. 优点

- **方法设计亮点**：
  - 将"关注什么—在哪里—如何行动"显式结构化，弥补文本 CoT 视觉 grounding 隐含的缺陷。
  - 利用 PaDT 动态视觉引用机制，实现文本 token 与图像 patch 引用在同一自回归序列中统一生成。
  - 引用 token 既作为输出选择、又作为输入嵌入，同时传递空间索引与图像条件视觉信息。
  - 三阶段训练（VRT 预热 → SFT → GRPO）循序渐进，兼顾表示学习与行为优化。
- **数据与标注亮点**：
  - 在现有 NAVSIM 场景中构建驾驶焦点标注，结合风险筛选、VLM 候选与人工审核，聚焦真正需要显式关注的场景。
  - 标注仅覆盖 13.1% 场景，却带来显著规划提升，说明"选择性显式焦点"的有效性。
- **实验亮点**：
  - 同时评估注视预测与端到端规划，验证焦点表示的"空间建模"与"行动指导"双重价值。
  - 消融实验系统分离了焦点监督、引用预热、图像条件输入三个因素。
  - 定性可视化清晰展示焦点选择与轨迹差异。

  - EPDMS 结果依赖更新版 NAVSIM 实现，与部分已发表结果可能不可直接比较。
  - 定性分析样本量有限，未系统统计失败案例或焦点选择错误的频率。
