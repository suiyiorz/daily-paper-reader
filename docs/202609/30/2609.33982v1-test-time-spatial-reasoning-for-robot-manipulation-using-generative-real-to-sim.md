## 摘要
空间推理是通用机器人智能的基础，因为它使机器人能够完成涉及多物体交互的长时程任务。我们提出 Simify，一种无需训练、在测试时运行的框架，通过大规模并行物理仿真执行显式空间推理。仅从场景的单张 RGB-D 图像，Simify 利用 3D 生成模型和视觉-语言模型重建可直接用于仿真的资产。然后，给定由奖励函数指定的任务（例如，搭建最高的塔），Simify 在仿真中启动数千个并行推演，并执行进化搜索以优化物体摆放，通常能在数秒内收敛。我们在真实机器人硬件上进行定量实验，以证明我们的框架能够端到端地执行涉及此前未见物体的复杂物体重排任务。结果表明，我们的框架通过在推理期间有效利用大规模并行仿真，优于此前用于空间推理的基础模型工作，同时也凸显了完整且准确的几何信息对于成功实现仿真到现实迁移的重要性。

## Abstract
Spatial reasoning is fundamental to general robot intelligence, as it enables robots to complete long-horizon tasks involving multi-object interaction. We introduce Simify, a training-free, test-time framework that performs explicit spatial reasoning via massively parallel physics simulation. From a single RGB-D image of a scene, Simify reconstructs simulation-ready assets leveraging 3D generative models and vision-language models. Then given a task specified by a reward function (e.g., build the tallest tower), Simify launches thousands of parallel rollouts in simulation and performs an evolutionary search to optimize object arrangements, typically converging within seconds. We conduct quantitative experiments on real-robot hardware to demonstrate the ability of our framework to execute complex object rearrangement tasks end-to-end with previously unseen objects. Results show that our framework outperforms prior work on foundation models for spatial reasoning by effectively exploiting large-scale parallel simulation during inference, and also highlight the importance of complete and accurate geometry for successful sim-to-real transfer.

## 1. 核心问题与研究动机

- **背景**：空间推理是通用机器人智能的基础，要求机器人不仅理解物体几何与空间关系，还要判断摆放是否稳定、能否产生期望的接触交互、以及是否可在真实世界中执行（物理接地）。
- **现有路线及其瓶颈**：
  - **3D 感知基础模型 / 空间感知 VLM**：擅长高层语义关系，但几何精度不足，难以保证堆叠、平衡等高精度、强物理约束任务的成功。
  - **端到端 VLA / 模仿学习**：依赖大量遥操作数据，测试时通常只是模仿已见过的动作模式，难以对全新任务发现新策略。
  - **TAMP / 重排方法**：通常假设已知物体模型、手工设计谓词约束，或需要成功排列的训练数据集。
- **本文定位**：聚焦于**测试时空间推理（test-time spatial reasoning）**这一互补范式——不依赖任务演示、成功排列的离线数据、已知物体模型或学习到的目标状态预测器，而是让机器人在测试时**从单张 RGB-D 图像重建当前场景的物理模型，并直接在仿真中搜索解**。
- **核心问题**：机器人能否仅凭单视角观测和任务奖励函数，对未见过的日常物体完成需要空间创造力的长时程多物体重排任务？

## 2. 方法论

### 2.1 整体框架（三阶段）

Simify 是**无需训练（training-free）**的测试时框架，流程为：

1. **Real-to-Sim 重建**：从单张 RGB-D 图像构建仿真就绪的场景。
2. **仿真中的进化优化**：搜索最优的放置顺序与目标位姿。
3. **真实机器人执行**：将最优排列迁移回现实并执行。

### 2.2 关键技术细节

- **问题形式化**：
  - 输入：单视角 RGB-D 观测 $I$，任务以标量奖励函数 $R_T$ 给出。
  - 输出：有序目标位姿序列 $G = (G_1, G_2, \dots, G_N)$，序列顺序即离散放置顺序，每个 $G_i$ 为 6D 连续目标位姿。
  - 物理沉降映射 $S$：执行后物体最终位姿 $\tilde{G} = S(G)$。
  - 目标：$G^* = \arg\max_G \mathbb{E}[R_T(\tilde{G})]$，约束 $\tilde{G} = S(G)$。

- **Real-to-Sim 管线**：
  - 用 **SAM-2** 生成分割提案；**VLM（GPT-4o）**列出可操作物体并将编号分割分配给各物体。
  - 用基于 Stable Diffusion 的 **2D amodal inpainting** 模型补全被遮挡区域（因 Hunyuan3D-2 等图像到 3D 模型训练时多为无遮挡视角）。
  - 用 **Hunyuan3D-2** 生成完整网格；网格无度量尺度，用 **ICP** 对齐到观测的局部深度点云以恢复尺度。
  - 用 **Foundation Pose** 估计初始位姿 $T_{WO}$；所有网格与位姿载入 **Isaac Lab** 进行 GPU 并行仿真。
  - 也支持多视角（SAM-2 跟踪 + 深度点云聚合），但论文评估单视角设置。

- **进化优化算法**（Algorithm 1）：
  - 初始化 $L$ 个随机放置顺序与位姿的解。
  - 每个解在并行仿真中顺序放置物体、每步后让场景沉降、计算最终奖励。
  - 保留 **top 5% 精英**不变；其余按奖励的 **softmax 采样**，并对位姿和放置顺序进行**变异**。
  - 优化过程中对目标位姿施加**高斯噪声** $\epsilon$，以增强对重建与执行误差的鲁棒性。
  - **验证阶段**：对最终代每个候选进行 $K$ 次带噪 rollout，计算期望奖励 $\bar{r} = \frac{1}{K}\sum_{k=1}^K r_k$，选取 $\bar{r}$ 最高者执行。
  - 噪声尺度可调：增大偏向鲁棒解，减小允许更精确但高风险排列。

- **真实机器人执行**：
  - 用 Foundation Pose 估计物体最新位姿；基于生成网格的三角面均匀采样接触点，按表面法线采样夹爪朝向，剔除与环境碰撞的抓取。
  - 用 **cuRobo**（CUDA 加速）并行采样无碰撞抓取与放置运动规划。
  - 对堆叠等需高精度的任务，末端**力传感器**闭环控制最后一段下压轨迹，检测到接触力显著增加后释放物体，避免提前掉落。

## 3. 实验设计

### 3.1 任务场景（Benchmark）

在真实 Franka Panda（7-DoF，配柔顺夹爪 + RealSense D435 腕部 RGB-D 相机）上评估三个日常物体任务：

- **Stacking**：用相机盒、玻璃瓶、胶带卷搭尽可能高的塔（固定 x,y，优化放置顺序、z 高度、x/y 轴朝向）。奖励 = 场景最高点距桌面高度。
- **Cantilever**：以不可移动的大支撑箱为基础，用重质思慕雪瓶和烘焙纸盒搭尽可能长的悬臂且不落地。奖励 = 悬臂伸出长度，任一物体触碰桌面则奖励为 0。
- **Dominoes**：用高绿瓶和重锡罐作为"多米诺"，击倒目标物体（底重蓝茶瓶）；可利用不可移动的书作为斜坡。奖励 = 场景沉降后目标物体位移距离。

### 3.2 对比方法

- **LLM-GROP**（GPT-5）：零样本 TAMP 基线，用 VLM/LLM 推断目标位姿。为公平起见，提示中包含奖励函数、轴约束、标注物体与场景坐标系的图像、以及由本文 real2sim 管线得到的物体名称/质量/3D 包围盒。
- **TSDF-EA**：消融 3D 生成先验，用输入 RGB-D 的 TSDF 重建可见几何，其余使用相同的进化算法。
- **自身消融变体**：MeshGen-Rand（随机采样位姿与顺序）、Simify-NoVal（去掉验证阶段）。

### 3.3 评估协议

- **仿真评估**（Q1、Q2）：每任务每方法 10 次重复（每次重新拍摄初始场景图像），将各方法输出的目标位姿载入评估仿真，加放置噪声、沉降后按奖励打分；每解 2048 次评估重复；奖励归一化为任务得分（%）。
- **真实机器人评估**（Q3）：每任务 10 次试验，比较 Simify 与 TSDF-EA，统计平均任务进度与失败阶段分布；Simify 额外做 30 次试验的失败分解。
- **网格质量评估**（Q5）：在 YCB 物体（Bottle、Bowl、Box、Pitcher）上对比生成网格与 TSDF 部分网格，指标包括 Chamfer Completeness、Chamfer Accuracy、F1-Score（0.01 m 阈值）、Normal Consistency，分低遮挡与高遮挡两种条件。
- **并行度研究**（Q4）：考察仿真环境数量对任务得分的影响，默认 1024 环境。

## 6. 主要结论与发现

- **Simify 在三个任务上均优于 LLM-GROP 与 TSDF-EA**：在仿真归一化得分上全面领先。LLM-GROP 在 Stacking 上表现尚可，但在 Cantilever、Dominoes 上不可靠，说明高层语义推理不足以确定连续目标位姿，尤其对需要精确物体-物体交互的任务。
- **完整几何对 sim2real 至关重要**：TSDF-EA 在 Stacking 中 10 次真实试验全部在 Stage 1（规划阶段）失败；生成式网格补全（如锡罐底面等不可观测表面）对任务成功与迁移至关重要。
- **显式搜索不可或缺**：MeshGen-Rand 表明仅靠完整几何而无进化搜索，任务得分极低（均值 10.3%）；说明任务需要显式的空间推理。
- **验证阶段提升鲁棒性**：Simify-NoVal 明显弱于完整 Simify（均值 64.0% vs 87.5%），说明仅按最优优化分数选解会产生对执行噪声脆弱的排列；验证阶段偏好高期望奖励的鲁棒解（如 Dominoes 中选择更稳健的"瓶子置于物体间、罐子滚下斜坡"策略，而非高风险直接倾倒策略）。
- **更多并行仿真提升性能**：环境数增加在所有任务上带来更高得分，尤其在 Cantilever 和 Dominoes 上，表明测试时计算可有效转化为更优解。
- **网格质量**：生成网格在可见表面精度上略逊于 TSDF，但**完整性显著更高**（Chamfer Completeness 均值 0.004 vs 0.018/0.024），F1-Score 与 Normal Consistency 也更高，且对遮挡更鲁棒。

## 7. 优点

- **范式创新**：将空间推理从"把几何与物理隐式编码进策略"转向"测试时调用外部仿真与搜索工具"，无需任何训练数据、演示或已知物体模型，泛化到未见物体与位姿。
- **生成式 real-to-sim 的巧妙利用**：用图像到 3D 生成模型补全不可观测表面（如物体底面），直接服务于下游物理仿真精度，并以消融实验证明其必要性。
- **混合离散-连续搜索**：进化算法同时优化放置顺序（离散）与 6D 目标位姿（连续），适配多模态、非凸的排列空间；softmax 采样在利用与探索间取得平衡。
- **鲁棒性设计**：优化中注入噪声 + 最终多 rollout 验证，显式应对重建与执行误差，选择高期望奖励解而非单次最优解。
- **端到端真实闭环**：从单张 RGB-D 到真实机器人执行完整打通，并用力传感器闭环解决高精度放置问题。
- **实验结构清晰**：五个研究问题（Q1–Q5）对应五组实验，仿真与真实、方法对比与消融互相印证；网格质量用标准 YCB 真值做定量评估，较为客观。

## 8. 不足与局限

- **物理参数假设**：假设质量、摩擦等物理参数已知，且质心按均匀密度设定；作者自己指出方法对这些参数敏感（尤其 Cantilever）。自动推断物理参数被列为未来工作。
- **放置时不模拟机器人**：为加速优化，物体被直接放入目标位姿而不在仿真中模拟机械臂，仅用启发式过滤运动学不可行解（如不采样背离机器人的旋转），因此输出排列不一定可直接执行。
- **单视图图像到 3D 模型的固有局限**：继承其精度限制；框架虽支持多视角，但未评估。网格生成质量对遮挡与物体类型仍敏感（如 Box 在高遮挡下 F1 仅 0.556）。

- **奖励函数需人工给定**：从语言自动合成奖励被明确列为未来工作。
- **语义缺失**：仿真仅考虑几何与物理，不考虑物体语义；作者提出与 VLM 结合是未来方向。

- **评估场景偏窄**：三个任务均为桌面级、刚性物体、单臂操作，未涉及杂乱堆叠、可变形物体、铰接物体、多臂协作或移动操作等更复杂场景，方法在开放环境中的泛化性仍待验证。
- **奖励函数与约束依赖人工设计**：任务奖励、轴约束、可移动/不可移动物体划分等均由人工给出，限制了方法在自然语言指令下的自主性；从语言自动合成奖励与约束被作者列为未来工作。
- **计算开销与实时性**：虽然默认 1024 个并行环境下优化平均耗时 73 秒，对真实部署尚可接受，但相比直接策略推理仍显著更慢；论文未给出完整端到端时延分解（图像采集、分割、3D 生成、位姿估计、进化优化、运动规划与执行）。
- **可复现性细节不足**：未明确 GPU 型号、数量与显存占用，也未完整给出进化算法超参数（种群规模、代数、精英比例、噪声尺度、验证 rollout 次数等）及代码/数据开源情况，影响复现与公平比较。
- **基线强度与公平性**：LLM-GROP 虽在提示中加入了由本文 real2sim 管线提供的物体名称、质量与 3D 包围盒，但其本质仍是零样本 TAMP，未进行大规模重采样或底层几何优化；真实机器人对比中统一采用固定仿真成功率阈值终止，阈值选择可能影响不同方法的成功率与失败阶段分布。
- **物理仿真保真度**：仿真中的接触、摩擦与碰撞模型与真实世界仍存在差距，尤其对悬臂、多米诺等强接触任务；作者通过噪声注入与验证阶段缓解，但未系统量化 sim2real 物理差距。

## 9. 总体评价与启示

- **核心贡献**：论文提出了一种训练-free、测试时空间推理框架 Simify，将生成式 real-to-sim 重建与进化搜索结合，使机器人仅凭单张 RGB-D 图像和标量奖励函数，即可对未见过的日常物体完成长时程多物体重排。其关键洞察是：与其把空间与物理推理隐式编码进策略，不如在测试时显式调用外部仿真与搜索工具。
- **方法亮点**：用图像到 3D 生成模型补全不可观测表面（如物体底面），显著提升下游物理仿真与 sim2real 成功率；进化算法同时优化离散放置顺序与连续 6D 位姿，并通过噪声注入与多 rollout 验证选择鲁棒解；真实执行阶段结合 cuRobo 并行规划与力传感器闭环，打通从单视角感知到真实操作的完整链路。
- **实验说服力**：仿真对比、真实机器人试验、内部消融、网格质量评估与并行度研究相互印证，逻辑链条较完整。结果清楚表明：完整几何、显式搜索与鲁棒验证三者缺一不可；高层语义推理（LLM-GROP）不足以确定精确连续位姿，尤其在 Cantilever 与 Dominoes 等强接触任务上。
- **主要局限**：物理参数假设已知、放置时不模拟机械臂、单视图生成精度限制、真实实验规模有限、奖励需人工给定。这些局限也指明了未来方向：自动物理参数估计、语言到奖励合成、多视图/主动感知、语义-物理融合、可变形与铰接物体操作，以及更大规模的真实世界验证。
- **总体判断**：Simify 为机器人空间推理提供了一条有前景的互补路线，特别适合无需演示数据、任务目标可用奖励函数描述、且允许测试时计算的重排场景。尽管在实时性、泛化性与真实场景覆盖上仍有提升空间，但其“生成式 real-to-sim + 测试时搜索”的范式对后续研究具有较强启发性。
