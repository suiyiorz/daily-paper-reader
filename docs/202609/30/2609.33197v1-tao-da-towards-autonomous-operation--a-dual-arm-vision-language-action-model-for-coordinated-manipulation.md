## 摘要
视觉-语言-动作（VLA）模型提供了一个统一框架，可将高层语义信息落地为底层机器人动作，从而使机器人能够在多样任务中实现可扩展的操作。然而，现有VLA模型缺乏显式机制来解耦双臂的状态与意图，导致意外的跨臂干扰，从而降低任务执行成功率。为解决该问题，我们提出了一种对称双臂专家（DAE）架构，其构建于共享的视觉-语言模型（VLM）主干之上，并采用解耦的、针对各臂的专家塔。专家选择通过一个两阶段双臂意图路由方案进行：第一阶段依据显式语言指令路由专家，第二阶段则依据隐式视觉语义路由专家。此外，我们引入了一个轻量级任务进度预测模块，该模块利用分块前时序特征与本体感觉和视觉观测的语义表示之间的交叉注意力，准确估计逐帧任务完成进度。该模块促进任务进度同步，以支持协作式多机器人任务的协调调度。实验结果表明，我们的模型在双臂意图路由和解耦跨臂干扰方面有效，并进一步提供了从单臂任务到双臂任务（以及反向）涌现技能泛化的初步证据，以及跨臂运动域技能迁移的初步证据。

## Abstract
Vision-Language-Action (VLA) models provide a unified framework for grounding high-level semantic information into low-level robot actions, enabling scalable robotic manipulation across diverse tasks. However, existing VLA models lack explicit mechanisms to disentangle the states and intents of the two arms, leading to unintended cross-arm interference that degrades task execution success. To address this issue, we propose a symmetric Dual-Arm Expert (DAE) architecture built upon a shared Vision-Language Model (VLM) backbone with decoupled, arm-specific expert towers. Expert selection is carried out through a two-stage dual-arm intent routing scheme, in which experts are routed either by explicit language instructions in the first stage or by implicit visual semantics in the second stage. Moreover, we introduce a lightweight task progress prediction module that leverages cross-attention between the pre-chunk temporal features and semantic representations of proprioceptive and visual observations to accurately estimate frame-wise task completion progress. This module facilitates task progress synchronization to support coordinated scheduling for collaborative multi-robot tasks. Experimental results demonstrate the effectiveness of our model in dual-arm intent routing and the disentanglement of cross-arm interference, and further provide preliminary evidence of emergent skill generalization from single- to dual-arm tasks (as well as the reverse), together with cross-arm motion-domain skill transfer.

## 一、核心问题与研究动机

- **背景**：视觉–语言–动作（VLA）模型将语言、视觉观测与机器人状态统一映射为操作动作，为语言条件下的机器人控制提供了可扩展接口；近期工作多采用自回归、扩散或流匹配（flow matching）作为动作生成器。
- **核心问题**：主流双臂 VLA 设计把两条手臂放进**统一动作生成器**中，虽然简化了动作接口，却把执行臂与另一条臂无关的状态、视觉变化**耦合**在一起。这种耦合在以下情形会显著伤害性能：
  - 任务只需要单臂；
  - 两臂执行**顺序子任务**；
  - 示范数据中两臂承担**非对称角色**。
- **需求**：双臂策略应同时保留**共享任务语义**与**可选择的臂级动作生成**，即显式解耦双臂状态与意图，抑制"非活动臂干扰"（inactive-arm interference）。
- **整体含义**：作者把非活动臂干扰**形式化为一个动作生成问题**，提出 TAO-DA 框架，围绕两条原则构建：共享多模态表示用于任务级推理，臂专属动作塔用于底层控制。

## 二、方法论

### 2.1 总体框架（TAO-DA）

- **输入**：多视角视觉观测（1 张自视角 + 2 张可选腕部末端视角）、一条语言指令、本体感觉状态。
- **编码**：每张图由预训练 **SigLIP** 视觉编码器编码；视觉 token 与语言 token 拼接后送入**冻结的 Eagle-2.5-VL** 主干，得到融合表示 $E_{VL}\in\mathbb{R}^{N\times D}$。
- **流程**：DAIR 依据语言与视觉上下文确定**活动臂集合** → 非活动臂的末端视角 token 在 VLM 输入端被掩码 → DAE 通过被选中的臂专属通路生成动作（流匹配训练）。
- **训练技巧**：每个任务的指令从一组**语义等价表达池**中随机采样。

### 2.2 DAIR：语言与视觉引导的双臂意图路由

- **意图表示**：活动臂集合编码为二值向量 $r=[r_L,r_R]\in\{0,1\}^2$，三类有效类别为
  - $\phi(0)=[1,0]$（仅左臂）、$\phi(1)=[0,1]$（仅右臂）、$\phi(2)=[1,1]$（双臂）。
- **分类训练**：作为三分类问题，交叉熵损失 $\mathcal{L}_{route}=-\log p_c$；三分类接口可避免产生非法的"无臂"向量 $[0,0]$。
- **第一阶段（规则语言解析）**：规则解析器识别 "left arm / right arm / both arms / left hand / right hand" 等显式表达并映射为 $\hat r_{rule}$；含双臂表达时双臂优先；**不使用空间表达**推断臂意图；若无可识别表达，返回内部"未匹配"码 $[0,0]$ 以触发第二阶段。
- **第二阶段（模型多模态意图预测）**：对 $E_{VL}$ 做 LayerNorm，用可学习 query 做多头注意力池化 $f=\mathrm{MHA}(q,E_{norm},E_{norm})$，经 MLP 输出三个 logit，取 argmax 后映射为 $\hat r_{model}=\phi(\hat c)$。
- **基于进度的保持机制**：推理时若任务进度足够，可沿用先前意图：
  - 若 $\hat r_{rule}\neq[0,0]$ → 采用 $\hat r_{rule}$；
  - 否则若 $\hat r_{t-1}$ 不可用或 $\hat p_t\le\tau_{hold}$ → 采用 $\hat r_{model}$；
  - 其余情况 → 沿用 $\hat r_{t-1}$。
  - 该机制用于稳定路由决策，与部署级任务调度器**不同**。

### 2.3 DAE：三种双臂专家变体

- **Single-Tower**：两臂状态与动作 token 拼接进同一个 DiT（统一动作空间）。
- **Dual-Mask（弱解耦）**：共享 DiT，但通过**臂模式注意力掩码** $M^{(m)}\in\{0,1\}^{N_{tok}\times N_{tok}}$ 限制 token 交互：
  $$\mathrm{Attn}(Q,K,V|M^{(m)})=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt d}+\log M^{(m)}\right)V$$
  - 输入含四组臂专属 token：$[X^L_{state},X^R_{state},X^L_{action},X^R_{action}]$；
  - 左臂模式仅左臂状态/动作组互相关注，右臂对称，双臂模式允许全部交互；多模态任务表示在各模式间共享。
  - 掩码限制了臂间 token 直接交换，但两臂仍共享 DiT 参数与条件通路。
- **Dual-Tower（强解耦，默认配置）**：两条同构但**参数独立**的分支 $T_L,T_R$，各自拥有状态编码器、动作 tokenizer、DiT 与动作解码器；两序列独立处理、共享路由后的多模态上下文。
  - 臂专属状态、动作 token 与参数完全分离；单臂执行时只有被选中的塔参与，双臂时两塔都接收共享任务上下文。
  - 代价：臂级组件参数量约**翻倍**（冻结 VLM 与 DAIR 仍共享）。
- **路由条件下的动作生成与监督**：训练时用标注的 $r$ 选择臂轨迹切片与动作目标；双臂样本在同一时间步同步监督两塔，单臂样本不监督非活动塔。总损失为
  $$\mathcal{L}_{act}=r_L\mathcal{L}^L_{FM}+r_R\mathcal{L}^R_{FM}$$
  其中 $\mathcal{L}^k_{FM}$ 为第 $k$ 臂的流匹配目标；Single-Tower 与 Dual-Mask 使用相同目标但共享动作生成结构。
- **臂条件下的视角掩码**：设 $V=[V_{ego},V_L,V_R]$ 与语言序列 $E_{lang}$，则
  $$e_V(r)=\mathrm{Mask}(V,r),\quad e_{EVL}(r)=\mathrm{VLM}(e_V(r),E_{lang})$$
  当 $r=[1,0]$ 时掩掉右腕视角，反之对称；$r=[1,1]$ 时两视角均保留；**自视角在所有模式下始终可用**。

### 2.4 任务进度预测模块

- 用 **GRU** 编码 DiT 时序特征 $H=[h_1,\dots,h_T]$ 得到 $S=\mathrm{GRU}(H)$；
- 通过交叉注意力与 VLM 表示融合：$Z=\mathrm{MHA}(S,E_{VL},E_{VL})$；
- 回归头预测 $\hat p_t$，**监督目标为归一化的轨迹时间**；
- 推理时该估计同时支持 DAIR 的保持机制与部署级调度器（任务进度同步、多机器人协同调度）。
