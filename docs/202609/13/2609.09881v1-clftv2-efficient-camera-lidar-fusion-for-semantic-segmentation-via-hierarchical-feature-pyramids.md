## 摘要
自动驾驶的语义分割需要在严重类别不平衡的情况下可靠地检测弱势道路使用者（VRUs）。我们提出 CLFTv2，一种层次化相机-LiDAR融合框架，它用基于 Swin 的多尺度编码器和轻量级 FPN 风格残差解码器取代全局 ViT 注意力。CLFTv2 在 2D 透视域中运行，通过移位窗口注意力和逐尺度残差融合来集成多尺度几何线索，避免了查询匹配解码器的计算开销。在三个驾驶数据集上，CLFTv2 一致地提升了 VRU 召回率。在 ZOD 上，CLFTv2-Large 达到 53.5% mIoU，相较之前的 CLFT 模型将行人 IoU 从 35.5% 提升至 44.9%。在 Waymo 上，CLFTv2 达到 61.7% mIoU。此外，一项模态隔离研究表明，ViT 的全局感受野仅在密集 LiDAR 回波下才能带来更强的融合增益。与基于 Swin 的 Mask2Former 改编版本相比，CLFTv2 所需的 GFLOPs 少 1.4 倍，吞吐量高 2.2 倍，同时达到相当的总体准确率。这些结果表明，对于智能交通系统中的实时车载感知，层次化局部注意力融合为全局注意力和基于查询的解码器提供了一种高效、可扩展的替代方案。源代码已公开。

## Abstract
Semantic segmentation for autonomous driving requires reliable detection of vulnerable road users (VRUs) despite heavy class imbalance. We introduce CLFTv2, a hierarchical camera-LiDAR fusion framework replacing global ViT attention with a Swin-based multi-scale encoder and a lightweight FPN-style residual decoder. Operating in the 2D perspective domain, CLFTv2 integrates multi-scale geometric cues through shifted-window attention and per-scale residual fusion, avoiding the computational overhead of query-matching decoders. Across three driving datasets, CLFTv2 consistently improves VRU recall. On ZOD, CLFTv2-Large achieves 53.5\% mIoU, improving pedestrian IoU from 35.5\% to 44.9\% over the prior CLFT model. On Waymo, CLFTv2 reaches 61.7\% mIoU. Additionally, a modality-isolation study suggests ViT's global receptive field yields stronger fusion gains only under dense LiDAR returns. Compared to a Swin-based Mask2Former adaptation, CLFTv2 requires 1.4$\times$ fewer GFLOPs and delivers 2.2$\times$ higher throughput, while achieving comparable overall accuracy. These results demonstrate that hierarchical local-attention fusion offers an efficient, scalable alternative to global-attention and query-based decoders for real-time on-vehicle perception in intelligent transportation systems. Source code is publicly available.

## 2. 方法论

### 2.1 核心思想
在 2D 透视投影域中，用 **Swin Transformer 层次化编码器**替换全局 ViT，配合**轻量级 FPN 风格粗到细残差解码器**，原生提取多尺度几何线索，避免查询匹配解码器的高开销。

### 2.2 关键技术细节

- **2D 透视域表示**：LiDAR 点投影到图像平面，编码为三通道坐标图 $(X, Y, Z)$（Z 表示深度），替代 RGB 通道，使其与标准视觉骨干结构兼容，可直接使用 ImageNet 预训练权重。
- **层次化骨干（SwinV2）**：
  - 输入分块为 $4\times4$ patch，经四个阶段处理；局部自注意力在 $M\times M$ 非重叠窗口内计算。
  - 交替块采用移位窗口（SW-MSA），偏移 $(\lfloor M/2\rfloor, \lfloor M/2\rfloor)$ 实现跨窗口信息流。
  - W-MSA 复杂度为 $\Omega = 4hwC^2 + 2M^2hwC$，即 $O(hw)$，而全局注意力为 $O((hw)^2)$。
  - Patch Merging 逐阶段减半分辨率、加倍通道，输出四层金字塔 $\{F_i\}_{i=1}^4$，步长 $S_i \in \{4, 8, 16, 32\}$。
  - Tiny 嵌入维度 $\{96,192,384,768\}$，Base $\{128,256,512,1024\}$，Large $\{192,384,768,1536\}$。
- **孪生编码（Siamese）**：两个共享参数 $\theta_{enc}$ 的 Swin 骨干并行处理 RGB 与 LiDAR 张量，权重绑定使参数量减半并复用预训练权重。
- **通道投影**：每层特征经 $1\times1$ 卷积投影到统一维度 $D=256$，保留原生空间分辨率。
- **粗到细残差融合解码器**：
  - 各模态先经独立的 ResConv 单元（两个 $3\times3$ 卷积 + ReLU + 恒等跳连）细化。
  - 最粗层（$i=4$）：$A_4 = R_{out}(R_{RGB}(F'_{RGB,4}) + R_{LiDAR}(F'_{LiDAR,4}))$。
  - 后续更细层（$i\in\{3,2,1\}$）：将上一层累积表示双线性上采样 2×，与细化后的模态特征相加，再经共享输出 ResConv：
    $A_i = R_{out}(R_{RGB}(F'_{RGB,i}) + R_{LiDAR}(F'_{LiDAR,i}) + \text{Up}_{2\times}(A_{i+1}))$。
  - 递归项 $\text{Up}_{2\times}(A_{i+1})$ 是精度主导因素；去掉它会使 ZOD mIoU 从 35.9% 骤降至 23.1%（绝对下降 12.8%）。
- **分割头**：$A_1$（$H/4$ 分辨率）经 3×3 卷积 + BN + ReLU → 1×1 卷积 → 4× 上采样，输出 $H\times W\times C_{cls}$ logits。
- **损失函数**：加权交叉熵，权重按数据集类别像素频率以近似逆平方根调度生成（如 ZOD 背景 0.1、车辆 10.0、行人 20.0、标志 17.0）。

## 6. 主要结论与发现

- **ZOD**：CLFTv2-Large 达 **53.5% mIoU**，较 CLFT-Large（46.8%）提升 6.7%；行人 IoU 从 **35.5% → 44.9%**，标志 IoU 从 33.2% → 43.2%。与 Mask2Former-Large（52.5%）精度相当，但训练时间约减半。
- **Waymo**：CLFTv2-Large 达 **61.7% mIoU**，但 ViT 全局注意力的 CLFT-Large（68.3%）与 CLFT-Base（66.3%）反超 6.6% / 4.6%。单模态下两者 mIoU 几乎相同（差 0.2–0.4%），说明差距源于融合交互机制——ViT 的全局感受野在**稠密 LiDAR 点云**下能建立更优的长程跨模态关联。
- **ISEAuto**：查询式模型领先（MaskFormer-Large 75.6%，CLFTv2-Large 73.3%），但 CLFTv2 召回率显著更高（94.3% vs 85.2%）。
- **模态隔离**：融合在所有 32 种设置中均优于 RGB-only。Waymo 上 CLFT 平均融合增益 +10.52%，CLFTv2 仅 +4.85%（约小 2.2×），进一步印证全局注意力在密集几何下融合增益更强。ISEAuto 上融合增益仅 +0.34%～+1.21%，说明密集标注且类别简单时 LiDAR 边际收益有限。
- **效率**：CLFTv2-Tiny 22.0 ms / 187 MB，比 Mask2Former-Tiny（48.4 ms / 314 MB）快 **2.2×**、显存低约 40%；CLFTv2-Large（204.4 GFLOPs / 81.8 ms）也比 Mask2Former-Large（265.3 GFLOPs / 118.2 ms）更轻更快。
- **安全剖面**：CLFTv2-Large 在 Waymo 上行人召回最高（Day Fair 96.1%，Night Rain 95.7%），但精度低于 CLFT-Large（64.5% vs 72.1%），呈现明确的**高召回-低精度权衡**。
- **天气鲁棒性**：Day Fair → Night Rain 的 mIoU 下降在 Waymo 约 2.3–2.5%，ZOD 约 8.8–9.4%，ISEAuto 约 15.9–17.1%。
- **迁移学习**：从相关数据集检查点初始化可系统性提升早期 epoch mIoU，类别重叠度决定迁移质量（ISEAuto→ZOD 因缺少 sign 类而较弱）。
- **融合设计**：递归残差路径是精度主导项（23.1% → 35.9%），额外门控参数在当前监督条件下无必要。

## 7. 优点

- **架构效率突出**：Swin 线性复杂度 + 轻量 FPN 解码器，避免了查询匹配解码器的匈牙利求解与深层监督开销，实现 1.4× 更少 GFLOPs 与 2.2× 更高吞吐。
- **2D 透视域的工程友好性**：LiDAR 投影为三通道坐标图，直接复用 ImageNet 预训练骨干，无需 3D 专用处理，降低实现与部署门槛。
- **多尺度原生提取**：Swin 四阶段金字塔天然适配小目标（VRU）检测，避免了 ViT 单尺度输出的局限。
- **消融设计有针对性**：窗口大小、模态隔离、融合策略三维度消融，清晰揭示递归残差路径的主导作用及门控机制的冗余性。
- **客观的方法学反思**：论文主动承认窗口消融与分辨率混杂、ZOD 伪标签局限、Waymo 上局部注意力的劣势，并据此提出混合全局-局部架构的未来方向，学术诚实度较高。
- **可复现性**：源代码、训练流程、数据预处理脚本及训练结果全部公开。

---

## 8. 不足与局限

- **Waymo 上的性能劣势**：Swin 局部窗口注意力在稠密 LiDAR 点云下无法完全替代 ViT 全局注意力的跨模态长程对齐能力，即使扩大窗口（24）仍存在 6.6% 的 mIoU 差距。
- **监督质量混杂**：ZOD 使用 SAM 生成的伪标签，且生成流程对遮挡/截断目标拒绝率较高，导致 IoU 分数受几何可见性约束，难以分离模型架构能力与对噪声标签的鲁棒性。
- **硬件验证局限**：效率指标仅基于高端 A100 GPU，未在低功耗边缘设备或微控制器上验证，而论文目标场景恰是实时车载部署。
- **消融混淆**：窗口大小消融与输入分辨率同时变化，无法干净分离两者贡献；融合策略门控变体仅报告 ±0.7% 的差异，且为单次运行，统计显著性不足。
- **对比公平性存疑**：不同架构训练 epoch 数不同，Mask 系列仅训 50/100 epoch 而 CLFTv2 训 100/200 epoch，虽为适配各自收敛，但可能系统性偏向 CLFTv2。
- **范式局限**：完全在 2D 透视域操作，丢弃了平面外 3D 几何信息，与 BEV 类方法不可直接数值比较，下游 3D 任务适用性受限。
- **精度-召回权衡**：CLFTv2 高召回伴随低精度（ZOD Day Fair 精度仅 51.4%），误检可能带来实际部署中的额外决策负担。
- **未报告统计显著性**：多数结果未提供标准差或置信区间，部分小差异（如 ZOD 上 CLFTv2-Base 与 MaskFormer-Base 差 0.11%）难以判断是否真实。
