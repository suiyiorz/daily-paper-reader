## 摘要
视觉-语言-动作（VLA）模型显著推进了语言引导的机器人操作，但可靠执行仍取决于识别指令所指的物理对象。在包含重复物体、歧义锚点或依赖参考系的空间术语的杂乱场景中，机器人可能对语义兼容但并非预期的实例执行几何上有效的动作；我们将这种失败称为身份切换。指称对象由三个耦合的潜变量共同决定：目标、锚点和参考系，因此在执行前就确定其中任何一个，都会将残余歧义转化为静默且不可逆的错误。我们提出 RefGuard，一个身份感知的定位框架，通过维持所有三个变量的联合后验来延迟承诺。RefGuard 从 RGB-D 观测中构建以对象为中心、以参考系为条件的场景图，将参考系无关的几何与方向关系分离，并通过决策策略处理后验，该策略可执行、澄清、重新观测或中止。在真实 UF850 机械臂上，RefGuard 在任何歧义压力试验中均未记录到身份切换，并在其中 90.0% 的试验中正确执行；而微调后的 VLA 和基于 LLM（大语言模型）的基线在相同试验中的身份切换率为 33-46%，同时在无歧义场景中保持 93.3% 的成功率，并在 86.7% 的试验中从定位后的场景变化中恢复。在包含 3200 个回合的程序化测试套件上，相较于在目标之前就锁定锚点和参考系的消融版本，它将可解指令的正确执行率从 56.6% 提升到 80.5%，同时延迟更少（19.5% 对 43.4%）。

## Abstract
Vision-language-action (VLA) models have substantially advanced language-guided robot manipulation, yet reliable execution still hinges on identifying which physical object an instruction refers to. In cluttered scenes containing repeated objects, ambiguous anchors, or frame-dependent spatial terms, a robot can execute a geometrically valid action on a semantically compatible but unintended instance; we call this failure an identity switch. The referent is jointly determined by three coupled latent variables: the target, the anchor, and the reference frame, so committing to any one of them before execution turns residual ambiguity into a silent and irreversible error. We propose RefGuard, an identity-aware grounding framework that delays commitment by maintaining a joint posterior over all three variables. RefGuard builds a frame-conditioned object-centric scene graph from RGB-D observations, separating frame-independent geometry from directional relations, and routes the posterior through a decision policy that executes, clarifies, reobserves, or aborts. On a real UF850 arm, RefGuard records no identity switch on any ambiguity-stress trial and executes correctly on 90.0% of them, whereas fine-tuned VLA and LLM (Large Language Model)-based baselines switch identity in 33-46% of the same trials, while retaining 93.3% success on unambiguous scenes and recovering from post-grounding scene changes in 86.7% of trials. On a 3200-episode procedural suite, it raises correct execution on solvable instructions from 56.6% to 80.5% over the ablation that commits to the anchor and frame before the target, while deferring less often (19.5% vs. 43.4%).

# RefGuard 论文总结

## 1. 核心问题与整体含义

- **研究动机**：语言引导的机器人操作（VLA 模型）虽已大幅进步，但可靠执行的前提是正确识别指令所指的物理对象实例。
- **核心失败模式——"身份切换"（Identity Switch）**：在杂乱场景中，当存在重复物体、歧义锚点或依赖参考系的空间术语（如"左边"）时，机器人可能对一个语义上兼容、几何上可抓取，但并非用户真实意图的物体执行有效动作。这种失败不是任何单一模块（检测、语言理解、抓取规划）的错误，而是**接地（grounding）歧义在执行阶段被过早固定**所导致的不可逆物理后果。
- **问题本质**：指称对象由三个**相互耦合的隐变量**共同决定——**目标（target）、锚点（anchor）、参考系（frame）**。任何一者的改变都会影响其余变量的最优解，因此必须联合建模三者的不确定性，而非独立估计后逐级硬性选择。
- **现有方法的不足**：
  - 端到端 VLA（如 GR00T、π0.5）与 LLM 驱动管线倾向**早承诺**（early commitment）：先选出一个最可能的目标/锚点/参考系，再交给下游规划，丢失了"该指代本身不确定"的信息。
  - 跟踪类系统只维持已分配的身份，却不判断语言原本指向哪个身份。
  - 求助类系统只在**方案之间**做选择，而非在单次动作内解析目标–锚点–参考系的耦合不确定性。
- **整体含义**：RefGuard 将"身份保持"重新表述为**目标–锚点–参考系上的联合后验推断**，在接地与动作接口处实行"延迟承诺"，让机器人具备接地可靠性意识，从而区分"有理有据的正确执行"与"自信但错误的执行"。

## 2. 方法论

### 核心思想
- 不再对 top-1 指代做硬性承诺，而是维持目标、锚点、参考系三者的**联合后验**，仅在证据充分支持安全动作时才执行；否则澄清、重观测或中止。

### 关键技术细节

- **语言解析**：使用 GPT-4o 作为解析器，将指令分解为有序的符号化原始查询序列 $\Pi = (Q_1, \dots, Q_L)$。每个查询表示为
  $Q_\ell = (\alpha_\ell, q_{t,\ell}, \{(q^{(k)}_{a,\ell}, r^{(k)}_\ell)\}, R_{0\ell}, c_{F,\ell}, C_{act,\ell})$
  其中 $\alpha$ 为动作（PICK/PLACE），$q_t$ 为目标短语，$(q_a, r)$ 为锚点短语及其关系，$R_0$ 为无锚点但依赖参考系的约束，$c_F$ 为参考系线索，$C_{act}$ 为动作可行性约束。解析器只输出符号结构，不做实例级绑定。

- **以对象为中心的**双层**场景图**：$G = (V, E_{pos}, \{E^f_{dir}\}_{f \in F})$
  - 节点 $o_i = (m_i, u_i, x_i, b_i, c_i, h_i, \sigma_i, \nu_i)$，涵盖几何、语义与不确定性。
  - **帧无关层** $E_{pos}$：度量距离、高度差、包围盒重叠、接触、包含关系等，支持 near/on/inside 等拓扑关系。
  - **帧条件层** $E^f_{dir}$：各候选参考系下的方向偏移，支持 left-of/right-of/in-front-of，避免提前锁定单一参考系。
  - 节点身份为当前场景局部 ID，场景图在每次观测后重建，支持物体移动/替换后的恢复。

- **三类证据打分**：
  - 目标软分数 $E_{obj}(o_i, q)$：类别匹配、属性匹配、检测置信度、可见性；缺失属性直接忽略而非惩罚。
  - 关系软分数 $E_{r^{(k)}}(i, j_k; f)$：拓扑用 $E_{pos}$，方向用 $E^f_{dir}$。
  - 动作可行性 $E_{act}(h)$：抓取可行性、碰撞裕度、可达性（PICK），支撑高度、间隙、容纳、关系一致性（PLACE）；硬性违规在归一化前剪枝。

- **联合假设表**：每行 $h = (i, j_1, \dots, j_m, f, s_h, w_h)$ 代表一个完整解释，行分数为
  $$s_h = E_{obj}(o_i, q_t) + \sum_{k=1}^m E_{obj}(o_{j_k}, q^{(k)}_a) + \log \pi_F(f) + \sum_{k=1}^m E_{r^{(k)}}(i, j_k; f) + E_{act}(h)$$
  行权重 $w_h = \exp(s_h) / \sum_{h' \in H_{valid}} \exp(s_{h'})$。
  - 无效行（目标与锚点必须不同却重合、必需锚点无候选、必需帧不可用、不可抓取、无法容纳、几何不可能等）在归一化前被剔除。

- **目标信念与不确定性诊断**：
  - 目标边际 $B_T(i) = \sum_{h: t(h)=i} w_h$，取 $\hat{t} = \arg\max_i B_T(i)$，$\Delta_T$ 为前两名差值。
  - 构建 top 假设集 $H_{top}$，比较其中变量差异，诊断出 TARGET-AMBIGUOUS、ANCHOR-AMBIGUOUS、FRAME-AMBIGUOUS、PERCEPTION-WEAK、SCENE-STALE。

- **后验到决策策略**：
  - 目标熵 $H_T$、归一化熵 $\bar{H}_T$，集中度分数 $\kappa = \frac{1}{2}p_1 + \frac{1}{2}(1 - \bar{H}_T)$。
  - 决策规则：
    - ABORT：$H_{valid} = \emptyset$
    - REOBSERVE：$p_1 < 0.50 \lor \kappa < 0.40$
    - CLARIFY：$p_1 - p_2 < 0.15 \lor H_T > 1.50 \lor NAE$（锚点/参考系不动作等价）
    - EXECUTE：其余情况
  - 阈值在 30 个开发回合上选定后冻结；PERCEPTION-WEAK/SCENE-STALE 诊断无条件路由至 REOBSERVE。

- **后验感知规划与验证**：
  - 执行时目标已由 $B_T$ 确定，但规划器保留高权重锚点与参考系假设，保持耦合关系。
  - 预执行契约检查：目标与相关锚点可见、位姿匹配、空间约束仍成立、动作仍可行；失败则重路由至 REOBSERVE/CLARIFY/ABORT。
  - 每个原始动作后重观测并重建场景图；已抓取物体作为"在夹持器记忆节点"保留，已放置物体按期望位姿匹配，短暂遮挡物体以降低置信度的记忆节点保留，一旦重检测即覆盖。

## 3. 实验设计

### 平台与数据集/场景
- **真实机器人平台**：UF850 桌面厨房场景，配备两个已标定的 Intel RealSense D435i RGB-D 相机（外部第三人称 + 腕部）。
- **物体集**：15 个农产品实例（10 个类别，其中香蕉、胡萝卜、甜椒、柠檬、茄子为重复对），加上碗、盘、杯、容器等餐具。
- **六部分 UF850 压力套件**（每设置 30 次试验）：
  - **S1 干净场景**：无歧义，报告任务成功率 TS。
  - **S2 重复目标**：同类多目标 + 唯一锚点 + 空间关系消歧。
  - **S3 重复目标+重复锚点**：锚点无法独立识别，必须与目标联合解析（直接测试联合公式）。
  - **S4 参考系条件**：显式参考系线索（机器人视角/用户视角/相机视角），不同标定参考系指向不同目标。
  - **S5 执行时扰动**：接地后目标被替换、锚点被移动、插入干扰物。
  - **S6 困难负样本**：证据不足以确定唯一安全动作，正确行为是延迟。
- **程序化 LIBERO 风格套件**：3,200 个开发不相交回合（2,400 可解 + 800 困难负样本），20 个物体类别，每场景 5–20 个物体。**注意：非官方 LIBERO benchmark**。
- **顺序组合与泛化**：L=2/4/6 共 30 个回合、120 个原始动作；2 个留出类别、18 回合、72 个原始动作；30 个自由形式复述；30 个动作后检查点。

### 指标
- 干净场景：任务成功率 $TS = C/N$。
- S2–S4：身份切换率 $ISR = I/(C+I)$（执行条件，分母为已执行试验数），并报告正确执行 $CE = C/N$、执行覆盖率 $Cov = (C+I+F)/N$、延迟率 $DR = D/N$。
- S5：扰动后恢复率（检测变化、重观测、重新接地并正确执行；以延迟结束不计为恢复）。
- S6：正确延迟率 $CDR = D/N$（越高越安全）。

### 对比方法
- **VLA 基线**：GR00T-N1.7-3B、π0.5（均在相同 UF850 示范数据集上微调）。
- **LLM 基线**：共享 RefGuard 的感知与运动规划器，但早承诺单一硬目标分配，且不重观测。
- **匹配模块化消融 Hard-A/F**：共享 RefGuard 的解析器、RGB-D、场景图、证据打分、四路决策接口、规划器、控制器与评估回合，唯一区别是**在推断目标前就承诺锚点与参考系**。
- **共享更新对照**：LLM+Update、Hard-A/F+Update（给予与 RefGuard 相同的扰动后观测与图更新）。
