## 摘要
在富接触操作中，可靠的动作评估需要超越当前观测，考虑未来的视觉与接触后果。现有的噪声空间强化学习能高效地引导冻结的视觉-语言-动作（VLA）策略，但其评价器在很大程度上忽略了这些后果。我们提出 Imagine-RL，它通过以动作为条件的视觉-力矩想象来增强噪声空间 VLA 后训练。对于每个候选动作块，一个冻结的视觉-力矩隐世界模型（VTLWM）自回归地预测紧凑的未来表征，而无需像素重建。当前图像-状态-动作查询会关注观测历史和预测未来，而前一窗口的预测残差提供逐 token 的置信度先验，以抑制不可靠的未来 token。通过将当前证据与预测后果相结合，动作评价器能更好地评估候选动作并监督 actor，同时 VLA 和 VTLWM 保持冻结。在四个真实机器人任务中，每个任务进行 50 次评估试验，Imagine-RL 仅使用 100 条 RL 轨迹，并将平均成功率相比 DSRL 提高了（23.6%），相比 VLA 基线提高了（60%）。

## Abstract
Reliable action evaluation in contact-rich manipulation requires looking beyond the current observation to future visual and contact consequences. Existing noise-space reinforcement learning efficiently steers a frozen Vision-Language-Action (VLA) policy, but its critics largely ignore these consequences. We present Imagine-RL, which augments noise-space VLA post-training with action-conditioned visual-torque imagination. For each candidate action chunk, a frozen visual-torque latent world model (VTLWM) autoregressively predicts compact future representations without pixel reconstruction. A current image-state-action query attends to observed histories and predicted futures, while previous-window prediction residuals provide token-wise confidence priors that suppress unreliable future tokens. By combining current evidence with predicted consequences, the action critic better evaluates candidate actions and supervises the actor, while the VLA and VTLWM remain frozen. Across four real-robot tasks with 50 evaluation trials per task, Imagine-RL uses only 100 RL trajectories and improves the average success rate by (23.6%) over DSRL and by (60%) over VLA baselines.

## 1. 核心问题与研究动机

- **背景**：VLA（Vision-Language-Action）模型能够把语言、图像和机器人状态映射为动作，并具备跨任务、跨本体的泛化能力，但其观测以视觉为主，对**富接触操作**（阻力、滑移、卡滞等接触现象）感知不足。
- **现有方案的缺口**：
  - ForceVLA、TA-VLA 等力/力矩感知 VLA 虽引入力矩信息，但仅用于**动作生成**，不用于**价值估计**；力矩信息对"这次按压是否有效"这类判断至关重要，却未被评论家（critic）利用。
  - 真实机器人 RL 交互成本高；传统 critic 仅根据**当前观测 + 候选动作**打分，当两个视觉上相似的动作分别导致成功或失败时，评分不可靠。
  - 在**潜在噪声空间 VLA-RL**（如 DSRL）中，动作评论家还会通过蒸馏去监督噪声评论家与噪声 actor，因此"后果感知的动作排序"尤为关键。
- **世界模型的现状**：已有工作（World-Env、WMPO、GigaBrain-0.5M*、RISE 等）用世界模型生成想象未来或虚拟交互，但多依赖**像素级视觉未来生成**，代价高；LeWorldModel 证明可用紧凑物理表征做免像素重建的预测，但**以动作为条件、面向 critic 学习的想象仍未被充分探索**。
- **核心命题**：把"当前证据"与"动作条件化的未来视觉–力矩后果"结合起来评估动作，可在**冻结 VLA、冻结世界模型**的前提下，用极少真实交互显著提升富接触操作的成功率。

## 2. 方法论

### 2.1 整体框架

- Imagine-RL 在**冻结的 flow-matching VLA（π0）的潜在噪声空间**上做轻量 RL，不直接学习机器人动作，而是学习一个轻量 **噪声 actor**：
  - `w_t ~ π_θ(w | o_t)`，再由冻结 VLA 解码出动作块 `ā_t = π_0(o_t, w_t)`（Ha=30，实际执行前 Hq=10 步后重规划）。
- 采用 **SAC 风格**的双评论家结构（图 3(b)）：
  - **动作评论家 `Q_a(o, ā; h_ā)`**：评价解码后的真实动作块，条件是当前观测 + 世界模型生成的未来视觉–力矩特征 `h_ā`。
  - **噪声评论家 `Q_w(o, w)`**：通过 `Q_w ≈ Q_a(o, π_0(o,w))` 从动作评论家**蒸馏**得到，从而在部署时保持轻量。
  - **噪声 actor π_θ**：最大化 `Q_w(o, π_θ(o))`，含熵正则。
- 训练全程 **VLA 与 VTLWM 均冻结**，只有噪声 actor 与评论家侧参数在更新。

### 2.2 视觉–力矩隐世界模型（VTLWM）

- 在 LeWorldModel 基础上扩展，**联合预测视觉与力矩表征，不做像素重建**（JEPA 式）。
- 输入构造：`x_t = [z_t, τ̂_t]`，`e_a_t = E_a(a_t)`；其中 `z_t` 为多视角图像经共享编码器融合的视觉隐变量，`τ̂_t` 为归一化关节力矩（12 关节 + 2 夹爪，D_τ=14），D_z=192。
- 预测形式：固定**一步预测器** `P_H = M_Ω(X_{0:H-1}, E_a_{0:H-1})`，历史长度 H=15，自回归滚动得到 Hf=10 步未来（30 Hz）。
- 训练损失（式 7）：
  - 视觉部分：`MSE(P^z_{1:H}, Z_{1:H})`
  - 力矩部分：`λ_τ · SmoothL1(P^τ_{1:H}, T_{1:H})`
  - 正则项：`λ_sig · L_SIGReg`（高斯隐变量正则，防止表征坍塌）
- RL 阶段 VTLWM 冻结，只作为 critic 特征生成器。

### 2.3 残差置信度引导交叉注意力评论家

这是论文的核心创新，分三步：

- **(a) 特征构建（WM feature & gate builder）**：对每个模态 m ∈ {z, τ} 生成
  - 历史 token：`X^{m,hist}_t`
  - 动作条件未来预测：`X^{m,fut}_t(a_t)`
  - 前一窗口预测：`P^{m,prev}_t`
  - **预测残差**：`R^m_{t,j} = X^{m,hist}_{t,j} − P^{m,prev}_{t,j}`（同一时间戳对齐，反映 WM 生成可靠性）

- **(b) 预测可靠性（置信度先验）**：
  - 用均值平方特征幅度 `E_m(x)=‖x‖²/D_m` 定义**相对误差**：
    `ρ^m_{t,j} = E_m(R^m_{t,j})^{1/2} / [E_m(X^{hist}) + E_m(P^{prev})] + ε`，ε=1e−6
  - **置信度**：`α^m_{t,j} = max(α_min, e^{−βρ})`，β=1 控制敏感度，α_min=0.05 为置信下限；不可用残差取 α_min、ρ=4。
  - 直觉：相对误差越小 → 置信度越高 → 未来 token 越被信任。

- **(c) 从 token 相关性到上下文（交叉注意力）**：
  - 查询：`q_t = f_q(ζ_t)`，ζ_t=(o_t, a_t)，维度 d=256。
  - 键/值：由历史与未来 token 加位置嵌入、动作嵌入后线性投影得到；Q^m_t = q_t W^m_Q，K^m_t = X̃^m_t W^m_K，V^m_t = X̃^m_t W^m_V。
  - **加性偏置** B^m_t：有效历史位为 0，有效未来第 j 步为 `log α^m_{t,j}`，无效槽位为 −∞。
  - 四头（每头 d_ℓ=64）注意力：
    `A^m_{t,ℓ} = softmax(Q K^T / √d_h + B)`，`c^m_{t,ℓ} = A V`，拼接后经输出投影与 LayerNorm 得 `c^m_t ∈ R^256`。
  - 加 `log α` 等价于把未来 token 的权重按可靠性 **α 折扣**，实现"相关性 × 可靠性"的联合筛选；无效序列上下文置零。

- **(d) 从上下文到动作价值**：
  - 可靠性统计量 `g^m_t` = 有效未来槽位上置信度的均值/最小值/最大值 + 平均相对误差（无有效位则取 0）。
  - 融合特征：`h_{a_t} = [c^z_t, c^τ_t, g^z_t, g^τ_t]`
  - 动作价值：`Q_a(o_t, a_t; h_{a_t}) = Q([ζ_t, h_{a_t}])`，Q 为 MLP critic。
  - 该特征构造过程即算法 1 中的 `Φ_ψ`。

### 2.4 训练算法流程（Algorithm 1）

- 输入：冻结 VLA π_0、冻结世界模型 M_Ω、离线数据 D_off；初始化回放池 B、动作评论家 Q_a 及目标网络、噪声评论家 Q_w、噪声 actor π_θ。
- 每次迭代从 B 采样 `(o_t, w_t, ā_t, r_t, o_{t+1})`，然后三步更新：
  1. **动作评论家更新**：采样 `w'_{t+1} ~ π_θ(o_{t+1})`，解码 `ā'_{t+1}`，计算动作对齐特征 `h`，最小化 Bellman 误差，目标为 `r_t + γ^{H_q} · Mean_i Q̄_{a,i}(o_{t+1}, ā'_{t+1}; h')`（式 3，n 个 Q 取均值降偏）。
  2. **噪声评论家蒸馏**：采样 `w̃_t ~ N(0,I)`，解码 `ã_t`，最小化 `(Q_w(o_t, w̃_t) − Q_a(o_t, ã_t; h_{ã_t}))²`（式 4）。
  3. **噪声 actor 更新**：最大化 `E[Q_w(o, π_θ(o))]`（含熵正则）。
- 回放池按 **chunk 级** 存储每条 VLA 查询一个 transition，奖励为 chunk 级、折扣为 γ^{H_q}。

## 6. 主要结论与发现

- **成功率**：Imagine-RL 在 4 个真实富接触任务上均取得最高成功率，相比纯 π0、TA-VLA 与无世界模型的 DSRL 有稳定提升；尤其在 Press-button、USB Plug-in 这类"视觉相似但接触后果差异大"的任务上优势更明显，说明动作条件化的未来视觉–力矩想象对区分"看似相同"的动作确有价值。
- **数据效率**：Press-button 上的延长实验表明，Imagine-RL 在更少在线轨迹处即达到较高成功率，且曲线上升更快、平台更高，体现出在冻结骨干与冻结世界模型约束下的样本效率优势。
- **世界模型质量**：
  - 视觉隐变量预测的平均余弦相似度约 0.913，说明 VTLWM 能在不做像素重建的前提下保持较高的语义一致性；
  - 力矩预测平均 MAE 约 0.0441，约为力矩取值范围的约 1.00%，表明关节力矩这一高动态信号被隐世界模型较好地捕捉。
- **评论家判别力**：在相同观测与相同动作块下，Imagine-RL 的 critic 对成功/失败轨迹给出更分离的 Q 值（ΔQ 更大），即"后果想象 + 置信度加权"确实提升了价值函数对成败的辨别能力，而非仅仅记住了任务先验。
- **机制解释**：残差置信度 `α` 起到了"可靠性门控"作用——当世界模型在某一时间步预测不可靠时，该未来 token 的注意力权重被 `log α` 压低，从而避免被错误想象误导；这使得 critic 在训练早期世界模型尚不准确时也能稳定学习。

---

## 7. 局限与不足

- **对世界模型质量的依赖**：整个 critic 的后果想象建立在 VTLWM 之上。虽然置信度机制可缓解不可靠预测，但若世界模型在分布外或强接触突变处系统性失准，置信度先验未必能完全识别，仍可能引入偏差。
- **置信度定义的启发式性**：`α = max(α_min, e^{−βρ})` 中的 β、α_min、残差范数的相对化方式均为手工设定，缺乏理论推导与敏感性分析；不同任务、不同模态（视觉 vs 力矩）是否需要不同的 β 未加讨论。
- **任务与平台覆盖有限**：仅 PIPER 单平台、4 个双臂富接触任务，未验证跨本体迁移；力矩信号依赖关节力矩（14 维）而非腕部 F/T 传感器，是否可推广到无力矩反馈的机器人存疑。
- **算力与训练细节透明度不足**：未报告总训练时长、VTLWM 预训练数据规模与算力、π0 参数量与来源，复现门槛较高。
- **缺少完整消融**：无法从论文中判断"交叉注意力 + 残差置信度"相对"简单拼接未来特征"的增益幅度，也无法判断力矩通道相对视觉通道的独立贡献。
- **评估统计性**：50 次试验虽具一定规模，但未报告种子方差与显著性检验，方法间微小差距的可靠性存疑。
- **奖励设计**：手工奖励（每步 −1、成功 +5、严重失败 −50）中的量级设定对策略行为影响较大，但未见奖励敏感性分析。

## 8. 启发与展望

- **方法论启发**：
  1. 把"世界模型的预测残差"转化为"注意力置信度先验"，是一种把**模型不确定性显式注入 critic 架构**的简洁做法，可迁移到其他以想象特征为条件的价值学习方法。
  2. 在**冻结大模型 + 轻量 RL 头**的范式下，世界模型与 VLA 均作为"基础设施"固定，只训练噪声空间的小 actor/critic，为真实机器人上的低成本 RL 提供了可行模板。
  3. 联合视觉与本体感受信号（力矩）做隐空间预测，避免像素重建，兼顾了语义表达力与计算开销。
- **可能的后续方向**：
  - 引入**校准化的不确定性估计**（如 ensemble 世界模型、贝叶斯最后一层）替代启发式 `e^{−βρ}`，使置信度具备概率解释；
  - 扩展到**长程、多阶段、可变形物体**任务，并检验世界模型在接触突变处的可靠性；
  - 做**跨本体与跨传感器**迁移（如无关节力矩时用力/触觉传感替代）；
  - 补充完整消融与多随机种子统计，明确各组件边际贡献；
  - 探索与世界模型**联合微调**（当前冻结）是否会带来进一步收益，以及由此引入的稳定性风险。

---

## 9. 一句话总结

Imagine-RL 的核心贡献在于：在冻结 VLA 与冻结视觉–力矩隐世界模型的前提下，用"动作条件化的未来视觉–力矩想象 + 预测残差导出的置信度门控交叉注意力"来构造后果感知的 critic，从而以极少的真实交互显著提升富接触操作的成功率；其思路清晰、工程轻量，但在消融完备性、统计严谨性与任务覆盖面上仍有提升空间。
