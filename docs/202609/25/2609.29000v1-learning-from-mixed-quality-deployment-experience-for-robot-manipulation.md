## 摘要
部署在真实环境中的机器人策略会自然积累混合质量的经验，包括成功执行、部分进展和失败。尽管这些 rollout 为进一步学习提供了有价值的信息，但直接将其纳入模仿学习可能会强化不良行为，而离线强化学习在稀疏奖励和数据覆盖有限的情况下往往面临不可靠的价值估计。我们考虑一种实际的部署后设置，其中学习仅依赖于自然积累的自主 rollout，而不需要额外的人工纠正或探索性交互。为有效利用此类经验，我们提出预测性动作块学习（Predictive Action Chunk Learning, PACL）。PACL 首先学习一个预测性块级评论家（critic），用于评估时间上扩展的动作序列，并通过未来潜在预测增强时序差分学习，从而为长时程价值估计提供更丰富的监督。随后，学习到的评论家将块级 Q 值转换为离散质量条件，引导扩散 actor 从这些混合质量经验中联合学习，而不会将所有行为视为同等监督。在推理时，actor 生成多个动作块，评论家选择价值最高的候选。在模拟和真实机器人操作任务上的实验表明，PACL 持续改进预训练策略，并优于强模仿学习和离线强化学习基线。

## Abstract
Robot policies deployed in real environments naturally accumulate mixed-quality experience, including successful executions, partial progress, and failures. Although these rollouts provide valuable information for further learning, directly incorporating them into imitation learning may reinforce undesirable behaviors, while offline reinforcement learning often suffers from unreliable value estimation under sparse rewards and limited data coverage. We consider a practical post-deployment setting where learning relies only on naturally accumulated autonomous rollouts, without additional human corrections or exploratory interaction. To effectively exploit such experience, we propose Predictive Action Chunk Learning (PACL). PACL first learns a predictive chunk-level critic that evaluates temporally extended action sequences and augments temporal difference learning with future latent prediction, providing richer supervision for long-horizon value estimation. The learned critic then converts chunk-level Q-values into discrete quality conditions, which guide a diffusion actor to learn jointly from these mixed-quality experiences without treating all behaviors as equivalent supervision. At inference, the actor generates multiple action chunks and the critic selects the highest valued candidate. Experiments across simulated and real-world robot manipulation tasks show that PACL consistently improves the pretrained policy and outperforms strong imitation learning and offline reinforcement learning baselines.

## 1. 核心问题与整体含义

- **研究背景**：机器人策略在真实环境部署后会自然积累大量自主 rollout，质量参差不齐——既有成功执行，也有部分进展和彻底失败。这些数据是进一步改进策略的潜在宝贵资源。
- **核心矛盾**：
  - **模仿学习路线**：仅使用成功 rollout 收益有限（大多重复已有能力），过滤不完美动作又会丢弃"失败诱因"片段，损失负面证据。
  - **离线强化学习路线**：可同时保留成功与失败经验并通过 TD 学习传播结果，但在视觉运动策略上，稀疏任务奖励 + 部署数据覆盖不足，导致难以把延迟结果可靠归因到引发它的动作序列。已有评测表明代表性离线 RL 方法在多源数据集上甚至不如强模仿学习基线。
  - **已有部署后改进方法**（人工干预/纠错、真实世界在线 RL）虽有效，但依赖人工监督或刻意探索交互，成本高且非"自然积累"。
- **论文定位**：提出一个更实际的部署后设定——**只依赖普通自主部署中自然积累的 rollout**（无额外人工纠正、无探索性交互），从中实现策略自主提升。核心问题即：如何把混合质量的部署经验可靠地转化为更好的机器人策略。

## 2. 方法论（PACL）

### 2.1 核心思想
- 基于 IQL 框架，将其从**单步动作**扩展到**时间上扩展的动作块（action chunk）**，使 critic 能直接评估扩散策略生成的整段动作序列。
- 引入**未来隐状态预测**作为稠密辅助监督，缓解稀疏奖励下块级价值学习信号不足的问题。
- 将学到的块级 Q 值**离散化为质量条件**，引导扩散 actor 从混合质量数据中学习，而非把所有行为同等对待。
- 推理时 actor 采样多个候选动作块，critic 选价值最高者执行。

### 2.2 问题形式化
- 采用 Diffusion Policy（DP）作为视觉运动策略 π_θ，输入最近 H_o 帧观测与本体状态，输出含 H_a 个连续动作的动作块 A_t。
- 初始策略 π_θ0 由人类演示数据集 D_h 模仿学习得到，随后自主部署收集轨迹。
- 部署轨迹按任务是否在 T_max 内完成标注二值结果 y_i∈{0,1}，划分为成功集 D_s 与失败集 D_f。
- 后训练数据集 D = D_h ∪ D_s ∪ D_f，全部离线进行。

### 2.3 预测式块级 Critic
- **块级 Q 定义**：Q 函数直接定义在完整动作块 A_t 上，折扣回报 R_t = Σ_{k=0}^{K_t-1} γ^k r_{t+k}，其中 K_t = min(H_a, T_i − t) 处理轨迹末尾截断。
- **隐状态编码**：z_t = f_ξ(o_{t−H_o+1:t}, s_t)，编码器与价值函数联合优化。
- **价值函数**：V_ψ(z_t) 拟合目标 Q 值的上期望分位（expectile），使用期望分位回归损失 L_V。
- **块级 TD 目标与 Q 损失**：
  - Y_t = R_t + (1 − d_t) γ^{K_t} V_ψ(z_{t+K_t})，d_t 表示块内是否终止。
  - L_Q = Σ_{j=1,2} E_D[(Q_{φj}(z_t, A_t) − Y_t)²]，使用 twin Q 与慢更新目标网络。
- **未来隐状态预测（关键辅助目标）**：
  - 随机采样预测时域 h ∈ {1,…,K_t}；为保持时序因果，仅向动力学预测器 F_η 提供前 h 个动作，后续动作被 mask。
  - 目标隐状态变化由 EMA 更新的目标编码器 f̄_ξ 计算：Δz̄_t^{(h)} = f̄_ξ(o_{t+h−H_o+1:t+h}, s_{t+h}) − f̄_ξ(o_{t−H_o+1:t}, s_t)。
  - 预测值：Δẑ_t^{(h)} = F_η(z_t, Ã_t^{(h)}, h)。
  - 损失 L_dyn = E_{D,h}[‖Δẑ_t^{(h)} − Δz̄_t^{(h)}‖²]，提供跨多个时域的稠密监督，促使表征对动作敏感。
- **总 critic 目标**：L_critic = L_Q + λ_V L_V + λ_dyn L_dyn。

### 2.4 Q 条件化 Actor 学习
- **条件构造**：对每个动作块计算保守块值 q_t = min_{j=1,2} Q_{φj}(z_t, A_t)；用部署经验 Q 值分布的百分位阈值 δ_l、δ_u（取 40% 与 60%）离散化为：
  - c_t = 1（q_t ≥ δ_u）、c_t = 0（q_t ≤ δ_l）、c_t = ∅（不确定，弃权区）。
- **依据**：状态价值 V 与块级 Q 在成功/失败 rollout 上呈强相关（Square 任务上 Pearson 相关分别为 0.994 与 0.955），Q 值分布能清晰区分成功与失败，故直接用 Q 而非 Q−V 构造条件。
- **Actor 后训练**：在预训练 DP 上加一个轻量**条件适配器**（唯一架构改动），将 c_t 映射为条件嵌入；c_t = ∅ 的样本用 null 条件无条件训练，人类演示统一赋 c_t = 1。以原始去噪目标在 D 上微调：
  - L_actor = E[‖ε − ε_θ(A_t^k, k, o, s, c_t)‖²]。
- **推理**：条件固定为 c_t = 1，actor 采样 N 个候选动作块，critic 评估并选最高价值者执行 H_a 步后重复。
- **与 IDQL/V-GPS 的区别**：PACL 的 critic 不仅用于推理时选动作，还通过 Q 条件化塑造 actor 的后训练分布，从而无需显式行为过滤即可利用全部混合质量数据。

  - 所有方法均从同一预训练 DP 热启动。

## 6. 主要结论与发现

- PACL 在所有 7 个任务上取得最优或并列最优结果，例如仿真 Transport 达 96.0%、Square 达 93.2%，真实 StackCup 达 100%、MoveSpoon 达 84%。
- 相比 SSDF 等需要显式提取失败轨迹中有用片段的方法，PACL 仅用轨迹级二值结果奖励即可直接从完整混合质量数据学习，自动化程度更高。
- **组件互补**：Q 条件 actor 提升后训练效果，预测式 critic 进一步通过候选排序提升执行质量。
- **Critic 设计**：标准 one-step critic 随候选数 N 增大性能急剧下降；加入下一帧隐状态预测显著改善；块级评估单独收益有限，与未来隐预测结合（即 PACL）最优。
- **条件策略**：critic 导出的块级条件优于 source-level 或 outcome-level 条件，直接 Q 条件（91.2%）优于 Q−V 条件（88.8%）。
- **失败经验关键**：仅用成功 rollout 训练会导致 critic 缺乏负样本、性能下降；加入少量失败 rollout 即显著提升（Square 77.6%→88.0%，Transport 83.2%→88.8%）。
- **人类演示仍有价值**：数据量更少的 PACL-small（350 条）优于不含演示的 PACL-rollout（500 条），说明演示是后训练的重要锚点。

## 7. 优点

- **问题设定务实**：聚焦"仅用自然积累的自主 rollout"这一无需人工干预的部署后场景，贴近真实机器人长期运行需求。
- **方法设计有针对性**：
  - 块级 Q 与扩散策略的块生成特性天然匹配，消除 transition-level 价值学习与 actor 之间的时间尺度错配。
  - 未来隐状态预测为稀疏奖励下的块级价值学习提供稠密视觉监督，是解决"高维动作空间 + 标量 TD 信号不足"的有效思路。
  - Q 条件化让 critic 同时参与 actor 后训练与推理选动作，区别于 IDQL/V-GPS 仅用于动作选择的做法。
- **工程轻量**：仅增加一个条件适配器，其余沿用预训练 DP 架构，便于实际部署。
- **实验较扎实**：仿真 + 真实双臂多任务，消融覆盖四个关键设计维度，结论有较强支撑。

- **推理开销偏大**：推理需对 N=12 个候选块各做 100 步 DDIM 去噪并由 twin critic 评估，计算量随 N 线性增长，论文未报告实际推理频率或延迟，难以判断在 20 Hz 真实控制回路下的实时裕度。
- **缺少理论刻画**：为何"Q 离散化条件 + 扩散 actor"能比显式行为过滤更有效，仅由经验结果支撑，没有关于分布偏移、条件化偏差或收敛性的分析。

## 9. 对领域的启示与可拓展方向

- **把"部署即数据"落到实处**：论文证明了在无需人工纠正、无需主动探索的前提下，仅凭自然积累的成败 rollout 即可实现可观的策略提升，为机器人长期自治部署后的"自我进化"提供了一条低人工成本的可行路径。
- **块级价值学习与扩散策略的适配**：将 critic 直接定义在动作块上、并用未来隐状态预测补足稠密监督，这一组合对当前以动作块生成为主的扩散/VLA 策略具有普遍参考价值——它缓解了"高维动作空间 vs 标量稀疏 TD 信号"的经典错配。
- **critic 的双重角色**：把 critic 从"推理期动作筛选器"扩展为"后训练期的分布塑造者"，是对 IDQL/V-GPS 范式的自然推广，提示价值函数可以在离线策略改进中承担更主动的角色。
- **可拓展方向**：
  - 将二值结果奖励推广到**进度/部分完成信号**（如阶段检测、奖励模型），以覆盖无明确终止判定的任务。
  - 研究**自适应质量阈值**，替代固定的 40%/60% 百分位划分。
  - 探索与 VLA 模型、在线-离线混合更新、以及多任务/跨本体部署数据的结合。
  - 降低推理开销（如候选剪枝、蒸馏、少步采样）以适配更高控制频率。

## 10. 总体评价

PACL 是一篇问题设定务实、方法设计针对性强的部署后策略改进工作。它把"混合质量自主 rollout"这一现实中必然出现却常被忽略的数据源，转化为可用的学习信号：通过块级 Q 与未来隐状态预测解决稀疏奖励下的价值学习，再以 Q 条件化让 critic 同时塑造 actor 后训练与推理选动作，从而在不做显式行为过滤的前提下利用全部数据。仿真与真实机器人的实验一致显示其优于模仿学习与离线 RL 基线，消融也较系统地验证了各设计选择。其主要短板在于奖励假设较强、真实实验统计规模偏小、超参敏感性与推理成本未充分讨论、对比范围有限。总体而言，该工作为"机器人长期自主部署后的自我提升"提供了一个有说服力的实践范本，但距离通用、低成本的部署后改进仍有距离。
