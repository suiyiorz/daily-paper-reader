## 摘要
机器人操作策略必须在视觉变化下具备泛化能力，同时保留与动作相关的场景上下文。通用视觉编码器并非为视觉运动控制量身定制，而以对象为中心的方法通常将分割掩码用作硬过滤器，从而丢弃可能有用的上下文。我们提出 RoboMP-DINOv2（Robotics Mask-Prompted DINOv2），一种全场景视觉编码器，将掩码视为空间提示而非可见性过滤器。它从完整观测中提取密集的 DINOv2 特征，在掩码位置注入学习到的区域特定嵌入，并对提示 token 与非提示 token 进行联合上下文建模以用于动作预测。我们进一步引入掩码区域颜色随机化（MCR）以提高外观鲁棒性，得到 RoboMP-DINOv2-MCR。在七种模拟操作设置中，RoboMP-DINOv2 在空间偏移下达到 60.7% 的成功率，在场景杂乱下达到 59.7%，相比之下，基于 DINOv2 的 Diffusion Policy 分别为 50.7% 和 41.0%。在未见过的物体颜色下，RoboMP-DINOv2-MCR 达到 72.5% 的成功率，而最强的颜色随机化基线为 35.1%。额外实验和表征分析表明，该方法在保留与行为相关的场景信息的同时提高了鲁棒性。代码见 https://github.com/han20192019/RoboMP_DINOv2。

## Abstract
Robot manipulation policies must generalize across visual shifts while preserving scene context relevant to action. General-purpose vision encoders are not tailored to visuomotor control, while object-centric approaches often use segmentation masks as hard filters that discard potentially useful context. We propose RoboMP-DINOv2 (Robotics Mask-Prompted DINOv2), a full-scene vision encoder that treats masks as spatial prompts rather than visibility filters. It extracts dense DINOv2 features from the full observation, injects learned region-specific embeddings at masked locations, and jointly contextualizes prompted and unprompted tokens for action prediction. We further introduce masked-region color randomization (MCR) to improve appearance robustness, yielding RoboMP-DINOv2-MCR. Across seven simulated manipulation settings, RoboMP-DINOv2 achieves 60.7% success under spatial shifts and 59.7% under scene clutter, compared with 50.7% and 41.0% for a DINOv2-based Diffusion Policy. Under unseen object colors, RoboMP-DINOv2-MCR achieves 72.5% success versus 35.1% for the strongest color-randomized baseline. Additional experiments and representation analyses show improved robustness while preserving behaviorally relevant scene information. Code is available at https://github.com/han20192019/RoboMP_DINOv2.

## 1. 核心问题与整体含义

- **研究动机**：机器人操作策略在部署时不可避免会遇到视觉分布偏移，例如背景变化、陌生物体、颜色变化、遮挡或杂乱场景。关键难点在于：视觉变化的大小并不等于行为相关性——干扰物可能大幅改变画面但不影响动作，而一个小障碍物进入路径却会改变正确轨迹。
- **现有方法矛盾**：
  - 通用视觉编码器（如 DINOv2）迁移能力强，但并非为视觉运动控制设计，可能对无关外观变化敏感。
  - 以对象为中心的方法常用分割掩码做“硬过滤”，只保留选中区域，丢弃未掩码上下文，导致分割误差成为信息瓶颈。
- **核心主张**：掩码应作为**空间提示（prompts）**，而不是**可见性过滤器（filters）**。即：用掩码标记感兴趣区域，但保留完整场景信息，让策略仍能访问障碍物、支撑面、其他机械臂、指示颜色等行为相关上下文。
- **整体含义**：论文提出 RoboMP-DINOv2，一种面向机器人操作的全场景视觉编码器，并进一步提出掩码区域颜色随机化（MCR），以提升在空间偏移、场景杂乱和未见物体颜色下的鲁棒性。

## 2. 方法论

- **核心思想**：在预训练 DINOv2 的稠密 patch 特征上，将输入掩码转化为可学习的区域提示嵌入，不删除任何空间 token，并通过轻量 Transformer 联合上下文化提示与非提示 token，最终聚合为全场景表示用于动作预测。
- **输入形式**：
  - RGB 观测 \(I_t\)
  - 机器人本体感觉 \(q_t\)
  - 语言指令 \(\ell\)
  - 有序二值掩码集合 \(M_t = (M_t^{(1)},...,M_t^{(R)})\)，每个掩码槽对应一个学习到的提示嵌入。
  - 编码器只接收有序二值掩码，不需要物体类别标签或文本物体描述。
- **四阶段编码流程**：
  1. **稠密全场景 DINOv2 特征提取**：将 RGB 图像 resize 后送入 DINOv2 ViT backbone，得到 patch token，恢复二维空间结构，并用 \(1\times1\) 卷积投影到维度 \(d\)，得到特征图 \(F_t\)。掩码不参与该阶段，因此完整场景信息被保留。
  2. **特征空间掩码提示**：为每个掩码槽 \(r\) 学习提示嵌入 \(e_r\)，将掩码 resize 到特征分辨率，并在对应位置加上提示嵌入和二维位置嵌入：
     \[
     S_t[:,u,v] = F_t[:,u,v] + P[:,u,v] + \sum_{r=1}^{R}\bar M_t^{(r)}[u,v]e_r
     \]
     该操作只“标记”区域，不删除或替换底层视觉特征；多个掩码重叠时提示嵌入相加。
  3. **全局上下文化**：将 \(S_t\) flatten 为 \(N\) 个 token，送入轻量 Transformer 编码器并做 LayerNorm：
     \[
     Z_t = LN(T(flatten(S_t)))
     \]
     自注意力让提示区域与未提示场景上下文交互，例如障碍物是否阻挡路径。
  4. **全场景聚合**：对上下文化后的 token 做全局平均池化，得到全场景表示：
     \[
     v_t = \frac{1}{N}\sum_{i=1}^{N}Z_{t,i}
     \]
- **策略条件与训练**：
  - 语言指令用冻结 CLIP 文本编码器编码，再经 MLP 投影。
  - 每步策略条件为 \(c_t = v_t \| q_t \| h_{lang}(\text{normalize}(\text{CLIP}(\ell)))\)。
  - 拼接最近 \(T_o\) 步条件，输入 Diffusion Policy。
  - 训练目标为标准扩散噪声预测损失：
    \[
    L_{policy}=\mathbb E_{t,k,\epsilon}\left[\|\epsilon-\epsilon_\theta(A_t^{(k)},k,C_t)\|_2^2\right]
