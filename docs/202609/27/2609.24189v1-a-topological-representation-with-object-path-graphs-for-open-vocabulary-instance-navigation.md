## 摘要
视觉语言导航要求具身智能体利用自然语言指令和视觉观测在环境中导航。现有方法通常将导航分解为序列化的语言引导决策，或依赖不包含先验环境知识的在线探索。场景图表示能够提供紧凑的语义记忆，但仍与下游导航相脱节，而下游导航仍依赖稠密度量地图。为弥合这一差距，我们提出一种物体-路径图，将开放词汇语义推理与拓扑导航统一起来。所提出的表示在单一轻量级拓扑框架内同时支持语义 grounding、基于图的定位与导航。基于该图，我们引入一种导航策略，通过轻量级节点定位和语义视觉伺服，将全局路径规划与局部节点间执行相结合，从而无需稠密度量重建即可直接在图上导航。在 HM3D 和 Replica 上的实验表明，通过所提出的分层图结构，在开放词汇物体 grounding 上取得了有竞争力的性能，同时实现了有效的导航性能。真实世界机器人实验进一步验证了所提出框架的实用性。

## Abstract
Vision-language navigation requires embodied agents to navigate environments using natural language instructions and visual observations. Existing approaches typically decompose navigation into sequential language-guided decisions or rely on online exploration without prior environmental knowledge. Scene graph representations offer compact semantic memory but remain decoupled from downstream navigation, which still depends on dense metric maps. To close this gap, we propose an object--path graph that unifies open-vocabulary semantic reasoning with topological navigation. The proposed representation jointly supports semantic grounding, graph-based localization, and navigation within a single lightweight topological framework. Building on this graph, we introduce a navigation strategy that combines global path planning with local inter-node execution through lightweight node localization and semantic visual servoing, enabling navigation directly over the graph without dense metric reconstruction. Experiments on HM3D and Replica demonstrate competitive performance in open-vocabulary object grounding through the proposed hierarchical graph structure, while achieving effective navigation performance. Real-world robot experiments further validate the practicality of the proposed framework.

## 2. 论文提出的方法论

### 核心思想
- 构建一个包含**物体层图**和**路径层图**的拓扑表示：
  - **物体图**：编码房间、支持物、普通物体及其语义/空间关系，用于开放词汇语义推理。
  - **路径图**：编码可通行自由空间的拓扑连通性，用于全局路径规划和节点间导航。
- 导航时，先通过物体 grounding 确定目标节点，再在路径图上进行最短路径搜索，最后通过**轻量级节点定位**和**语义视觉伺服**执行节点间移动，全程无需稠密度量地图。

### 关键技术细节与流程

#### (1) 开放词汇 3D 物体建图
- 输入 RGB-D 帧序列，使用 **SAM** 生成类别无关的 2D 分割掩码，结合深度投影到 3D，得到局部点云段。
- 利用几何重叠和 CLIP 语义相似度关联新观测与已有物体：
  - 几何重叠：\(O(m,n)=a(S_m,S_n)/\max(n(S_m),n(S_n))\)
  - 语义相似度：\(C(m,n)=f_m^\top f_n/(\|f_m\|\|f_n\|)\)
  - 仅当两者均超过阈值时合并。
- 物体特征通过加权融合更新：\(f=\sum_i w_i f_i,\; w_i=n(S_i)/\sum_j n(S_j)\)。
- 使用 VLM 生成多视角物体描述，再由 LLM 精炼为统一的物体级描述。

#### (2) 物体场景图
- 利用投影结构布局和欧氏距离场（EDF）将环境划分为房间，每个房间为一个**房间节点**，由 LLM 生成开放词汇房间标签。
- 物体分为**支持物**（床、桌、柜等大型结构物）和**普通物体**（书、杯、键盘等小型可移动物），依据 3D 包围盒体积判定。
- 支持物直接连接父房间节点；普通物体根据空间邻近性连接到一个或多个支持物。
- 相邻物体间通过 3D 邻近建立候选边，由 LLM 根据物体描述和相对空间配置预测语义关系（如 on top of、inside、next to）。
- 相邻房间通过可通行门洞连接，形成开放词汇场景图 \(G_O=(V_O,E_O)\)。

#### (3) 可通行导航图
- 根据周围视图变化生成导航节点：视图相似度由共享可见物体数与总观察物体数之比衡量。
- 初始节点来自机器人记录位姿；当视图显著变化时新增节点；门洞区域显式插入节点。
- 对轨迹未充分覆盖的自由空间，随机采样候选位置并按视图相似度分组，取组均值作为补充节点。
- 若两节点间直线路径无碰撞，则建立边；对稀疏采样导致的断开组件，插入额外节点以保持连通。
- 得到可通行图 \(G_P=(V_P,E_P)\)。

#### (4) 物体导航
- **地图表示**：环境表示为稀疏的物体接地拓扑图 \(G_O=(V_O^{room}\cup V_O^{obj},E_O)\)。物体节点状态为 \(v_i=\{p_i,f_i,c_i,d_i\}\)，其中 \(p_i\) 为质心，\(f_i\) 为 VLM 语义特征，\(c_i\) 为类别/开放词汇描述，\(d_i\) 为体积。
- **节点初始化**：机器人短程探索构建全景语义描述子，每个导航节点存储一个旋转不变的全景语义描述子 \(s_i\)。通过余弦相似度检索起始节点：\(v^*=\arg\max_{v_i\in V_P}\cos(s_{query},s_i)\)。
- **拓扑导航**：
  - 全局路径：在可通行图 \(G_P\) 上用 Dijkstra 算法计算从起始节点 \(v^*\) 到目标节点 \(v_T\) 的最短路径 \(P=(v_0,\dots,v_M)\)。
  - 节点间执行：将导航建模为视觉伺服，对齐当前观测与目标节点的全景快照。
  - 对每个分割物体提取关键点（中心、标签、语义特征），仅保留独特关键点。
  - 角误差：\(e_i=(\theta_{i+1}^c-\theta_i^c)-(\theta_{i+1}^g-\theta_i^g)\)，加权和 \(E=\sum_i w_i\|e_i\|\)，其中 \(w_i\) 来自语义相似度。
  - 控制律：\(u=Kwe\)，映射到独轮车控制 \(v=\sqrt{v_x^2+v_y^2},\;\omega=k\cdot\mathrm{atan2}(v_y,v_x)\)。
  - 当 \(\|e\|<\epsilon\) 时终止节点间导航。

## 7. 优点
