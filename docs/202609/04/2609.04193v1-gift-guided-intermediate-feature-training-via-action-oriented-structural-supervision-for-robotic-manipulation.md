## 摘要
视觉-语言预训练和预测性世界建模为机器人策略提供了丰富的语义和动态视觉特征，但其原生动作与视觉预测目标可能遗漏关键的物理和任务结构，同时保留与控制无关的视觉冗余。我们将这种视觉丰富性与控制效用之间的不匹配称为动作充分性差距。我们研究了是否可以通过引导中间特征保留机器人操作中三种控制相关的结构来弥合这一差距：控制运动可行性的几何结构、编码指令相关实体的可供性，以及将指令锚定到任务相关区域的目标基础。为此，我们提出了GIFT（引导中间特征训练），一种架构灵活的学习中间特征框架，通过几何对齐、可供性预测和目标区域重构将这些结构转化为训练时的约束。我们在视觉-语言-动作（VLA）策略、直接动作世界动作模型（WAM）以及逆动力学WAM中实例化GIFT，同时保持每个模型的动作公式。在零样本迁移至LIBERO-Plus时，GIFT-VLA、GIFT-WAM-Fast和GIFT-WAM-IDM分别比StarVLA-OFT、Fast-WAM和Fast-WAM-IDM高出4.6、12.6和5.2个百分点，分别达到79.6%、72.6%和87.8%。在RoboCasa上，三种GIFT变体分别达到61.4%、83.6%和82.3%，分别比对应模型高出12.6、9.0和8.4个百分点。这些结果共同表明，学习功能结构化中间特征可作为跨模型特定动作公式的可复用原则，尤其在铰接物体任务以及未见视觉和空间扰动下的高精度真实世界操作中取得了特别大的收益。项目页面：https://openphoenix-team.github.io/GIFT-pages。

## Abstract
Vision-language pre-training and predictive world modeling provide robot policies with rich semantic and dynamic visual features, but their native action and visual-prediction objectives may omit critical physical and task structure while retaining control-irrelevant visual redundancy. We call this mismatch between visual richness and control utility the action-sufficiency gap. We investigate whether this gap can be bridged by guiding intermediate features to preserve three control-relevant structure in robotic manipulation: geometry governing motion feasibility, affordance encoding instruction-relevant entities, and goals grounding instructions in task-relevant regions. To this end, we present GIFT (Guided Intermediate Feature Training), an architecture-flexible framework for learning intermediate features that translates these structures into training-time constraints through geometry alignment, affordance prediction, and goal-region reconstruction. We instantiate GIFT in a Vision-Language-Action (VLA) policy, a direct-action World-Action Model (WAM), and an inverse-dynamics WAM while retaining each model's action formulation. Under zero-shot transfer to LIBERO-Plus, GIFT-VLA, GIFT-WAM-Fast, and GIFT-WAM-IDM outperform StarVLA-OFT, Fast-WAM, and Fast-WAM-IDM by 4.6, 12.6, and 5.2 points, reaching 79.6%, 72.6%, and 87.8%, respectively. On RoboCasa, the three GIFT variants reach 61.4%, 83.6%, and 82.3%, outperforming their counterparts by 12.6, 9.0, and 8.4 points, respectively. Together, these results establish learning functionally structured intermediate features as a reusable principle across model-specific action formulations, with especially large gains on articulated-object tasks and high-precision real-world manipulation under unseen visual and spatial perturbations. ## 1. 核心问题与研究动机
- **核心问题**：视觉—语言预训练和预测性世界建模为机器人策略提供了丰富语义、动态的视觉特征，但这些特征的“**原生训练目标**”（VLA 的动作监督目标、WAM 的视觉预测目标）并不保证保留“真正对控制有用”的物理与任务结构，反而可能保留大量**与控制无关的视觉冗余**。
- 论文将这种**视觉丰富性与控制效用之间的不匹配**定义为“**动作充分性差距**（action-sufficiency gap）”。
- 已有方法（如 SpatialVLA、GuidedVLA、DreamVLA、World Guidance、Flex-π 等）只针对某一种或几种结构信号、或只限定在特定策略家族/注意力结构/预测接口下验证，缺少**跨策略架构的、统一的可复用原则**。
- 论文的核心研究问题是：**能否通过引导中间视觉特征，保留三类循环出现的控制相关结构（几何、可供性、目标），从而在不改动作接口的前提下提升不同策略的操控性能与泛化鲁棒性？**

## 2. 方法论
### 2.1 总体思想
- 提出**GIFT（Guided Intermediate Feature Training）**：一种**架构灵活**的中间特征训练框架。
- 它不是规定一个共享的动作推理接口，而是规定“**中间特征应保留哪些控制相关信息**”，将这些结构转化为**训练时约束**，作用于中间视觉 token 上。
- 三类互补结构：
  - **几何（Geometry）**：决定运动可行性；
  - **可供性（Affordance）**：编码指令相关实体、目标为中心末端执行器配置；
  - **目标（Goal）**：把指令锚定到任务相关的动作区域。

### 2.2 三个辅助监督头
- **几何对齐（Geometry Alignment）**：
  - 使用冻结的 **VGGT 几何基础模型**作为训练时 teacher，不额外增加推理期几何输入。
  - 将 student 中间 token 投影为 VGGT 空间的“方向 + 幅度”两部分。
  - 损失包括**角度对齐损失** \(L_{ang}\)（方向余弦距离）和**尺度对齐损失** \(L_{scale}\)（log 幅度回归）：
    \[
    L_{geo} = \lambda_{ang} L_{ang} + \lambda_{scale} L_{scale}
    \]
  - 去除特征范数差异带来的数值不稳定性，同时保留幅度信息。
- **可供性预测（Affordance Prediction）**：
  - 将交互可供性定义为**指令条件化、对象为中心的结构化实体—末端执行器关系**。
  - 每个槽位 \(u_{t,k}\in R^{20}\) 包括：角色 ID、在锚对象坐标系中的位姿、末端执行器在实体坐标系中的位姿、夹爪/手部闭合状态。
  - 用 \(K\) 个可学习 query 从视觉 token 池化，并用 Smooth L1 损失监督：
    \[
    L_{aff} = \frac{1}{Q_t}\sum_{k=1}^{K} q_{t,k} \, \text{SL1}(\hat{u}_{t,k}, u_{t,k})
    \]
  - 该参数化显式耦合“指令相关实体”与“交互所需的末端执行器位姿”，并降低对全局相机坐标系的依赖。
- **目标区域预测 / 重建（Goal-Region Prediction）**：
  - 对每个输入视角生成**二值目标 mask**，标出指令相关的操作对象或任务相关动作区域。
  - 使用**BCE + Dice 损失**，计算在低分辨率网格上：
    \[
    L_{goal} = \lambda_{bce}\text{BCE}(\hat{M}_t, M_t) + \lambda_{dice}(1-\text{Dice}(\hat{M}_t, M_t))
    \]
  - 目标 mask 是“唯一”目标监督，不额外提供运动意图目标。

### 2.3 统一训练目标
- 总目标为：
  \[
  L_{GIFT} = L_{native} + \lambda_{geo} L_{geo} + \lambda_{aff} L_{aff} + \lambda_{goal} L_{goal}
  \]
- 默认采用 **no-injection（不注入）** 变体：辅助预测**只在训练时通过梯度影响共享中间特征**，不输入到动作生成器，即：
  \[
  \hat{A}_t = A_\phi(Z_t, C_t^{native})
  \]
- 与 injection 变体对比，用于确定性能提升来自“表示塑造”而非“额外条件输入”。

### 2.4 跨三类策略的实例化
1. **GIFT-VLA**（语义中心直接动作策略）：在 StarVLA-OFT 基础上使用 Qwen3-VL 骨干，附加 goal token、affordance token、action-query token；用直接回归损失 \(L_1\)。
2. **GIFT-WAM-Fast**（WAM 直接动作扩散）：沿用 Fast-WAM 的混合 Transformer，quick-mode attention；辅助目标作用在当前帧视频 token 上，原生流匹配损失不变。
3. **GIFT-WAM-IDM**（未来条件逆动力学）：视频分支先预测未来视频，然后以 teacher-forcing 的未来特征为条件生成动作；测试时先采样未来视频再执行动作；同样只加 GIFT 辅助约束。

## 6. 主要结论与发现
- **LIBERO 原始域**：GIFT 保持并发性能（GIFT-VLA 97.9%，GIFT-WAM-Fast 97.7%，GIFT-WAM-IDM 98.5%），说明结构化监督不损害域内控制能力。
- **LIBERO-Plus 零样本**：对基线分别提升 4.6、12.6、5.2 点，达到 79.6%、72.6%、87.8%；GIFT-WAM-IDM 整体最优（87.8%）。
- **RoboCasa**：分别提升 12.6、9.0、8.4 点，达到 61.4%、83.6%、82.3%；GIFT-WAM 在铰接物体任务上相对基线提升 21–24 点。
- **真实世界**：GIFT-VLA 平均成功率从 35.0% 升到 57.5%；GIFT-WAM-IDM 从 52.5% 升到 87.5%；扰动条件下明显优于基线。
- 消融表明：
  - 三个信号互补，单独增加均有收益（几何最有利于摄像头视角变化，可供性最有利于机器人初始化变化，目标最有利于背景/传感器噪声等）；
  - **no-injection 优于 injection**，说明只需塑造共享中间特征，不必向动作头注入辅助预测作为条件；
  - GIFT 的主要增益来自结构化监督，而非动作头架构变动（3.9 点 vs 0.7 点）。

## 7. 优点
- **统一原则、跨架构验证**：同一“几何–可供性–目标”监督被应用于 VLA、直接动作 WAM、逆动力学 WAM，证明该方法具有通用性。
- **训练时约束、推理零负担**：冻结几何 teacher 与辅助头仅训练时用；默认 no-injection 不改变动作生成输入，推理成本不变。
- **监督信号设计具有物理意义**：
  - 几何对齐兼容深度诊断；
  - 可供性采用对象为中心、锚对象相对表示，自然支持双臂、变实体数量情况；
  - 目标 mask 采用指令条件化 action-region 监督，提供密集空间定位。
- **实验体系完整**：跨越多个模拟环境、两种不同机器人形态、真实世界平台以及强扰动测试；同时设计了 injection/no-injection、单信号消融、动作头控制、可视化诊断等，结论较清晰。
- **消融揭示科学结论**：通过“相对原始动作头 + 无 GIFT”控制与“注入 vs 不注入”对比，明确把收益归因于表示塑造，而非额外条件输入；注意力可视化进一步支撑解释。

## 8. 不足与局限
- **基线与实现不完全一致**：
  - GIFT-VLA 修改了动作头（BridgeAttention），虽然提供了同头无监督的对照，但这种改动并非 GIFT 的必要条件，可能削弱“仅需辅助监督”的纯粹性描述。
  - WAM 与 VLA 的基线来自不同作者/版本，超参数和训练预算未完全对齐，外部公平性有限。
- **计算资源开销大**：
  - 使用 32–64 张 GPU（或 64 张高显存 PPU）进行训练，成本较高；
  - 论文未报告详细 wall-clock 时间、token 开销、辅助标签预处理成本。
- **依赖人工/仿真标注**：
  - 仿真环境可使用 state 标签，但真实世界中目标 mask、对象位姿、可供性槽位依赖 Grounding DINO + SAM2 + 人工校正等流程，扩展到大规模数据可能成本较高、难以自动化。
- **失效场景仍未彻底解决**：
  - 在严重传感器噪声、大视角变化、背景杂散物体干扰下，几何/可供性/目标预测可能失败（如错认目标物体、角色槽混淆、mask 扩展到背景），说明监督并未消除感知歧义。
- **适用范围局限**：
  - 实验限于桌面/近桌操作，未覆盖移动操作、灵巧手复杂抓持、动态环境或长时序任务；
  - 真实任务规模较小（每任务 100 条演示，10 次试评），统计功效有限。
- **数据与事故风险**：论文未讨论由感知误差导致的负迁移或实际系统安全性、失败恢复机制。
