## 摘要
自动驾驶涉及多模式不确定性下耦合的决策与场景演化。为捕捉这种耦合与不确定性，我们提出 MM-Future，一种世界-动作模型，它生成多个成对的场景-动作假设，并建模每一对内部的双向交互。每个假设由结构化动作先验与独立的未来场景源初始化，随后通过模态感知的扩散 Transformer 协同演化。为支持高效的多模式推演，MM-Future 将多视角视频压缩为面向规划的表示，称为 MM-Tokens。最后，一个以未来为条件的提议评分器根据共享的历史上下文及其成对的预测未来对轨迹候选进行排序。在 NAVSIM navtest 上，MM-Future 取得 94.0 PDMS 与 91.5 EPDMS，并在 HUGSIM 的零样本闭环评估中获得 32.3 HD-Score。消融实验表明，相较于单模式与仅动作的变体均有稳定提升，验证了多模式联合世界-动作建模的优势。

## Abstract
Autonomous driving involves coupled decision-making and scene evolution under multi-mode uncertainty. To capture this coupling and uncertainty, we introduce MM-Future, a world-action model that generates multiple paired scene-action hypotheses and models bidirectional interaction within each pair. Each hypothesis is initialized from a structured action prior and an independent future scene source, which are then co-evolved through a modality-aware diffusion Transformer. To support efficient multi-mode rollout, MM-Future compresses multi-view video into planning-oriented representations, dubbed MM-Tokens. Finally, a future-conditioned proposal scorer ranks trajectory candidates by shared history context and their paired predicted future. On NAVSIM navtest, MM-Future achieves 94.0 PDMS and 91.5 EPDMS, while attaining a 32.3 HD-Score in zero-shot closed-loop evaluation on HUGSIM. Ablations show consistent improvements over both single-mode and action-only variants, validating the benefit of multi-mode joint world-action modeling.

## 一、核心问题与研究动机

- **背景**：端到端（E2E）自动驾驶直接将传感器观测映射为轨迹，而世界-动作模型（World-Action Model, WAM）进一步建模场景未来演化，从而支持“后果感知”的规划——驾驶模型不仅要判断“该怎么做”，还要推断“可能会发生什么”。
- **现有 WAM 的两类范式均存在缺陷**：
  - **级联式（Cascaded）WAM**：通过顺序条件化支持多模式推演，但场景与动作之间的影响是**单向的**（下游变量无法反过来修正上游变量）。
  - **联合式（Joint）WAM**：在共享生成过程中实现场景-动作双向交互，但通常**只产生单一配对推演**，缺乏模式覆盖。
- **核心矛盾**：驾驶既需要**多模式覆盖**（同一观测对应多种合理交互结果），也需要**双向耦合**（动作影响场景、场景反过来影响动作），而现有方法二者只能取其一。
- **典型场景**：无信号交叉路口，同一观测可能产生两种截然不同的交互结果——加速会促使对方让行，减速则让对方驶入并强化自身等待的决策。
- **三大技术挑战**：
  1. 如何从**单结果监督**（每个训练片段只有一种已实现的场景-动作结果）中学习多样化的驾驶意图；
  2. 如何以**可控的计算开销**生成多个未来假设（稠密视频 latent / 图像块 / BEV 网格随预测时域与模式数增长而急剧膨胀）；
  3. 如何从多个成对假设中**识别最合适的驾驶动作**（仅凭历史观测可能不足以区分候选）。

## 二、方法论

### 2.1 核心思想

将合理的驾驶结果表示为**成对的“世界-动作”假设** $\mathcal{H}^m = (\hat{\tau}^m, \hat{X}^+_m)$，$M$ 个模式从联合条件分布 $p_\Theta(\tau, X^+ \mid O)$ 中采样，其中每个假设内的场景与动作**双向协同演化**。

### 2.2 三大组件

- **规划导向 MM-Tokens（紧凑场景表示）**
  - 用视觉骨干 $E$（DINOv2-S，LoRA 微调）提取每相机每帧的 register tokens $P^v_t \in \mathbb{R}^{L_v \times d}$。
  - 将时间序列划分为 $C$ 个时间块，每块内收集所有帧、所有视角的 register tokens $P^{(j)}$，用 $N_x$ 个可学习的块级查询 $Q^{(j)}$ 通过自注意力 $A$ 聚合，输出 MM-Tokens $X^j \in \mathbb{R}^{N_x \times d}$。
  - **不施加 RGB 或 BEV 重建损失**，而是由多模式联合世界-动作建模目标直接塑造；有限的 token 预算迫使表示保留与未来演化和规划相关的场景线索。
  - 表示传播开销从 $\sum_{t \in T_j}\sum_{v=1}^{V}\frac{H\times W}{p^2}$ 降至 $N_x$。
  - 目标编码器 $\bar{E}_{\bar{\theta}_e}$ 同构，用 EMA（衰减 0.999）更新，提供未来目标 $\bar{X}^+ = \mathrm{sg}(\bar{E}_{\bar{\theta}_e}(I^+))$。

- **多模式联合世界-动作流**
  - **结构化配对源**：GT 轨迹编码为连续动作 token $a_{gt} = E_a(\tau^{gt}) \in \mathbb{R}^{T_a \times 4}$（含归一化差分运动 $\Delta x, \Delta y, \sin\psi, \cos\psi$）。对归一化训练轨迹做 K-means 聚类，用各簇经验均值与方差参数化**高斯混合噪声（GMN）**，采样 $M$ 个动作先验 $\{\epsilon_a^m\}$，各自与独立未来 token 噪声 $\epsilon_x^m \sim \mathcal{N}(0,I)$ 配对。
  - **联合条件流**：对模态 $\kappa \in \{a, x\}$ 采样独立流时间 $\rho_\kappa \in [0,1)$，构造线性路径 $z_\kappa = (1-\rho_\kappa)\epsilon_\kappa + \rho_\kappa y_\kappa$；生成器 $(\hat{y}_a, \hat{y}_x) = G_{\theta_g}(z_a, z_x; X^h, s^h, c, \rho_a, \rho_x)$。
  - **模态感知 Transformer**：共享多模态注意力实现场景-动作双向交互，模态专属 AdaLN 调制与 FFN 分支保留各自统计特性；**非对称块掩码**将历史视为干净前缀（历史 query 只关注历史 key，动作与未来 query 可互相交互）；模式维度折叠进 batch 维度，参数共享但各模式间不交换 token。
  - **Best-of-Many（BoM）监督**：采用 x-prediction 参数化，速度目标 $\hat{u}_\kappa = \frac{\hat{y}_\kappa - z_\kappa}{1-\rho_\kappa}$，$u_\kappa = \frac{y_\kappa - z_\kappa}{1-\rho_\kappa}$。由解码轨迹与 GT 的距离选出获胜模式 $m_{win}$，**同一模式索引同时监督两个流**：$\mathcal{L}_{BoM} = \sum_{\kappa \in \{a,x\}} \lambda_\kappa \|\hat{u}_{\kappa}^{m_{win}} - u_{\kappa}^{m_{win}}\|_2^2$。共享获胜索引保持场景-动作对应关系，避免所有源被拉向同一条件均值。
  - 推理时用短 Euler 调度从噪声积分采样，得到 $\{(\hat{\tau}^m, \hat{X}^+_m)\}_{m=1}^M$。

- **未来条件提议打分器**
  - 将停止梯度的轨迹作为 proposal queries，通过自注意力相互比较，再经 cross-attention 以历史 MM-Tokens 为条件：$q^h_{1:M} = D_h(g_\tau(\mathrm{sg}[\hat{\tau}_{1:M}]), X^h)$。
  - 第二个解码器让每个 query **仅以其配对预测未来为条件**：$q^+_m = D_f(q^h_m, \mathrm{sg}[\hat{X}^+_m]) + g_s(s_0)$，未来注意力为块对角（模式 $m$ 只能访问自己的未来）。
  - 输出模块 $H$ 预测 PDMS 各分量的 logits，损失为 $\mathcal{L}_{score} = \frac{1}{M}\sum_m \mathrm{BCEWithLogits}(\ell_m, y^m)$；对轨迹提议与未来 MM-Tokens 停止梯度，防止生成器为简化打分而扭曲输出。

### 2.3 训练目标与推理

- 总损失：$\mathcal{L} = \mathcal{L}_{BoM} + \lambda_s \mathcal{L}_{score}$，在线 MM-Encoder、联合生成器、打分器联合优化，目标编码器仅由 EMA 更新。
- 训练时未来图像只提供目标 $\bar{X}^+$，绝不进入历史条件。
- 推理流程：(i) 编码历史多视角观测 → (ii) 积分 $M$ 组成对场景-动作 token 流 → (iii) 用共享历史上下文与配对想象未来对每条轨迹打分 → (iv) 返回最高分轨迹。
