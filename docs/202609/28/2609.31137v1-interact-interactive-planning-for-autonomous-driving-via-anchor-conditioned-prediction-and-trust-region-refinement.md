## 摘要
在密集城市交通中驾驶具有交互性：汇入或非保护转向能否成功，取决于周围智能体如何响应自车。传统规划器先预测、后规划，因此无法考虑这种依赖关系。将预测与规划集成的方法要么联合训练二者，这会引入任务干扰；要么保持二者分离，但受限于预定义的候选方案集合。我们提出 INTERACT：通过锚点条件预测与信赖域精化的自动驾驶交互式规划。我们的关键洞见是，周围智能体响应的是轨迹所表达的意图，而非其精确实现，因此一次反应式预测就能对一整族规划保持有效。因此，INTERACT 将交互式规划分解为跨驾驶意图的预测与各意图内的优化。我们从地图几何中推导出一小组多样化意图，称为锚点；针对每个锚点查询一次专用的自车条件预测模型，并在信赖域惩罚下使用交叉熵方法对每个锚点进行精化，该惩罚使精化后的规划与其锚点保持足够接近，从而使以锚点为条件的反应仍然适用。这样，预测仍是一个独立模型，避免了任务干扰，同时以锚点为条件保留了这种依赖关系。由于每个锚点都被连续精化，最终规划不局限于锚点集合；但 INTERACT 仅需每个锚点查询一次预测器，而不是每个候选规划查询一次，且所有锚点并行处理。在 nuPlan 和 interPlan 闭环基准上，INTERACT 刷新了当前最优结果，且提升最大的正是在推动该方法的交互式场景中。代码将在论文被接收后发布。

## Abstract
Driving in dense urban traffic is interactive: whether a merge or an unprotected turn succeeds depends on how surrounding agents respond to the ego vehicle. Conventional planners predict first and plan second and, therefore, cannot account for this dependency. Methods that integrate prediction and planning either train both jointly, which introduces task interference, or keep them separate and are restricted to a predefined set of proposals. We present INTERACT: Interactive Planning for Autonomous Driving via Anchor-Conditioned Prediction and Trust-Region Refinement. Our key insight is that surrounding agents react to the intent a trajectory expresses rather than to its exact realization, so a single reactive prediction stays valid across an entire family of plans. INTERACT therefore decomposes interactive planning into prediction across driving intents and optimization within each intent. We derive a small set of diverse intents, which we call anchors, from map geometry, query a dedicated ego-conditioned prediction model once per anchor, and refine every anchor with the Cross-Entropy Method under a trust-region penalty that keeps the refined plan close enough to its anchor for the conditioned reaction to still apply. Prediction thus remains a separate model, avoiding task interference, while conditioning on anchors preserves the dependency. Because each anchor is refined continuously, the final plan is not restricted to the anchor set, yet INTERACT requires only one predictor query per anchor rather than one per candidate plan, with all anchors processed in parallel. On the nuPlan and interPlan closed-loop benchmarks, INTERACT sets a new state of the art, with the largest gains precisely in the interactive scenarios that motivate the method. The code will be released upon acceptance.

### 2. 论文提出的方法论

- **核心思想**：
  - 从地图几何中生成少量多样化、运动学可行的自车轨迹，称为**锚点（anchors）**，代表不同驾驶意图。
  - 对每个锚点，仅查询一次自车条件预测模型，得到周围智能体对该意图的反应式预测。
  - 在每个锚点对应的预测条件下，用交叉熵方法（CEM）连续精化该锚点，并通过信赖域惩罚保持精化后的轨迹与锚点足够接近，使条件预测仍然有效。
  - 最终在精化后的轨迹中选择得分最高者执行。最终规划不局限于初始锚点集合，但每个锚点只需一次预测查询，且所有锚点可并行处理。

- **关键技术细节与流程**：
  1. **锚点生成**：
     - 从路线中心线和相邻车道构造路径，用三次贝塞尔曲线连接当前位姿与车道点，路径按弧长参数化。
     - 每条路径搭配五种目标速度剖面，目标速度为限速的固定比例，并以恒定加速度/减速度逼近。
     - 路径决定机动形状，速度剖面决定时间进程；参考轨迹由 LQR 跟踪，再用运动学自行车模型滚出可行轨迹。
     - 候选按连续 PDM 替代分数排序，并用最远点采样在轨迹空间选 \(N=5\) 个锚点，初始化用最高分候选而非随机点，以增强空间多样性。
  2. **锚点条件预测**：
     - 基于 SMART 多智能体 next-token 预测模型，将轨迹离散为运动 token，按时间自回归分解联合未来。
     - 将锚点轨迹 token 化后，在采样过程中把自车 token 替换为锚点 token，从而实现对锚点的精确条件化。
     - 对每个锚点得到一个条件预测 \(\hat{Y}_i\)，所有锚点的预测并行计算。预测模型无需架构修改或重新训练，保留专用预测模型质量。
  3. **信赖域 CEM 精化**：
     - 在控制序列空间优化，控制量为加速度 \(a_t\) 与转向率 \(\dot{\delta}_t\)，用运动学自行车模型 rollout。
     - 目标函数为：
       \[
       J_i(u)=S(BM(u),\hat{Y}_i)-\lambda\frac{1}{T}\sum_{t=1}^T\|(x_t,y_t)-(x_i^t,y_i^t)\|^2
       \]
       第一项为通用规划评分，含舒适性、碰撞避免、可行驶区域等，交互相关项针对条件预测 \(\hat{Y}_i\) 评估；第二项为信赖域惩罚，限制偏离锚点。
     - 评分 \(S\) 是 PDM 分数的连续替代，保留乘法门控与加权平均结构，但将碰撞、可行驶区域、行驶方向、TTC 等离散项替换为连续项，使梯度更平滑，便于 CEM 优化。
     - 每个锚点维护对角高斯分布，初始化均值于锚点控制序列，初始探索范围 \(\rho=0.15\)。每次迭代采样 \(P=24\) 个控制序列，选 \(E=6\) 个精英重拟合分布，共 \(K=10\) 次迭代。扰动采用 iCEM 的彩色噪声，使搜索偏向平滑控制。
     - 信赖域使 CEM 搜索局部化，避免单分布平均不同模式，也避免在优化中反复查询预测器。
  4. **最终规划选择**：
     - 对每个精化轨迹 \(\tau_i^*\) 及其条件预测 \(\hat{Y}_i\) 计算评分，选择 \(\arg\max_i S(\tau_i^*,\hat{Y}_i)\) 执行。

### 6. 论文的主要结论与发现

- INTERACT 在多个交互密集 benchmark 上取得新 SOTA：
  - **Test14-hard**：85.28，优于最强反应式学习基线 BIBeR-CV 2.28。
  - **Dynamic-10**：94.65，优于最强报告方法 PDM-Closed 3.15，优于最强反应式学习基线 HYPE 3.38。
  - **interPlan-LC**：89.07，优于 BIBeR-CV 4.54。
  - **interPlan-full**：79.11，优于 TerraZero 7.80。
  - **Val14**：93.18，排名第二，低于 TerraZero 的 94.19。
  - **Test14-random**：92.48，排名第二，与固定预测方法差距较小。
  - **interPlan**：58.29，低于 TerraZero 的 70.87。
- 结论：交互式条件预测在交互密集场景中收益最大；在交互较弱的场景中，固定预测或无条件学习预测仍可能足够强。
- 消融结论：
  - 锚点是最重要组件，移除后性能大幅下降，说明其提供了结构化的驾驶意图先验。
  - CEM 精化负责适配交互预测并提升效率，移除后进度和舒适性下降。
  - 连续 PDM 替代分数比离散分数提供更平滑、更有信息量的排序，移除后 TTC 和进度下降。
  - 信赖域权重 \(\lambda=0.1\) 取得最佳权衡；\(\lambda=0\) 过度激进，TTC 下降；\(\lambda=0.5\) 约束过强，进度下降。
  - 锚点数从 1 增至 5 显著提升，继续增加收益有限甚至增加风险。
  - 条件预测在 interPlan-LC 上明显优于无条件预测和恒速预测，说明交互场景中条件化建模更重要。
