## 摘要
驾驶世界模型能够从视觉观测中学习到对周围环境的丰富预测性表征，然而准确的视觉预测并不一定能转化为有效的轨迹规划。我们认为，关键瓶颈在于视觉世界状态与原始几何轨迹之间的不匹配，这可能限制了规划器利用世界模型所编码的动作相关语义的能力。为解决这一问题，我们提出用于潜在轨迹的世界模型对齐（World-Model Alignment for Latent Trajectories, WALT），它通过从冻结的预训练驾驶世界模型迁移信息来学习紧凑的生成式轨迹潜在空间，且不修改世界模型本身。WALT 不是直接生成原始路点，而是通过双分支轨迹自编码器将其映射为紧凑表征，并将冻结视觉世界模型中的语义知识迁移到该轨迹空间，促使学习到的动作表征捕捉与未来运动和规划相关的场景级线索。除了我们提出的方法，我们还系统研究了基于联合嵌入预测架构（JEPA）的潜在学习以及遵循表征对齐（REPA）的特征对齐，以探究仅轨迹表征学习如何影响下游规划。我们在 NAVSIM 基准上评估 WALT。相对于原始路点基线，WALT 在 NAVSIMv1 上将 PDMS 从 89.4 提升至 89.8，在 NAVSIMv2 上将 EPDMS 从 87.3 提升至 87.9，同时将轨迹规划器的 FLOPs 降低 30.5%。这些结果表明，在保留世界表征的同时提取动作相关信息，为基于世界模型的轨迹规划提供了一种有效接口。

## Abstract
Driving world models learn rich predictive representations of the surrounding environment from visual observations, yet accurate visual prediction does not necessarily translate into effective trajectory planning. We argue that a key bottleneck lies in the mismatch between visual world states and raw geometric trajectories, which may limit the planner's ability to exploit action-relevant semantics encoded by the world model. To address this issue, we propose World-Model Alignment for Latent Trajectories (WALT), which learns a compact generative trajectory latent space by transferring information from a frozen pretrained driving world model without modifying the world model itself. Rather than directly generating raw waypoints, WALT maps them into compact representations through a dual-branch trajectory autoencoder and transfers semantic knowledge from the frozen visual world model into this trajectory space, encouraging the learned action representation to capture scene-level cues relevant to future motion and planning. Beyond our proposed formulation, we systematically study latent learning based on Joint-Embedding Predictive Architectures (JEPA) and feature alignment following Representation Alignment (REPA) to investigate how trajectory-only representation learning affects downstream planning. We evaluate WALT on the NAVSIM benchmarks. Relative to the raw-waypoint baseline, WALT improves PDMS from 89.4 to 89.8 on NAVSIMv1 and EPDMS from 87.3 to 87.9 on NAVSIMv2 while reducing trajectory planner FLOPs by 30.5%. These results suggest that preserving world representations while extracting action-relevant information provides an effective interface for world-model-based trajectory planning.

- **核心矛盾**：**高保真的视觉预测或视觉丰富的潜空间，并不保证可靠的轨迹规划**。论文指出关键瓶颈在于「视觉世界状态」与「原始几何轨迹」之间的**表征错配（representation mismatch）**。
- **问题本质**：动作头（action head）必须把丰富的预测状态映射到动作表征，而常见规划器通过**原始路点、局部运动增量或离散运动 token** 来暴露这一接口。这种接口无法充分利用世界模型中编码的、与动作相关的语义信息。
- **已有路线的局限**：近期统一的视觉–运动模型（如 WorldDrive、DriveLaW）将轨迹表征纳入世界模型联合训练，使视觉预测与运动规划交互，但**把动作接口耦合到一个需重新设计的多模态世界模型上**，代价是必须联合训练融合的视觉与运动表征。
- **核心追问**：能否在**不修改冻结预训练世界模型**的前提下，把其视觉知识迁移到轨迹生成空间？
- **整体含义**：WALT 提出首个通过从冻结驾驶世界模型迁移信息来学习紧凑生成式轨迹潜空间的框架，主张「保留世界表征的同时提取动作相关信息」是有效的世界模型规划接口。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体流程（两阶段）

- **Stage 1**：训练双分支轨迹自编码器，把原始路点压缩为紧凑潜表征；训练目标 = 重建损失 + 世界模型对齐损失（世界模型全程冻结）。
- **Stage 2**：冻结轨迹 tokenizer 与原始世界模型通路，仅训练轨迹规划头（rectified-flow 规划器），让其生成对齐后的轨迹潜变量，再解码为路点。

### 2.2 双分支轨迹 Tokenizer

- **输入/输出设定**：未来轨迹点序列 $A = \{A_i\}$（N 为最后观测时刻，P 为预测时域），压缩为 K 个潜 token，下采样比 $q = P/K$。
- **双分支设计**：两分支**共享编码器**，用各自独立的 refiner 产出：
  - 语义特征 $z_{sem}$（承载动作相关语义）
  - 重建特征 $z_{rec}$（保留度量几何信息）
  - 沿通道维拼接：$z_A = [z_{sem};\, z_{rec}]$，再由解码器还原 $\hat{A} = D(z_A)$。
- **重建损失**：$L_{rec} = \mathbb{E}_A[\|\hat{A} - A\|_1]$
- **总损失**：$L_{tokenizer} = \lambda_{rec} L_{rec} + \lambda_{align} L_{WALT}$
- **语义掩码机制**：以概率 $p_{sem}$ 整体掩蔽 $z_{sem}$ 而保留 $z_{rec}$，**迫使重建分支独立保留足够几何信息**，避免重建能力依赖语义分支。

### 2.3 世界模型对齐（WALT 核心）

- **思想**：把冻结世界模型的视觉特征当作**上下文教师（contextual teacher）**，将动作相关语义迁移进轨迹潜空间；视觉编码器与骨干冻结，任务专用预测头在 tokenizer 训练时不使用。
- **教师特征**：每帧及其轨迹对应隐藏状态 $H_w \in \mathbb{R}^{N_b \times M \times d_w}$（$N_b$ 为展平的批×帧维度，M 为教师 token 数）。
- **学生投影**：学习投影器 $g$，得 $U = g(z_{sem})$，映射到教师通道维度。
- **CLIP 式对比目标**：
  - 样本级相似度对 KM 个 token 对的余弦相似度取平均：
    $$S_{ij} = \frac{1}{KM}\sum_{k=1}^{K}\sum_{\ell=1}^{M} \frac{U_{ik}^\top H_{w,j\ell}}{\|U_{ik}\|_2 \|H_{w,j\ell}\|_2}$$
  - **正样本**：同一 sample 与同一 frame index；其余 gathered 的样本或帧均视为负样本。
  - 学生特征跨 GPU 带梯度 gather，冻结教师特征无梯度 gather，候选集覆盖全局 batch。
  - 对称 CLIP 损失：$L_{WALT} = \frac{1}{2}CE(\alpha S, y) + \frac{1}{2}CE(\alpha S^\top, y)$，其中可学习 logit 尺度 $\alpha = \exp(s)$ 且有界。
- **要点**：对齐是**语义层面的迁移**，而非把场景特征直接拼接进轨迹潜变量。

### 2.4 潜轨迹生成（Stage 2）

- 采用 **rectified-flow 规划器**作为轨迹头，条件流匹配目标，但**生成目标从 P 个原始路点 token 改为 K 个拼接潜 token $z_A$**。
- 训练构造：$\epsilon \sim \mathcal{N}(0,I)$，$t \sim U[0,1]$，则
  $$z_t = (1-t)\epsilon + t z_A,\quad v_{target} = z_A - \epsilon$$
- 流匹配损失：$L_{flow} = \mathbb{E}_{A,\epsilon,t}\left[\|\hat{v}_A(z_t, t; H_w) - (z_A - \epsilon)\|_2^2\right]$
- 推理：从 $\hat{z}_0 \sim \mathcal{N}(0,I)$ 出发，从 $t=0$ 积分到 $t=1$（$\hat{z}_{t+\Delta t} = \hat{z}_t + \Delta t\, \hat{v}_A$），再由解码器还原路点 $\hat{A} = D(\hat{z}_1)$。

### 2.5 仅轨迹表征的对照设计（用于消融）

- **JEPA-Traj**：把连续路点当序列输入，抽取重叠子轨迹并用同一语义 tokenizer 编码；以较早子轨迹的语义 token 预测较晚子轨迹的语义 token，用 **SIGReg 正则**防止表征坍缩。目标为 $L_{JEPA} = \lambda_{sigreg} L_{sigreg} + \lambda_{pred} L_{pred}$，替换 tokenizer 训练中的世界模型对齐项，保留重建损失。
- **REPA-Traj**：保留**原始路点生成**，额外在流匹配规划头的轨迹流表征 $h_{traj}$ 与冻结的 JEPA-Traj 语义目标 $z^*_{sem} = sg(z_{sem})$ 之间加辅助余弦距离对齐（经投影器 $g_R$）。
