## 摘要
近期视觉语言模型（VLM）的进展展示了其在静态视觉识别和高层次语义推理方面的显著能力。然而，当前的具身探索范式仍严重依赖从人类标注轨迹中进行的模仿学习，这极大地限制了智能体的泛化能力。实现通用自主具身智能体的关键瓶颈在于通用化的视觉接地探索：即在没有手册或特定训练的情况下，通过主动将抽象世界知识接地到细粒度视觉可供性中，来操作新型设备的能力。然而，现有基准未能评估这一能力：它们通常依赖显式文档和标注轨迹，忽视了功能性设备操作所必需的动态假设-交互-细化过程。为弥合这一差距，我们引入了VGEBench，一个旨在评估VLM通用化视觉接地探索能力的综合基准。与静态数据集不同，我们构建了一个逻辑驱动状态机框架。该框架模拟多轮交互循环，迫使智能体通过主动视觉感知和反馈驱动的修正来实现目标。实验结果表明，现有VLM在将语义知识转化为物理执行以及维持长时程状态跟踪方面面临重大挑战。

## Abstract
Recent advancements in Vision-Language Models (VLMs) have demonstrated impressive capabilities in static visual recognition and high-level semantic reasoning. However, current embodied exploration paradigms still heavily rely on imitation learning from human-annotated trajectories, which severely limits agents' generalization ability. The key bottleneck of realizing general autonomous embodied agents lies in Generalizable Visually Grounded Exploration: the ability to operate novel devices without manuals or specific training by actively grounding abstract world knowledge into fine-grained visual affordances. Yet, existing benchmarks fail to evaluate this capability: they generally rely on explicit documents and annotated trajectories, neglecting the dynamic Hypothesis-Interaction-Refinement process essential for functional device operation. To bridge this gap, we introduce VGEBench, a comprehensive benchmark designed to evaluate the generalizable visually grounded exploration capabilities of VLMs. Unlike static datasets, we construct a Logic-Driven State Machine framework. This framework simulates multi-turn interaction loops, compelling agents to achieve goals by active visual perception and feedback-driven correction. Experimental results demonstrate that existing VLMs face significant challenges in translating semantic knowledge into physical execution and maintaining long-horizon state tracking.

- 人类在这种任务中依靠 “**假设 — 交互 — 修正**（Hypothesis-Interaction-Refinement）”这一动态反馈闭环来感知并学会操作未知设备，而现有基准恰恰忽略了这一动态过程，大多依赖显式文档、静态 VQA 式评估或已标注轨迹，无法测出模型在该维度的真实水平。  

**核心挑战**：
1. **知识接地（Knowledge Grounding）**：概括知识映射到未标注的细粒度视觉可供性。  
2. **视觉接地（Visual Grounding）**：超越静态识别，准确定位可交互组件。  
3. **反馈驱动推理（Feedback-Driven Reasoning）**：根据状态变化或失败反馈实时修正动作。

## 2. 方法论与关键技术

**总体框架**：提出了 **VGEBench**，一个基于 **Logic-Driven State Machine（逻辑驱动状态机）** 框架的高保真、多视角、无说明书的动态交互评测系统，旨在模拟真实物理设备操作中的多轮探索闭环。

**发展流程（数据构建的三步管线）**：
- **原始视图收集**：从 Sketchfab 和 3D Warehouse 筛选高质量 3D 模型，每个人工审核，最终收集 968 个设备、26 类，每件采集 8 个多视角视图（6 正交 + 2 轴测），总计 7,888 张。
- **状态机标注与匹配**：
  - 设计每个类别的 **Universal Category State Machine（UCSM）**，作为该类潜在功能的超集；
  - 再基于单件实例可见组件，经人工剪枝生成 **Specific State Machine（SSM）**（如设备缺少充电口，则删除相关状态与转换）；
  - 操作逻辑绑定在组件的原子动作与参数上，组件名称不暴露给模型，避免文字捷径。
- **指令生成**：基于路径搜索，将状态转换序列化作多轮或单轮自然语言指令（由 LLM 负责语义转述）。

**交互与反馈机制**：
- 每一项任务由按序可达的状态序列 G=[g1, g2, ..., gn] 定义；
- 智能体在每步输入当前视图、可访问视图列表、上一步反馈和当前指令；
- 使用层次化验证：先检查视图/坐标合法性，再匹配组件的包围盒、动作类型和参数；
- 反馈分为状态变化成功反馈、操作错误反馈和无效果反馈，对应不同信息量；
- 定义全局交互预算（Global Interaction Budget, Bglobal）与局部交互预算（Local Interaction Budget, Blocal），以控制长程任务成本，允许合理冗余探索（冗余系数λ=5）。

## 6. 主要结论与发现

1. **当前 VLM 在 VGEBench 中整体表现困难**：  
   - 最高的 Gemini-3-Flash 也只有 54.27% SR；其余均低于 25% SSR，很多模型不足 15%；
2. **“一次成功”概率很低**：  
   - 即使是 Gemini-3-Flash，其 PSR 也仅为 12.94%，与其 62.86% 的SSR相比差距明显，说明模型主要依靠反馈修正而非首次准确操作；
3. **延长交互预算带来递减收益**：  
   - 整体上更强的模型更能利用多轮扩展修改，而能力弱的模型会较早在探索中趋于饱和；
4. **瓶颈主要在于细粒度的视觉接地**：  
   - 导航层面模型之间相对差距较小，但在坐标精度（Ang Dist、W-Dist）上差异悬殊；
   - GPT-5-mini 比 Gemini-3-Flash 的坐标误差高 63.9%（Avg Dist）乃至 77.3%（Avg W-Dist）；
   - 视觉扰动实验表明，对高频细节敏感，性能退化尤其明显；
5. **现有 VLM 仍显著落后于人类**：  
   - 人类同条件下的 SR（74.50%）与 SSR（81.43%）远高于 Gemini-3-Flash（56.38% vs.64.32%）；
   - 人类更少触发“坐标无效”类错误，从而获得更多有效反馈；
6. **误差分析显示，细粒度视觉接地错误是主要失败原因**（约占 66.1%），远高于动作执行（17.2%）和视觉导航（16.7%）。
