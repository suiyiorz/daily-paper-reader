## 摘要
视觉-语言-动作（VLA）模型直接将视觉观察和语言指令映射到机器人动作，但长时程任务要求的不仅仅是动作预测。智能体必须在物理状态演化过程中协调感知、规划、执行、进度验证与恢复。单独的动作预测或模型生成的技能决策，其本身并不能保证所提议的操作在当前状态下有效，也不能保证其结果将得到验证。我们提出EmbodiedSkills，一个将每个技能决策视为执行提议的统一框架：运行时在执行前检查其前置条件，并在事后验证结果。一个共享的可执行技能接口将高层技能选择、有界的低层VLA执行和动作后验证连接在单个智能体循环中。由于该接口保持固定，低层VLA策略可以在不改变智能体循环的情况下被替换或调整。该接口还将规划、执行、验证和恢复事件记录为结构化轨迹，为各个组件提供监督，并可在有交互反馈时支持可选的在线适应。我们在RoboTwin 2.0和LIBERO上使用Qwen3-VL和OpenPI/pi0.5实例化了EmbodiedSkills。任务自适应的低层VLA策略在50个RoboTwin 2.0任务上实现了86.20%的平均成功率，在四个LIBERO套件上实现了97.40%的平均成功率。这些结果确立了EmbodiedSkills中所使用的任务自适应低层VLA策略的执行性能。在四个依赖记忆的RMBench任务上，相同的任务自适应执行方法实现了12.5%的平均成功率。该框架提供了一个可训练且可检查的智能体层，用于将这些策略转化为闭环具身系统。

## Abstract
Vision-language-action (VLA) models map visual observations and language instructions directly to robot actions, but long-horizon tasks require more than action prediction. An agent must coordinate perception, planning, execution, progress verification, and recovery as the physical state evolves. An action prediction or a model-generated skill decision does not, by itself, guarantee that the proposed operation is valid in the current state or that its outcome will be verified. We propose EmbodiedSkills, a unified framework that treats each skill decision as an execution proposal: the runtime checks its prerequisites before execution and verifies the outcome afterward. A shared executable-skill interface connects high-level skill selection, bounded low-level VLA execution, and post-action verification within a single agent loop. Because this interface remains fixed, low-level VLA policies can be replaced or adapted without changing the agent loop. The interface also records planning, execution, verification, and recovery events as structured trajectories, which provide supervision for individual components and can support optional online adaptation when interactive feedback is available. We instantiate EmbodiedSkills with Qwen3-VL and OpenPI/pi0.5 on RoboTwin 2.0 and LIBERO. Task-adapted low-level VLA policies achieve an average success rate of 86.20% across 50 RoboTwin 2.0 tasks and 97.40% across the four LIBERO suites. These results establish the execution performance of the task-adapted low-level VLA policies used in EmbodiedSkills. On four memory-dependent RMBench tasks, the same task-adapted execution approach achieves 12.5% average success. The framework provides a trainable and inspectable agent layer for turning these policies into closed-loop embodied systems.

- 论文提出 **EmbodiedSkills**，旨在搭建 **“模型级决策”**和 **“物理世界执行”** 之间的桥梁，将 VLA 策略转化为真正的闭环具身系统，打破“直接预测动作”与“单纯高层规划”之间的割裂。

## 2. 论文提出的方法论

**核心思想：**

- **技能即执行提议（Skill as Execution Proposal）**：将每个技能决策视为一个“待执行的提案”，运行时（Runtime）在动作执行前检查其前置条件（Prerequisites），执行后验证结果（Outcome），杜绝无效决策被静默执行。
- **策略-运行时分离（Policy-Runtime Separation）**：高层策略（Policy）只负责“提议（Propose）”，即输出结构化的技能调用；而守护运行时（Guarded Runtime）负责“强制（Enforce）”，即校验状态转移的合法性。

**关键技术细节与核心概念：**

- **Agent 状态与上下文**：
  - 方法级状态定义为 `st = (zt, Mt, Ht)`，其中 `zt`为当前阶段（Phase），`Mt`为任务产物集合（Artifacts），`Ht`为有序的循环轨迹（Loop Trace）。
  - 策略接收紧凑上下文 `Ct = Ψ(x, zt, Mt, Ht)`，通过预算机制保留完整计划、活跃子目标及近期摘要。
- **六大阶段（Phase-Structured Skill Space）**：
  - `Z = (Observe, Plan, Preflight, Execute, Verify, Recover)`。
  - 这不是固定流水线，阶段可依据证词（Evidence）循环跳转。
- **决策控制类型**：
  - `dt ∈ { RunSkill(k, q), AdvanceStage, FinishRun }`。
  - 技能执行、阶段推进、任务终止共享统一决策接口。
- **执行契约（Skill Contract）**：
  - 每个技能定义为 `k = (Xk, Yk, pre_k, exec_k, post_k, fail_k)`，包含类型化输入输出、前置条件、状态更新逻辑与失败映射。
  - 产物携带来源与新鲜度信息，确保过时证据不会被静默复用。
- **有界动作执行（Bounded Action Execution）**：
  - 低层 VLA 策略将活跃子目标（`gt`）、当前图像（`Ot`）、机器人状态等映射为有界动作块 `at = (τt, Ut, Ht, ηt)`。
  - 运行时通过检查动作块的天花板长度 `0 < H_t ≤ H_max`、数值有效性、上下文一致性来判断是否接受。
- **验证与恢复（Verification & Recovery）**：
  - 验证路由集合为 `V = {Advance, Continue, Reobserve, Replan, Recover, Finish}`，决定是前进、重试还是重新规划。
- **GUARDED RUNTIME（公式核心逻辑）**：
  - 守卫函数对技能提案进行拦截：`G_skill = 1[...] * 1[阶段匹配] * ∏ 1[前置条件满足]`。
  - 阶段推进需满足当前阶段产生了继任者所需的证据（`G_advance`）。
  - 状态更新遵循 `s_{t+1} = U(...) / N(...) / F(...) / B(...)`，分别对应记录操作结果、推进循环、终止循环、记录被拦截决策。
- **训练范式**：
  - **组件级监督（Component-Level Supervision）**：分别训练规划器、调度器（基于轨迹监督）；低层 VLA 策略通过**子任务级演示**（Subtask-level Demonstrations）进行微调，保持其冻结，以隔离训练过程。
  - **部署一致训练样本**：训练样本采用与部署时完全相同的上下文输入（如公式 15），避免训练测试偏差。
  - **可选的在线适应**：支持基于群组相对策略优化（如公式 17-18），利用交互反馈优化高层决策，但不作为主推训练机制。

## 7. 优点

- **模块化与可组合性**：以固定接口连接规划、验证与动作生成组件，在不打乱已有的算法逻辑的情况下，可独立优化单个模块。
- **闭环保真（闭环性）**：通过前置检验和事后验证，阻断了未经验证的动作，大大增强了系统的鲁棒性。

- **语义不确定性**：即使行动在物理上

- **语义不确定性**：即使行动在物理上成功，语义层的“成功判定”仍依赖预定义的验证函数；对于需要细粒度物理交互（如柔性物体操作、接触力控制）的任务，图像级或状态级验证难以捕捉细微的成功标准。

- **长时程任务的“隐藏代价”未被量化**：虽然成功率提升了，但缺少对时间开销、Token 消耗、重试次数的统计。对于需要在有限时间内完成的任务，多轮 VLM 验证与重规划可能使系统无法满足实时性要求。

- **真实世界（Real-World）部署证据缺失**：所有评估均在模拟环境中完成，缺少对真实机器人硬件上的泛化性与鲁棒性测试。模拟中的“干净”感知输入与真实场景中的光照变化、遮挡、动态干扰存在显著差距。

- **高层组件依赖基础 LLM 能力**：规划器与调度器基于 Qwen3-VL，其决策质量受限于底层模型的推理能力与上下文长度处理能力；在极长任务（如数百步）中，预算机制（压缩与摘要）可能导致关键信息丢失。

- **缺乏对失败模式的结构化分类统计**：虽然框架具备可诊断性，但论文未系统性地给出各阶段（Plan/Execute/Verify）失败占比的统计表格，读者难以量化判断“到底是哪个模块贡献了最多失败”。

## 9. 对领域与未来工作的启示

**领域定位**：

- EmbodiedSkills 可视为一种 **“面向 VLA 智能体的软件工程范式”**——它不追求用一个更大的端到端模型解决一切，而是承认“决策模型 + 执行模型”各有局限，通过显式的运行时守护层来兜底。这为具身智能研究提供了端到端范式之外的一种互补路线。

**对未来工作的启发**：

1. **自动化验证器学习**：如何自动学习或合成后置条件验证器（而非手工预定义），是框架从模拟走向真实世界的关键。
2. **统一接口标准化**：若能进一步将 Skill Contract 的接口标准化为社区通用协议，则可实现不同实验室的 VLA 模型与规划器之间的即插即用。
3. **在线适应机制深化**：论文虽提出了可选的在线优化公式（GRPO-based），但并未做系统实验，未来工作可探索如何在部署中持续改进规划器而不遗忘旧技能。
4. **跨 Embodiment 的验证迁移**：同一技能契约能否在机械臂、人形机器人、移动操作平台之间共用验证逻辑，值得进一步探索。
5. **延迟与成功率的多目标优化**：在保证成功率的同时，如何权衡验证频率（多大粒度做一次验证）与任务完成时长，是一个有趣的优化主题。

## 10. 个人综合评价

**总体判定**：这是一篇工程完成度高、实验体量大、框架设计严谨的系统论文。其核心思想——用结构化技能契约 + 运行时守护来解决 VLA 在长时程任务中的不可靠性——具有清晰的实用价值，在 RoboTwin、LIBERO、RMBench 三个基准上均取得了优于参考基线的结果，消融实验有力地支撑了各模块的必要性。

**核心亮点再聚焦**：论文最值钱的观点不是某个模型，而是 **“验证本身就是决策的一部分”** 。它把机器人系统中长期存在但 Often overlooked 的“这个动作到底做没做成”的问题，提升为一等公民（First-class Citizen），并通过结构与训练手段将其制度化。这一点无论在学术还是工程上都具有很强的借鉴意义。

**最大疑虑**：论文与现有 VLA 主流的“scaling law”叙事背道而驰，走的是“结构化组合 + 显式状态机”的经典机器人路线。这种路线在模拟环境（状态可精确获取）中优势明显，但真实世界中的状态估计与验证函数天然带噪，其优势能否保持是个未解问题。因此，该工作的下一步生死线在于**验证模块在真实环境中的可靠性**。

**可复现性预期**：论文框架高度依赖自定义的运行时实现与任务特定的验证函数。由于论文正文给出了完整的符号定义与算法逻辑，理论上可复现框架骨架；但复制出论文中的精确数值结果需要大量工程细节（提示词模板、验证函数阈值、超参数等），建议读者优先关注其方法论思想，而非具体数字。

---

**一句话总结**：EmbodiedSkills 用一套精心设计的“技能契约 + 守卫运行时”体系，为 VLA 智能体在长时程任务中装上了“事前检查和事后验收”的双重保险，是端到端路线之外一个极具工程参考价值的系统级方案。
