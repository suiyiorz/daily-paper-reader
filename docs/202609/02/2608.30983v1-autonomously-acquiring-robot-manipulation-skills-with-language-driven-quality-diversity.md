## 摘要
质量-多样性（QD）算法在机器人学习中日益受到关注，其中多样化的运动基元库使机器人能够在部署时零样本适应约束条件。然而，此类方法通常需要专家设计者编写成功条件、适应度和多样性指标，这严重限制了机器人的自主性。另一方面，现有的基于大语言模型（LLM）的奖励塑形技术允许机器人自主学习，但仅输出单个高性能解决方案，限制了机器人的适应性。在本文中，我们提出了一种方法，通过自主利用质量-多样性算法来输出多样化的运动基元库，仅需任务的自然语言自由形式描述。为了解决设计相关适应度和多样性指标的难点，我们提出了一种自主探索机制，能够可靠地输出覆盖适应度和行为描述符（BD）空间的函数集。首先，我们将策略探索构建为函数设计问题，其中函数空间比完整的BD和适应度空间维数更低，并提出一种基于LLM的探索方案，无需任何任务特定提示、微调或专家干预即可从这些低维空间采样。我们改进了MAP-Elites成功（MES）算法的多BD变体，旨在利用异构的BD样本。最后，通过基于genesis模拟器的实验，我们展示了我们的方法能有效地生成多样化的运动基元库，在4个机器人操作任务上优于使用推断和手写参数化的经典QD算法。

## Abstract
Quality-diversity (QD) algorithms have been gaining traction in robot learning, where diverse motion primitive libraries allow robots to adapt zero-shot to constraints at deployment time. However, such methods typically require expert designers to write the success condition, fitness and diversity metrics, and this strongly limits the robot's autonomy. On the other hand, existing LLM-based reward-shaping techniques allow robots to learn autonomously but only output single high-performing solutions, limiting the robot's adaptability. In this paper, we propose an approach designed to output diverse motion primitive archives by autonomously leveraging quality-diversity algorithms, only requiring a free-form description of the task in common language. To address the difficulty of designing relevant fitness and diversity metrics, we propose an autonomous exploration mechanism able to reliably output sets of functionals covering the fitness and behavior descriptor (BD) space. First, we pose policy exploration as a functional design problem, where the functional spaces are lower-dimensional than the full BD and fitness spaces, and propose an LLM-based exploration scheme to sample from these low-dimensional spaces without any task-specific prompts, fine-tuning or expert intervention. We adapt a multi-BD variant of the MAP-Elites success (MES) algorithm, designed to leverage the heterogeneous BD samples. Finally, through experiments based on the genesis simulator, we show that our method effectively generates archives of diverse motion primitives, outperforming classical QD algorithms with inferred and hand-written parametrizations on a set of $4$ robotic manipulation tasks.

## 2. 提出的方法论

**核心思想**：将 QD 算法的参数化问题看成低维“功能性空间”上的设计问题，并利用 LLM 对该空间进行零样本、无需专家干预的探索；随后用带有多行为描述符网格的 MAP-Elites Success（MES）变体来训练并产出多样化的技能档案。

**关键技术细节**：

- 问题形式化：假定任务 $t$ 已知，而任务实例分布 $T$ 未知。目标是求得一个动作原始技能档案 $A^*$，使该档案对给定任务所有可能实例的成功概率最大化（即文中公式（1））；与“求单个最优动作”相比，该方法直接生成包含多种方案的档案（archive）。
- 成功条件推断：由于成功条件很关键但设计门槛相对较低，任务只需使用一次 LLM 推断单个成功条件函数。
- 适应度函数推断：假设适应度可表达为逐时间步数值的均值，为此 LLM 一次性采样三个候选适应度信号（不放回，以减少重复并扩大覆盖）。
- BD 空间分解：BD 函数空间很大，直接让 LLM 推断理想的 BD 既困难又缺乏可解释性。本文将 BD 分解为两个较低维函数空间的组合：
  - $h$：确定从模拟中取出信息的时间点（如首次接触、仿真结束等），以生成 “时间戳” 函数集；
  - $g$：确定在该时间点要读取的身体/场景物理量（如夹爪位置、目标物位置等）以形成“信息提取”函数；
  - 对两个空间分别进行采样，再将二者组合成“BD mesh”（如 $g_k \circ h_j$ 的笛卡尔组合）。
- 多 BD 的 MES 算法：对每个 BD 单独维护一个 MAP-Elites 网格，每次评估结果都会插入所有网格；选择阶段从各网格中选出个体，并拼接列表再变异，使不同 BD 能引导不同方向的进化。文中把整套网格集合称为 multi-BD archives。
- Fitness 挑选机制：先用三个已推断适应度分别训练一小段时间，每个都配合完整的 BD mesh 建立多 BD 档案；比较“成功个体总数”，挑最多成功个体的适应度继续生成最终档案。
- 整体流程（Algorithm 1）：包括四步，
  1. 推断成功条件、适应度、时间戳与 BD 网格；
  2. 分别用各适应度进行短训练（Multi-BD MES）探索；
  3. 根据各候选档案中的成功个体数量选择最优适应度；
  4. 用该适应度进行完整训练输出最终动作档案。

- 任务范围应从“单阶段、刚性物体、末端位置控制”扩展到多阶段任务（如开抽屉后取出物体）、可变形物体（布料）以及自由文本中隐含的约束（如“用左手”“不超过施加力 10N”）。这也需要 LLM 在推断 BD 时同步考虑约束信息，而不仅仅是成功条件。
- 可引入“情境化多 BD”：即根据任务描述动态地挑选或重新组合时间戳与物理量的网格结构，甚至让 LLM 在训练过程中根据早期搜索反馈做二次修正，使 LLM 的离线先验与 QD 的在线演化反馈形成闭环。
- 为提高 sim2real 的可迁移性，结合域随机化是可行的方向：在 MES 评估阶段随机化物体质量、摩擦系数、视觉外观、位姿噪声等，并验证所得档案在不同物理参数下的零样本覆盖表现；同时可训练一个“档案选择策略”，根据真实实例的观测选择档案中最合适的原始技能执行。
- 与奖励塑形类强化学习方法相比，本工作提供了一种新的范式：LLM 给出“如何描述多样性”而非“如何做动作”，相当于将 LLM 从“最优策略生成器”转变为“搜索空间设计器”。未来可进一步研究基于 LLM 的搜索空间设计（不只 BD，还包括动作参数化、约束函数、甚至变异策略符号化）在更宽泛的机器人任务中的通用性。
- 在 QD 算法层面，多 BD 网格的维护方式仍比较朴素（每个 BD 独立 MAP-Elites 且选择时均等拼接）。可探索自适应权重、按网格密度分配选择压力、或在 BD 之间共享/迁移精英等更高效的协同机制，以同时提高覆盖率和训练稳定性。
- 需要建立更标准化的评估协议：除成功数与 GT BD 覆盖外，建议加入多样性的均匀性（如可对 GT BD 空间求熵）、轨迹的自然度/能量消耗、以及在不可见实例上的成功率等综合指标，并明确报告所需的仿真环境与 GPU 算力基线，提升结果可比性。

## 10. 总体评价

该文提出了一种将 LLM 用于自动设计 MAP-Elites 算法参数（成功条件、适应度、行为描述符）的新框架，并把传统 QD 的单一 BD 网格拓展为多 BD 网格，从而让仅以自然语言任务描述为输入即可生成多样的机器人操作技能档案。该思路在“语义理解—多样化搜索”这一交叉口上具有明显的创新价值和广泛的后续发展空间。实验覆盖了四个不同难度的单步操作任务，相对手写专家 QD 与 LLM 直接推断基线均展示了显著性能优势，特别是在成功个体数量与功能多样性（GT BD 覆盖数）两个维度上。局限主要存在于任务复杂度有限、过程方差偏大、未进行真实机器人验证以及缺少算力/消融细节等方面。整体上，该工作为后续“用语言模型指导进化搜索空间设计”提供了坚实的实证基础和清晰的实现范式，虽然距离完全自主的通用机器人技能获取仍有很大距离，但其研究方向值得持续深入。
