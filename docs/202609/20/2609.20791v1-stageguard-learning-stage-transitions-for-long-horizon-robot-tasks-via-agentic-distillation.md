## 摘要
分层规划框架通过组合来自多个机器人控制策略的技能来执行长时程任务，其中确定何时终止当前技能并推进到下一子任务至关重要。现有方法通常依赖预先设计的完成信号检测器，而这些检测器在真实世界执行中难以获取。大规模视觉语言模型（VLM）具备强大的推理能力，但其决策边界并非天然与任务完成标准对齐；同时，云端部署与冗长的推理过程会带来显著延迟，限制了实时监控。我们提出 StageGuard，一种用于实现准确且高效阶段转换决策的智能体蒸馏框架。StageGuard 将教师模型的推理与演示轨迹相结合，生成关于子任务完成与策略切换的结构化解释。轻量级学生 VLM 利用这些解释生成紧凑的自我解释，并用于监督微调。我们在两个基准的轨迹上评估阶段转换预测，并通过将其集成到 BEHAVIOR-1K 上的分层机器人控制中评估闭环任务成功率，同时在真实机器人上进一步验证。结果表明，该方法在阶段转换预测方面取得显著提升，同时支持高效的在线监控。

## Abstract
Hierarchical planning frameworks combine skills from multiple robot control policies for long-horizon task execution, where determining when to terminate the current skill and advance to the next subtask is essential. Existing approaches often rely on pre-designed completion signal checkers that are hard to obtain in real-world execution. Large-scale vision-language models (VLMs) offer strong reasoning capabilities, but their decision boundaries are not inherently aligned with task completion criteria, while cloud deployment and lengthy reasoning introduce substantial latency, limiting real-time monitoring. We propose StageGuard, an agentic distillation framework for accurate and efficient stage-transition decisions. StageGuard combines teacher-model reasoning with demonstration trajectories to generate structured explanations of subtask completion and policy switching. A lightweight student VLM uses these explanations to generate compact self-explanations, which are used for supervised fine-tuning. We evaluate stage-transition prediction on trajectories from two benchmarks and assess closed-loop task success through integration into hierarchical robot control on BEHAVIOR-1K, with further validation on real robots. Results show substantial improvements in stage-transition prediction while supporting efficient online monitoring.

- **任务背景**：长时程机器人任务通常采用分层规划框架，将高层目标分解为子任务，并调用多个机器人控制策略（skill / policy）依次执行。在这一范式下，**"何时终止当前技能、推进到下一子任务"** 成为关键瓶颈——过早切换会使前置条件未满足，延迟切换则引入延迟或破坏已达成状态，且错误会沿后续子任务级联传播。
- **现有做法的困难**：
  - 传统方法依赖**预定义的技能终止条件**或**仿真器特权信号**，但这些信号在真实世界执行中难以获得，对学习到的策略更难人为规定。
  - 大规模 VLM 具备视觉理解与推理能力，但直接用作执行监控器存在两个问题：① **决策边界与子任务完成标准不对齐**，看似合理的场景解释可能得出错误的切换判断；② **云端部署 + 长链推理带来高延迟**，限制在线监控频率。
- **关键洞察**：演示轨迹本身标注了子任务何时完成，但仅有转换标签无法解释"为何此刻切换"的视觉证据与任务依赖关系。因此需要**显式地把观测与任务上下文连接到完成/切换的决策边界**上。
- **整体含义**：论文提出 StageGuard，用"教师智能体推理 → 轻量学生自解释蒸馏"的方式，把演示中隐含的阶段边界知识迁移给一个小型 VLM，使其成为**既准确又低延迟**的执行监控器，从而真正释放分层规划框架的性能。

## 2. 方法论

### 2.1 问题形式化

- 机器人在任务计划 $P$ 下执行目标 $g$。第 $t$ 轮监控输入为 $x_t=(g, u_t, o_t, h_{t-1}, P)$，其中 $u_t$ 为当前自然语言子任务、$o_t$ 为当前观测、$h_{t-1}$ 为语义历史。
- 决策空间 $\mathcal{A}=\{\text{continue}, \text{advance}, \text{skip}\}$，分别表示保持当前子任务、推进、跳过（不可恢复失败）。
- 结构化输出 $y_t=(d_t, v_t, h_t)$，$v_t$ 为下一子任务规格，$h_t$ 为更新后的语义历史。
- 演示数据 $\mathcal{D}=\{(g_i,P_i,\tau_i)\}$，轨迹 $\tau_i=\{(o_{i,t},u_{i,t},d^\star_{i,t},v^\star_{i,t})\}$，上标 $\star$ 表示真值。
- 目标：用教师 $M_T$ 的推理构造训练语料 $\mathcal{C}=\{(x_{i,t}, r^S_{i,t}, y_{i,t})\}$，微调轻量学生 $M_\theta$ 得到监控器 $M^{FT}_\theta$，使其在低延迟下预测与演示边界对齐的 $d_t$ 与 $v_t$。

### 2.2 多层智能体推理（Multi-Layer Agentic Reasoning）

教师推理被组织为三个层次，每层由角色专用 prompt 实例化的多个智能体构成，输出拼成教师推理轨迹 $r^T_t$：

- **状态层（State Layer）**：四个智能体带显式信息依赖。
  - 历史观测智能体：从 $h_{t-1}$ 提取相关变化与既往执行事件；
  - 机器人状态智能体：从 $o_t$ 描述机器人构型与夹爪状态；
  - 物体空间关系智能体：结合上述输出与 $o_t$ 分析物体与目标区域间关系；
  - 机器人–物体关系智能体：综合前两者识别抓取、持握、释放等交互。
  - 四者输出汇总后送入任务层，提供历史上下文与当前物理证据。
- **任务层（Task Layer）**：**不接触真值**，独立推导决策与理由。
  - 任务计划智能体：在 $P$ 中定位当前子任务，识别其依赖与预期后继；
  - 子任务理由智能体：解释当前子任务对 $g$ 的贡献并给出完成条件；
  - 决策理由智能体：结合状态证据推断 continue / advance / skip 并解释依据。
- **决策层（Decision Layer）**：用真值标注对任务层推理进行校验。
  - 进度智能体：将"已完成控制帧 / 子任务总控制帧"的比例分桶为语义进度阶段（starting、early、middle、later、completing），提供辅助监督；
  - 下一步智能体：校验任务层预测的后继是否与 $v^\star_t$ 一致并解释偏差；
  - 决策对比智能体：将初始监控决策与 $d^\star_t$ 对比，一致时说明支撑证据，不一致时指出错误推理并论证标注决策。
- **注意**：真值标注仅在**语料构建阶段**使用，学生推理时不依赖真值。

### 2.3 Learning by Explanation（基于解释的学习）

直接让学生模仿完整教师 CoT 有两个问题：长轨迹增加训练与推理成本；教师的推理结构与细节粒度超出学生可稳定复现的能力（消融实验证实：全 CoT 训练在简单任务尚可，在困难任务上较差）。因此设计三步流程：

- **学生自解释**：给定 $x_t$、教师轨迹 $r^T_t$ 与目标 $y_t$，提示初始学生 $M_\theta$ 用自己的语言解释监控决策，产出紧凑轨迹 $r^S_t$，保留决定性观测证据、相关完成/失败条件、以及决策与下一任务的依据。教师推理只作为"解释性上下文"，学生可改写为自己更易表达与学习的推理模式。
- **紧凑 CoT 质量监控**：对学生并行推理生成**多个候选**（论文中为 3 个），再用教师 $M_T$ 作为**评判者**挑选一个 $r^S_t$。评判标准为：是否扎根于 $x_t$、是否保留 $r^T_t$ 中与决策相关的推理、是否能一致地支撑 $d^\star_t$ 与 $v^\star_t$；在保留必要证据的前提下避免冗余细节。被选中的解释与结构化目标共同构成训练语料 $\mathcal{C}$。
- **加权监督微调**：令 $z=(r^S, y)$ 为串联序列，$z_\ell$ 为第 $\ell$ 个 token，目标函数为加权自回归语言建模：
  $$L_{\text{SFT}}(\theta)=-\mathbb{E}_{(x,r^S,y)\sim\mathcal{C}}\left[\sum_{\ell=1}^{|z|} w_\ell \log p_\theta(z_\ell \mid x, z_{<\ell})\right]$$
  其中 $w_\ell=\lambda$（当 $z_\ell$ 属于 $r^S$）或 $1$（当 $z_\ell$ 属于 $y$），超参 $\lambda>0$ 调节"解释学习"与"结构化输出监督"的相对权重。训练完成后，监控器 $M^{FT}_\theta$ 仅从 $x_t$ 直接生成紧凑推理与监控输出，并把更新后的 $h_t$ 带入下一轮；教师推理与并行质量监控**只在训练数据构建阶段需要**。

## 3. 实验设计

### 3.1 数据集与场景

- **LIBERO-Logic**：在标准 LIBERO 基础上增加真值子任务分割与状态转换标注；桌面短时程操作，工作空间受限，用于研究受约束场景下的阶段转换监控。
- **BEHAVIOR-1K**：家庭移动操作任务，含真值子任务分割与状态转换标注；因算力限制**仅选取 6 个任务**（打开收音机、捡垃圾、搬箱入库、安装调制解调器、收集易拉罐、安装扫描仪）。任务包含导航、物体搜索与操作，时程更长，视角与背景变化大，对 VLM 极具挑战。
- **数据划分**：每个任务用 **10 条轨迹**训练，其余轨迹用于评估。
- **真实机器人**：UR5e 单臂（开抽屉、把盘子从架子上转移到柜中、关抽屉）与 Piper 臂（更灵巧：抓取盘子并插入架子），每个子任务采集 50 条演示。

### 3.4 实现配置

- 教师 $M_T$：Qwen3.5-397B-A17B；学生 $M_\theta$：Qwen3.5-0.8B。
- 每个训练样本并行生成 3 个紧凑 CoT 候选，教师评判选 1 个。
