## 摘要
视觉-语言-动作模型的最新进展激发了人们对水下具身智能日益增长的兴趣。然而，它们对大规模交互数据的依赖限制了其在水下的适用性，因为水下数据采集成本高昂且十分稀缺。为应对这一挑战，我们提出了 AquaCap，一个无需训练的 Code-as-Policy 框架，用于自主水下导航与操作。AquaCap 采用双层智能体，将任务指令和环境观测转化为条件感知的规划和可执行的控制程序。随后，结构化感知为智能体在水下退化条件下提供语义、几何和可靠性感知的观测。故障感知记忆可诊断不成功的动作，并支持闭环重规划和代码修正。该设计无需任务特定训练或参数更新即可实现在线自适应。AquaCap 在仿真中达到了 66.43% 的成功率。真实世界实验进一步展示了 ROV 的自主抓取和物体运输，包括对受水动力扰动而移位目标的操控。

## Abstract
Recent advances in vision-language-action models have stimulated growing interest in underwater embodied intelligence. However, their reliance on large-scale interaction data limits their applicability underwater, where data collection is costly and scarce. To address this challenge, we present AquaCap, a training-free Code-as-Policy framework for autonomous underwater navigation and manipulation. AquaCap employs a dual-layer agent that translates task instructions and environmental observations into condition-aware plans and executable control programs. Structured perception then provides the agent with semantic, geometric, and reliability-aware observations under degraded underwater conditions. A failure-aware memory diagnoses unsuccessful actions and supports closed-loop replanning and code revision. This design enables online adaptation without task-specific training or parameter updates. AquaCap achieves a 66.43% success rate in simulation. Real-world experiments further demonstrate autonomous grasping and object transport with an ROV, including the manipulation of targets displaced by hydrodynamic disturbances.

## 二、论文提出的方法论

### 核心思想
- 使用 **Code-as-Policy** 替代数据密集型 VLA 策略：由 LLM 在运行时生成 Python 控制程序。
- 采用 **双层智能体**：
  - **Policy Agent**：负责任务分解、规划与重规划；
  - **Coding Agent**：负责当前动作的可执行代码生成与局部修复。
- 引入 **结构化感知** 和 **失败感知记忆**，使系统在水下退化观测和动态扰动下仍能闭环执行。

### 关键技术细节

#### 1. AquaCap-Agent：双层闭环 Code-as-Policy
- 输入：任务指令 \(l\)、结构化观测 \(o\)。
- Policy 生成有序计划 \(\Pi\)，每个动作包含：
  - 目标；
  - 前置条件；
  - 后置条件；
  - 时间预算。
- 执行循环：
  1. 取当前动作 \(A\)，调用 Perception 获取观测 \(o\)；
  2. 检查传感器有效性和前置条件；
  3. 检索 Memory 中的修正 \(h\)；
  4. Coding 结合动作、观测、API 文档和修正生成 Python 程序；
  5. 静态验证语法与 API 使用，沙箱执行并限制运动、权限和时间；
  6. 执行后再次 Perception，验证实际物理结果；
  7. 验证通过则推进计划，否则进入恢复：
     - 若可局部修复且重写预算允许，保留动作目标，修改代码；
     - 否则 Policy 根据失败证据和 Memory 重规划剩余任务；
  8. 传感器故障、不可恢复故障、时间/恢复预算耗尽则停止。
- 关键设计：**程序执行完成不等于目标达成**，必须用新观测验证后置条件和下一动作前置条件。

#### 2. AquaCap-Perception：结构化水下感知
- 分为语义目标识别和近场几何估计。
- **语义目标识别**：
  - VLM 根据指令和 RGB 图像识别目标；
  - 提示 SAM3 分割目标，得到掩码、可见性和置信度。
- **近场几何估计**：
  - 腕部深度图中的局部表面凸起提供互补掩码；
  - 对选中掩码 \(M\)，有效像素集合 \(\Omega_M\) 通过深度和相机内参反投影为点云：
    \[
    P_0=\{D(u)K^{-1}\tilde u \mid u\in\Omega_M,\ \tilde u=(u_x,u_y,1)^\top\}
    \]
  - 深度滤波和离群点去除后得到观测点 \(P=\{p_j\}\)；
  - 对圆柱类目标，用 PCA 初始化中心和主轴；
  - 用 ICP 将参考模型点 \(Q=\{q_k\}\) 对齐到观测点，最小化：
    \[
    (\hat R,\hat t)=\arg\min_{R\in SO(3),t\in\mathbb R^3}\sum_{j\in I}\|p_j-Rq_{c(j)}-t\|_2^2
    \]
  - 将相机系位姿变换到机器人基座系：
    \[
    \hat T_{BO}=T_{BC}\hat T_{CO}
    \]
  - 输出目标位置和主轴；圆柱绕对称轴的旋转不可观测；
  - 根据收敛性、拟合质量、可见范围、掩码大小和轴向判断是否接受估计。
- Policy 和 Coding 只接收结构化字段，如目标身份、距离、几何质量、相机状态、夹爪状态，不直接接收原始图像。

#### 3. AquaCap-Memory：失败感知记忆
- 每个 trial 开始时 Memory 为空，不更新模型参数。
- 每条记录关联：
  - 动作与场景描述；
  - 执行结果与证据；
  - 失败原因诊断；
  - 建议修正。
- 检索依据：任务、当前动作、初始场景描述符。
- 检索结果分别用于：
  - 给 Policy 提供规划建议；
  - 给 Coding 提供实现约束。
- 例如失败抓取可提示 Policy 重新对齐，提示 Coding 降低接近速度或调整夹爪闭合程度。
- 修正仅在同一 episode 内复用，当前观测仍决定目标几何并验证结果。
