## 摘要
基于视觉-语言-动作（VLA）策略的长时间跨度的机器人操作仍然易受执行时偏差的影响，这是因为最终任务成功与否为诊断和纠正由动作噪声、物体位移或目标未对齐所引发的故障提供的信息极少。我们提出了一种阶段感知的失败验证与提示恢复框架，该框架能够在无需参数更新或特权模拟器状态的情况下，实现对固定VLA策略的闭环校正。该框架引入了一个基于可观测历史的学习型验证器，通过时序建模多视角视觉观测、本体感觉状态及已执行动作，联合估计操作进度和执行风险。为提供可解释的任务理解，我们用语义进度阶段来表征操作执行过程，包括接近、对齐、抓取、搬运和放置，并识别各阶段特有的失败模式。当检测到异常执行时，该框架保留原始指令，并生成阶段条件的恢复提示，使同一冻结的VLA策略能够产生纠错动作。在LIBERO和LIBERO Plus上进行的大量多轮评估表明，所提出的方法在多种扰动下显著提升了闭环可靠性。在无法获得特权物体或目标坐标的情况下，在所评估的场景中，学习型验证器的恢复性能接近基于特权的规则验证器。这些结果表明，可观测的视觉-本体感觉-动作历史足以推断潜在的任务状态，并为现有VLA策略实现实用的故障恢复。

## Abstract
Long-horizon robot manipulation with Vision-Language-Action (VLA) policies remains vulnerable to execution-time deviations, as final task success provides little information for diagnosing and correcting failures caused by action noise, object displacement, or goal misalignment. We introduce a stage-aware failure verification and Prompt Recovery framework that enables closed-loop correction of a fixed VLA policy without parameter updates or privileged simulator states. The framework introduces an observable-history-based Learned Verifier that jointly estimates manipulation progress and execution risk by temporally modeling multi-view visual observations, proprioceptive states, and executed actions. To provide interpretable task understanding, we represent manipulation execution through semantic progress stages, including approach, alignment, grasp, transport, and placement, and identify stage-specific failure patterns. Upon detecting abnormal execution, the framework preserves the original instruction and generates a stage-conditioned recovery prompt, allowing the same frozen VLA policy to produce corrective actions. Extensive multi-round evaluations on LIBERO and LIBERO Plus demonstrate that the proposed approach substantially improves closed-loop reliability under diverse perturbations. Without access to privileged object or goal coordinates, the Learned Verifier achieves recovery performance close to that of the privileged rule-based verifier in the evaluated settings. These results show that observable visual-proprioceptive-action history is sufficient to infer latent task states and enable practical failure recovery for existing VLA policies.

# VLA-Corrector 论文总结

## 1. 论文的核心问题与整体含义

- **核心问题**：基于视觉-语言-动作（VLA）策略的长时间跨度机器人操作极易受执行偏差影响——动作噪声、物体位移、目标区域偏移等扰动会使本应合理的轨迹逐步偏离预期，而**最终任务成功信号无法为中途故障提供诊断与纠正信息**。VLA 系统能够根据指令生成行动，但缺少对"自己是否在执行中犯错"的自我监控能力，即作者所称的 **执行状态理解缺失**。
- **研究动机**：现实操作中的失败主要源于交互过程中的累积执行偏差，而非任务理解的错误。对于长时程任务，若策略对异常执行状态无感知并持续执行，往往丧失了自主恢复所需的时序余量。生物智能体通过持续性自我监控来规避这类问题，这提示执行状态感知是稳健具身智能的关键支柱。
- **研究问题**：能否仅凭**可观测交互历史**推断智能体自身的执行状态（阶段与风险），并在**不修改底层策略、不访问特权环境信息**的前提下提升闭环可靠性？
- **整体含义**：作者提出了 **VLA-Corrector** 框架——一种轻量级的"验证-恢复"解耦方案，用学习式验证器做在线监控、用提示工程驱动冻结的 VLA 策略去自我纠错，为现有 VLA 策略赋予无需参数更新的闭环恢复能力。

## 2. 论文提出的方法论

**核心思想**：将 VLA 的**动作生成能力**与**执行监控能力**解耦——冻结的 VLA 策略只负责产出动作，而一个独立的验证器负责监控执行状态，在检测到异常时通过阶段感知的恢复提示引导同一策略进入纠错模式。该方法既不需要微调策略参数、也不需要训练额外的动作头或特权状态输入。

**关键技术细节**：

- **可观测历史建模**：验证器的输入为时序历史 $h_t$，其中每一步包含：
  - 双视角 RGB 图像（agent 视角与 wrist 视角）；
  - 8 维可观测本体感觉状态向量 $s_t$；
  - 7 维实际执行动作 $u_t$。

- **执行阶段表示**：将操作过程划分为五个非终止语义阶段——**接近（APPROACH）、对齐（ALIGN）、抓取（GRASP）、搬运（MOVE）、放置（PLACE）**，终态 SUCCESS 由环境判定，不纳入阶段分类。

- **判定公式化**：验证器输出两个预测头：
  - **风险头**：$p_t = \Pr(f_t = 1|h_t)$，估计窗口内发生教师定义失败事件的概率；
  - **阶段头**：$\hat{c}_t = \arg\max_c \mathrm{Softmax}(W_{\text{stage}} z_t + b_{\text{stage}})$，路由恢复提示类别。

- **网络结构**：轻量 GRU 时序模型，具体为：
  - 视觉分支采用**参数无关的空间统计特征**（adaptive-average-pooling + RGB 均值和标准差），每视角 54 维特征；
  - 状态-动作向量经过线性投影后与视觉特征拼接；
  - GRU（hidden=64）融合时序后输出风险与阶段预测。

- **教师监督**：特权规则验证器只在离线阶段生成标签，不进入在线部署。
  - 教师将 BDDL 谓词等表征任务进度状态的信息转化为操作化阶段标签；
  - 风险标签按时间窗判定——距教师失败事件 ≤10 步为正样本，>20 步为负样本，中间模糊区不参与二分类训练。

- **在线触发门控**：采用"阈值（τ=0.40）+ 连续四帧确认 + 10 步冷却"策略抑制瞬时误报与重复干预；每 2 个环境步查询一次验证器。

- **Prompt Recovery 机制**：检测到异常时，系统**保留原始任务指令 q**，拼接阶段条件化的恢复指令片段 $r_t$（$q_{\text{rec}} = q \oplus r_t$），使同一冻结策略生成纠错动作；恢复完成后恢复原始指令继续执行。若阶段预测置信度较低（<0.9625）则默认由无特化的通用恢复提示接管。恢复时 replan_steps 降为 3，允许单次最多 100 个恢复动作。

## 6. 论文的主要结论与发现

1. **可观测历史足以推断执行状态**：仅基于视觉-本体感觉-动作时序数据即可有效估计操作阶段与执行风险，而不需要特权坐标或 BDDL 谓词等内部环境信息。
2. **学习验证器性能接近特权上界**：在标准 LIBERO 上，Learned Binary + Prompt 平均成功率 80.2%，Rule + Prompt 为 82.6%，差距缩小在 2.4 pp 以内，表明特权信息不是检测执行风险的必需品。
3. **提示恢复一致提升闭环可靠性**：几种扰动条件下都体现出显著提升；在标准 LIBERO 中，对目标物体/目标区域的位移，提升分别可达约 11.7 pp 的上界与 9.3 pp（Learned 下与组合条件相比 No Assistance 的 +9.3 pp 等均见原文表 3），较之自然滑移、单一噪声或目标偏移情况，收益更突出。
4. **执行状态监控对于长时程 VLA 策略的抗扰动能力是真实有效的**，不是依赖较优任务理解或技能泛化，而是来自在线监控和动作层面的自我纠偏。
5. **门控明显抑制误触发**：Raw 验证器 Precision/Recall 为 61.1%/94.9%（Pos. F1 74.4%），但经提示连续帧确认与冷却期机制，在线门控触发精度上升至 79.2%，使系统支持安全的恢复干预。
6. **恢复动作与生成动作可以由同一策略完成**：无论 Rule + Prompt 还是 Learned Binary + Prompt，到达恢复时机后，整体恢复成功率（77.0% 与 75.0%）都让平均成功率往检测阶段的增益方向迁移。

## 7. 优点

- **概念性贡献清晰**：明确把"执行状态理解"视为 VLA 的隐式短板，并以"what-to-do 与 whether-doing-it-rightly"的对立提出区分化补足思路，既有新颖性也有工程意义。
- **接口设计克制优雅**：只用一个可插拔的监控模块+提示拼接接口包装原策略，恢复全程不需要 fine-tune、新增 action 头或直接改动动作序列，对现有策略复用友好，真实部署简单。
- **避开了特权信息依赖**：使用了"特权规则验证器只做离线教师，学习验证器只依赖可观测输入"的构造，同时在部署时消解了大规模仿真数据的依赖——实验中没有使用任何真实数据来重新训练任何模块。
- **全面的评估设计**：同时报告了模拟/真实实验、检测指标/端到端成功率/门控质量/消融，对每种条件的变化给出解析性数据（如最后在组合扰动下仍保持收益），论证结构较为完整。
- **语义**恢复路由的引入支持可解释地纠正各阶段异常；采用 low-confidence 兜底与提示恢复的纠错格式在简化系统上达成了不错的性能上界。

## 8. 不足与局限

- **策略与模型前提的限制**：整体框架仅冻结评估一个 π0.5-libero 策略，论文没有验证适配其他 VLA 策略（如 OpenVLA、其他权重）的兼容性与可迁移性，因而其标题里"通用闭环修复"的普适更有待后续证明。
- **没有大规模模型或训练参数披露**：上节所述，训练 GPU 型号/数量/时长均未提及，这不利于完整复现与评估部署成本。
- **真实实验面偏窄**：真实世界的任务只包含一种物体非严格对称、放置/抓取类直线型技能，覆盖面小；在真实非扰动条件下每个任务也都使用目标物体的位置突变，未评估自然噪声与逐步漂移；另外，没有说明真实场景下模型是否真正完成接近/对齐之后的动作，而较粗的运动学细节可能会减弱结论强度。
- **标签与教师范式的类目限制**：风险窗口和阶段定义是离散阈值化的，中间区域不参与负/正样本学习，模糊区间被完全屏蔽，因而演示出的高 recall 可能意味着在模糊约束内部仍有隐蔽的分辨风险；且现阶段的"风险"高度绑定五段式任务分解表内，对于重叠、非前-后结构任务、或者早期错误的影响模式可能反映不够。
- **评估对特定扰动设置较敏感**：模拟扰动只展现单一幅度（0.1 m、σ=0.1），没有做幅度扫描分辨率曲线评估的鲁棒走向，因此性能上限的广度只能理解为在固定扰动强度下的表现。
- **若干统计流程未强调不确定性**：论文报告一次 70.9%→80.2~82.6% 等主数字时，几乎没有给出置信区间或显著性检验；另外困难档的自定义评估标准也没有明确指出在 LibeRO Plus 5 时为什么不报告 Spatial 与 Goal 套件的结果，削弱了评分者对不同条件可比性的判断。
- **计算开销**：虽然在线推理延迟极低，但在训练侧未描述所需 GPU 成本，在复杂任务/多模态大上下文下要加一个额外的时序验证器是否会带来在数据/模型维度上付出的代价尚未讨论。
