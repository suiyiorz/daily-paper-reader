## 摘要
视觉语言模型（VLMs）在自动驾驶领域展现了潜力，但仍然存在幻觉、时空感知弱和泛化受限的问题。近期方法通过思维链（CoT）解释、检索增强生成或静态注入工具输出来改进推理和决策。虽然这些机制丰富了上下文，模型却既不会主动感知场景信息，也不会在回答之后积累经验。为克服这些局限，我们提出了（据我们所知）首个协同框架，该框架在闭环推理中将分层记忆与主动工具调用紧密耦合。我们的贡献有三方面。(i) 分层驾驶记忆：场景级短期记忆维持动态场景状态，演进式长期记忆检索可复用经验与工具策略。(ii) 记忆-工具协同推理框架：在场景状态和检索到的经验引导下，模型在推理时自适应调用工具以细化推理，并在离线时将可复用经验巩固到长期记忆池中。(iii) 数据生成与两阶段训练流程：通过多步教师展开构建的经验证记忆-工具轨迹用于SFT和GRPO训练。我们的7B模型在DriveLMM-o1上取得总体推理分数80.03和MCQ准确率79.09%，超出最强基线7.74个MCQ点，并在多个基准上展现出强泛化性。值得注意的是，消融和分析研究验证了各组件的有效性，并进一步揭示了分层记忆的互补作用：短期记忆增强时空理解，使STSBench准确率提升24.2点；离线长期记忆巩固则在全部参数冻结的情况下额外带来3.57个MCQ增益，证明了通过累积驾驶经验实现的持续自我进化。

## Abstract
VLMs have shown promise for autonomous driving, yet still suffer from hallucination, weak spatio-temporal perception, and limited generalization. Recent methods improve reasoning and decision-making through CoT explanations, retrieval-augmented generation or the static injection of tool outputs. Although these mechanisms enrich the context, the model neither proactively perceives scene information nor accumulates experience after answering. To overcome these limitations, we present, to our knowledge, the first synergistic framework that tightly couples hierarchical memory with proactive tool invocation in a closed reasoning loop. Our contributions are threefold. (i) Hierarchical Driving Memory: a scene-level short-term memory maintains the dynamic scene state, and an evolving long-term memory retrieves reusable experience and tool strategies. (ii) Memory-Tool Synergistic Reasoning Framework: guided by the scene state and retrieved experience, the model adaptively invokes tools to refine its reasoning at inference time and consolidates reusable experience into a long-term memory pool offline. (iii) Data Generation and Two-stage Training Pipeline: verified memory-tool trajectories built by multi-step teacher rollout are used to train with SFT and GRPO. Our 7B model reaches an overall reasoning score of 80.03 and MCQ accuracy of 79.09% on DriveLMM-o1, surpassing the strongest baseline by 7.74 MCQ points and generalizes strongly across benchmarks. Notably, ablation and analysis studies validate the effectiveness of each component and further reveal the complementary roles of hierarchical memory. Short-term memory strengthens spatio-temporal understanding, improving STSBench accuracy by 24.2 points, while offline long-term memory consolidation yields an additional 3.57-point MCQ gain with all parameters frozen, demonstrating continual self-evolution through accumulated driving experience.

  3. **泛化能力有限**：面对未见场景或跨数据集的任务时，性能显著下降。

- 现有方法的三种主流路线均有明显局限：
  - **思维链（CoT）方法**：通过引导生成逐步推理来提高透明性，但本质上仍是被动地将输入展开为更长的模板化解释。
  - **检索增强生成（RAG）方法**：将外部知识或案例拼接入上下文，但模型只是被动接收信息。

- 作者指出上述方法的共同症结：**模型的答案与收到的信息量持续增长，但其理解能力并未随证据和反馈不断演进**，即不存在闭环的"感知—行动—学习"机制。

- 论文以人类驾驶模式为参照：驾驶并非静态帧的一次性识别，而是"主动感知"、"时空理解"与"经验积累"的统一过程。当前方法缺乏三个关键能力：
  - 可随观测动态演化的场景状态（foresight/先见之明的载体）；
  - 跨场景沉淀并复用的驾驶经验（hindsight/后见之明的载体）；
  - 由证据缺口驱动的主动信息搜寻。

- 核心问题：能否通过集成时空感知、主动感知和经验积累，构建一个统一的闭环推理框架，使驾驶 VLM 接近人类驾驶中的"先见之明"与"后见之明"？

- 论文主张自动驾驶 VLM 的研究应实现范式转变——从静态感知规模扩展和孤立推理，转向一种**持久的、可交互的驾驶智能**，能够随证据与经验不断演进。隐含的判断是：可交互性、经验积累和记忆机制可能是弥补当前端到端 VLM 在安全关键驾驶任务中不足的关键方向。

## 2. 方法论：核心思想与关键技术细节

### 核心思想
- 受人类"后见之明"（运用长期经验判断当前）和"先见之明"（跟踪场景随时间演化的趋势）的启发，提出一个**闭环的记忆-工具协同推理框架**。
- 核心特征是：将**分层驾驶记忆**（短期场景状态 + 跨场景长期经验）与**按需主动工具调用**在推理闭环中紧密结合；推理结束后，将通过验证的经验离线巩固回长期记忆中，从而实现模型的持续自我进化。

### 三个核心贡献的技术细节

**(1) 分层驾驶记忆（Hierarchical Driving Memory）**

- **场景级短期记忆（STM）**：
  - 由两个相邻时刻（t−1 与 t）的六视图图像通过预训练 BEV 感知模型编码为结构化场景描述与属性（含参与者、道路元素、位置、定性关系与运动趋势），再组织成场景图：`Ms = (V, R)`。
  - 短记忆在场景推进时刷新，在一个推理片段内作为只读场景先验。在实现中还包含"时间-空间图"状态，记录自车状态、关键物体、空间扇区、距离带、运动状态、风险等。
- **跨场景长期记忆（LTM）**：
  - 存储条目包括场景/任务适用条件、风险因素、可复用的成功推理模式、有效工具策略和检索效用等。
  - 查询由问题与短记忆共同编码，按语义相似性与归一化效用排序，取 top-K 条目。
  - **离线巩固（Offline Consolidation）**：推理阶段长期记忆不更新；一段轨迹通过验证（答案正确性、工具调用有效性、推理观测一致性）后，被提炼为新经验，经过语义聚类、去重、冲突消解和抽象，合并入长期记忆库；已有条目的效用权重按 `wi ← wi + η·gi(C)` 递增。

**(2) 记忆-工具协同推理框架（MTSR）**

- 以初始上下文 `x0 = (q, I, MS, EK)` 为起点，产生完整轨迹 `C = (x0, s1, ..., sT, y)`，其中每一步 `st = (ht, at, ot, ut)` 含推理状态、动作、工具观测和更新的场景信念。
- 推理遵循 **"思考→行动→观测→更新"** 的循环（Think-Action-Observation-Update），无预定工具流程：模型根据上下文选择下一步推理与动作，直至认为证据充分，发出 `finish`，生成最终答案。
- 工具库共 27 个可调用函数，核心 20 个，涵盖视觉锚定（2D open-vocab检测）、三维度量几何（相机坐标系定位/深度/距离/顺序）、物体检测、自车状态估计、轨迹预测、占用率与地图查询等。

**(3) 数据生成与两阶段训练管线**

- **多步教师展开与验证（Multi-Step Teacher Rollout）**：教师 VLM（Qwen3.6-Plus）从初始上下文出发，在已初始化长期记忆上，经 MTSR 循环生成多步轨迹，并通过验证（答案正确性、工具调用合法性/参数、观测来源与推理一致性等）。7,000 条生成轨迹中有 6,383 条通过。验证轨迹既是训练集，也被巩固为学生的初始长期记忆。
- **分步监督微调（两阶段 SFT）**：
  - 第一阶段：移除工具执行器返回的观测，训练模型学会选择工具与生成参数（3 轮，13,679 条记录）。
  - 第二阶段：保留完整记忆与工具反馈，学习基于观测的推理（20 轮，20,062 条记录）。执行器返回的观测被排除在训练 loss 之外，只作为上下文。
- **轨迹级 GRPO 强化学习**：
  - 从 Phase-2 检查点出发，每个输入采样 G=8 条轨迹，使用正确性门控的分层奖励（表 8）：正确+工具+引用记忆 +0.7；正确+工具无记忆引用 +0.5；正确无工具 0.0；错误+工具 +0.2；错误无工具 0.0；格式错误 0.0。
  - 特别设计了"工具使用不完全以正确性为门控"的奖励结构——错误但合法使用了工具的轨迹获得小正奖励，目的是提供引导信号（避免正确但无工具的短路径投机）并促进工具执行能力的引导式训练；但 Tier 4 严格劣于 Tier 2/1（具有工具的正确轨迹奖励更高），且优点在组内标准化，因此不可被利用。
  - 优化目标为带组相对优势与 KL 散度约束的 GRPO 损失。

### 核心公式（文字说明）

- 策略条件化：`y ~ πθ(q, It, Ms, EK, T)`。
- 长期记忆检索评分：余弦相似度 + λ×归一化效用，取 top-K。
- 离线巩固：`M(n+1)_l = Φcon(M(n)_l, B+n)`，效用权重的显示式更新 `wi ← wi + η·gi(C)`。
- 推理：每步 `(ht, at) ~ πθ(· | x0, H<t)`，`at ∈ T ∪ {finish}`。
- SFT 目标：分位置监督，仅模型生成 token（工具调用、推理、信念更新、最终回答）计入损失。
- GRPO：组内相对优势 + KL 散度正则。

- **训练规模**：教师模型（Qwen3.6-Plus）生成 7,000 条工具执行轨迹（6,383 条通过验证）；第一阶段 SFT 3 轮（13,679 条工具决策记录），第二阶段 20 轮（20,062 条记录），均使用 LoRA（r=16，α=32，dropout 0.05），冻结视觉编码器；GRPO 连续四阶段训练（每阶段 500–800 步）。总体算力需求不高，可在单张消费级 GPU 上完成推理（峰值约 19-24GB）。
- 教师展开 API：2026-05-09 至 2026-05-13，日志调用 6,395 次。

## 5. 实验数量与充分性

- **实验数量与类型**：
  - 主实验（1组全面对比）、跨了两个额外基准的零/单样本泛化测试、多个明确消融组（训练阶段 4 种变体、记忆 4 种变体、时间表示 4 种变体）、以及大量的行为与定性分析（含 DriveBench 鲁棒性场景下的 4+ 个定性案例）。
  - 统计稳健性方面，仅对 DriveLMM-o1 指标提供了基于 10,000 次重采样的自举 95% 置信区间。
- **充分性与客观性分析**：
  - **优点**——消融设计清晰：将训练后模型设为无记忆变体，逐一叠加 LTM、STM 与两者组合，能干净地分离各记忆层贡献；跨三个公开基准的零样本与单样本结果能较有力地证明泛化能力；并发最强模型（DriveAgent-R1）未能完全复现的问题也有提及。
  - **限制与不对称**——推理分数的对比存在一定缺陷：根据附带的置信区间，作者自己的模型与最强基线（AgentThink）在推理总分数上的差异并不具备统计显著性（基线 79.68 落在自举区间 [79.46, 80.57] 内），不过他们在 E.2 节诚实说明了这一点，说明只在 MCQ 准确率上有稳健优势。他们没有详细披露 DriveLMM-o1 上开放式问题的子集或逐维度的置信范围，而开放性任务分数在训练目标中未被强化（天然欠优化，见附录 F）。
  - 强化训练只在 MCQ 正确性上施加梯度，开放性回答在 RL 中不作奖励，评估不对称可能使推理分数中的描述性维度（如语义覆盖、缺失步骤）明显偏低。
  - 报告单次确定性推理运行，但只对训练一次，未报告独立的重复训练运行间差异或不同种子（GRPO 因采样不可逐位复现，但文中声明训练种子固定为 42）。附录提供了相当详细的超参记录，便于审阅。
  - **总体评价**：实验数量丰富、覆盖场景较全面，消融设计能够支撑其核心结论；但由于训练运行不一致、某些指标（推理质量）缺乏超越显著优势的证据，以及跨三个数据集之外的某些测试仅以少量定性例子为主（DriveBench 没有定量）。

## 6. 主要结论与发现

1. **性能最强**：7B 模型在 DriveLMM-o1 上取得推理分数 80.03 与 MCQ 准确率 79.09%，以绝对优势优于其他可复现方法，比同规模的 AgentThink 高 7.74 MCQ 分，且在规则遵守与场景理解维度领先。
2. **泛化良好**：零样本 DriveMLLM AccS 74.36，单样本 80.59，全面超越基线；在未见过的 STRIDE-QA 上，MLSR 3.9（在开放模型中最高），在 t=2/3 s 的长距离预测中优势显著。
3. **两类记忆互补且各有贡献**：短记忆贡献更大（单独提升 MCQ 到 76.91，STM 单独相比无记忆提升 4.75 个点），长期记忆的增益稳定但较小；两者结合获得最优表现（79.09%）。STSBench 实验进一步显示，显式的短记忆结构化时间状态优于多帧原始视觉输入（55.61% vs. 35.64%），提升 24.2 个百分点。
4. **SFT 是 GRPO 的先决条件**：GRPO 直接加在基础模型上仅达到 73.85/64.49（推理/问答），低于经过两阶段 SFT 加的 GRPO（80.03/79.09），证明两阶段范式对建立有效工具-记忆交互很必要。
5. **非参数自我进化可能**：固定全部模型权重，仅通过离线长时记忆巩固，MCQ 从 79.09 提升至 82.66（第 9 轮增益 3.57 分），超过第 10 代会轻微下降，表明有饱和点。
6. **按需交互、低冗余**：97.4% 的查询涉及 1–3 次工具调用，平均调用 2.10，无工具回答仅 0.5%；工具调用成功率 99.74%，轨迹主要为正常终止（98.94%）；行为表现显示出"任务条件化且有变化

…的分布，但充分性尚待人工分析进一步确认。

7. **规则遵循与结构化感知优势明显**：在 DriveLMM-o1 的规则遵守维度上领先基线幅度最大，说明记忆约束与闭环验证能有效抑制无根据的自由生成；在 STRIDE-QA 长时预测（t=2/3 s）上表现突出，印证了短期记忆中的运动趋势状态比单帧视觉特征更利于推断未来事件。

8. **错误模式与残余局限**：附录与案例分析显示，模型仍存在细粒度深度误判、部分长尾场景经验不足、以及开放性描述相比多选题仍有明显下滑等问题；开放题未经强化学习直接优化，是分数偏低的结构性原因。这表明闭环推理虽然缓解了幻觉，但并未完全消除时空不确定性下的推理噪声。

## 7. 局限性与未来方向

**已明确的局限性：**

- 教师模型调用与验证依赖较强的第三方 VLM（Qwen3.6-Plus），在数据生成阶段可能承袭教师的系统偏差；验证只能排除格式性与明显冲突的错误，无法保证所有轨迹在物理层面完全合理。
- 长期记忆的离线巩固只在训练/自我进化阶段发生，在推理时并不实时更新，因此"在线适应新场景"的能力仍受限。
- 短期记忆依赖预训练 BEV 感知模型的结构化输出；若上游目标检测或轨迹预测出错，下游推理会承袭该错误，文中对此类噪声传播的量化分析较有限。
- 只能对模型回答中可机器校验部分（如 MCQ 准确率）作可靠奖励信号，开放性推理质量仍需依赖 LLM 评判，带来评判偏差的可能。
- DriveLMM-o1 开放式题目中，一些维度（如空间深度）分数仍低于强基线或与其互有胜负，无法宣称全面碾压。

**值得关注的未来方向：**

- 将长时记忆的巩固从离线推进到在线，依托持续交互实现真正的终身驾驶学习；
- 将记忆内容扩展到驾驶风格、环境光照/天气条件等跨模态因素，并研究记忆的遗忘机制；
- 探索更强的证据归因：在最终答案中显式标注每条结论来源对应的工具观测或记忆条目，提高可审计性；
- 将工具库从几何/检测类扩展至规控模拟器，使模型不仅理解场景，还能在闭环仿真中执行动作并接收反馈；
- 引入不确定性校准，让模型在证据不足时主动发问或要求更多观测，而不是生成低置信度的猜测。

## 8. 总体评价与可复现性建议

**总体评价：**

- 该论文提出的分层驾驶记忆（STM+LTM）与记忆-工具协同推理（MTSR）框架，在驾驶 VLM 范式中引入了清晰的时间结构化场景状态与跨场景经验累积机制，是对现有单次前向推理/被动工具注入范式的实质推进。其价值不限于分数上的增益，更在于提出了一套如何让 VLM 像人类驾驶员一样随证据与经验演进的实现路径。
- 消融设计完整、行为分析细致，使"STM 作为主要收益来源，LTM 提供额外泛化增益"这一判断具有较高可信度；训练门槛相对亲民（消费级 GPU 可推理、LoRA 训练），使后续复现具备较好条件。
- 但需注意其在多项维度上的优势并未达到统计显著，宣称"全面领先"的措辞应仅限于报告所覆盖的环境与指标；跨数据集泛化能力仍需在更广的驾驶数据源上验证。

**可复现性建议：**

- 建议作者发布：
  1) 经过后处理的长期记忆库转储（或去隐私的样本条目）；
  2) 两阶段 SFT 的完整数据模板与工具观测的序列化格式；
  3) 27 个工具函数的具体 API schema 与关键实现参数；
  4) 确定性评估中各基准的详细提示词与检索超参数。
- 这种程度的开放能够使后续工作不仅复现最终分数，还能对比"记忆内容设计"和"巩固调度策略"等更本质的设计变量。

## 9. 结尾一句话总结

本文的核心启示是：让驾驶 VLM 真正接近人类驾驶员，不能只靠更多参数或有更多工具的提示词，而需要为其构建可演化的记忆、可验证的感知闭环和随经验不断更新的推理依据；这为自动驾驶视觉语言模型从"能看懂"走向"会判断"提供了一条值得持续探索的技术路线。
