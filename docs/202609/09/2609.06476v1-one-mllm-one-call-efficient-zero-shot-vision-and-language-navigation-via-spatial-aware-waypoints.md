## 摘要
连续环境中的视觉-语言导航（VLN-CE）要求具身智能体通过遵循自然语言指令在未见过的环境中导航。当前的零样本VLN-CE方法要么依赖预训练的路点预测器，要么在每一步需要多次查询大型模型。为了解决高昂的推理延迟和计算开销，我们提出了O2C-Nav，一种高效的零样本导航框架，每个决策步骤仅调用单个大型模型一次。我们的方法引入了一种无需训练的结构化路点生成器，以及一种新颖的抽象表示，将稀疏的、具有历史感知的候选路点直接投影到RGB图像上作为视觉标记。MLLM在每一步选择一个路点或生成一个后备的目标边界框，而底层的快速行进法（FMM）规划器将所选目标转换为可执行的无碰撞路径。这种范式为模型提供了具体的空间感知和显式记忆，同时显著减少了视觉处理负载。在R2R-CE和RxR-CE基准上的广泛评估表明，O2C-Nav优于当前最先进的零样本方法，突显了其在实时机器人部署中的巨大潜力。代码可在 https://github.com/kkpsq/O2C-Nav-Code 获取。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires an embodied agent to navigate unseen environments by following natural language instructions. Current zero-shot VLN-CE methods either rely on pre-trained waypoint predictors or require multiple queries to large models per step. To address prohibitive inference latency and computational overhead, we propose O2C-Nav, an efficient zero-shot navigation framework that calls only a single large model once per decision step. Our approach introduces a training-free structured waypoint generator and a novel abstract representation that projects sparse, history-aware candidate waypoints directly onto RGB images as visual markers. The MLLM selects a waypoint or generates a fallback target bounding box at each step, while a low-level Fast Marching Method (FMM) planner converts the selected target into an executable collision-free path. This paradigm provides the model with concrete spatial perception and explicit memory while significantly reducing the visual processing load. Extensive evaluations on the R2R-CE and RxR-CE benchmarks demonstrate that O2C-Nav outperforms current state-of-the-art zero-shot methods, highlighting its great potential for real-time robotic deployment. Code is available at https://github.com/kkpsq/O2C-Nav-Code.

- **任务背景**：视觉-语言导航（Vision-and-Language Navigation, VLN）要求具身智能体通过理解自然语言指令在真实物理环境中导航。该任务已从传统的离散导航图场景（VLN）演进至更贴近实际部署的连续环境（VLN-CE），其间对智能体的场景理解、泛化能力与低层连续控制能力提出了更高要求。
- **问题定义**：VLN-CE 智能体需要根据自然语言指令在未见过的连续环境中完成导航，每个时间步仅利用四视图（前/后/左/右）RGB-D 感知输入生成动作。
- **现有方法的核心痛点**：
  - **监督学习方法**：依赖大规模环境特定训练数据，标定成本高，泛化受限。例如 CMA、RecBERT、ETPNav、HNR 等方法虽性能较强，但可扩展性差、训练开销高。
  - **现有零样本方法推理效率差**：多数基于(M)LLM的导航框架以牺牲推理效率为代价换取导航精度，如 STRIDER 每步调用 MLLM 三次、LaViRA 两次、Open-Nav 两步决策，导致推理延迟与计算开销居高不下。
  - **单一调用范式的挑战**：若仅允许一次调用，需要在同一次决策中整合视觉感知、空间推理与行动规划，信息量大；同时 MLLM 缺少低层度量的空间能力，难以在无图的连续物理空间中选择合适路点。
- **论文核心研究问题**：能否设计一种零样本框架，既做到**每个决策步骤只调用一次 MLLM**，又能**有效增强模型的环境理解与决策能力**？

### 2. 方法论（O2C-Nav 框架）

#### 2.1 核心思想

- 提出 **O2C-Nav（One MLLM, One Call）**：每个决策步骤仅调用一次 MLLM，同时通过**基于空间感知的路点可视化**，将候选路点以颜色编码的标记直接投影到多视角 RGB 图像上，为 MLLM 提供具体的空间感知与显式历史记忆。
- 范式分工：MLLM 只做高层规划（选择目标），底层路径执行交给规则化/几何控制器，降低模型负载。

#### 2.2 整体流程（算法流水线）

每个时间步执行以下步骤：
1. **获取感知与状态**：采集四视角 RGB-D 观测和实时位姿；
2. **可通行区域提取**：基于深度数据与视觉基础模型（Grounding DINO等）提取语义标签，过滤障碍物、构建 2D 顶视角语义栅格地图，得到二值可通行掩膜；
3. **历史路点更新**：记录已到达位姿，若距已有路点大于阈值δ则新增节点；
4. **结构化路点生成**：对可通行掩膜执行形态学闭运算与骨架化（Zhang–Suen 细化），提取拓扑关键节点（走廊端点 deg=1 与路口 deg>2），并沿骨架按采样间隔执行 NMS 均匀采样得到候选路点集合 W。
5. **抽象路点可视化**：通过相机内参、地图分辨率与位姿变换，将 3D 空间中路点坐标投影至各视角 2D 图像平面，渲染为带唯一 ID 的视觉标记，获得可视化观察 Vt。其中青色标记"未访问候选"，红色标记"已访问位置"。
6. **MLLM 决策**：输入包括语言指令 I、可视化观察 Vt、执行历史 Ht（滑动窗口 w=5）、对象列表 Et；MLLM 输出高维决策（方向 at, 目标路点 ID 或回退边界框 Bt）。为缓解局部陷入循环，引入路点访问计数和循环警告机制（C(w)>n 时在提示中附加警告）。
7. **低层控制执行**：若选中路点 ID，取其像素坐标；若无可用路点，以目标 bbox 底部中心作为目标像素，反投影为 2D 全局坐标，再通过 Fast Marching Method（FMM）规划无碰撞最短路径，转化为离散运动指令执行。

#### 2.3 关键公式
- 可通行掩膜：Mtrav = { p ∈ Mt | Label(p) ∈ Walkable }
- 历史路点合并：当 min‖pt − w‖ ≥ δ 时新增节点，否则合并到最近节点。
- 骨架化：S = Skeletonize(Mtrav > 0)
- 路点稀疏约束：dist(wj, wj′) ≥ dsample/Δ
- 决策函数：(at, ID*t, Bt) = MLLM(I, Ht, Vt, Et)

#### 2.4 回退机制

- 当所选方向没有候选路点时，MLLM 可输出目标物体的边界框（BBox）作为空间目标，弥补结构化路点覆盖不足的盲区。

### 6. 主要结论与发现

1. **单次调用范式可行**：O2C-Nav 证明了在每步仅 1 次 MLLM 调用的情况下可以达到当前零样本 VLN-CE 最先进的导航成功率，同时大幅降低推理开销。
2. **抽象路点视觉化有效**：将 3D 拓扑路点投影为 RGB 图像彩色标记，可弥补 MLLM 固有的低层度量空间能力缺陷，增强空间感知与具象推理。
3. **历史轨迹视觉标记有效**：区分"已访问"与"未访问"路点，辅以循环警告，可显著缓解智能体原地打转和重复探索问题。
4. **BBox 回退是必要的补充机制**：当结构化路点覆盖不足时，BBox 作为空间目标的回退值能有效避免卡死情况。
5. **骨干模型差异显著**：Gemini-2.5-Pro 在终点目标识别方面出色（NE 最低），Qwen3-VL-235B 则在 SPL/NDTW 上表现均衡、是性价比最高的选择。
6. **真实可部署性**：在真实机器人上无需任何微调即可零样本执行 VLN（50% 成功率）与 ObjectNav（50% 成功率）任务，证明框架具备实时定位部署的可行性。

### 7. 方法优点与亮点

- **高效性设计**："One MLLM, One Call"范式直击现有零样本方法的多查询开销痛点；相比 STRIDER/LaViRA 等多调用方法，调用次数降低 33%–67%，端到端延迟降约 20%–50%。
- **训练无关（Training-free）**：整个路点生成与决策框架无需任何训练或微调，易于面对新环境快速部署。
- **人机交互友好的可视化**：将路点以可视化的标记直接叠加在 RGB 图像上，是一种新颖且直观的"抽象空间表示"范式，显著降低 MLLM 将 3D 空间转换为 2D 视觉推理的复杂度。
- **提示工程设计完善**：对 MLLM 提供结构化的 progress analysis, reasoning, action framework，配合防循环警告与对象检测列表，提升长程语义跟踪能力。
- **全局拓扑覆盖**：基于全局地图骨架的路点生成优于 STRIDER 的局部 12 视角端点限制，可达到更高的拓扑覆盖率和稀疏性。
- **模块解耦、公平对比态度好**：在多组实验中将传播器、提示与控制器固定，已注意隔离干扰变量；公开真实场景效果与失败案例分析，增强可信度。

### 8. 不足与局限

- **NDTW 偏低**：单次调用下的稀疏路点策略使路径更趋向直接、偏离人类轨迹的高保真度，论文为优先保证 SR/SPL 而明显牺牲 NDTW（GPS 与 STRIDER 的 NDTW 约低 9–15 个百分点），在进行任务类精度对照时需要权衡。
- **视角信息限制**：依赖 4 视角离散观察，部分周边视角缺失可能造成候选路点遗漏，导致不规则或次优路径。
- **MLLM 幻觉风险**：长程指令 + 2D 标记叠加时可能出现空间关系误判或对几何可达性的误解，造成导航失败（论文失败审计指出 36/54 失败源于路点选择错误）。
- **基准样本量有限**：R2R-CE 零样本协议只使用 100 个随机 episode，而标准完整验证集通常远大于此，判断统计显著性支撑相对较弱；且 R2R-CE 多轮多次结果主要交换 GPT-4o，未提供 Gemmine 与 Qwen 在多轮多次运行的完整标准误。
- **物理机器人验证样本小**：真实实验只有 10 个 VLN 任务与 10 个 ObjectNav 任务，成功率 50%；摄像头噪声对建图稳定性的影响仍明显。
- **部分对比方法延迟数值缺失**：SmartWay/STRIDER 的 N/A 标注（未提供全部延时分解），导致对比不完整。
- **闭源模型依赖**：依赖 CPT-4o/Gemini-2.5-Pro/Qwen3-VL-235B 等商用大模型 API，存在网络延迟、成本与可控性等实际部署问题。
