## 摘要
一个动作块可能跨越操作任务的多个阶段，但其第一步的标签仅描述当前阶段。我们提出了块对齐语义蒸馏（CASD），为整个动作块推导语义目标。一个离线视觉-语言模型将示范分割为已描述的阶段。这些阶段在每个动作块内的占用情况决定了一个加权语义目标，包括阶段之间的转换。一个CASD生成器学习从当前观察、机器人状态和任务指令中预测该目标。然后我们冻结生成器，并训练一个以其预测为条件的策略。语义分支每次策略查询仅运行一次，无需在线VLM调用或推理轨迹解码。在带注释的LIBERO训练片段上，教师匹配对于单阶段和跨边界块均高于偶然水平。我们在四个基准上评估了三种Fast-WAM变体和一个DreamZero集成，包括LIBERO-Plus上的分布偏移。与已发表的参考文献相比，IDM+CASD在LIBERO上的平均成功率从98.0%提升至98.9%，而Uncond则低于其参考值。Joint+CASD在RoboTwin 2.0上从90.6%提升至93.0%，DreamZero+CASD在MolmoSpaces四类别操作平均成功率上从40.7%提升至47.9%。不同主干集成的表现有所差异。

## Abstract
An action chunk can span several stages of a manipulation task, yet a label for its first step describes only the current stage. We introduce Chunk-Aligned Semantic Distillation (CASD), which derives semantic targets for entire action chunks. An offline vision--language model segments demonstrations into described stages. Their occupancy within each action chunk determines a weighted semantic target, including transitions between stages. A CASD generator learns to predict this target from the current observation, robot state, and task instruction. We then freeze the generator and train a policy conditioned on its predictions. The semantic branch runs once per policy query, without online VLM calls or reasoning-trace decoding. Teacher matching on annotated LIBERO training episodes is above chance for both single-stage and boundary-crossing chunks. We evaluate three Fast-WAM variants and a DreamZero integration across four benchmarks, including distribution shifts on LIBERO-Plus. Compared with published references, IDM+CASD reaches 98.9\% versus 98.0\% average success on LIBERO, while Uncond falls below its reference. Joint+CASD reaches 93.0\% versus 90.6\% on RoboTwin 2.0, and DreamZero+CASD reaches a 47.9\% four-category MolmoSpaces manipulation average versus 40.7\%. Performance varies across backbone integrations.

## 1. 核心问题与研究动机

**核心问题：**
在视觉-语言-动作（VLA）模型中，动作块（action chunk）通常一次预测未来 H 步的连续动作。然而在多阶段操作任务中，标签只描述当前第一步所在的阶段，无法覆盖整个动作块可能跨越的多个任务阶段——当动作块恰好处于两个阶段的边界附近时（例如"把碗放入抽屉"与"关闭抽屉"的交接处），该块的标签无论标注为哪一个阶段都是不完整的，即使列出所有重叠阶段，也丢失了"每个阶段在块中占据多大比例"的关键信息。

**整体含义：**
论文主张将语义监督的目标与动作预测的时间尺度（horizon）对齐——即语义标签应定义在与被监督动作相同的时间区间上。用"阶段在动作块内的占用比例（occupancy）加权混合"来描述整个预测块的语义构成，是解决这一错配问题的根本思路。

## 2. 方法论

### 2.1 核心思想
CASD 分为两个阶段进行"特权信息蒸馏"：
- **离线阶段**：用视觉-语言模型（VLM）将示范轨迹分割为有序的连续阶段，并为每个阶段生成自由文本描述（不依赖预定义的全局阶段词汇表）。
- **在线阶段**：训练一个轻量生成器，仅从当前观测、机器人状态和任务指令预测"块级语义目标"；随后冻结该生成器，用它产生的语义 token 条件化下游视频-动作策略。

### 2.2 关键技术细节

**① 块对齐监督（Chunk-Aligned Supervision）**
- 对查询时刻 t，取后续 H=32 步示范动作的**有效**（非补齐）部分构成集合 C_t；
- 定义阶段 k 的占用权重：`w_{t,k} = |{τ ∈ C_t : g_τ = k}| / |C_t|`，所有权重归一化求和为 1；
- 完全处于一个阶段内的块权重为 1（Pure）；跨边界的块则是加权混合（Mixed）。这些占用信息来自示范的未来，属于训练时可见、部署时不可得的特权信息。

**② 语义教师（Chunk-Aligned Semantic Teacher）**
- 用冻结的 UMT5 编码器将每段自由文本描述编码为 token 序列；
- 将 token 序列划分为 N=4 个**有序槽位**（slots），每个槽位做区间内均值池化；
- 教师目标为各阶段槽位向量按占用比例加权的混合：`T_{t,n} = R( Σ_k w_{t,k} (h̄_{k,n} − μ) )`；
- 无论块内重叠多少个阶段，教师目标的尺寸都固定为 4×128，记录的是阶段**比例**而非阶段**顺序**。

**③ CASD 生成器**
- 输入：当前帧的冻结 VAE 视觉隐变量 z_t、机器人状态 s_t、任务指令 ℓ；
- 通过交叉注意力从完整指令 token 序列中提取信息，N 个并行查询对应 N 个有序语义槽位，一步直接回归混合目标；
- 推理时每个策略查询只运行一次，**无在线 VLM 调用、无文本推理链解码、无子目标图像生成**。

**④ 训练流程**
- **阶段 A（语义蒸馏）**：仅训练生成器。损失 = 归一化直接回归损失 `L_dir` + 同任务最难负例的排序损失 `L_rank`（用于区分同一任务内的不同语义上下文）。
- **阶段 B（策略学习）**：冻结生成器，在原始骨干损失（视觉动态损失 + 动作流匹配损失）基础上，将生成器的预测 token 经独立低秩投影和逐块交叉注意力适配器注入视频专家与动作专家。最终适配器投影零初始化，保持预训练函数不被破坏。
- 训练与部署使用**同一来源的语义条件**（即生成器预测而非教师目标），使策略在训练期就暴露于生成器误差中。

### 2.3 核心公式（文字说明）
- 占用权重：`w_{t,k} = 阶段k在有效动作块中的步数 / 有效总步数`
- 教师目标：各阶段投影槽位的占用加权混合（均值中心化后经固定随机投影降维）
- 蒸馏损失：`L_A = L_dir + λ_rank·L_rank`，其中直接回归为归一化 Frobenius 距离，排序损失拉大正样本与同任务负样本的距离差
- 策略损失：`L_B = L_dyn + L_act`（原始骨干目标不变）

## 6. 主要结论与发现

1. **教师匹配**：CASD 生成器能从当前输入恢复块级语义上下文。Pure 查询 Recall@1 为 0.430（随机基线 0.185，2.3×）；跨边界 Mixed-3+ 为 0.790（随机 0.166，4.8×）。
2. **LIBERO（分布内）**：IDM+CASD 达 98.9%（较参考 +0.9 pp，表中最高）；Joint+CASD 为 98.8%（+0.3 pp，Long 套件增益最大 +1.2 pp）；**Uncond+CASD 下降到 94.5%（−3.2 pp，Goal 套件 −4.4 pp）**。
3. **LIBERO-Plus（分布偏移）**：三项 CASD 变体均高于 RIFT 参考（+7.5 / +4.1 / +2.5 pp）；相机视角是最薄弱类别（Joint+CASD 仅 46.0%）。
4. **RoboTwin 2.0（双臂）**：Joint+CASD 以 93.0% 平均成功率领先表格（较官方基线 +2.4 pp）；IDM+CASD 为 92.4%，Uncond+CASD 为 90.9%。
5. **MolmoSpaces（DreamZero 集成）**：DreamZero+CASD 达 47.9% 平均成功率（较参考 40.7% 提升 +7.2 pp），Pick-and-Place 与 Open 增益最大（+10.5 / +10.2 pp）。
6. **整体**：CASD 的收益**强依赖骨干集成方式**——对 IDM/Joint 稳定提升，对 Uncond 反而有害；语义监督能帮助某些骨干，但非普适增强。

## 7. 优点

**方法层面：**
- 将语义监督精确对齐到动作预测的时间尺度（块级），这是此前 RT-H、PALO、SARM 等方案未曾直接解决的粒度问题；
- 使用自由文本描述 + 占用加权的连续混合，不需要全局阶段词汇表，能表达"3/4 搬运 + 1/4 释放"这类精细化上下文；
- 避免在线 VLM 调用：生成器每次策略查询单次前向即可，训练与部署使用同一条件源（冻结生成器），规避了教师-学生分布不一致的问题；
- 对骨干侵入小：使用低秩交叉注意力适配器、零初始化，保留预训练能力；
- 教师目标尺寸固定（4×128 tokens），不随阶段数变化，架构简洁。

**实验层面：**
- 评估矩阵覆盖面广（4 个基准、3 种 Fast-WAM 变体 + DreamZero）；
- 诚实报告负面结果（Uncond 下降）；
- 提供了可解释性的案例分析（配对 rollout + 语义拟合），将语义 token 变化与具体行为切换（释放碗 vs 继续持握）相关联；
- 附录提供了完整的 RoboTwin 逐任务数据与 LIBERO-Plus 聚合细节，便于审计；
- 教师匹配采用 episode 内检索设计，避免了跨任务随机基线的偏差问题。

## 8. 不足与局限

1. **骨干依赖性问题未解决**：Uncond+CASD 出现明显性能下降（−3.2 pp），论文只描述了现象而未深入归因；"语义上下文如何与不同骨干表示相互作用"仍是不透明的。
2. **对比公平性受限**：LIBERO-Plus 与 MolmoSpaces 的对比为跨报告/跨榜单引用，训练配方与检查点不一致，无法严格归因增益来自 CASD。
3. **消融缺失**：未做置换实验以区分——是"块级加权混合"还是"额外语义 token"带来了增益？当前阶段标签（single-stage label）、等权混合、仅路由到视频专家/仅动作专家等条件的对比均未实施。
4. **教师信息不完整**：加权混合丢弃了阶段**顺序**信息；不同执行顺序只要描述集相同就会产生相同的教师目标；教师假设线性混合可表达阶段语义，缺乏验证。
5. **可靠性与质量限制**：依赖 GPT-5.4 自动注释（温度 0.1，非确定性），无标注者间一致性报告；注释分数为启发式且不参与训练权重；论文也承认自动注释存在接地与边界误差。
