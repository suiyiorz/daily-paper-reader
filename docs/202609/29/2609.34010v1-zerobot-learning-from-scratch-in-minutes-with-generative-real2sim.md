## 摘要
我们提出了ZeroBot，一个real2sim框架，可在具有挑战性的条件下于数分钟内从零开始学习机器人操作任务：零人类演示、零策略预训练以及零已知物体模型。仅给定物体的单视图和该物体的目标位姿，ZeroBot使用图像到3D生成模型获得完整物体网格，并将其用于仿真中进行大规模并行强化学习。为加速训练，我们引入一种动作空间，利用生成的几何结构和学习到的价值函数来采样涉及机器人-物体接触的状态。在包括抓取、推动、铰接物体交互和多阶段操作的真实世界任务上评估时，ZeroBot达到了87%的成功率，平均训练时间为119秒。这些结果表明，在real2sim框架中使用图像到3D模型对于快速、自主的机器人学习具有价值。

## Abstract
We present ZeroBot, a real2sim framework for learning a robot manipulation task from scratch in minutes under challenging conditions: zero human demonstrations, zero policy pre-training, and zero known object models. Given only a single view of an object and a goal pose for that object, ZeroBot uses image-to-3D generative models to obtain a complete object mesh, which is used in simulation for large-scale parallel reinforcement learning. To accelerate training, we introduce an action space which leverages the generated geometry and learned value function to sample states involving robot-object contact. When evaluated on real-world tasks including grasping, pushing, articulated object interaction, and multi-stage manipulation, ZeroBot achieves an 87% success rate with an average training time of 119 seconds. These results show the value of using image-to-3D models in a real2sim framework for rapid, autonomous robot learning.

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：用生成式 real2sim 替代人工建模或扫描；用生成网格加速仿真训练；用学习到的价值函数指导接触状态采样，从而在分钟级完成策略学习并零样本迁移。
- **三阶段框架**：
  1. **生成物体网格用于仿真**：
     - 机器人用腕部相机拍摄单视角 RGB-D 图像。
     - 用户点击目标物体，SAM 2 生成分割掩码。
     - 掩码 RGB 图像输入 InstantMesh 图像到 3D 生成管线：扩散模型生成新视角，Transformer 预测 3D 特征图，提取网格。
     - InstantMesh 不预测度量尺度，因此用同视角深度点云与生成网格做批量 ICP 对齐，恢复尺度。
     - 得到带颜色的度量尺度网格。
  2. **仿真中学习**：
     - 使用 Isaac Gym 和 PPO 进行大规模并行强化学习，256 个并行智能体。
     - 奖励函数采用统一的密集 **goal flow**：对物体上每个点构造指向目标位姿对应位置的目标流向量，最小化其范数即最大化奖励，避免位置与方向误差权重调参。
     - 状态向量包括：物体位置与四元数、夹爪左右指位置、夹爪四元数、夹爪开合二值指示。
     - 训练时物体初始位姿与真实一致，并从低高度释放以避免背景碰撞；部分实验随机化初始位姿以测试泛化。
  3. **真实机器人部署**：
     - 使用 Foundation Pose 和生成网格进行物体 6D 位姿跟踪。
     - 训练得到状态策略 π(s) 和价值函数 V(s)，部署时零样本执行。
     - 用 cuRobo 做无碰撞运动规划，移动到高价值接触位姿，再执行策略动作。
- **接触动作空间（关键创新）**：
  - 核心洞察：完成任务前必然存在机器人-物体首次接触状态，因此可直接采样高价值接触状态，避免在自由空间中浪费仿真时间。
  - 算法流程：
    1. 从生成网格表面均匀采样接触点，并依据表面法线随机采样夹爪朝向。
    2. 用 cuRobo 做 GPU 加速碰撞检测，剔除物理无效接触位姿。
    3. 对每个有效接触位姿构造“想象状态” s，即当前场景不变但夹爪位于该接触位姿。
    4. 用学习到的价值函数 V(s) 计算每个接触状态的价值。
    5. 训练时按 softmax 概率采样接触状态以平衡探索与利用：
       \[
       p(s)=(1-K)\frac{e^{V(s)/T}}{\sum_i e^{V(s_i)/T}}+K\frac{1}{N}
       \]
       其中 T 控制温度，K 控制均匀采样概率；还使用“价值函数预热”，初期高 K 以减少价值函数初始化偏差。
    6. 测试时选择最高价值且有无碰撞逆运动学解的接触位姿，用运动规划移动到位。
  - 接触后策略输出 6D 相对末端执行器动作；为加速探索，策略学习残差动作，叠加在缩放后的 goal flow 向量上。
  - 多阶段任务中，完成第一阶段后再次采样接触状态，重复“接触—执行策略”过程直到超时。
- **铰接物体扩展**：
  - 对铰接物体，仍用 InstantMesh 从单视图生成整体网格。
  - 假设关节参数、关节限制和门分割已知。
  - 用 Foundation Pose 跟踪铰接部件位姿，并作为策略输入。

## 3. 实验设计：数据集 / 场景、Benchmark 与对比方法

- **硬件平台**：
  - 7-DoF Franka Research 3 机械臂，配柔性夹爪。
  - 腕部相机 RealSense D435，用于拍摄物体 RGB-D 图像和重建背景。
  - 外部 RealSense D455 相机，用于执行时通过 Foundation Pose 跟踪物体。
- **Benchmark**：论文没有使用公开数据集，而是自建六个真实世界操作任务作为端到端 benchmark：
  1. **MultiStageBook**：先把书推到盒子侧面以暴露可抓取位置，但不能推落，再进行 6-DoF 抓取；多阶段、混合接触、两侧交互。
  2. **PushUpRamp**：把可乐罐推或滚上斜坡；需要精确平衡，且罐子未观测表面几何要正确生成。
  3. **SlideBowl**：从碗的远侧推动，使碗沿桌面滑向机器人；远侧不可见。
  4. **NovelPoses**：抓取并提起茶瓶；训练时物体在 20×20 cm 区域随机初始化并随机 z 轴朝向，测试新初始位姿泛化。
  5. **PullFromShelf**：从杂乱货架中拉出瓶子；多数抓取因碰撞无效，且扫描因遮挡不可行。
  6. **GraspHandle**：抓取玻璃杯；输入视角下手柄仅部分可见，但完成任务关键。
- **成功判定**：使用目标区域。MultiStageBook 要求书质心抬高，仅抓取算失败。
- **主要对比方法**：
  - **ZB-NoPrior**：不用 3D 先验，仅从单视图点云用 Poisson 表面重建部分网格。
  - **ACDC-NN**：ACDC real2sim 框架的最近邻检索基线，从数据库检索最相似物体网格。
  - 为公平比较，所有 real2sim 方法在构建仿真后都使用 ZeroBot 的 RL 训练框架。
- **训练速度消融对比**：
  - **NoContAct**：不使用接触动作空间，仅笛卡尔策略。
  - **NoContAct-Rew**：加入鼓励夹爪-物体接触的辅助奖励，类似 Gen2Sim。
  - **TrajOpt-Rew**：使用 CEM 与协方差钳制的轨迹优化，开环执行。
  - **CRL-Octree**：使用 Coarse-to-fine RL 通过八叉树逐步聚焦高价值区域。
  - **ZeroBot-Res**：主方法，接触后预测残差动作。
  - **ZeroBot-Dir**：接触后直接预测动作。
- **铰接物体实验**：
  - 任务：抓取并打开微波炉门。
  - 对比单视图生成网格与 RialTo 风格 oracle 网格：用 Polycam 从 164 个视角手动扫描重建。
  - 两种方法都使用 ZeroBot 的接触动作空间，因为 RialTo 原方法需要演示且训练超过 2 天，系统级比较不可行。
