## 摘要
难以直接从视觉推断的隐式物体属性，例如材质、容器内容物或柔软度，可以通过触觉传感和探索性交互得以揭示。然而，由于触觉信号是瞬态且稀疏的，提取有信息量的触觉事件并将其有效融入机器人操作仍然是一个挑战。在这项工作中，我们提出了一种以物体为中心的上下文感知操作框架，通过触觉探索学习任务无关的物体表示。一个 token 学习器自主地从长时程探索中选择具有代表性的触觉片段，而与描述性文本嵌入的对比对齐则使得潜在空间能够捕捉多种物理物体属性。随后，这些学到的表示被用作语义上下文，以指导以物体为中心的操作策略，并根据物体属性调整策略。实验表明，学到的表示在已见和未见物体上分别达到 93% 和 84% 的属性估计准确率。在涉及视觉模糊物体的三个任务（即多物体重排、倾倒和开箱）上进行评估，所提出的框架改善了目标选择和依赖属性的操作适应，在汇总所有评估试验后，相较于没有物体上下文条件的基线策略，将任务成功率在已见物体上从 41% 提升到 92%，在未见物体上从 19% 提升到 67%。视频和更多结果见 https://xinyiyxyx.github.io/tactile-object-centric/。

## Abstract
Implicit object properties that are difficult to directly infer from vision, such as material, container contents, or softness, can be revealed through tactile sensing and exploratory interactions. However, because tactile signals are transient and sparse, extracting informative tactile events and effectively incorporating them into robotic manipulation remains a challenge. In this work, we present an object-centric context-aware manipulation framework that learns task-agnostic object representations through tactile exploration. A token learner autonomously selects representative tactile segments from long-horizon exploration, while contrastive alignment with descriptive text embeddings enables a latent space that captures multiple physical object properties. These learned representations are then used as semantic context to guide object-centric manipulation policies and adapt strategies based on object properties. Experiments show that the learned representations achieve 93% and 84% property estimation accuracy on seen and unseen objects. Evaluated on three tasks involving visually ambiguous objects, i.e. multi-object rearrangement, pouring, and box opening, the proposed framework improves both target selection and property-dependent manipulation adaptation, raising task success, aggregated over all evaluation trials, from 41% to 92% on seen objects and from 19% to 67% on unseen objects over baseline policies without object-context conditioning. Videos and additional results are available at https://xinyiyxyx.github.io/tactile-object-centric/.

## 1. 核心问题与整体含义

- **研究动机**：视觉操作策略主要依赖可直接观察的视觉线索，但对于不透明或封闭容器等视觉模糊物体，材质、容器内容物、柔软度、填充程度等隐式属性无法从视觉直接推断，导致操作决策不确定、性能下降。
- **背景**：触觉传感与交互感知（如摇晃、滑动、敲击等探索性动作）能够揭示这些隐藏物理属性，对选择合适操作策略至关重要（如区分空/满容器以决定是否倾倒、根据刚性调整抓取方式）。
- **核心挑战**：触觉信号具有**瞬态、稀疏、事件驱动**的特性，关键物体线索被稀释在长时程探索序列中，因此需要紧凑且信息量高的表示学习方法；同时，如何将触觉得到的物体级语义有效融入下游操作策略也是一个难题。
- **整体含义**：论文提出一个以物体为中心、上下文感知的操作框架，通过触觉探索学习任务无关的物体表示，并将其作为语义上下文指导操作策略，以应对视觉模糊场景下的目标选择与属性自适应操作。

## 2. 方法论

### 2.1 核心思想

- 框架由两部分组成：
  1. **任务无关的物体表示学习模块**：通过触觉交互探索，学习捕捉多种物理属性的紧凑物体嵌入。
  2. **上下文感知的操作策略学习器**：将学到的物体表示作为语义上下文，指导基于 Action Chunking Transformer 的操作策略。
- 关键理念：用语言对齐的语义表示替代原始触觉嵌入作为策略条件，降低潜在空间变异，提升泛化性与策略稳定性。

### 2.2 物体表示学习

- **物体探索**：每个物体标注四个属性轴——内容物（空/固体/颗粒/液体）、填充程度（空/半满/全满）、材质（塑料/金属/玻璃）、刚性（刚性/可变形）。设计六种探索程序（EP）：摆动、摇晃、桌面敲击、陶瓷腔体敲击、挤压、桌面滑动。
- **多模态编码**：
  - 触觉振动信号：0.5 秒窗口、0.25 秒重叠，STFT 转频域（320 hop size、64 mel bins），用基于 PANN 的 CNN 骨干编码为 256 维 token。
  - 力信号（6 轴力/力矩）与末端速度信号（3 维线速度）：以 100 Hz 采样，各窗口 50 个样本，用 MLP 编码为 256 维 token。
  - 三种 token 拼接为多模态 token 序列。
- **Token 学习器**：
  - 学习一个评分函数为每个 token 分配相关性分数，前向传播中选择得分最高的 **K=18** 个 token。
  - 采用**直通估计器**：前向用硬 top-K 掩码，反向用可微软掩码，使评分网络能接收所有 token 的梯度。
  - 评分网络仅由三元组损失优化，无需辅助选择损失。
  - 选中的 token 按分数降序排列、拼接，投影为 256 维物体嵌入并做 L2 归一化。
- **文本语义对齐**：
  - 使用预训练 SentenceTransformer（all-MiniLM-L6-v2）生成属性描述文本嵌入（如“deformable”“empty”）。
  - 在每个属性轴上构造三元组（正样本属性匹配、负样本属性不匹配），聚合所有属性轴的三元组损失训练模型，margin=0.2。
  - 推理时通过物体嵌入与候选文本嵌入的**余弦相似度**估计物体属性。

### 2.3 上下文感知策略学习

- 基于 **Action Chunking Transformer**，由 Transformer 观测编码器和动作解码器组成。
- **物体上下文构建**：将学到的物体表示与物体坐标 (x, y, z) 的位置嵌入拼接，形成时间不变的物体上下文。
- 上下文以 **FiLM 风格**调节策略，与时间变化的视觉、本体感觉、触觉观测共同条件化。
- 物体位置嵌入用于对外部图像 token 进行注意力，生成以物体为中心的视觉嵌入；本体感觉特征关注腕部相机 token。
- 策略输出：7 维关节角度 + 1 维夹爪指令，动作块大小 64。
- 多物体场景下，先探索每个物体生成表示，策略依次以各物体表示与位置为上下文执行任务；当输出空闲动作时切换到下一物体。

  3. **开箱**（多指手）：四个外观相同盒子中识别并打开装有螺丝的重盒。

- **对比配置（六种）**：
  1. 无上下文基线（仅目标物体位置）
  2. 无物体位置基线（仅触觉交互 token）
  3. 触觉上下文、仅视觉
  4. 文本上下文、仅视觉（通过最近邻从触觉嵌入解码语义文本嵌入）
  5. 触觉/文本上下文 + 在线振动触觉（反应式输入）

## 6. 主要结论与发现

- **物体表示学习**：
  - 已见物体属性估计平均准确率 **93% ± 0.02**，未见物体 **84% ± 0.06**，泛化能力良好。
  - 三模态（振动触觉+力+速度）组合优于单模态或双模态，力与速度提供互补的激励动力学和接触状态信息。
  - Token 学习器优先选择挤压、摆动、摇晃、腔体敲击等短时高信息密度事件，而非均匀关注整个轨迹。
  - 与 CE 监督分类基线准确率相当（0.92/0.85 vs 0.93/0.84），但本文方法的错误模式为边界抖动，CE 基线存在系统性自信错误（玻璃材质物体 8 个种子全部失败）。
  - 开放词汇解码准确率仅小幅下降（0.88/0.81），表明嵌入空间与语言模型语义空间对齐。
  - 省略桌面敲击和滑动可将探索时间从 223 秒降至 138 秒，且保持属性预测精度。
  - 多指手上达到 96%（已见）/ 88%（未见）准确率，但在重量和颗粒度属性上表现较弱。
- **操作策略**：
  - 汇总所有评估试验，文本上下文策略在已见物体上成功 **154/167（92%）**、未见物体 **43/64（67%）**，基线无上下文仅 **69/167（41%）** 和 **12/64（19%）**。
  - 多物体重排：0.41 → 0.83（已见）、0.15 → 0.67（未见）；倒水：0.47 → 0.77；开箱：0.25 → 1.00。
  - 文本对齐语义上下文优于直接使用原始触觉嵌入（如 0.70→0.83、0.73→0.89），因为多对一映射降低潜在变异，决策更稳定。
  - One-hot 上下文在分布内表现接近（0.91/0.78 vs 0.94/0.83），但在未见物体上脆弱（0.80/0.48 vs 0.93/0.67），语言对齐上下文能捕捉属性值间语义关系，支持跨配置迁移。
  - 在线振动触觉反馈提升执行成功率（0.73→0.80、0.89→1.00），提供抓取稳定性所需的即时接触信息。
  - 未见物体上预测文本上下文与 Oracle 上下文任务成功率相同（0.67 vs 0.67），剩余失败主要来自低层执行（抓取不稳定、滑落、放置不准），而非语义误分类。

## 7. 优点

- **方法创新性**：
  - 将 TokenLearner 式自适应 token 选择引入长时程触觉探索，有效解决触觉信号稀疏、瞬态问题。
  - 触觉-语言对比对齐构建可解释语义潜在空间，支持开放词汇属性查询和跨物体泛化。
  - 将物体级触觉语义作为策略条件，区别于以往仅将触觉作为短时反馈的做法，实现属性依赖的操作策略自适应。
- **实验设计亮点**：
  - 在真实机器人平台上验证三个视觉模糊任务，涵盖平行夹爪与多指手两种具身形态。
  - 消融系统全面，包含模态、token 选择、监督方式、上下文类型、在线触觉、Oracle 对照等多维度。
  - 跨 8 个训练种子报告均值与标准差，统计严谨。
  - 区分决策准确率与任务成功率，能有效定位失败来源。
  - 开放词汇实验和探索时间-准确率权衡实验增强了实用价值。
- **结果表现**：已见/未见物体属性估计准确率高，下游任务成功率提升显著（41%→92%、19%→67%）。

## 8. 不足与局限

- **依赖预定义探索程序**：六种 EP 固定，机器人无法根据任务需求自主选择探索动作，也无法在物体上下文不足时主动请求额外观测。
- **离线数据收集与独立探索阶段**：操作前需要单独的探索阶段，增加任务总时间；不支持任务驱动的在线探索。
- **泛化瓶颈在执行层**：未见物体上语义决策准确率很高（0.93），但任务成功率受限于低层执行（不稳定抓取、滑落、放置不准），说明几何感知的抓取优化仍有提升空间。
- **多物体扩展性**：扩展到更大规模多物体场景需要更多演示数据，样本效率有待提高。
- **属性覆盖有限**：每个任务仅涉及 1–2

个物体或少数属性配置，难以充分验证模型在更复杂、多属性耦合场景下的鲁棒性；部分属性（如重量、颗粒度）在多指手实验上表现较弱，说明某些物理属性的触觉可分性仍受传感器精度、探索动作设计与数据覆盖限制。

- **语言对齐依赖预定义属性词汇**：文本嵌入来自预定义的属性描述及其释义，开放词汇能力仍受训练时属性轴和候选文本集合约束；对于训练中未出现的全新属性类别或更细粒度描述，泛化能力尚未充分验证。
- **硬件与传感器依赖较强**：方法依赖接触麦克风、六轴力/力矩传感器等高精度触觉硬件，跨平台迁移到低成本、不同构型或不同触觉模态的机器人系统时，通常需要重新采集数据并调整编码器与对齐策略。
- **在线探索与策略耦合仍不充分**：策略虽然可以接收在线振动触觉作为反应式反馈，但物体级语义主要来自离线探索阶段，尚未实现任务驱动地主动选择探索动作，或根据操作不确定性按需补充触觉信息。
- **计算与部署成本未充分披露**：论文未报告 GPU 型号、数量、训练时长、推理延迟与实时性指标，难以评估该方法在真实机器人系统中的部署可行性与计算开销。
- **对比基线范围有限**：未与更多现有触觉表示学习、多模态语言对齐或机器人操作策略方法进行直接比较，外部有效性与方法优越性仍需更多独立复现和跨实验室验证。
- **评估场景规模有限**：下游任务中的物体数量、场景布局与任务类型仍较受控，倒水等任务仅涉及少量容器，多物体重排也限于三物体；向开放环境、长时程任务和动态干扰场景扩展时，数据需求与泛化挑战会显著增加。

## 9. 总体评价与启示

- 论文的核心贡献在于将触觉探索得到的**物体级语义表示**与下游操作策略解耦又衔接，形成“探索—表示—决策—执行”的闭环：先通过触觉交互学习任务无关的物体嵌入，再以语言对齐的语义上下文条件化操作策略。
- 通过触觉-语言对比对齐，物体表示获得了可解释性与开放词汇查询能力，使策略能够在未见物体上保持较高的语义决策准确率，并显著优于无上下文或仅依赖原始触觉嵌入的基线。
- 实验表明，在视觉模糊场景中，触觉语义上下文对操作策略选择至关重要；但最终任务成功率仍受低层执行能力制约，尤其是抓取稳定性、滑落与放置精度，说明语义理解与几何操作需要更紧密的协同优化。
- 方法的主要启示是：触觉不应仅作为短时反应式反馈，而可以提升为物体级、任务相关的语义上下文；语言对齐则提供了一种紧凑、可迁移且便于人机理解的中间表示形式。
- 未来可能的方向包括：任务驱动的主动触觉探索与在线表示更新、更丰富的属性与物体类别覆盖、跨触觉硬件与具身形态的迁移、与几何抓取规划和低层控制更紧耦合的端到端策略，以及在更大规模多物体基准和仿真到现实环境中的验证。
