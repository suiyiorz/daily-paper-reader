## 摘要
人形移动操作要求机器人在执行协调的全身运动的同时，理解任务指令和场景语义。我们提出了一种分层框架，使用运动关键帧作为视觉语言模型（VLM）规划与强化学习（RL）控制之间的中间表示。每个关键帧指定目标全身机器人位姿，并在适用时指定物体位姿。给定语言指令、场景观测和执行反馈，VLM从预定义库中选择连续的与任务相关的关键帧。所选关键帧被重定向到当前场景，以考虑物体位姿和尺寸。随后，一个以关键帧为条件的全身策略生成关节级动作以达到这些目标。我们引入了一种基于显著性的关键帧采样策略用于底层策略训练，在使用稀疏VLM关键帧时将端到端任务成功率从44%提升至92%。我们在仿真和Unitree G1人形机器人上对物体拾取、运输和放置任务评估了我们的框架。系统成功执行单手和双手操作，并能泛化到训练参考数据之外的放置位置。

## Abstract
Humanoid loco-manipulation requires robots to interpret task instructions and scene semantics while executing coordinated whole-body motions. We propose a hierarchical framework that uses motion keyframes as an intermediate representation between Vision-Language Model (VLM) planning and Reinforcement Learning (RL) control. Each keyframe specifies a target whole-body robot pose and, when applicable, an object pose. Given a language instruction, scene observations, and execution feedback, the VLM selects successive task-relevant keyframes from a predefined library. The selected keyframes are retargeted to the current scene to account for object poses and dimensions. A keyframe-conditioned whole-body policy then generates joint-level actions to reach these goals. We introduce a saliency-based keyframe sampling strategy for low-level policy training that improves end-to-end task success rate from 44% to 92% when using sparse VLM keyframes. We evaluate our framework on object pickup, transport, and placement tasks in simulation and on a Unitree G1 humanoid. The system successfully performs both one- and two-handed manipulation and generalises to placement locations beyond the training reference data.

## 1. 核心问题与研究背景

- **研究动机**：人形机器人在真实环境中执行 loco-manipulation（移动操作）任务时，既需要理解任务指令与场景语义、将长时程任务分解为子任务，又需要生成动态可行的全身协调运动。这两类需求分别对应高层任务规划与底层运动控制，如何将二者有效集成是通用人形操作的核心难题。
- **现有方法的瓶颈**：
  - **VLA（Vision-Language-Action）端到端模型**可直接从图像与指令预测动作，但需要大规模、机器人本体相关的交互数据，采集成本高、耗时长。
  - **强化学习（RL）**在复杂腿足系统低层控制上表现强大，可从重定向的人类动作中学习行走、舞蹈等技能，但难以扩展到需要多技能规划与切换的长时程任务。
  - **关键接口问题**：VLM 用视觉和语言推理语义目标，而低层 RL 控制器通常需要精确状态观测与结构化目标输入，二者之间缺乏合适的中间表示。
- **论文含义**：提出以**运动关键帧（motion keyframes）**作为语言级规划与关节级控制之间的中间表示，构建分层框架 KINO，在无需机器人特定大规模数据的前提下，将 VLM 的语义推理能力与 RL 全身控制能力结合，并在仿真与真机上验证。

## 2. 方法论

### 2.1 核心思想
- 系统解耦高层语义推理与低层全身运动执行：给定文本指令、机器人状态上下文与场景视觉观测，VLM 从预定义**关键帧库**中选择下一个任务相关关键帧（如接近、下蹲、拾取等中间姿态）；关键帧经**重定向（retargeting）**适配当前场景后，交由**关键帧条件化的低层策略**生成关节级动作。
- 通过将 VLM 约束为“关键帧选择”而非连续关节命令预测，避免为高层规划收集机器人特定数据。

### 2.2 关键帧条件化策略（Low-Level Policy）
- **问题建模**：低层运动执行建模为目标条件化 RL 问题。策略在每个控制步接收本体感知、物体状态、上一动作与下一关键帧。
- **观测向量**：包含机器人基座局部线/角速度、投影重力向量、关节位置与速度、物体局部位置与四元数、上一动作、关键帧目标 K_t。
- **关键帧表示 K_t**：包含目标根位置与朝向（基座坐标系）、目标关节角、目标物体位置与朝向；若关键帧不涉及物体，则物体项置零。策略输入使用过去 10 帧观测历史。
- **非对称 Actor-Critic**：Critic 额外接收特权观测（参考运动状态、当前状态与目标误差 ΔK_t、剩余时间 τ_t），并使用 3 帧时序历史，以辅助训练期价值估计；部署策略仅依赖真实可得观测。
- **训练算法**：PPO；参考运动数据库涵盖 locomotion、箱子操作、水桶操作。
- **奖励设计**：分为三组——参考跟踪奖励（DeepMimic 形式，匹配根位姿/速度、关节构型、身体位姿、物体位姿）、关键帧目标达成奖励（仅在目标时刻激活）、正则化奖励（惩罚力矩、动作变化率、关节加速度、足部打滑）。采用**多 Critic 公式**（V_track、V_goal、V_reg）缓解不同奖励组间的负干扰。
- **动作输出**：29 维目标关节位置，由 PD 控制器跟踪（Unitree G1）。
- **Sim2Real**：采用域随机化，包括摩擦、物体与机器人质量、质心偏移、执行器增益、关节参数、执行器延迟、观测噪声、外部推力。

### 2.3 机器人关键帧：采样与库构建
- **显著性关键帧采样（核心贡献之一）**：
  - 以参考运动中的代表性帧作为训练关键帧目标，要求训练关键帧分布接近推理时 VLM 预测的稀疏关键帧。
  - 对 locomotion，随机采样未来帧即可；但对 pick-and-place 等含明显阶段（接近、抬起、运输、放置）的任务，均匀采样会过度代表行走中间帧、低估关键事件。
  - 方法：基于选定机器人身体与物体运动的加速度剖面提取显著关键帧。先计算聚合加速度信号 Γ(t) = Σ_j ‖p̈_j(t)‖₂，经低通滤波后在局部邻域内取极大值得到候选 P_Γ；再过滤由周期性腿运动引起的候选（通过左右腿加速度剖面的相位相似性与周期性判断）；随后用物体竖直加速度峰值作为物体事件候选 P_o 进行精修，保留时间容差 δ 内的候选，并补充未与已有候选重合的物体事件；最终显著关键帧集为 P_salient = {1, T} ∪ P_r ∪ P_new_o。
- **关键帧库**：包含运动数据集中代表性姿态，每个关键帧对应一个语义运动阶段（接近、抬起、搬运等），包含机器人全身姿态及（若适用）物体位姿，规定机器人与被操作物体的标称空间关系，并配对自然语言描述。在线执行时 VLM 依据文本标签选择关键帧。

### 2.4 场景对齐
- **关键帧重定向**：因库中为通用机器人-物体配置，而实际物体位姿与尺寸可能不同，需先旋转源物体坐标系对齐目标物体朝向，再通过变换 T_{i→∗}(p) = c* + R*((R_iᵀ(p − c_i)) ⊘ h_i ⊙ h*_i) 将末端执行器与机器人根位置变换到目标物体位姿与尺寸（⊘、⊙ 为逐元素除/乘，h 为包围盒半尺寸）。机器人根仅更新水平坐标。之后用迭代阻尼最小二乘 IK 恢复其余机器人构型，目标函数最小化末端位置误差与加权竖直足部残差（保持足部贴地），使用 MuJoCo 广义位置积分。
- **路径规划**：部署时在初始与目标 locomotion 关键帧之间构造中间关键帧序列，用切向对齐的圆弧（必要时最短有效 Dubins 路径）表示轨迹；曲率限制为 3 m⁻¹（最小转弯半径约 0.33 m），以限制训练中未出现的急转。路径密集采样后贪婪选取中间目标：从每个选定目标出发，选择航向累计变化不超过 45° 且相对上一目标欧氏位移不超过 2 m 的最远后续样本。

### 2.5 VLM 规划器
- **角色**：解释用户指令与当前场景，选择下一语义关键帧，并判断任务是否完成。
- **规划上下文**：每次请求前更新，包含上一关键帧、上一目标是否完成及成功与否、当前机器人根位姿、当前物体位姿、目标物体位姿、控制器诊断（如目标误差）。若上一关键帧成功到达则推进到下一阶段，否则重试或选择恢复关键帧。
- **约束输出**：强制返回结构化 JSON（如 keyframe、object_to_manipulate、task_complete）。物体操作标志决定重定向是否保持物体相对手部构型以及物体位姿是否作为活动目标；任务完成标志终止规划循环。
- **闭环执行**：事件驱动循环，仅在机器人与物体达到静止状态且上一目标有足够时间完成后才发送新 VLM 查询；收到有效响应后关键帧进入重定向模块生成低层策略目标。

## 6. 主要结论与发现

- **关键帧作为接口有效**：运动关键帧可作为 VLM 语义规划与 RL 全身控制之间的实用、可解释的中间表示，支持长时程人形 loco-manipulation。
- **显著性采样显著提升成功率**：在稀疏 VLM 关键帧条件下，端到端任务成功率从**均匀采样的 44% 提升到 92%**（分阶段：Pick 97%→99%，Place 63%→95%）。
- **目标到达精度提升**：显著性采样在大多数阶段取得更低的目标到达误差（根位置、关节 RMSE、物体位置），唯一例外是放置阶段的物体位置误差（0.227 m 高于均匀采样的 0.082 m），原因是参考运动中放置关键帧的箱子离机器人过近导致动作不稳定，RL 策略通过匹配根位置而把物体放得更远来修正。
- **泛化能力**：策略能在训练参考数据覆盖轮廓之外的放置位置成功放置，说明关键帧目标使策略具备超出训练轨迹的泛化性。
- **语义选择能力**：VLM 能根据指令中的物体类型选择单手或双手操作关键帧，并能检测失败并自主重试。
- **实时性**：VLM 规划（<0.2 s）与重定向（约 5 ms）开销小，可嵌入实时控制管线。

## 7. 优点

- **接口设计巧妙**：将 VLM 限制为从带语言标签的关键帧库中做离散选择，避免了对机器人特定动作数据的依赖，同时保留 VLM 的语义与视觉推理能力，输出结构化、可直接对接重定向器与策略。
- **显著关键帧采样有针对性**：通过加速度剖面 + 腿部周期性过滤 + 物体运动精修，使训练关键帧分布贴近推理时的稀疏 VLM 关键帧，直击“训练/推理关键帧分布不匹配”问题，且消融显示巨大收益（44%→92%）。

- **工程可复现性较好**：对观测向量构成、关键帧表示、奖励分组、域随机化项、路径曲率限制（3 m⁻¹）、中间目标选取规则（航向累计 ≤45°、位移 ≤2 m）等均有较具体描述，便于他人复现与调参。
- **实时性满足闭环要求**：VLM 决策 <0.2 s、重定向约 5 ms，相比低层控制周期几乎可忽略，说明该分层接口在实际机器人管线中是可用的。

## 8. 局限与不足

- **任务域较窄**：仅验证了两类 pick-transport-place（双手箱子、单手水桶），未涉及装配、工具使用、多物体交互、需要精细力控或接触丰富型的操作，也未涉及更长时程、多阶段依赖的任务。
- **依赖预定义关键帧库与人工语义标注**：关键帧库来自参考运动数据集并配对自然语言标签，系统能力上界受限于库的覆盖范围；对于库中不存在的技能或物体类别，VLM 无法“创造”新关键帧，只能从已有选项中选。
- **依赖外部物体位姿估计**：真机实验中物体相对位姿来自外部动捕系统，而非机载视觉；这削弱了“仅凭 VLM + 本体感知即可部署”的主张，也限制了在非结构化环境中的实用性。
- **训练资源与成本未披露**：低层 RL 策略的 GPU 型号/数量、训练时长、环境步数、参考运动规模对性能的影响等均未报告，难以评估方法的整体计算代价与可扩展性。
- **缺乏与强基线的定量对比**：没有与端到端 VLA、其他分层规划方法（如 ReKep、FALCON 等）在统一任务与指标下比较，因此“关键帧接口优于其他中间表示”的结论证据尚不充分。
- **真机评估偏定性**：真机仅提供示例性展示，缺少多次试验的成功率统计与误差分布，难以判断 sim-to-real 差距的实际大小。
- **失败模式与恢复策略分析有限**：论文指出放置阶段物体位置误差反而变大（0.227 m vs 0.082 m），归因于参考运动中放置关键帧箱子离机器人过近导致策略不稳定，但未进一步给出系统性修正方案或更细的失败分类统计。
- **关键帧采样方法的通用性待验证**：基于加速度显著性与腿部周期性过滤的采样策略在 locomotion + 操作混合场景中有效，但对纯操作、非周期性或慢速精细任务是否仍适用，尚缺证据。
- **VLM 幻觉与鲁棒性风险**：规划器仅被约束为从库中选择，若 VLM 误判场景或物体类型，可能导致错误关键帧选择；论文虽有失败重试机制，但未量化 VLM 误判率及其对整体成功率的影响。

## 9. 启示与可借鉴之处

- **“离散语义接口”是连接大模型与低层控制的有效范式**：把连续动作预测问题转化为从带语言标签的离散技能/姿态库中选择，既降低了对机器人特定数据的需求，也让高层输出天然结构化、可校验、可回滚。
- **训练分布要匹配推理分布**：显著性关键帧采样之所以带来 44%→92% 的巨大提升，本质是让训练时目标关键帧的稀疏性与推理时 VLM 输出对齐；这一“分布对齐”思路可迁移到其他分层/目标条件化 RL 系统。
- **重定向层的归一化变换设计**：基于相对位置归一化 + 包围盒尺寸缩放 + IK 足部约束，使同一通用关键帧可适配不同尺寸与位姿的物体，是一种低成本获得几何泛化的实用技巧。
- **多 Critic 分解奖励**：将跟踪、目标达成、正则化三组奖励分别配一个价值函数，缓解奖励组间的梯度冲突，对多目标 RL 训练有普遍参考价值。
- **闭环事件驱动规划**：仅在系统静止且上一目标有充足执行时间后才查询 VLM，既节省算力，也避免高频重规划带来的抖动，是 LLM/VLM 嵌入实时控制回路的良好工程实践。
- **可解释性与可调试性**：关键帧携带语义阶段标签，使失败可定位到具体阶段（Approach/Pick/Place），便于分阶段统计与针对性改进。

## 10. 总体评价

KINO 的核心贡献不在于提出新的 RL 算法或新的 VLM，而在于**接口设计**：用带语义标签的运动关键帧作为 VLM 与全身控制器之间的中间表示，并配套解决了“训练关键帧分布与推理关键帧分布不匹配”这一关键工程问题。方法在两类人形 loco-manipulation 任务上展示了较高的仿真成功率、超出训练覆盖的泛化能力以及可用的真机实时性，消融结果（44%→92%）具有较强的说服力。

其主要短板在于任务多样性、基线对比、真机定量评估与训练成本透明度。总体而言，这是一篇问题定位清晰、系统集成完整、工程细节扎实的工作，为“大模型语义规划 + RL 全身控制”的分层人形操作提供了一个可复用的参考框架，但距离通用人形操作仍有明显距离。
