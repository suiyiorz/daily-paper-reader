## 摘要
人类演示提供了一种可扩展的方式来收集操作数据，但当其接触被迁移到机器人手时，可能不稳定或不可行。直接在目标机器人上收集演示可以避免这种不匹配，但会大幅增加数据收集成本。为了解决这一权衡，我们提出了 Touch2Robot，一个让人类在收集演示的同时看到目标机器人手将如何接触物体的框架。我们捕获人类操作过程中的人手运动、触觉手套测量和物体运动。这些记录指导针对特定物体的强化学习（RL）策略复现所演示的物体运动，同时偏好与所记录人类触觉一致的接触。我们将学习到的行为蒸馏为一个统一的实时重定向器，将输入的人类观测和物体几何映射为机器人手构型。在收集过程中，预测的机器人构型与仿真中跟踪的物体位姿同步，以重建机器人-物体接触，并将其可视化，以帮助演示者调整后续交互以适应目标手。在四个真实世界任务中，相比仅视觉反馈，Touch2Robot 将平均真实机器人重放完成率从 37.9% 提高到 72.1%，同时将每次重放成功演示的收集时间从 58.6 秒减少到 18.2 秒。重建的目标手接触相对于真实机器人触觉测量达到 44.2% F1，而在 Touch2Robot 演示上训练的策略相比仅视觉反馈，将下游 Diffusion Policy 性能提高了 29.1 个百分点。这些结果表明，将机器人触觉引入人类演示闭环可以提高可扩展灵巧数据收集的质量和效率。项目网页：https://Touch2Robot.github.io/。

## Abstract
Human demonstrations offer a scalable way to collect manipulation data, but their contacts may be unstable or infeasible when transferred to a robot hand. Collecting demonstrations directly on the target robot avoids this mismatch but substantially increases the cost of data collection. To address this trade-off, we present Touch2Robot, a framework that lets humans collect demonstrations while seeing how the target robot hand would contact the object. We capture human hand motion, tactile-glove measurements, and object motion during human manipulation. These recordings guide object-specific RL policies to reproduce the demonstrated object motion while favoring contacts consistent with the recorded human touch. We distill the learned behaviors into a unified real-time retargeter that maps incoming human observations and object geometry to robot hand configurations. During collection, the predicted robot configuration is synchronized with the tracked object pose in simulation to reconstruct robot-object contacts, which are visualized to help the demonstrator adapt subsequent interactions to the target hand. Across four real-world tasks, Touch2Robot improves average real-robot replay completion from 37.9% to 72.1% over visual-only feedback, while reducing the collection time per replay-successful demonstration from 58.6s to 18.2s. Reconstructed target-hand contacts achieve 44.2% F1 against real-robot tactile measurements, and policies trained on Touch2Robot demonstrations improve downstream Diffusion Policy performance by 29.1 percentage points over visual-only feedback. These results show that bringing robot touch into the human demonstration loop improves both the quality and efficiency of scalable dexterous data collection. ## 1. 核心问题与整体含义
- **研究动机**：人类演示是采集操作数据的可扩展方式，但人手接触模式受人类形态与运动学约束，迁移到机器人手时可能不稳定或不可行。
- **现有矛盾**：直接在目标机器人上采集演示可保证具身兼容，但每条演示都需物理机器人执行，成本高、速度慢。
- **现有路线不足**：
  - 以人为中心的采集可扩展，但不暴露目标机器人接触状态。
  - 机器人遥操作能捕获目标具身交互，但依赖昂贵硬件。
  - 人到机器人重定向可可视化机器人手，但仅显示运动学姿态，无法揭示“是否、何处、何时”建立接触。
- **核心问题**：能否在人类演示采集过程中，让演示者看到目标机器人手的接触状态并据此调整动作，而无需为每条演示执行物理机器人？
- **整体含义**：论文提出 Touch2Robot，将机器人触觉反馈引入人类演示闭环，把人类触觉视为跨具身接触偏好，在保持人类演示可扩展性的同时提升机器人可执行性与数据质量。

## 2. 方法论
### 2.1 核心思想
- 人类触觉作为**跨具身接触偏好**：物体运动规定“应发生什么”，人类触觉指导“机器人应如何接触物体”。
- 三阶段框架：
  1. 触觉引导的物体特定 RL 重定向教师；
  2. 蒸馏为统一实时重定向器；
  3. 闭环演示采集中在线重建并可视化目标手接触。

### 2.2 触觉引导 RL 重定向
- 采集带触觉的人类演示轨迹：人手运动 \(q_H\)、触觉观测 \(\tau_H\)、物体 6D 位姿 \(x_o\)。
- 建立人机共享语义接触空间：
  - 将人手与机器人手映射到对应语义区域（指尖、手掌、侧接触等）。
  - 接触状态表示为二值向量 \(c_H, c_R \in \{0,1\}^K\)。
  - 计算接触转移 \(\Delta c_H = c_H^t - c_H^{t-1}\)，\(\Delta c_R\) 同理。
- 触觉奖励同时匹配瞬时接触模式与接触出现/消失时序：
  - \(r_{tac} = -D(c_H, c_R) - \lambda_\Delta D(\Delta c_H, \Delta c_R)\)。
  - \(D\) 为对应区域平均绝对差。
- 物体特定 RL 教师：
  - 基于 ConTrack 约束跟踪形式，使用 MTBench 多轨迹优化。
  - 策略输出相对参考的残差动作：\(q_{tar} = q_{ref} + a_R\)。
  - 残差惩罚：超过关节特定阈值的残差被平方惩罚。
  - 物体跟踪奖励：位置误差与旋转误差的加权平方惩罚。
  - 总奖励：\(r = \lambda_1 r_{obj} + \lambda_2 r_{tac} + \lambda_3 r_{act}\)。
- **引导到自由的动力学课程**：
  - 轨迹分为自由动力学前缀和参考引导后缀。
  - 前期由模拟器物理推进物体状态，后期重置到参考状态。
  - 逐步增大自由动力学前缀 \(T_f\)，直至全程自由动力学。

### 2.3 统一重定向器蒸馏
- 输入：
  - 物体几何经 PointNet 编码为 32 维特征 \(g_o\)。
  - 近期人类运动、触觉偏好、物体运动历史 \(h_t\)。
- 使用轻量因果 Transformer 融合历史与几何，预测机器人目标构型与接触状态：
  - \((\hat q_{tar}, \hat c_R) = f_\theta(h_t, g_o)\)。
- 蒸馏损失：
  - 机器人关节目标回归损失 + 接触状态二元交叉熵损失。
- 蒸馏后得到单一几何条件化模型，支持实时部署。

### 2.4 闭环演示采集
- 采集时记录人类运动、人类触觉与物体位姿。
- 重定向器预测机器人构型，在仿真中重建机器人手并与跟踪物体位姿同步。
- 将仿真接触映射到目标手语义触觉区域，生成二值触觉状态。
- 通过 VR 以 30 Hz 显示机器人手运动与重建接触，端到端延迟 122 ms。
- 演示者可根据接触差异调整后续动作，形成在线闭环。
- **机器人就绪视觉观测**：用 SAM 分割并移除人手，用 ProPainter 修补背景，再按标定相机参数渲染机器人手，生成与目标具身一致的 RGB 观测。
