## 摘要
任务规划在长时程操作中连接高层指令与可执行行为，然而现代视觉-语言-动作（VLA）系统往往将这一中间结构隐式化。现有的思维链（CoT）规划器也往往依赖粗粒度的任务级标注，或逐 token 序列化冗长的推理轨迹。我们提出 X-Planner，一个规划前端，同时处理具身推理的监督与表示问题。我们的规划数据在分层粒度下融合了 Ego、UMI 与遥操作，且标注深度因数据来源而异。接管时刻标注与人工设计的失败案例监督进行中的错误识别。在模型方面，一个共享的 VLM 主干提供两种事件结构化规划形式：一种离散接口，输出可解释的事件状态；以及一种潜在接口，通过 Staircase Decoding 在交错的 Transformer 深度间传递连续的 CoT 状态。一个冻结的潜在到文本重建目标为潜在表示提供语义锚点。离线两步规划评估中，在 BERTScore-F1 与基于评判器的 Overall 分数上，X-Planner 在四个受评估模型中均位列第二。在真实机器人实验中，分别优于所评估的基线。这些结果刻画了规划文本质量与下游执行性能。

## Abstract
Task planning bridges high-level instructions and executable behavior in long-horizon manipulation, yet modern Vision-Language-Action (VLA) systems often leave this intermediate structure implicit. Existing chain-of-thought (CoT) planners also tend to rely on coarse task-level annotations or serialize long reasoning traces token by token. We present X-Planner, a planning front-end that addresses both the supervision and representation of embodied reasoning. Our planning data combine Ego, UMI, and teleoperation under a hierarchy granularity with source-dependent annotation depth. Takeover-time annotations and human-designed failures supervise ongoing error recognition. On the model side, a shared VLM backbone exposes two event-structured plan forms: a discrete interface that emits interpretable event states and a latent interface that relays continuous CoT states across staggered Transformer depths through Staircase Decoding. A frozen latent-to-text reconstruction objective provides a semantic anchor for the latent representation. Offline two-step planning evaluation places X-Planner second among four evaluated models on both BERTScore-F1 and a judge-based Overall score. In real-robot experiments, respectively, outperforming the evaluated baselines. These results characterize planning-text quality and downstream execution.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作（VLA）模型通过"观测→动作"的直接映射，在短时程、规格明确的技能上表现良好；但长时程任务需要智能体先选择并排序有落地意义的子目标，再下发低层指令。
- **核心矛盾**：现代 VLA 系统普遍把这一中间规划结构**隐式化**，规划既是多模态表示问题，也是规划问题。已有 CoT 规划器虽引入推理，但具身任务规划在**数据构造、规划粒度、解码策略**三方面仍然割裂。
- **论文归纳的三个缺口**：
  - **数据缺口**：常用任务级描述或手写子目标列表，很少标明子目标边界；重抓取、失败接触、重试、姿态微调等会被"pick up the object"一类标签掩盖；且失败样本常来自单一策略，过度代表该策略的特征性错误。
  - **粒度缺口**：多数规划器采用外部强加的单一粒度（固定语义层级的文本，或预测子目标图像/光流）。固定长度 chunk 可能切裂一个行为或合并多个行为。
  - **延迟缺口**：传统 CoT 逐 token 自回归解码，长 rollout 中反复处理重叠的视觉-语言上下文，串行关键路径长且易误差传播；潜变量 CoT 虽用连续状态替代离散 token，但许多方法仍保留潜变量步间的串行依赖。
- **论文主张**：以**语义事件**作为规划单元——一段时间上连贯、可执行的行为（如 reach、grasp、lift、place），其边界跟随行为变化；这样的规划步在语言上有意义、在视频中可观察、在控制上可实现，是高层指令与低层控制之间的合适中间层。
- **整体含义**：X-Planner 被定位为一个**规划前端**，接收高层指令与当前多视图观测，输出事件结构化表示，用于条件化下游的 world-action 模型。

## 2. 方法论

### 2.1 核心思想
用共享 VLM 主干同时提供两种事件结构化的规划形式：**离散接口**（可解释的事件状态）与**潜变量接口**（经 Staircase Decoding 在交错 Transformer 深度间传递的连续 CoT 状态），并用冻结的潜变量→文本重建目标为潜变量提供语义锚点。

### 2.2 规划数据与分层监督
- **三源数据**：Ego、UMI、遥操作演示，统一到 **L3 Task / L2 Subtask / L1 Action / L0 Segment** 层级。
  - 遥操作：四层齐全（L3–L0）；
  - Ego 与 UMI：仅 L1–L3，因其运动更快、L0 边界难以可靠标注，Action 为其最细标注层。
  - 使用前对视觉/动作流做同步与缺失观测、时间戳不一致、不可用记录的筛查。
- **失败感知的进行中监督**：标注干预回合中的**接管时刻**，为执行期错误识别提供时间监督；再用**人工设计的失败演示**补充策略采集的失败，以降低对单一策略失败分布的依赖。
- **三类结构化状态**：初始计划（有序事件计划，执行开始时）、进行中（当前/下一事件、归一化进度、延续状态、错误识别）、回合结束（最后一个可用媒体帧的最终事件状态与 episode-end 标记）。
- **标注缺口处理**：缺失层级不贡献监督；Ego/UMI 无 L0 不被当作"负 Segment 标签"。

### 2.3 两种计划形式
- **离散形式**：输出紧凑事件状态而非孤立 caption；启动时给出有序初始计划，rollout 中覆盖归一化进度、当前事件、下一事件、延续状态与执行错误识别；最后输出 episode-end 标记。状态可被人类或上游智能体检视与编辑，事件描述即下游 world-action 模型的文本接口。
  - 明确说明：episode-end 标记仅表示**记录媒体的边界**，本身不是语义任务成功的证明。
- **潜变量形式**：以 K_c 个连续推理状态表示计划，由 staircase 分支并行生成并直接注入下游 cross-attention 通路；两种形式共享 VLM 主干与事件落地语义，差别仅在计划以文本还是连续状态暴露。

### 2.4 文本条件接口
- 由边界掩码 m_txt 选取文本 token 的 VLM 隐状态 H_q，经可学习投影 P_Q 后，再经下游主干原生文本 MLP（M_T）映射到下游条件空间：
  **c_ℓ = M_T(P_Q(H_q[m_txt]))**。
- 该序列与图像 token 一起进入 world-action 的 cross-attention 层；对齐目标促使投影后的 VLM 状态匹配固定下游模型期望的文本特征几何，从而在不替换下游文本通路的前提下加入场景消歧、任务分解与进度感知的事件上下文。

### 2.5 Staircase Latent CoT（潜变量规划）
- 将 Transformer 在**中继深度 N_r** 处分割：下层编码共享的视觉-语言上下文，上层在不同推理步间专门化。
- 第一个潜变量位置遍历下层，产生被所有推理位置共享的**中继表示**；上层块随后**并行**更新各潜变量状态，每个位置拥有独立因果缓存：
  **ŷ_{1:K_c} = F_stair(x; N_r)**，其中 x =（多视图观测、指令 ℓ、可选历史 h）。
- 相对于完全自回归 rollout，该调度复用下层视觉-语言特征，潜变量无需离散 token 采样即可条件化下游 cross-attention。
- 作者明确限定：这种**架构上的串行计算缩减本身并不等于端到端控制延迟更低**，后者还取决于整个执行与调度栈。

### 2.6 冻结潜变量到文本重建
- 用前缀投影器 P_pref 将潜变量映射为冻结轻量语言模型嵌入空间中的 soft prefix（z_{1:K_c}），条件化该语言模型自回归重建对应文本 CoT 轨迹，损失为负对数似然 L_CoT。
- 仅优化 staircase 推理分支与 P_pref，重建模型保持冻结；目标是让潜变量保留**高层语义**，而非复制特定的 token 级隐状态轨迹；冻结解码器也可将潜计划渲染为文本以供定性检查。
