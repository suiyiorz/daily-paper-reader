## 摘要
我们提出了 S2Planner，一种轨迹规划器，它将三个前向摄像头与自车运动历史及当前驾驶指令相结合。经过微调的 DINOv3 主干网络和空间调优适配器生成多尺度图像特征；随后，一个由粗到细的解码器利用轨迹自注意力和相机投影交叉注意力来细化候选路点。其贡献在于将自车条件轨迹初始化与对多尺度图像特征的迭代、几何引导采样相集成，而非提出新的视觉主干网络或注意力算子。在 NAVSIM v1 非反应式评估中，先前报告的 navtest 运行获得了 88.03 PDMS。由于该运行是依据 navtest 性能选择的，这一数值具有探索性，不能解释为无偏的测试估计。要在未暴露数据上进行验证集选择评估、重复运行以及计算量测量，才能确立泛化性和效率。

## Abstract
We present S2Planner, a trajectory planner that combines three front-facing cameras with ego-motion history and the current driving command. A fine-tuned DINOv3 backbone and a Spatial Tuning Adapter produce multi-scale image features; a coarse-to-fine decoder then uses trajectory self-attention and camera-projected cross-attention to refine candidate waypoints. The contribution is the integration of ego-conditioned trajectory initialization with iterative, geometry-guided sampling of multi-scale image features, rather than a new visual backbone or attention operator. On the NAVSIM v1 non-reactive evaluation, the previously reported navtest run obtained 88.03 PDMS. Because that run was selected using navtest performance, this number is exploratory and cannot be interpreted as an unbiased test estimate. Validation-selected evaluation on unexposed data, repeated runs, and computational measurements are needed to establish generalization and efficiency.

## 1. 核心问题与整体含义

- **研究背景**：自动驾驶的运动规划要求模型综合场景观测、自车近期运动状态与导航指令，输出一条可行的未来轨迹。端到端规划器可直接学习这一映射，但由于传感配置、状态输入、评测协议与检查点选择方式的差异，不同方法之间难以公平比较。
- **核心问题**：作者探讨一个具体的设计问题——**能否跳过显式 BEV 表示与大规模轨迹词表，直接在候选轨迹点附近采样多尺度图像特征**，用于轨迹规划。
- **评测背景**：NAVSIM v1 在四秒**非反应式**仿真中评测轨迹（其他交通参与者按记录轨迹运动，自车按提议轨迹被 LQR 跟踪），PDMS 综合了碰撞、可行驶区域、进度、TTC 与舒适度。作者明确指出 PDMS 并不能代表交互式交通或闭环部署性能。
- **定位澄清**：模型使用三路前视相机 + 自车速度、纵向加速度、位姿历史与驾驶指令，因此被描述为"相机+自车状态"规划器，而非纯图像方法；缺少 LiDAR 不等同于仅用图像。
- **整体含义**：论文的核心贡献是**将自车条件轨迹初始化与几何引导的多尺度特征迭代采样进行整合**，而非提出新的视觉骨干或注意力算子。

## 2. 方法论

### 2.1 核心思想
以轨迹 token 为中心：先用自车状态生成粗略候选轨迹，再在每个细化阶段让候选路点通过标定投影去"采样"多尺度相机特征，并迭代更新路点坐标。全程不使用显式 BEV 预测头，也不依赖固定的轨迹词表（"anchor-free"仅指无预定义轨迹词表，粗路点仍作为注意力的参考点）。

### 2.2 语义多尺度场景编码器
- **特征提取**：三路前视相机（前左、前、前右）图像缩放后按顺序拼接为 $I_{all}\in\mathbb{R}^{H\times 3W\times 3}$，由微调 DINOv3 骨干编码，取多个中间块的 spatial 输出 $F^{(\ell)}=B_\ell(I_{all})$。由于是拼接后联合自注意力，不同视图 token 可互相访问，但也存在跨图像接缝的注意力问题。
- **多尺度模块**：采用 DEIMv2 的 Spatial Tuning Adapter（STA），将中间特征转换为多尺度层级 $F^{(s)}_{all}$；每个尺度按宽度三等分为三个相机带 $F^{(s)}_i$，用于后续交叉注意力的采样。

### 2.3 由粗到细轨迹解码器
- **初始化与 token 化**：学习轨迹 token $Q_{traj}\in\mathbb{R}^{M\times L\times D}$（$M$ 候选模式、$L$ 未来路点、$D$ 维度）。
- **初始轨迹编码（算法 1）**：先用 MLP 编码自车历史作为 K/V，通过交叉注意力把运动先验注入各模式；再用 DiT 风格的 scale-and-shift 条件调制块（条件来自瞬时速度、纵向加速度、驾驶指令），经自注意力与 FFN + 残差输出粗略轨迹 $T_{coarse}\in\mathbb{R}^{M\times L\times 3}$。**该块不做扩散采样。**
- **空间 Transformer（堆叠 K 次）**：
  - **轨迹自注意力（TSA）**：以粗轨迹点（中心点 + 四个自车足迹角点，归一化到前向 $x\in[0,32]$ m、侧向 $y\in[-32,32]$ m 区域）为参考位置，用可变形注意力在候选模式间交换信息。
  - **空间交叉注意力（SCA）**：每个轨迹查询只关注少量空间相关位置。粗轨迹点 $(x,y)$ 处于自车度量坐标系，按 pillar 式构造 $N_{ref}$ 个高度 $z_j$ 得到 3D 参考点，用各相机自身标定 $P_i$ 投影：
    $\tilde u_{ij}=P_i[x,y,z_j,1]^T$，有效投影需深度为正且像素落在该相机图像内；有效像素坐标再转换到 $F^{(s)}_i$ 的局部坐标系。最终按相机、pillar 高度、尺度三层求和聚合采样特征。
  - **关键几何细节**：前相机的标定投影**不**因拼接而偏移前左图像宽度，宽度偏移仅用于从拼接张量中切出该相机的特征带；无效投影应在注意力权重归一化前被掩码。
- **更新与打分**：每个阶段后经 MLP 解码出更新后的轨迹点，并作为下一阶段的参考点；最终阶段 token 经 MLP 输出各模式分数，返回最高分模式。

### 2.4 损失函数
- **中间监督**：多阶段 MoN（Minimum over N）损失，对各阶段预测与专家轨迹的 L1 距离取模式最小值，并按 $\alpha^{K-k}$ 衰减加权。
- **最终阶段损失**：由三部分组成——预测最优轨迹与专家轨迹的 L1、标签最优轨迹与专家轨迹的 L1、预测最优与标签最优之间的 L1（三者平均），再加上对模式分数的 BCE 损失（以 L1 距离最近模式为正样本构造 one-hot 标签），总分 $L_{total}=L_f+L_{intermediate}$。

## 6. 主要结论与发现

- S2Planner 将微调 DINOv3 + STA 与自车条件、由粗到细的轨迹解码器结合，其特点是**在候选路点的标定投影处采样多尺度相机特征，并在细化阶段之间更新路点**。
- 先前报告的 88.03 PDMS 与 DiffusionDrive 报告的 88.1 接近，但由于传感器、状态通道、算力预算与选择流程未对齐，且 S2Planner 为测试选择结果，**不能得出任一方法更优的结论**。
- BEV 辅助头实验只涉及一种头部设计与损失设置，其较低分数**不能推广为"BEV 表示普遍不必要"**。
- 现有单次运行消融与定性示例**无法**确立泛化性、相对近邻基线的统计优势、实时性或交互式驾驶能力。
- 后续工作路径：从 navtrain 构建日志不重叠的验证子集并在其上选定全部超参、冻结配置后再评测；由于 navtest 已被用于开发，独立泛化声明需要**未暴露的新评测集**；还需重复种子、场景级配对分析、仅状态对照、分相机编码对照，以及在指定软硬件下测量参数量、FLOPs、延迟、显存与吞吐，并进行交互式仿真或实车测试。

## 7. 优点

- **学术诚实度极高**：主动、反复地声明主结果与消融为 test-selected 的探索性结果，明确写出"88.03 不能作为无偏测试估计"，并给出可执行的纠正协议，这在同类论文中非常少见。
- **几何一致性处理细致**：明确区分"用于切出特征带的宽度偏移"与"标定投影"，指出前相机投影不应被前左图像宽度偏移；规定无效投影需在 softmax 归一化前掩码；指出投影坐标需在各尺度相机带局部坐标系内归一化。
- **对方法边界刻画清晰**：显式讨论拼接图像跨接缝注意力带来的限制、自车坐标系下 TSA 在非规则 (x,y) 网格上双线性采样的物理含义不明、空投影集回退行为待核实等实现级不确定性。
- **评测协议说明严谨**：给出 PDMS 官方实现链接、强调不能用取整平均列反推 PDMS、指出 NAVSIM v1 无标准 navval 因而需自行构建日志不重叠验证集。
- **方法设计合理**：用轨迹点作为可变形注意力的参考位置，避免固定轨迹词表与显式 BEV 头，稀疏采样降低注意力位置数量（尽管效率未被测量）。

## 8. 不足与局限

- **偏差风险（最严重）**：检查点与全部超参基于 navtest 选择，主结果与消融均被测试集污染；即使重跑也无法恢复 navtest 的"未触碰"地位，需要全新未暴露评测集。
- **统计与效率证据缺失**：无重复种子、无不确定性估计、无场景级配对分析；无延迟、显存、FLOPs、吞吐测量，因此**不能声称实时性或更低计算成本**。
- **复现性缺口**：DINOv3 变体、图像分辨率、接缝 patch 处理、模式数、路点间隔、采样点数、损失权重、训练轮数、随机种子均未记录；架构图与算法 1 中历史注意力与条件 Transformer 的处理顺序不一致，需查代码确认。
- **评测覆盖有限**：NAVSIM v1 为四秒非反应式仿真，背景参与者不响应自车，无法评估交互、长时域闭环与舒适性/类人行为；定性叠加图也不能证明无碰撞或对他车意图的预判。
- **对照不充分**：缺少仅自车状态基线、相机+状态基线、分相机 vs 拼接编码对照，以及等训练/等算力预算下与最近邻细化解码器的受控比较；BEV 结论仅来自单一头部设计。
- **应用限制**：方法未验证在交互式交通、真实道路部署中的表现；其"无 BEV、无轨迹词表"的设计是否在更复杂场景中保持优势仍是开放问题。
