## 摘要
本文提出了一种元多智能体强化学习（meta-MARL）框架，用于实现多智能体系统（MAS）中交互策略的快速适应。元强化学习（meta-RL）通过双层优化机制使智能体能够快速适应新任务/新环境。然而，现有的元强化学习通常聚焦于单智能体系统。将这些框架和算法扩展到多智能体系统会带来额外挑战，因为任务不仅由环境刻画，还由智能体的策略交互所刻画。为应对这些挑战，我们将多智能体强化学习（MARL）问题建模为马尔可夫博弈（MGs），并开发了一个元MARL框架，以实现在马尔可夫博弈分布上的交互策略快速适应。我们定义了一个称为meta-NE的新概念，用以描述元MARL问题中期望的解概念。我们建立了meta-NE与基于梯度博弈的元MARL算法的驻点之间等价的充分条件。我们在自动驾驶任务上的评估表明，所提出的meta-MARL方法相比预训练的MARL基线实现了更快的适应，验证了该框架的有效性。

## Abstract
This paper develops a meta-multi-agent reinforcement learning (meta-MARL) framework to enable fast adaptation of interactive policies in a multi-agent system (MAS). Meta-reinforcement learning (meta-RL) enables agents to rapidly adapt to new tasks/environments using a bi-level optimization mechanism. However, existing meta-RL generally focuses on single-agent systems. Extending these frameworks and algorithms to multi-agent systems poses additional challenges, as tasks are characterized by not only the environment but also agents' strategic interactions. To address these challenges, we model multi-agent reinforcement learning (MARL) problems as Markov games (MGs) and develop a meta-MARL framework for rapid interactive policy adaptation across a distribution of MGs. A new concept, called meta-NE, is defined to describe the desired solution concept in a meta-MARL problem. Sufficient conditions for the equivalence between a meta-NE and a stationary point of the gradient-play-based meta-MARL algorithm are established. Our evaluation on autonomous-driving tasks demonstrates that the proposed meta-MARL method achieves faster adaptation than pretrained MARL baselines, validating the effectiveness of our framework.

## 二、论文提出的方法论

### 2.1 核心思想

- 将 MARL 问题建模为**马尔可夫博弈（MG）**，每个任务由一个 MG 刻画（同时包含环境与智能体交互结构）。
- 在 MG 分布 $p(\mathcal{M})$ 上构建 **meta-MARL 双层优化框架**：内层对每个采样任务求取任务特定策略（即 NE），外层优化初始化的后适应性能。
- 定义 **meta-Nash equilibrium（meta-NE）** 作为元博弈的期望解概念，并建立其与梯度博弈算法驻点的等价条件。
- 针对**马尔可夫势博弈（MPG）**这一特殊子类，利用势函数构造 MAML 风格的元训练目标。

### 2.2 关键技术细节

- **MG 建模**：MG 由元组 $\mathcal{M} = (\mathcal{N}, \mathcal{S}, \mathcal{A}, P, r, \gamma, \rho)$ 定义，策略 $\pi$ 按智能体分解为 $\pi_1 \times \cdots \times \pi_N$，智能体 $i$ 的期望回报为 $J_i(\theta) = \mathbb{E}_{s_0 \sim \rho} V_i^\theta(s_0)$。
- **NE 与 MPG**：NE 定义为无智能体可通过单方面偏离提高回报的策略组合。MPG 是存在标量势函数 $\phi$ 的特殊 MG，满足智能体单边激励与势函数变化一致，从而具备确定性 NE 存在性和梯度博弈收敛性（Lemma 1）。
- **梯度博弈**：在 MPG 中，$\nabla_{\theta_i} J_i(\theta) = \nabla_{\theta_i} \Phi(\theta)$，因此梯度博弈等价于在总势函数 $\Phi$ 上的联合梯度上升。

### 2.3 Meta-MARL 框架

- **元博弈定义**：定义智能体 $i$ 的期望后适应回报
$$\Psi_i(\theta) := \mathbb{E}_{\mathcal{M}_m \sim p(\mathcal{M})} J_{i,m}(U_m(\theta))$$
其中 $U_m = U_{1,m} \times \cdots \times U_{N,m}$ 为分散式联合适应规则，且适应可依赖联合策略（coupled adaptation）。由此诱导出元博弈 $G = (\mathcal{N}, \{\mathcal{X}_i\}, \{\Psi_i\})$。
- **Meta-NE（Definition 3）**：策略初始化 $\theta^\star$ 为 meta-NE，若
$$\Psi_i(\theta_i^\star, \theta_{-i}^\star) \geq \Psi_i(\tilde{\theta}_i, \theta_{-i}^\star), \quad \forall \tilde{\theta}_i \in \mathcal{X}_i, i \in \mathcal{N}$$
- **Theorem 1（等价性）**：在正则性假设（Assumption 1）与元梯度支配假设（Assumption 2）下，策略是元博弈的一阶驻点**当且仅当**它是 meta-NE。证明通过凸性 + 方向导数（必要性）与梯度支配不等式（充分性）完成。
- **Proposition 1（势结构）**：若每个智能体的适应规则**独立于其他智能体策略**（即 $U_{i,m}(\theta_i, \theta_{-i}) = U_{i,m}(\theta_i, \theta'_{-i})$），且采样任务以概率 1 为 MPG，则元博弈 $G$ 是精确势博弈，势函数为
$$\Gamma(\theta) := \mathbb{E}_{\mathcal{M}_m \sim p(\mathcal{M})} \Phi_m(U_m(\theta))$$

### 2.4 MAML 风格算法

- **内层更新**（单步梯度上升）：
$$\theta'_{i,m} = \theta_i + \eta_1 \nabla_{\theta_i} J_{i,m}(\theta) = \theta_i + \eta_1 \nabla_{\theta_i} \Phi_m(\theta)$$
堆叠后为 $\theta'_m = \theta + \eta_1 \nabla_\theta \Phi_m(\theta)$。
- **元目标**：
$$\max_\theta \Gamma(\theta) = \max_\theta \mathbb{E}_{\mathcal{M}_m} \Phi_m(\theta + \eta_1 \nabla_\theta \Phi_m(\theta))$$
- **精确元梯度**（含 Hessian 项）：
$$\nabla_\theta \Gamma(\theta) = \mathbb{E}_{\mathcal{M}_m}\left[(I + \eta_1 \nabla_\theta^2 \Phi_m(\theta))^\top \nabla_{\theta'_m} \Phi_m(\theta'_m)\right]$$
- **一阶近似**：仿照 first-order MAML，省略 Hessian 项，用
$$\widehat{\nabla}_\theta \Gamma(\theta) := \mathbb{E}_{\mathcal{M}_m}\left[\nabla_{\theta'_m} \Phi_m(\theta'_m)\right]$$
- **Algorithm 1 流程**：采样任务批次 → 用 $\pi_{\theta^{(k)}}$ 收集轨迹 → 计算 $\nabla_\theta \Phi_m$ → 得到适应参数 $\theta'_m$ → 用 $\pi_{\theta'_m}$ 再收集轨迹 → 计算 $\nabla_{\theta'_m} \Phi_m$ → 估计一阶元梯度并更新 $\theta^{(k+1)} = \theta^{(k)} + \eta_2 \widehat{\nabla}_\theta \Gamma(\theta^{(k)})$。
