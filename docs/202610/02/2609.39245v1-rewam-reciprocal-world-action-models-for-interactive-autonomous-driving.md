## 摘要
在交互场景中，自动驾驶系统需要在其他智能体行为的影响下生成自车动作。现有的世界动作模型（WAMs）通常将其他智能体建模为世界模型的组成部分，而非将其视为从根本上塑造自车动作的决策者，这损害了它们在密集交互场景中的性能。我们提出互惠世界动作模型（ReWAM），一种博弈论世界动作建模框架，通过将自车和其他智能体表示为动作相互影响的条件响应者，来捕捉二者之间的相互影响。我们用一个 Level-$k$ 响应层级来实例化该框架，其中角色特定的自车和其他动作 DiT 通过跨智能体注意力交换紧凑策略令牌，同时仍以未来驾驶世界的共享表示为根基。为了从示范中学习自车的响应策略，我们将专家动作表述为来自最佳响应分布的样本，并使用条件流匹配联合优化整个层级。我们的框架在 NAVSIM 数据集上进行了评估，与基线相比取得了最先进的性能。该提升在交互场景中尤为显著，验证了建模互惠响应为交互感知的世界动作生成提供了更有效的基础。

## Abstract
In interactive scenarios, an autonomous driving system is required to generate ego actions under the influence of other agents' behaviors. Existing World Action Models (WAMs) typically model other agents as components of the world model rather than as decision-makers that fundamentally shape the action of the ego agent, which impairs their performance in dense interaction scenarios. We introduce Reciprocal World Action Models (ReWAM), a game-theoretic world action modeling framework that captures the reciprocal influence between the ego agent and other agents by representing them as conditional responders whose actions are mutually influenced. We instantiate this framework with a Level-$k$ response hierarchy, where role-specific ego and other action DiTs exchange compact strategy tokens through cross-agent attention while remaining grounded in a shared representation of the future driving world. To learn the response policy of the ego agent from demonstrations, we formulate expert actions as samples from the best response distribution and jointly optimize the entire hierarchy using conditional flow matching. Our framework is evaluated on the NAVSIM dataset and achieves state-of-the-art performance compared to baselines. The improvement is particularly significant in interactive scenarios, validating that modeling reciprocal responses provides a more effective foundation for interaction-aware world action generation.

  - **世界模型 / 世界动作模型（WAM）路线**：学习场景如何随时间演化，并将预测性世界表征直接暴露给规划过程。但现有 WAM 主要建模"自车动作如何影响未来世界"，**将他车仅视为世界模型的组成部分**，而非将其动作组织为对自车计划的策略性响应。因此，动作条件下的未来可能视觉上合理，却与交互诱发的行为不一致。
- **核心矛盾**：WAM 具备富有表现力的动作条件化潜表征，但缺乏显式的策略推理结构；交互感知预测与规划方法虽建模行为响应，却主要工作在显式状态/动作空间，其交互模块与生成式世界建模相分离，未能直接利用生成式世界模型的潜表征。
- **论文含义**：论文提出 **ReWAM（Reciprocal World Action Models）**，将博弈论中的 **Level-k 有限理性响应层级**直接嵌入生成式 WAM 的潜表征中，把自车与他车表示为**相互条件响应的决策者**，从而把 WAM 从单向的自车动作条件化推进到策略耦合的多智能体动作生成。

## 2. 论文提出的方法论

### 核心思想

- 用 **Level-k 博弈**将同时耦合的多智能体依赖关系转化为有限深度的策略响应序列：每个参与者在第 $k$ 层的最优响应，以其余参与者在第 $k-1$ 层的策略为条件，从而在避免在线求解联合均衡的同时保留互惠交互。
- 所有动作分支都**共享同一个未来驾驶世界的潜表征**，使自车与他车的响应建立在一致的世界演化预测之上。

### 关键技术细节

1. **Level-k 博弈建模**：
   - 参与者集合 $\mathcal{P}=\{e,1,\dots,N\}$，观测 $O_t$ 包含视觉历史、文本导航条件和当前参与者状态。
   - 定义参与者 $i$ 的期望回报 $J_i(\pi_i,\pi_{-i};O_t)$ 与最优响应集合 $BR_i(\pi_{-i};O_t)$。
   - Level-k 响应：$\pi_i^{(k)} \in BR_i(\pi_{-i}^{(k-1)};O_t)$，将循环依赖转化为有限序列，避免实时求解联合均衡。

2. **世界表征条件化的 Level-k 推理**：
   - 世界模型（Video DiT）由历史视觉观测 $I_{t-H:t}$ 和文本导航条件 $c_t$ 生成共享未来世界潜表征 $W_t \in \mathbb{R}^{L_v \times d_v}$。
   - **自车动作 DiT**（参数 $\theta_e$）预测自车对上一层所有他车策略的响应；**他车动作 DiT**（参数 $\theta_o$，在所有他车间共享）预测每个他车的响应。
   - 条件采样：$\tau_e^{(k)} \sim q_{\theta_e}(\cdot \mid W_t, s_t^e, Z_{-e}^{(k-1)})$，$\tau_i^{(k)} \sim q_{\theta_o}(\cdot \mid W_t, s_t^i, Z_{-i}^{(k-1)})$，其中 $Z^{(k-1)}$ 是上一层动作的策略编码器表示。

3. **从示范中学习最佳响应**：
   - 假设示范动作由联合专家策略 $\pi^E$ 产生，其各分量互为奖励最大化响应；据此定义示范诱导的条件响应分布 $p_{\text{demo}}(\tau_i \mid W_t, s_t^i, Z_{-i})$。
   - 学习目标为条件分布匹配：$\theta_i^\star = \arg\min_{\theta_i} \mathcal{D}(p_{\text{demo}}, q_{\theta_i})$，得到最优响应策略的摊销随机代理。

4. **Level-k 交互块（Action DiT Block）**：
   - 每个块依次执行：目标参与者未来动作 token 上的**时序自注意力** → 对 Video DiT 特征的**交叉注意力**（世界接地） → 对上一层其余参与者动作假设的**跨智能体注意力**（策略交互） → 前馈变换。
   - 跨智能体注意力：以目标参与者动作 token 为 Query，以前一层策略表示为 Key/Value，并通过掩码 $M_i$ 抑制 padding 参与者与目标自身策略 token，实现角色相关的可见性。

5. **联合学习与推理（条件流匹配）**：
   - 对参与者 $j$、推理层 $k$，采样示范动作 $x_{0,j}$、噪声 $\epsilon \sim \mathcal{N}(0,I)$、流时间 $r \sim U(0,1)$，构造插值状态 $x_{r,j}=(1-r)x_{0,j}+r\epsilon$ 与目标速度 $u_{r,j}=\epsilon-x_{0,j}$。
   - 参与者级损失为速度回归 $\mathcal{L}_j^{(k)}=\mathbb{E}\|v_{\theta_j}(x_{r,j},r \mid W_t,s_t^j,Z_{-j}^{(k-1)})-u_{r,j}\|_2^2$。
   - 按角色聚合（自车损失 + 他车掩码加权平均），再按归一化深度权重 $\alpha_k = k^p / \sum_{\ell=1}^{K_{\text{train}}} \ell^p$ 聚合为总损失 $\mathcal{L}_{\text{flow}}$，联合优化全部可训练参数。
   - 在总体最优处，条件流匹配可恢复每个有效参与者和每个监督推理层的示范条件响应分布。

## 6. 论文的主要结论与发现

- **SOTA 性能**：ReWAM 在 NAVSIM 上取得最高 PDMS **90.6**，比 DriveLaW 骨干提升 **1.5** 分，比此前 SOTA 方法 ReWorld 高 **0.2** 分；提升伴随 NC、DAC、TTC、EP 的全面改善，EP 提升最大。
- **推理深度效果**：从 Level-1 到 Level-4，PDMS 从 90.03 持续提升至 90.64，最大单层增益出现在 Level-2，之后递减；Level-5 在 NC 和 EP 上略有提升但 PDMS 不再增长且 DAC 略降，说明更深推理能捕捉策略依赖，但在主导交互结构被解析后出现收益饱和。
- **交互强度分层**：ReWAM 在全部五组中均优于两个基线，且优势随交互强度增加而扩大；在 Critical 组相对 DriveLaW 提升 4.59 PDMS，相对 DiffusionDrive 提升 2.54 PDMS。
- **密集交互分解**：在 Critical 子集上，ReWAM 在所有非饱和指标上均占优，NC 与 TTC 同时改善说明时空冲突预判能力更强；同时 DAC、DDC、EP 更高，说明冲突规避并非通过越野、方向不一致或过度保守实现，而是安全、规则合规与通行效率的更好协调。
- **定性结果**：窄路场景中 ReWAM 成功通过而两个基线失败；左转场景中 DiffusionDrive 轨迹近乎直行、错过转向，ReWAM 符合转向几何并保持平滑；直行场景中 DiffusionDrive 过度减速损失进度、DriveLaW 响应不足导致碰撞，ReWAM 以恰当轨迹与速度剖面避免冲突且不牺牲进度。
- **总体结论**：有界互惠响应推理为交互式世界动作建模提供了实用且有效的基础。

- **理论假设偏强**：
  - “专家示范动作互为奖励最大化最佳响应”是学习目标成立的前提，但真实驾驶日志中的专家行为包含多模态、次优、甚至非理性成分，条件分布匹配本质上仍是模仿学习，**不具备显式安全约束或硬性保证**。
  - 模型默认他车同样是 Level-k 响应者，但现实中他车可能非理性、具有不同信息集或采取对抗行为；论文未分析当交互对象偏离该假设时 ReWAM 的鲁棒性，也未与“他车视为环境”的基线在**非理性他车**场景下对比。
  - Level-k 的层级语义在自车与他车之间是对称施加的，但真实交互中自车通常拥有更强的感知与规划能力，这种角色不对称是否应反映在响应层级或策略先验中，论文未作讨论。
- **评价体系与结论稳健性**：
  - 仅使用 NAVSIM 的 PDMS 系列开环指标，PDMS 与真实闭环安全性、舒适性之间的相关性有限，且开环评估无法体现规划动作对后续他车行为的反馈闭环。
  - 未报告置信区间、多次随机种子运行结果或显著性检验；与 ReWorld 的 0.2 PDMS 差距、以及部分分量上 ReWorld 反而更优的事实，使“全面 SOTA”的结论需要更谨慎表述。
  - 缺少失败案例分析、长尾/极端场景（如施工区、无保护左转中的多车博弈、行人/骑行者混行）的针对性评估，定性示例仅三个场景，覆盖面较窄。
- **架构与训练细节的透明度**：
  - Video DiT 与 VAE、文本编码器被冻结，虽然降低了训练成本，但世界表征可能无法针对互惠推理任务进一步适配；论文未消融“冻结 vs. 微调”的取舍。
  - 先训练 Level-1 再微调 $k\ge2$ 的分阶段策略，其必要性、对最终性能的影响、以及各层是否共享或独立参数，均缺少消融支撑。
  - 深度权重指数 $p$、自车/他车损失权重 $\lambda_{\text{ego}}/\lambda_{\text{other}}$、他车 DiT 参数共享方式等关键超参数的敏感性未报告，复现与调参成本不明确。

## 9. 总体评述与启示

- **方法论贡献**：ReWAM 的核心价值在于把“交互”从世界模型的外部附加模块，转化为**潜表征内部的策略耦合结构**。Level-k 响应层级与生成式 WAM 的结合，提供了一条在保持世界动力学建模能力的同时引入有限理性策略推理的可行路径，避免了在线求解联合均衡的不可处理性。
- **对后续研究的启示**：
  - 可将互惠响应推理从“模仿专家最佳响应”推进到**与奖励/约束联合学习**，例如引入安全批评器、可行域投影或逆强化学习，以弥补纯分布匹配缺乏硬约束的缺陷。
  - 推理深度可探索**自适应机制**：根据交互复杂度动态选择 $K$，在简单场景节省算力、在关键博弈中加深推理，从而缓解收益饱和与实时性之间的矛盾。
  - 交互对象可扩展到行人、骑行者及异构交通参与者，并研究不同响应层级先验的分配策略。
  - 评估上亟需**闭环仿真与真实路测**，以检验开环 PDMS 增益能否转化为闭环安全与效率收益，并补充推理延迟、算力占用等部署指标。
- **定位判断**：论文在问题刻画、理论框架与架构设计上具有清晰创新，实验的分层分析也较有针对性；但受限于单一数据集、开环指标、组件级消融缺失以及性能优势幅度较小，其结论应视为“有前景的方向验证”，而非已被充分确证的最终方案。总体而言，ReWAM 为交互式世界动作建模提供了一个结构优雅、工程可复用的研究起点。
