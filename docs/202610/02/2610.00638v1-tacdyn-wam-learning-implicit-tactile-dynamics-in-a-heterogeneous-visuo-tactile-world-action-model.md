## 摘要
世界动作模型通过以预测的未来为条件来改进机器人操作，然而现有的触觉变体大多继承了视频生成流程，通过迭代去噪重建未来触觉观测。在部署漂移下，这种预测可能变得不可靠：接触位置或力的微小变化可能显著改变触觉像素，即使潜在的接触演化仍然可预测。我们提出 TacDyn-WAM，一种异构视触觉世界动作模型，其预测隐式触觉动力学，而非重建未来触觉观测。它学习 TacRep，一种具有动力学感知的触觉目标空间，通过触觉片段的掩码时空预测进行训练，并由关系结构蒸馏进行正则化。一个视觉专家和一个隐式触觉动力学专家在各自的目标空间中预测未来的视觉和触觉表征，同时通过联合注意力进行交互；触觉专家在单次前向传播中预测多个时域的未来表征及其变化，而只读触觉记忆提供当前触觉状态。在 UniVTAC 上，TacDyn-WAM 仅使用所提供的演示就达到了 81.5% 的平均成功率，达到最先进水平，并与在大规模视触觉轨迹上预训练的模型相比仍具竞争力。消融实验证实了两条触觉通路以及 TacRep 相对于像素重建和静态替代方案的益处。在五个真实机器人任务上，TacDyn-WAM 达到 71.0% 的平均成功率，而适度规模的预训练将其提升至 85.0%，进一步验证了我们的方法。

## Abstract
World action models improve robotic manipulation by conditioning actions on predicted futures, yet existing tactile variants largely inherit video-generation pipelines that reconstruct future tactile observations through iterative denoising. Such prediction can become unreliable under deployment drift: small changes in contact position or force may substantially alter tactile pixels even when the underlying contact evolution remains predictable. We introduce TacDyn-WAM, a heterogeneous visuo-tactile world action model that predicts implicit tactile dynamics rather than reconstructing future tactile observations. It learns TacRep, a dynamics-aware tactile target space trained through masked spatio-temporal prediction on tactile clips and regularized by relational structure distillation. A visual expert and an Implicit Tactile Dynamics Expert predict future visual and tactile representations in separate target spaces while interacting through joint attention; the tactile expert predicts future representations and their changes at multiple horizons in a single forward pass, and a read-only tactile memory supplies the current tactile state. On UniVTAC, TacDyn-WAM achieves an average success rate of 81.5% using only the provided demonstrations, reaching state-of-the-art-level performance and remaining competitive with models pretrained on large-scale visuo-tactile trajectories. Ablations confirm the benefits of both tactile pathways and TacRep over pixel-reconstruction and static alternatives. On five real-robot tasks, TacDyn-WAM reaches 71.0% average success, and modest-scale pretraining raises it to 85.0%, further validating our method.

# TacDyn-WAM 论文总结

## 1. 核心问题与整体含义

- **研究背景**：世界动作模型（World Action Model, WAM）通过“预测未来”来条件化动作生成，在机器人操作中取得进展。但现有触觉变体大多直接继承视频生成管线——用同一个 VAE 编码相机与触觉帧，并用视频骨干网络迭代去噪未来触觉 latent。
- **核心痛点**：
  - 迭代去噪导致推理慢，且将预测绑定到像素重建，而触觉观测本质上不适合像素重建。
  - **部署漂移（deployment drift）**：专家示范只覆盖“正确接触”附近的触觉图像；闭环误差使策略偏离示范分布。此时相机视图可能几乎不变，但接触位置或力的微小变化就会显著改变触觉像素。
  - 尽管像素层面剧变，**接触演化本身（压痕加深、滑动、旋转）往往仍然可预测**。
- **核心主张**：应进行**隐式触觉动力学建模**——在动力学感知的表征空间中预测接触演化，而非重建未来触觉观测。
- **关键判断**：并非所有 latent 空间都适合预测触觉演化。N0-VTLA 在冻结 DINOv2 特征空间中预测单时域净变化，但 DINOv2 是在静态自然图像上训练的，未显式优化帧间触觉演化；V-JEPA 2.1 通过预测掩码时空特征学习表征，更鼓励编码器捕捉可预测运动而非精确像素。

## 2. 方法论

### 2.1 整体架构

- **基础模型**：InternVLA-A1 的 3B checkpoint，Mixture-of-Transformers 世界动作模型，三个专家通过块级因果联合注意力耦合：
  - Understanding Expert（Qwen3-VL-2B）：编码当前 RGB 与语言指令为前缀块 U。
  - Visual Generation Expert：用冻结 Cosmos tokenizer 编码视觉历史块 V，预测未来视觉 latent $z^v_{t+15}$。
  - Action Expert：接收机器人状态 $s_t$ 与加噪动作块 A，通过 flow matching 去噪长度 H=50 的动作 chunk。
- **新增第四个专家**：Implicit Tactile Dynamics Expert（ITDE），与视觉专家构成**异构视触觉世界模型**——两者使用独立参数与独立目标空间，但每层通过联合注意力交互。
- **问题设定**：K 个基于视觉的触觉传感器（每夹爪两个）。给定 $C_t=(U,V,\{x^k_{t-3:t}\}_{k=1}^K,s_t)$，预测：
  - $\hat{z}^v_{t+15}=f_{vis}(C_t)$
  - $(\hat{z}^k_{t+h},\Delta\hat{z}^k_{t+h})=f_{tac}(C_t)$，其中 $h\in\{5,15,25\}$
  - $\hat{a}_t=f_{act}(C_t)$
  - 触觉目标为冻结动力学感知编码器 E 产生的未来表征 $z^k_{t+h}=E(x^k_{t+h})$ 及其相对当前的变化 $\Delta z^k_{t+h}=z^k_{t+h}-z^k_t$。

### 2.2 TacRep：动力学感知触觉表征空间

- **Tactile Dynamics Prediction（TDP）**：
  - Tactile Context Encoder $E_\theta$ 从蒸馏的 V-JEPA 2.1 ViT-B 初始化；输入四帧触觉视频片段，按 2 帧一组的 tubelet 分组为 2×24×24 patch token 网格。
  - Dynamics Target Encoder $\bar{E}$ 为 $E_\theta$ 的 EMA 副本。
  - 掩码一组时空块 M，编码可见 token，训练轻量预测器 $P_\phi$ 恢复被掩码 token 的目标编码器特征：$L_{TDP}=E_M\|P_\phi(E_\theta(X\setminus M),M)-sg[\bar{E}(X)]\|_1$。
  - 使用两个掩码视图（多小块 / 少大块），并在可见 token 上加同损失（权重 0.5）。每个掩码块跨全部四帧，迫使编码器理解压痕如何随时间移动。
- **Relational Structure Distillation（RSD）**：
  - 用冻结 DINOv2 ViT-B 作为关系结构教师，正则化局部 patch 关系，防止触觉输入偏离示范时空间结构不稳定。
  - 不直接回归特征值（会与 TDP 产生冲突目标），而是对齐局部余弦关系：$L_{RSD}=\frac{1}{|N|}\sum_{(i,j)\in N}\text{SmoothL1}(z_i^\top z_j-d_i^\top d_j)$，N 为 7×7 网格上相距不超过 2 行 2 列的 patch 对。
  - Stage 1 目标：$L_{TDP}+\lambda_{RSD}L_{RSD}$，$\lambda_{RSD}=0.1$。
  - 训练后丢弃预测器与教师，保留 Dynamics Target Encoder 作为后续 ITDE 使用的冻结 TacRep Encoder。

### 2.3 Implicit Tactile Dynamics Expert（ITDE）

- **上下文 token 与未来查询**：
  - 冻结 TacRep Encoder 将每个传感器的四帧片段转成两个时间特征图，平均池化为 4×4 网格，投影到 ITDE 隐藏维度，每个传感器得到 32 个 TacRep 上下文 token。
  - 每个预测时域 h∈{5,15,25} 附加 16 个可学习 Future Token Query（4×4 空间网格）。
  - 上下文与未来 token 均加空间、模态、连续时间嵌入；机器人状态 $s_t$ 在每层 Transformer 后通过零初始化条件块注入。
  - 每传感器 80 个 token 经过 28 层 Transformer（隐藏维度 1024，约 0.4B 参数），与视觉/动作专家层几何一致以便共享注意力，但从零初始化。
- **Future 与 Delta 表征**：
  - 未来 token 通过两个独立细粒度读出监督：16 个紧凑 token 在 0.4B 预测器外扩展为 7×7 预测。
  - Future Readout 与 Delta Readout 各含 49 个 7×7 可学习查询，交叉注意一个时域的 16 个未来 token，再经线性头映射到 TacRep 维度。
  - 目标来自冻结 TacRep Encoder 对单帧的编码并池化、归一化：$z^k_{t+h}=\text{norm}(\text{pool}(E(x^k_{t+h})))$，$\Delta z^k_{t+h}=z^k_{t+h}-z^k_t$。
