## 摘要
从有限示范中学习面向多样、长时程任务的鲁棒操作策略，仍是机器人学中的一项基础性挑战。我们提出 DROM，一种语言引导的扩散框架，使机器人能够在单一生成策略中学习、表示并组合多种操作技能。DROM 利用动态运动基元（DMPs）将少量专家示范扩充为具有表现力的多技能数据集，在显著减少数据采集的同时，提升超出示范工作空间的空间泛化能力。在运动规划扩散（MPD）的基础上，我们扩展了扩散架构，通过交叉注意力支持语言条件下的多技能轨迹生成，使单一模型能够为多种操作基元生成技能一致的运动，包括使用传统运动规划或硬编码控制器难以设计的姿态敏感行为。对于长时程操作，大型语言模型将高层操作员请求分解为可执行的技能序列，从而实现自然语言交互与自主任务执行。我们在 Franka Emika Panda 机器人、FANUC CRX25ia 机器人以及 MuJoCo 仿真中，针对广泛的操作任务验证了 DROM。实验结果表明，DROM 优于运动规划扩散和行为克隆基线，实现了稳健的多技能泛化，并能组合所学技能，仅使用少量人类示范即可根据自然语言指令可靠地执行长时程操作任务。数据集、仿真环境及更多内容见 https://github.com/automation-robotics-machines/drom。

## Abstract
Learning robust manipulation policies for diverse, long-horizon tasks from limited demonstrations remains a fundamental challenge in robotics. We present DROM, a language-guided diffusion framework that enables robots to learn, represent, and compose multiple manipulation skills within a single generative policy. DROM leverages Dynamic Movement Primitives (DMPs) to augment a small set of expert demonstrations into expressive multi-skill datasets, substantially reducing data collection while improving spatial generalization beyond the demonstrated workspace. Building upon Motion Planning Diffusion (MPD), we extend the diffusion architecture to support language-conditioned multi-skill trajectory generation through cross-attention, allowing a single model to generate skill-consistent motions for a diverse set of manipulation primitives, including orientation-sensitive behaviors that are difficult to design using conventional motion planning or hard-coded controllers. For long-horizon manipulation, a large language model decomposes high-level operator requests into executable sequences of skills, enabling natural language interaction and autonomous task execution. We validate DROM on a Franka Emika Panda robot, a FANUC CRX25ia robot, and in MuJoCo simulation across a wide range of manipulation tasks. Experimental results demonstrate that DROM outperforms Motion Planning Diffusion and Behavior Cloning baselines, achieves robust multi-skill generalization, and composes learned skills to reliably execute long-horizon manipulation tasks from natural language instructions using only a limited number of human demonstrations. Datasets, simulation environments, and more at https://github.com/automation-robotics-machines/drom.

  - 视觉-语言-动作（VLA）等基础模型虽然具备强生成与多模态推理能力，但依赖互联网规模数据、推理计算量大、延迟高，难以在真实硬件上实现实时响应式控制。

- **关键缺口**：如何在**不进行大规模人类示范采集**的前提下，满足扩散模型对密集数据的需求，同时实现语言引导的长时程任务执行，且不将语言模型延迟引入底层控制回路。
- **整体含义**：DROM 提出一个语言引导的多技能扩散框架，将 **DMP 数据增强**、**语言条件多技能扩散**与**LLM 高层任务分解**结合，实现从少量示范到多技能学习与长时程组合的规模化桥接。

## 2. 方法论

### 2.1 核心思想

DROM（Diffusion for RObotic Manipulation）由四阶段流水线构成：
1. 少量专家示范采集；
2. 基于 DMP 的合成数据增强；
3. 技能条件扩散模型训练；
4. 在仿真与真实平台部署。

推理时，通过聚类共形预测判断用户指令对应**单一操作基元**还是**长时程任务**：前者由语言编码器直接映射到对应技能；后者交由 LLM 分解为有序技能序列。

### 2.2 数据采集与 DMP 增强

- **示范采集**：通过动觉教学（真实机器人 FANUC CRX25ia、Franka Emika Panda）或 SpaceMouse（MuJoCo 仿真）采集，频率 30 Hz，轨迹固定视界 H=64。
- **轨迹表示**：每个路点包含笛卡尔末端位置 (Px, Py, Pz)、四元数姿态 (Qx, Qy, Qz, Qw) 及二值夹爪指令 G∈{−1,+1}。
- **DMP 增强**：为每条示范学习一个 DMP，通过扰动起始与目标状态生成轨迹变体，保持底层运动模式。每个技能生成固定 **300 条**合成轨迹；若同一技能有 Lk 条示范，则轨迹预算均分给对应 DMP。
- **DMP 公式**：采用二阶动态系统  
  $\ddot{y}(t)=\alpha_y(\beta_y(g-y(t))-\dot{y}(t))+f(x)$  
  其中 $f(x)$ 为归一化径向基函数加权和，使用 N=200 个高斯基函数，$\alpha_y=25$、$\beta_y=6.25$，通过局部加权回归学习权重。

### 2.3 技能条件扩散模型

- **基础架构**：沿用 MPD 的 Temporal U-Net，含 4 层时间下采样（通道 32→256）、瓶颈层、对称上采样与跳跃连接，约 **6000 万**可训练参数。
- **扩散过程**：
  - 前向：$q(\tau_t|\tau_{t-1})=\mathcal{N}(\tau_t;\sqrt{1-\beta_t}\tau_{t-1},\beta_t I)$
  - 闭式边际：$q(\tau_t|\tau_0)=\mathcal{N}(\tau_t;\sqrt{\bar\alpha_t}\tau_0,(1-\bar\alpha_t)I)$
  - 训练目标：$L(\theta)=\mathbb{E}_{t,\epsilon,\tau_0}[\|\epsilon-\epsilon_\theta(\tau_t,t)\|_2^2]$
- **技能条件注入**：将学习到的语言嵌入 $f_\theta(p)$ 通过 **交叉注意力层**注入 U-Net 每一层，使单一模型可表示 17 种操作基元，并区分几何相似但运动策略不同的行为。
- **多模态性**：模型学习的是有效操作策略的分布，而非记忆单条轨迹，能根据物体配置选择正确的操作模式。

### 2.4 语言引导规划

- **聚类共形预测**：
  - 离线阶段为每个技能收集话语样本，计算同技能样本间最大余弦相似度作为共形分数，将技能聚类后按分位数设定阈值 $\lambda_k$。
  - 推理时三种情形：① 所有技能分数均高于阈值 → 视为未脚本化/OOD 任务，交由 LLM；② 多个技能低于阈值 → 分类不确定，交由 LLM 消歧；③ 仅一个技能低于阈值 → 直接选择该技能执行。
- **LLM 技能序列生成**：
  - 使用 **gpt-oss-120b**，提示中包含可用动作列表、可用物体、各动作参数及 few-shot 示例。
  - 采用 **思维链** 结构生成技能序列 $s=[p_1,p_2,\dots,p_n]$ 或返回不可执行 token。
  - 应用**约束解码**，屏蔽不在可用技能集合中的生成结果，降低幻觉风险。
- **语言编码器**：使用预训练 **all-MiniLM-L6-v2**（6 层 Transformer，384 维嵌入），兼顾语义区分与低延迟。

## 3. 实验设计

### 3.1 数据集与场景

- **真实机器人平台**：FANUC CRX25ia 与 Franka Emika Panda，共 **17 种操作基元**（Pick/Place Battery、Pick/Place Bottle、Pick Cup、Pour Liquid、Co-Transport、Shelf、Button、Slide、Stir、Pick/Stack Cube、Grab Handle、Open/Close Drawer、Place in Drawer）。
- **仿真环境**：MuJoCo + Robosuite 的 **Stack** 与 **Mug Cleanup** 环境，镜像真实 Franka 设置。
- **语言评估数据**：
  - 语言编码器：600 条平衡标注指令（6 个技能 × 100 条）。
  - LLM 规划：每类任务 50 条自然语言指令，共 250 条查询，5 个随机种子。
  - 共形预测：900 条话语（750 单技能、50 长时程、100 OOD），150 条校准集 + 750 条测试集。
- **长时程任务**：Pick and Place、Pour、Stack、Hide、Clean Up（1–3 个物体，序列长度 5–9）。

### 3.2 Benchmark 与对比方法

- **主要对比基线**：
  - **MPD（Motion Planning Diffusion）**：单任务扩散规划器，作为主要对比。
  - **Behavior Cloning（BC）**：仿真环境中的模仿学习基线。
- **评估指标**：任务成功率、技能组合成功率、序列执行成功率、端到端请求到目标成功率、语言识别准确率/精确率/召回率/F1。

### 3.3 实验设置

- 扩散模型训练 500  epochs，DDIM 调度器 25 步去噪，Adam 优化器，batch size 32，初始学习率 $10^{-5}$，早停。
- 每个技能 50 次验证试验，部分实验使用 3 个随机种子。
- 物体定位使用 50mm×50mm ArUco 标记（DICT 4X4），PnP 算法估计位姿，2 秒滚动中值滤波。

## 6. 主要结论与发现

- **RQ1**：DMP 增强使少量示范即可训练出鲁棒策略。增加示范**多样性**（而非单纯数据量）是提升方向敏感技能性能的关键：Pick Bottle、Pick Cup、Pour Liquid 从 1 个示范的 24%/28%/22% 提升至 4 个示范的 84%/86%/92%。
- **RQ2**：单一语言条件扩散模型可有效编码 17 种操作技能，DROM 在所有技能上一致优于 MPD，并在仿真中优于 BC。模型展现出多模态轨迹生成能力，能根据物体配置选择正确操作模式（如瓶把手插入方向、抽屉把手几何）。
- **RQ3**：DROM 能端到端执行语言引导长时程任务，Pick and Place 成功率 86.0%，Hide 70.4%，Pour 70.0%，Stack 67.5%，Clean Up 60.9%。技能组合成功率（72.5%–100%）是端到端性能的主要瓶颈，而非扩散模型执行能力（80%–90%）。
- **失败分析**：最大失败来源为 LLM 生成错误技能序列（16.8%），扩散模型相关失败较少（抓取失败 4.4%、放置失败 2.8%、碰撞 2.8%）。
- **不确定性量化**：共形预测将 69% 的测试话语路由至 LLM，31% 路由至嵌入模型，平均延迟从 3996 ms 降至 2761.49 ms，整体准确率 78.40%。
- **总体结论**：DROM 以少量人类示范实现语言引导的多技能学习与组合，为通用长时程机器人操作提供了可扩展的生成式策略框架。

## 7. 优点

- **数据效率高**：DMP 增强将少量专家示范扩展为密集多技能数据集，显著降低数据采集成本，并提升超出示范工作空间的空间泛化能力。
- **统一多技能建模**：通过交叉注意力将技能嵌入注入 Temporal U-Net，单一扩散模型同时处理 17 种操作基元，避免为每个子任务单独训练模型。
- **语言条件双通道设计**：轻量语言编码器负责单技能快速检索，LLM 负责长时程任务分解与 OOD 检测，兼顾低延迟与高层推理。
- **不确定性量化**：引入聚类共形预测，显式区分单技能请求、长时程任务请求与 OOD 请求，并降低平均推理延迟。
- **跨平台验证**：在 MuJoCo 仿真与两个真实机器人平台（FANUC CRX25ia、Franka Emika Panda）上验证，增强结论的可信度与硬件泛化性。
- **多模态轨迹生成**：定性实验证明模型学习的是操作策略分布而非记忆单条轨迹，能根据物体姿态选择正确操作模式。

## 8. 不足与局限

- **动态适应性不足**：扩散模型不显式考虑执行过程中物体位置变化；一旦轨迹生成，环境或物体配置的变化无法直接触发轨迹重生成。
- **感知与生成模块解耦**：视觉管线与扩散模型为独立模块，无法在轨迹生成过程中持续融合视觉观测，限制了反应式适应能力。
- **依赖基准标记**：物体定位依赖 ArUco 标记，虽有助于隔离感知误差，但限制了在非结构化环境中的直接部署。
- **高层规划为主要瓶颈**：LLM 生成错误技能序列占失败总数的 16.8%，长时程与可变长度任务（如 Clean Up）的组合成功率较低。
- **成功率的误差累积**：端到端成功率大致为组合成功率与执行成功率的乘积，长序列任务中早期错误会传播并降低整体性能。
- **算力资源有限**：仅在单张 RTX 4070 上训练与评估，未验证更大规模模型或更大数据集下的扩展性。
- **应用限制**：当前框架适用于结构化工业与协作场景，向动态环境、人机协作、在线自适应及未知物体操作的扩展仍需进一步研究。
