## 摘要
在本文中，我们提出了一种用于自动驾驶的偏好自适应滚动时域控制框架，该框架考虑了乘客偏好和晕动症易感性。我们构建了一个有限时域最优控制问题，其中速度、加速度舒适性和晕动症的权重可自适应调整，同时保持碰撞风险的权重固定。我们使用基于晕动症症状分类（MISC）量表的个体化模型在线预测晕动症，并利用贝叶斯推断根据由情绪导出的成对比较离线更新偏好权重。确定性安全监督器检查规划轨迹，并在必要时修改控制指令。我们在三种晕动症易感性水平下，使用三种模拟乘客画像对框架进行评估。学习到的权重产生了不同的闭环行为，并且在九个场景中有七个场景的平均评估情绪得分得到提升。在全方法实验中未发生碰撞，而安全监督器在学习帧中进行了1.621%的干预。

## Abstract
In this paper, we present a preference-adaptive receding-horizon control framework for autonomous driving that accounts for passenger preferences and motion-sickness susceptibility. We formulate a finite-horizon optimal control problem with adaptive weights for speed, acceleration comfort, and motion sickness, while maintaining a fixed weight for collision risk. We predict motion sickness online using an individualized model on the Motion Illness Symptoms Classifi- cation (MISC) scale and update the preference weights offline from emotion-derived pairwise comparisons using Bayesian inference. A deterministic safety supervisor checks the planned trajectory and modifies the control command when necessary. We evaluate the framework using three simulated passenger profiles under three motion-sickness susceptibility levels. The learned weights yield distinct closed-loop behaviors, and the mean evaluation emotion score improves in seven of nine scenarios. No collisions occur in the full-method experiments, while the safety supervisor intervenes in 1.621% of the learning frames.

## 一、核心问题与研究动机

- **背景**：自动驾驶在安全性与机动性上已有长足进展，但乘客个体差异巨大——对"速度 vs 舒适"的权衡偏好不同，对晕动症（motion sickness）的易感性也不同。采用固定控制目标的控制器无法代表个体乘客的真实偏好。
- **现有方法的缺口**：
  - 逆强化学习、轨迹比较/偏好学习、贝叶斯优化等虽可适配车辆行为，但**未直接建模个体化、历史依赖的晕动症**。
  - 晕动症源于前庭—视觉信息冲突的**累积效应**，无法由瞬时加速度单独刻画；已有的感官冲突模型与个体化累积模型（如 Kotian 等基于 Oman 框架的 AM2 模型）只解决"预测"问题，**未解决"如何从乘客反馈中推断其对晕动症、速度、加速度舒适度的权衡"**。
- **整体含义**：论文试图把"个体化晕动症预测"与"基于情绪反馈的偏好学习"耦合进滚动时域控制中，使自动驾驶控制既能适配个体偏好，又由独立安全监督器兜底，为个性化且安全的自动驾驶提供一条可行路径。

## 二、方法论

### 1. 核心思想
- 构造**有限时域最优控制问题**，其中速度、晕动症、加速度舒适度的权重 `w = [wv, wM, wa]` 由乘客偏好学习得到并自适应更新；**碰撞风险权重固定**，使学习只改变乘客相关目标的相对重要性。
- 采用"在线规划 + 离线偏好学习 + 独立安全监督"的三段式架构（论文图 1）：
  - **在线**：由 ego、乘客、周围车辆状态进入有限时域规划，输出加速度/转向指令；
  - **离线**：由闭环 episode 的成本轨迹与情绪分数进行 episode 选择、偏好查询与权重更新，再回灌给规划器。

### 2. 关键技术细节

**（1）车辆动力学与约束**
- 状态 `s = [x, y, ψ, v, δ]`，控制 `u = [ax, δcmd]`，采用运动学自行车模型并以中点法离散；由模型导出横摆角速度 `ωz` 与侧向加速度 `ay`。
- 输入约束：转向速率/转角幅值限制、纵向加速度区间；运动约束：车速上限、横摆角上限、侧向加速度上限。
- 道路约束分两层：车辆外包矩形（含横摆引起的侧向膨胀 `hy(ψ)`）不得越界 + 车身中心位置额外规划裕度。

**（2）乘客状态与晕动症模型**
- 以 **MISC 量表**（0 = 无症状，10 = 呕吐）表征晕动症，采用 Kotian 等的个体化模型：先用 Wada 的群体平均 SVC 模型生成感官冲突，再用基于 Oman 的**两参数累积模型 AM2** 累积冲突。
- 乘客内部状态 `χ = (ξ, z1, z2)`，易感参数 `θ = (θT, θK)` 假设已知（可由既有方法独立辨识，不在本文范围）。视觉模式 `g ∈ {internal, external, closed}` 每步可得。

**（3）代价函数**
- 总代价：`min Σ [λp·Jp(k) + λs·J_TTC(k)]`，其中 `λp + λs = 1`，实验中取 `λp = λs = 0.5`。
- 乘客相关代价：`Jp = wv·Jv + wM·JM + wa·Ja`
  - 速度代价 `Jv = ((vmax − vk+1)/vmax)²`（速度亏缺的平方）；
  - 加速度舒适代价 `Ja = ½[(ax/ax,lim)² + (ay/ay,max)²]`，加速/制动分别用不同归一化量；
  - 晕动症代价 `JM = αM·h(f_M) + (1−αM)·M/Mmax`，其中 `h(z) = 6z⁵ − 15z⁴ + 10z³` 为平滑阶跃，`f_M` 在 `[M0, M1]` 区间内线性过渡，参数取 `M0 = 0.75, M1 = 1, Mmax = 10, αM = 0.75`。即：在快速恶化区之前代价很小，接近不适阈值时急剧上升。
- 碰撞风险代价：以 **TTC** 为软约束，用与中点航向对齐的**保守旋转椭圆**包住 ego 与周围车辆的重叠区域，椭圆半轴 `Ai,k, Bi,k` 由相对位置/速度解析求最小非负解得到 TTC；`J_TTC = (1 − min(TTC/TTCth, 1))²`，阈值 `TTCth = 5 s`，TTC 越大代价为 0。

**（4）贝叶斯偏好学习**
- 定义 episode 的奖励特征 `r(τ) = [−Jv^τ, −JM^τ, −Ja^τ]ᵀ`（episode 内累积）。
- 假设 4：乘客偏好 episode 平均情绪分更高者——把情感响应转成二元比较标签，避免要求乘客回忆整段行程。
- 偏好概率用 Bradley–Terry / softmax 形式：`pab(w) = exp(wᵀr(τa)) / [exp(wᵀr(τa)) + exp(wᵀr(τb))]`。
- 用 `max min{Ew[1−pab], Ew[pab]}` 主动挑选信息量最大的 episode 对。
- 后验 `p(w | q1:Nq) ∝ p(w) · Π p(qm | w)`；为强制权重为正且和为 1，令 `w = softmax(η)`，对 `η` 各分量放独立标准正态先验；用 **MCMC** 采样后验，取归一化样本均值作为后续 episode 的偏好向量。
- 每 `L = 8` 个新 episode 更新一次；合格对须含至少一个新 episode 且 `‖Δr‖ > 1e−8`；按信息量排序保留至多 L 对，打标签后丢弃平局。

**（5）滚动时域实现与安全监督**
- 每步用 **SLSQP（NLopt）** 求解 Problem 1；ego 与乘客状态按各自模型前推，周围车辆用 **IDM** 预测；假设乘客视觉策略已知。
- 只执行首个控制指令；若求解失败，退化为"零纵向加速度 + 朝全局前向转向"的**回退序列**（注意：该回退由直接生成而非约束优化得到，不保证满足标称约束）。
- **确定性安全监督器**：在短时域 `HS = 6` 步（1.5 s）内检查预测轨迹是否"可容许"（ego 足迹与中心在道路边界内、且不进入保守成对碰撞包络）。若不可容许，则在有限候选常数指令集 `US` 中搜索，用 `JS(u*)` 选择最接近触发时速度/航向的可行指令；若无可容许候选，则选择**使预测违规时间最晚**的指令。

## 三、实验设计

- **场景**：直行三车道高速公路，车道宽 3.6 m，18 辆由 IDM 控制的周围车辆，期望速度 12–21 m/s；ego 从中道 16 m/s 起步。约束：`0 ≤ v ≤ 25 m/s`、`−4.0 ≤ ax ≤ 2.2 m/s²`、`|ay| ≤ 2.2 m/s²`。
- **乘客画像（合成测试用例，非人群级模型）**：
  - **Alice**（速度导向）：情绪 = `|v|`，视觉模式恒为 internal；
  - **Bob**（连续权衡）：情绪 = `|v| − 2|ax| − 3|ay| − 4M`，视觉模式随 MISC 分段切换；
  - **Zoey**（阈值敏感）：MISC < 1 时情绪 = `clip(|v|/25, 0, 1)`，MISC ≥ 1 时情绪 = `−1000·clip(M, 1, 10)`（刻意设置的不连续，用以测试平滑加权目标能否容纳突变偏好）。
- **易感水平**：Low / Medium / High 三档，采用 Kotian 等报告的个体参数聚类（θK = 9.5/10.8/41.5，θT = 86.2/27.2/58.4 s），共 **3 × 3 = 9 个场景**。
- **Benchmark / 对比基线**：
  - 主要基线是**初始均匀权重** `wv = wM = wa = 1/3`，与学习后的最终权重在**相同 4 个固定评估种子**上对比；
  - **特征消融**对比：Full（三特征）vs **VA**（仅速度+加速度）vs **VM**（仅速度+MISC），两者权重各初始化为 0.5。
- **学习与评估协议**：每场景 256 个学习 episode，每 8 个更新一次，共 32 次更新；每次后验更新用 4 条 MCMC 链，1000 步 burn-in + 4000 步采样，隔一取一（每链 2000 个保留样本），提议标准差 0.3。评估用 4 个固定种子 episode（不参与学习）。全方法研究共 **2304 个学习 episode、1188 个评估 episode**。单 episode 最长 60 s，碰撞则提前终止；控制间隔 0.25 s，预测时域 40 步（10 s），用 4 段分段常数控制块降维。

## 六、主要结论与发现

- **学到的偏好具有区分度**：
  - Alice 三档易感下均学成强速度导向，`wv ∈ [0.865, 0.983]`；
  - Bob 在低/中易感下 `wM` 最大（0.806 / 0.648），高易感下权重转向速度与加速度（0.550 / 0.423）；
  - Zoey 随易感升高，`wv` 从 0.874 降至 0.610、`wa` 从 0.032 升至 0.331，而显式 MISC 权重一直较小。
  - 作者强调这些权重**不应解读为对情绪函数系数的还原**，而是"控制器特征在解释 episode 比较时的相对贡献"。
- **闭环性能**：9 个场景中 **7 个平均情绪提升**；Alice 三档车速均上升但 MISC 与 RMS 加速度同步上升；Bob-low 在维持车速的同时把平均 MISC 从 0.254 降到 0.229。
- **失败案例（关键发现）**：Zoey-high 中一个评估 episode 越过 `M = 1` 阈值（峰值 1.079，持续 7.75 s），触发情绪函数中的大惩罚，导致平均情绪从 0.746 崩到 **−33.250**——说明**平滑加权代理目标难以表示
