## 摘要
将机器人技能从仿真迁移到现实，需要任务知识在感知、动力学和具身形态的差异下仍然可用。我们提出 Skill2Real，一个智能体式策略框架，通过共享应用程序接口（API）学习可执行技能。提议者-验证者-调控者（PVG）循环利用特权仿真证据来诊断结果并验证更新，同时使学到的技能以公开观测和 API 语义为基础。小脑（Cerebellum）首先习得局部操作技能；随后大脑（Brain）在小脑冻结的情况下学习任务级组合。两类记忆均可迁移到真实机器人，而无需任务策略微调或技能记忆更新。当 GPT-5.6 Sol 在 LIBERO-90 上学习技能时，用 GPT-6 Astra 评估每个冻结检查点，将 LIBERO-Pro Long 的成功率从 2.0% 提升至 56.3%，且未在 Pro Long 上训练。独立的 Robosuite 训练在七个任务上分别使用 Sol 和 Opus 5 达到 85.1% 和 89.4% 的平均成功率。冻结的 Sol 训练的 LIBERO-90 技能在 Astra 下的四个真实世界操作任务中达到 78.75% 的平均完成率。在 LIBERO-90 训练期间移除验证者或调控者，会分别使最终 Pro Long 成功率下降 17.3 和 13.3 个百分点。这些结果支持通过通用机器人接口学习和迁移可执行技能的层级结构。

## Abstract
Transferring robotic skills from simulation to reality requires task knowledge that remains usable across differences in perception, dynamics, and embodiment. We introduce Skill2Real, an agentic policy framework that learns executable skills through a shared application programming interface (API). A Proposer-Verifier-Governor (PVG) loop uses privileged simulation evidence to diagnose outcomes and validate updates, while keeping learned skills grounded in public observations and API semantics. The Cerebellum first acquires local manipulation skills; the Brain then learns task-level composition with the Cerebellum frozen. Both memories transfer to the real robot without task-policy fine-tuning or skill-memory updates. As GPT-5.6 Sol learns skills on LIBERO-90, evaluating each frozen checkpoint with GPT-6 Astra raises LIBERO-Pro Long success from 2.0% to 56.3%, without training on Pro Long. Independent Robosuite training reaches 85.1% and 89.4% mean success with Sol and Opus 5 across seven tasks, respectively. Frozen Sol-trained LIBERO-90 skills achieve 78.75% mean completion across four real-world manipulation tasks with Astra. Removing the Verifier or Governor during LIBERO-90 training lowers final Pro Long success by 17.3 and 13.3 percentage points, respectively. These results support learning and transferring a hierarchy of executable skills through a common robot interface.

# Skill2Real 论文详细总结

## 1. 核心问题与整体含义

- **研究背景**：零样本仿真到现实（zero-shot sim-to-real）机器人操作，目标是把仿真中学到的经验直接部署到物理机器人，无需真实世界任务训练。仿真是可扩展的学习环境，但外观、动力学、接触、本体形态的差异会阻碍迁移。
- **长时程操作的额外挑战**：不仅要迁移单个动作，还要可靠执行局部操作技能、把它们组合成任务级行为、并在中间动作失败时恢复。
- **现有方法的瓶颈**：
  - 域随机化与非对称 actor-critic 通过适配神经策略或表征来改善迁移，但外观/纹理等任务无关变化的建模会消耗大量学习预算。
  - 代码生成方法（如 Code as Policies）让行为可组合，但只是组装给定原语，而非从经验中习得局部技能与任务策略。
  - 技能库系统（如 Lifelong Robot Library Learning）通常依赖人类指导或真实世界执行反馈来积累程序。
- **论文主张**：应把仿真学习的方向从"任务无关低层表征"转向"经校验的、可复用的、可执行的任务知识"，并借助基础视觉语言模型（VLM）的跨域 grounding 能力实现零样本迁移。

## 2. 方法论

### 核心思想
- **信息分离原则**：用于*监督技能学习*的信息（仿真器特权状态）与*执行技能*所需的信息（公开观测 + API 语义）分离。特权信息只在训练时用于评估与改进行为，持久化的技能知识完全以公开信息表达。
- **共享代码式策略接口作为迁移边界**：仿真与真实环境暴露同一 API 契约 A = {a_k}，语义共通但实现各异（后端各自负责感知、标定、低层控制）。策略只通过该接口推理，因此迁移的是"可执行行为与任务知识"，而非模型参数。

### 关键公式与流程
- **Proposer 采样程序**：c_t ∼ π_M(c | g, o_≤t, D_A, S_cer, S_brain)，即基于语言目标、公开观测历史、API 文档与两级记忆生成可执行程序。
- **非对称 PVG 循环**：
  - 确定性执行评估器给出 e = E_exec(τ, x_priv)，即特权仿真状态下的真实物理结果摘要；
  - Verifier 产生反馈 f = Verifier(τ, e)，并强制约束 f ∈ F_pub（只能用公开观测与 API 语义表达），从而把特权监督"翻译"为可部署的公开反馈；
  - Proposer 据此撰写候选更新 δ，随后收集验证证据 e_δ（后续 rollout 的任务完成/失败/相对更新前的回归），由 Governor 判断是否接纳。
- **两级层次化技能**：
  - **Cerebellum**：局部操作技能，每条技能 = 自然语言指导 + API 级代码模板 + 轻量结构化状态描述；
  - **Brain**：任务级技能，组合 Cerebellum 库为长时程程序，负责任务顺序、规划与恢复。
  - 顺序训练：S*_cer = TrainStage(Q_cer, ∅)，S*_brain = TrainStage(Q_brain, S*_cer)，即 Brain 训练时 Cerebellum 冻结，只作为固定上下文。
- **算法流程（Algorithm 1）**：采样任务 → Proposer 在仿真中 rollout → 评估器产生特权证据 e → Verifier 生成公开反馈 f → Proposer 在全新上下文中整合出候选 δ → 收集验证证据 → Governor 决定 accept/reject → 接纳则更新记忆；循环直到预设的 stage 级验证标准满足。
- **零样本部署**：只保留 Proposer + 共享接口 + 冻结的两级记忆；真实后端提供感知与低层执行；无 Verifier/Governor、无在线记忆更新、无真实任务微调。

## 6. 主要实验结果

### 6.1 LIBERO-Pro Long 零样本迁移
- **层级结构的增益**：完整 Brain–Cerebellum 层级相对仅 Cerebellum（C3）在两类扰动下均取得明显提升，Task 扰动（指令改写）上的增益通常大于 Pos 扰动（物体/目标位置变化），说明 Brain 层主要贡献在于**任务级语义重组与恢复**，而非低层动作精度。
- **随训练迭代的趋势**：迁移成功率随 Cerebellum 迭代（C1→C3）先快速上升后趋于平台；随 Brain 迭代（B1→B4）继续爬升，且 B4 相对 B1 的增益在 Task 扰动上更显著。这被作者用来支撑"两级记忆分别对应局部技能与任务策略"的设计假设。
- **与外部基线对比**：在相同评估协议下，完整方法优于 CaP-Agent0、ASPIRE、Zetta；与 π0/π0.5 这类端到端 VLA 策略的比较中，论文强调本方法在**长时程组合任务**上优势更大，而在单一短时程任务上差距缩小甚至持平。

### 6.2 源任务套件（LIBERO-90 与 Robosuite）
- **LIBERO-90**：C1–B4 检查点在 450 trials/评估点上的成功率单调上升，六个任务族中"物体重排""抽屉/容器操作"提升最明显，"精细装配"类提升相对有限，作者归因于该类任务对接触动力学与力控精度更敏感，而 API 级代码抽象难以完全编码此类细节。
- **Robosuite 七任务**：单臂与双臂任务均能习得可执行技能，双臂 handover 任务的成功率低于单臂任务，说明多本体协调对公开 API 语义的表达能力提出更高要求。

### 6.3 真实机器人（UR5e + Pika）
- 四个真实任务的成功率呈明显层级：R1（拾取放置）与 R2（属性分拣）在完整层级下成功率较高，接近仿真内水平；R3（等式组装，23+45=68）需要多步组合与中间状态校验，成功率下降但仍显著高于其他配置；R4（抽屉操作）只有完整层级达到约 50%，其余配置为 0%。
- **Brain-only 对照**：去掉 Cerebellum 后真实场景性能大幅下降，验证了"任务级策略必须建立在可复用的局部技能之上"。
- **失败模式**：作者报告的主要失败包括抓取位姿偏差导致的滑落、抽屉把手的视觉定位误差、以及中间步骤失败后恢复程序未能触发（Brain 层恢复逻辑对公开观测中失败信号的依赖较强）。

### 6.4 消融实验
- **w/o Verifier**：在 Pro Long 与 LIBERO-90 上均出现明显下降，且下降幅度随 Brain 迭代增加而扩大，说明 Verifier 的公开反馈在把特权信息转译为可迁移知识中作用关键。
- **w/o Governor**：下降幅度小于 w/o Verifier，但表现为**训练不稳定**——部分迭代出现记忆退化（后续检查点成功率低于前一检查点），说明 Governor 的 accept/reject 机制主要起稳定与防回归作用。
- 作者明确指出，"w/o Verifier"消融同时移除了特权信息与 Verifier 角色本身，因此不能干净地分离"特权信息价值"与"Verifier 机制价值"。

### 6.5 跨 Proposer 模型验证
- 用 GPT-5.6 Sol、Claude Opus 5、GPT-6 Astra、Claude Opus 4.6 分别作为 Proposer，在固定 C3/B3 技能库上评估，成功率差异在可接受范围内，且不同模型的失败任务分布不完全重叠。
- 论文据此主张：方法增益主要来自**PVG 循环与两级记忆结构**，而非某一特定 LLM 的能力，即增益与 Proposer 模型选择近似正交。

## 7. 贡献与创新点

- **迁移边界的重新定义**：把 sim-to-real 的迁移对象从"神经策略参数/表征"改为"经校验的可执行任务知识（代码式技能 + 任务策略）"，并给出共享 API 契约这一明确边界。
- **非对称 PVG 循环**：以确定性执行评估器提供特权证据、Verifier 强制把反馈约束在公开信息空间、Governor 基于验证证据决定是否接纳，形成"特权监督 → 公开知识"的可部署翻译机制。
- **两级层次化技能记忆**：Cerebellum（自然语言指导 + API 级代码模板 + 结构化状态）与 Brain（任务级组合、规划与恢复），并以顺序冻结训练避免层级间干扰。
- **零样本部署范式**：部署时只保留 Proposer + 共享接口 + 冻结记忆，不依赖 Verifier/Governor、不做在线更新与真实微调。

## 8. 局限性

- **算力与成本未量化**：未报告 GPU 资源、token 消耗、API 调用次数与推理延迟，难以评估方法的实际工程成本；作者亦承认需降低 VLM 推理延迟以支持闭环执行。
- **统计证据强度不足**：所有成功率均为固定库单次训练 run 的点估计，缺少跨独立训练 run 的方差估计；真实实验样本量小（4 任务 × 20 trials）。
- **训练预算不匹配**：Cerebellum 与 Brain 阶段的对比不是 matched training budget，Brain 增益混入了额外训练量效应。
- **特权信息依赖**：整个学习过程依赖仿真器特权状态，若仿真物理与真实偏差较大，特权证据本身可能误导知识更新。
- **公开 API 表达力上限**：方法性能受限于 API 契约能否表达精细力控、接触丰富操作等任务需求，精细装配类任务提升有限即为证据。
- **基线可比性**：外部基线沿用各自原文协议，与本文评估设置并非严格一致。
- **泛化证据偏定性**：外观/光照等视觉域偏移的鲁棒性只有定性展示，缺少逐条件成功率。

## 9. 结论与启示

- **核心结论**：在长时程机器人操作中，把仿真学习的目标从任务无关低层表征转向"经校验、可复用、可执行的任务知识"，并借助 VLM 的跨域 grounding 能力，可以实现无需真实任务训练的零样本迁移；两级记忆结构分别支撑局部技能复用与任务级组合恢复。
- **方法学启示**：
  - "特权信息只用于训练、持久化知识只用公开信息表达"是一条可推广的迁移设计原则，其关键在于存在一个**强制输出空间约束**的翻译环节（Verifier）。
  - 迁移边界的显式化（共享 API 契约）使仿真与真实后端解耦，便于分别升级感知、标定与低层控制。
  - 记忆的接纳机制（Governor）对长时程学习稳定性不可或缺，但相比反馈翻译机制，其影响更偏稳定性而非上限。
- **后续方向**：降低 VLM 推理延迟以实现更紧的闭环；引入仅基于公开观测的 Verifier 以干净分离各组件贡献；增加独立训练 run 与更大规模真实实验以强化统计结论；扩展 API 语义以覆盖接触丰富与力控任务；探索在线/持续记忆更新而不仅限于冻结部署。
