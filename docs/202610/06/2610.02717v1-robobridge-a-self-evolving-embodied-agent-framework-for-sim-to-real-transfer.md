## 摘要
将具身智能引入真实世界的一项关键挑战在于，把能力从仿真迁移到现实，并使智能体在部署后能够持续适应。端到端视觉-语言-动作策略具备强大的操作能力，但其向物理环境的迁移通常依赖于校准仿真中的视觉与动力学条件、收集额外的目标域演示，并通过进一步训练来优化策略。使用工具的具身智能体可提供灵活的任务编排，但现有系统主要侧重于给定环境中的任务执行与经验复用，对程序性知识的迁移以及跨仿真与现实持续自适应这类知识的支持仍然有限。我们提出RoboBridge，一个将Sim-to-Real迁移视为可执行任务技能持续适应的框架。该智能体将任务知识表示为连接任务意图、观测、工具操作与结果验证的流程。交互反馈用于生成候选技能修订，这些修订在持久化或拒绝之前会先经过评估。预训练的视觉-语言-动作策略被暴露为可复用的动作工具，并通过推理时引导得到增强，从而无需重新训练底层策略即可实现细粒度执行。RoboBridge将可迁移技能建立在仿真与现实共享的任务语义和交互接口之上。这种表示保留了可复用的任务结构，同时允许依赖环境的操作通过真实世界的执行反馈进行选择性修订。我们在LIBERO-PRO及相应的物理任务上评估该框架，研究技能演化与迁移后自适应。我们的框架提供了一条从一次性策略部署到跨环境持续程序性学习的路径。

## Abstract
A key challenge in bringing embodied intelligence into the real world is transferring capabilities from simulation to reality and enabling agents to continually adapt after deployment. End-to-end vision-language-action policies provide strong manipulation capabilities, but their transfer to physical environments typically relies on calibrating simulated visual and dynamical conditions, collecting additional target-domain demonstrations, and optimizing the policy through further training. Tool-using embodied agents offer flexible task orchestration, yet existing systems primarily emphasize task execution and experience reuse within a given environment, with limited support for transferring procedural knowledge and continuously adapting it across simulation and reality. We propose RoboBridge, a framework that treats sim-to-real transfer as the continued adaptation of executable task skills. The agent represents task knowledge as procedures connecting task intent, observations, tool operations, and outcome verification. Interaction feedback is used to generate candidate skill revisions, which are evaluated before being persisted or rejected. A pretrained vision-language-action policy is exposed as a reusable action tool and enhanced with inference-time guidance, enabling fine-grained execution without retraining the underlying policy. RoboBridge grounds transferable skills in task semantics and interaction interfaces shared across simulation and reality. This representation preserves reusable task structure while allowing environment-dependent operations to be selectively revised through real-world execution feedback. We evaluate the framework on LIBERO-PRO and corresponding physical tasks, studying both skill evolution and post-transfer adaptation. Our framework provides a route from one-shot policy deployment to continual procedural learning across environments.

## 2. 方法论

### 2.1 核心思想
- 用**智能体（agent harness）**承载显式、可编辑的任务技能；把**冻结的预训练 VLA 策略**降级为一个"可复用的动作工具"。
- 分工：**技能（过程）**决定"做什么、按什么顺序、何时调用、结果是否达标"；**VLA 策略**只提供短程细粒度操作能力。
- 迁移的桥梁不是参数，而是**跨环境对齐的任务语义 + 观测格式 + 工具接口**。

### 2.2 关键技术细节

**（1）问题形式化与智能体执行循环**
- 任务由语言指令 ℓ 与完成条件 G 指定；智能体维护可编辑技能 S（连接观测→工具操作→验证条件）。
- 技能演化：由 rollout 轨迹 τₖ 驱动的带验证更新过程 U：
  - **Sₖ₊₁ = U(Sₖ, τₖ)**；候选失败时保留当前技能。
- 迁移映射：**Sʳ₀ = Φ(Sˢ_K)**，s 为仿真、r 为现实，K 为源域演化步数；Φ 刻画任务语义、观测格式、工具接口的对齐。迁移后技能继续用真实反馈通过 U 演化。
- 执行循环（每轮）：规划器 Π 基于 (ℓ, oₜ, fₜ₋₁, Sₖ) 产出结构化调用 cₜ；工具执行 E 返回新观测与反馈：
  - **cₜ = Π(ℓ, oₜ, fₜ₋₁, Sₖ)**，**(oₜ₊₁, fₜ) = E(oₜ, cₜ)**。
- 每轮**至多一次物理操作**，操作完成/失败后刷新观测再决策；终止条件为 G 满足、显式终止或预算耗尽。轨迹被记录为后续技能更新的证据。

**（2）具身反馈驱动的技能演化**
- 技能被视作**关于"任务应如何完成"的可执行假设**，描述"观测变化 → 后续行为"的关系；且**不绑定具体物体身份**，而是围绕任务相关状态与操作可供性（affordance）组织，从而把任务意图与物理实现解耦。
- 每轮 rollout 收集：场景观测、工具结果、中间验证信号、最终任务结果。
- 演化**不是追加式积累**，而是允许**局部修订**：新增缺失操作、替换不可靠转移、删除不再成立的行为/验证条件，同时保留未受影响部分。
- **验证门（validation gate）**：候选技能须在与当前技能**可比的任务条件**下评估，只有有效且提升执行表现的候选才被固化为新版本；否则保持当前技能、候选仅作审计记录。技能带版本号，旧版本可作回退。

**（3）从冻结策略到自引导动作工具**
- 智能体指定局部操作，策略翻译为短动作片段；**操作选择与结果验证显式保留在智能体循环中**。
- 推理时引导：当需要时，智能体由子任务目标、执行约束与观测反馈构造奖励 rₜ，在去噪过程中修正候选动作：
  - **A⁽ʲ⁾ₜ,guided = A⁽ʲ⁾ₜ + ηₜ,ⱼ ∇_{A⁽ʲ⁾ₜ} rₜ(A⁽ʲ⁾ₜ; oₜ, uₜ)**
  - ηₜ,ⱼ ≥ 0 控制引导强度，η=0 即无引导；梯度只对候选动作求，**策略参数保持冻结**。
- 两个层次互补：**技能演化**跨 episode 调整过程知识（选择、顺序、验证）；**推理时引导**在单次调用内适应当前条件。二者都由执行反馈驱动。

**（4）系统实现要点（附录）**
- 观测与执行解耦：环境适配器负责分割、几何重建、观测打包与刷新；规划器负责任务分解、目标选择、运动偏移与结果验证。
- 结构化观测快照包含：观测 id/步、坐标系与单位、外部与腕部 RGB 图像及标注、实体与测量参考点、关系、机器人本体状态、新鲜度与不确定性。
- 动作库：笛卡尔运动（Cartesian Move / Pose Alignment）、姿态调整（Wrist Rotation / Wrist Tilt）、夹爪控制（Open Gripper / Gripper Control）、基于策略的操作（Policy Grasp / Policy Contact，可按需加引导）。
- 工具完成 ≠ 任务成功；仿真成功由 benchmark 判定，真机由人工标注。
- 真机适配器执行前检查工作空间与运动约束；执行错误则中止 episode。

- **仿真 benchmark**：**LIBERO-PRO**（在 LIBERO 上加入受控的任务要求与场景配置变化），覆盖四个任务族：

  - 每个任务单元做 **2 轮技能演化，每轮 5 个训练种子**。

- **真机任务**（3 个，语义与仿真任务对应但物体与操作方式不同）：
  1. 两个方块分别放入对应碗；
  2. 蛋糕放入锅中并盖上锅盖；
  3. 笔插入笔架。
- **对比方法**（LIBERO-PRO 表 1）：OpenVLA、π0、π0.5、MolmoAct、NORA、X-VLA、AtomVLA、πRLinf、CaP-X、RATs、ASPIRE、**Harness VLA (Codex)**，以及本文方法（Codex）。
- **消融**（SPATIAL-T 与 OBJECT-T 两个设置）：w/o Skill、Append Only、w/o Validation Gate、w/o Inference Guidance、Full。

## 6. 主要结论与发现

- **仿真主结果（LIBERO-PRO，表 1）**：本文方法整体成功率 **74.4%**，超过最强基线 Harness VLA (Codex) 的 **72.1%**（+2.3 个百分点），在 GOAL-T 上高出 5 个百分点；直接使用 πRLinf 仅 **50.0%**，说明增益并非仅来自底层端到端策略。其余端到端 VLA 在分布偏移下普遍严重退化（OpenVLA、π0、NORA 接近 0）。
- **消融结论**：
  - 去掉技能引导：SPATIAL-T 83%→21%（−62pp），OBJECT-T 94%→16%（−78pp），技能引导是最大贡献项。
  - 仅追加更新（禁止修订/删除）：44% 与 57%（−39pp / −37pp），说明**修订与删除**对技能演化至关重要，追加式积累会污染技能记忆。
  - 去掉验证门：69% 与 63%（−14pp / −31pp），说明候选更新在持久化前须经执行验证。
  - 去掉推理时引导：75% 与 82%（−8pp / −12pp），说明"技能演化 + 推理时引导"贡献互补。
- **真机迁移结论**：
  - 直接迁移仿真技能即可提升（4/15→9/15、2/15→7/15、3/15→7/15），说明仿真经验提供有效的初始行为指导。
  - 真机反馈继续演化后达 **15/15、14/15、15/15**，说明目标环境反馈能进一步精炼迁移流程。
  - 效率：仿真初始化 **12 次迭代**达到 15/15，从零需 **16 次**（迭代数减少 25%）；累计 token 由 **52.39M 降至 13.08M**（约减少 75%）。
- **总体结论**：当任务语义与交互接口对齐时，仿真中形成的程序性技能可作为真机可复用的初始知识，并能在部署后继续从物理反馈中适应；既提升任务效果，也降低交互与推理开销。

## 7. 优点

- **问题重定义有价值**：把 Sim-to-Real 从"策略适配/再训练"转为"可执行技能的持续适应"，把任务知识从参数中解放出来，使其**可读、可编辑、可回滚**。
- **表示设计合理**：技能围绕任务相关状态与可供性组织，而非绑定具体物体与坐标，天然支持跨环境复用与局部修订。
- **验证门机制**：候选技能必须与当前技能在可比条件下对比、通过验证才持久化，避免单次失败 rollout 永久污染技能记忆；保留被拒候选作为审计记录，工程上稳健。
- **两级自适应互补**：跨 episode 的技能演化（改过程）与单次调用内的推理时奖励引导（改执行）职责清晰，且**不更新任何策略参数**，成本低、可解释。
- **冻结策略的务实利用**：把强 VLA 当"动作原语"，用 agent 补上编排、验证与纠错，规避了目标域数据收集与微调的昂贵环节。
- **评测设计较规范**：训练/验证/测试种子不相交、测试期技能冻结、官方完成谓词判定、仿真与真机双阶段验证，并报告了 token 层面的效率收益。
