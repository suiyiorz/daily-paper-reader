## 摘要
尽管大型视觉语言模型（VLMs）显著推进了具身导航，但其直接部署仍具挑战性，因为现有方法常迫使VLM进入与其二维预训练先验不符的非自然动作空间，加之僵化的推理调度和低效的记忆管理。为克服这些局限，我们提出TAMP-Nav，一个用于高效具身导航的统一框架。首先，我们引入像素到三维动作公式（指向），将导航重新表述为二维视觉提示。具体而言，VLM仅选择二维像素，随后将其投影至三维坐标以供低层SLAM控制器使用。该设计自然地将具身执行与VLM固有的二维视觉能力对齐。其次，我们提出集成选择性推理与锚点轨迹记忆机制（思考与记忆），该机制动态触发思维链，并仅在关键节点保留高保真记忆，将冗余轨迹压缩为轻量级时空指示器，从而保留关键历史信息并增强时空感知。最后，我们通过组相对策略优化（GRPO）设计高效的两级对齐范式（对齐）。通过叠加全局结果奖励与细粒度过程奖励，这种密集监督将智能体的认知规划与物理环境反馈紧密对齐，赋予模型自适应推理能力。实验表明，TAMP-Nav实现了最先进的性能（例如在R2R-CE上SR达66.2%），并具有高运行效率和样本效率（仅需9万条训练轨迹）。

## Abstract
Although Large Vision-Language Models (VLMs) have significantly advanced embodied navigation, their direct deployment remains challenging, as existing methods often force VLMs into unnatural action spaces that misalign with their 2D pre-training priors, compounded by rigid reasoning schedules and inefficient memory management. To overcome these limitations, we propose TAMP-Nav, a unified framework for efficient embodied navigation. First, we introduce a Pixel-to-3D Action Formulation (Point) that reformulates navigation into 2D visual prompting. Specifically, the VLM merely selects 2D pixels, which are then projected into 3D coordinates for a low-level SLAM controller. This design naturally aligns embodied execution with the VLM's inherent 2D visual capabilities. Second, we propose an integrated Selective Reasoning and Anchor-Trajectory Memory mechanism (Think and Memorize), which dynamically triggers Chain-of-Thought and retains high-fidelity memory only at critical nodes, compressing redundant trajectories into lightweight Space-Time Indicators, thereby preserving critical historical information and enhancing spatio-temporal perception. Finally, we design an efficient Two-Level Alignment Paradigm (Align) via Group Relative Policy Optimization (GRPO). By superimposing global outcome rewards with fine-grained process rewards, this dense supervision tightly aligns the agent's cognitive planning with physical environmental feedback, endowing the model with adaptive reasoning capabilities. Experiments demonstrate that TAMP-Nav achieves state-of-the-art performance (e.g., 66.2% SR on R2R-CE) with high runtime and sample efficiency (requiring only 90k training trajectories).

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：具身导航要求智能体理解自然语言指令并在复杂环境中执行物理导航。大型视觉语言模型（VLMs）虽已显著增强多模态理解能力，但直接部署于具身导航面临三大关键瓶颈。
- **瓶颈一：动作公式的几何鸿沟（Geometric Gap in Action Formulation）**。现有方法要么将观察映射为低层原子动作（如“左转30°”），要么回归3D空间坐标。但VLM主要基于2D图像-文本对进行预训练，强制其学习复杂的3D几何变换会导致空间幻觉与低样本效率。
- **瓶颈二：导航性能与推理效率的两难（Dilemma Between Performance and Efficiency）**。既有方法常在每个步骤或固定间隔触发思维链（CoT）推理，虽提升决策质量，却带来严重的推理延迟，无法在运行效率与导航性能间取得最优平衡。
- **瓶颈三：长程记忆中关键信息与时空感知的丧失（Loss of Key Information in Long-Horizon Memory）**。现有记忆机制要么因保留全部历史视觉特征导致注意力稀释与记忆溢出，要么不加区分地丢弃历史观察导致关键信息丢失；且大多缺乏显式时空坐标来组织历史信息。
- **论文对策**：提出 **TAMP-Nav** 统一框架（即 Think、Align、Memorize、Point），通过动作空间、认知架构与优化范式三方面的协同设计突破上述瓶颈。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### （1）Pixel-to-3D 动作公式（Point）
- **核心思想**：将导航重构为2D视觉提示任务，让VLM仅充当“视觉指针”，绕过复杂的3D几何推理。
- **具体流程**：智能体在每一步接收四个第一人称视角图像覆盖360°视野 → VLM选择最优视角并输出一个2D像素坐标（u, v）指向目标路径点 → 该像素借助深度图 `D_t,i` 与相机内参矩阵 `K` 投影为本地3D点 `P_t = D_t,i(u,v)·K⁻¹[u,v,1]ᵀ` → 坐标变换至世界系后交由低层SLAM控制器执行局部运动。
- **优势**：将VLM从3D几何变换学习中解放出来，使其专注于视觉-语义接地；仿真中直接使用真值深度，真实部署采用深度相机。

#### （2）选择性推理与锚点轨迹记忆（Think & Memorize）
- **选择性推理**：摒弃固定步长或固定间隔的CoT触发方式，模型仅在**关键拓扑节点**（如十字路口、门口、目标附近）动态触发深度CoT；常规路径区间则跳过推理，以控制延迟。
- **锚点轨迹记忆（Anchor-Trajectory Memory, AT-Mem）** 由两类异构组件构成：
  - **显式锚点（Explicit Anchors）**：在触发CoT的关键节点存储三元组 `⟨STI坐标, 高保真原始视觉特征, CoT状态语义摘要⟩`，支持像素级闭环检测与任务阶段定位。
  - **时空指示器（Space-Time Indicators, STI）**：对两个锚点之间的冗余路径区间，丢弃视觉特征，仅保留轻量化的时空流 `[E_STI(t, x_t, y_t, yaw_t)]`。STI通过将3D空间坐标（x,y）、时间索引 t、偏航角 yaw 的三角表示分别经2D/1D RoPE编码后拼接并经MLP投影为统一token，显式注入绝对时空状态。
- **推理时上下文**：每次决策将工作记忆（当前与最近锚点间的两次均匀采样帧）与长程拓扑记忆（锚点与STI序列的重建）拼接。

#### （3）两级GRPO对齐范式（Align）
- **训练流程**：先基于MultiNav-CoT数据集对 Qwen2.5-VL-7B 进行 SFT 冷启动（1 epoch），再进行 GRPO 强化学习微调。
- **局部步骤奖励（Local Step Rewards）**：包含五个显式组件——目标接近奖励（距离变化经符号Sigmoid映射）、碰撞避免奖励（基于障碍物距离）、停止动作奖励（根据STOP时距目标距离分级）、推理价值奖励（仅当CoT导致决策优于本地基线时给予正奖）、格式遵循奖励（JSON格式与像素范围合法性）。
- **全局轨迹奖励（Global Trajectory Rewards）**：包含任务成功奖励（严格成功/中继成功/失败）、轨迹效率奖励（SPL）、推理密度奖励（限制CoT比例过高）。
- **两级rollout机制**：对每条指令生成 G=8 条完整轨迹；每条轨迹在每个决策步通过温度采样生成 M=4 个候选动作，用局部奖励评估。引入**退火引导采样**（annealed guided sampling），β 指数衰减，早期按局部奖励加权选择高质量候选，后期趋近均匀探索。
- **优势融合**：全局优势（对G条轨迹的全局奖励做Z-score标准化）与局部优势（对M个候选的局部奖励做Z-score标准化）叠加为总优势，提供无需逐步专家强制的密集监督，使模型涌现出状态依赖的元认知推理触发能力。

### 6. 主要结论与发现

- **SOTA性能**：TAMP-Nav 在 R2R-CE Val-Unseen 取得 **SR = 66.2%、SPL = 58.8%、NE = 3.85**；在 RxR-CE Val-Unseen 取得 **SR = 65.7%、SPL = 56.9%、nDTW = 72.4**，全面超越现有方法。
- **高采样效率**：仅需90k轨迹，相比 DualVLN（763k）与 NavFoM（3.37M交互）大幅降低数据需求；GRPO强化学习将SFT-only的SR从55.7%提升至66.2%，证明密集奖励RL比纯监督学习更擅长从有限数据中内化复杂逻辑。
- **涌现按需推理**：RL训练后，模型自主将CoT集中在十字路口、门口、目标附近等关键节点；直走廊中的推理比例从SFT模型的38%降至11%。自动触发（CoT比例26.3%）以仅0.6点SR差距逼近 Dense CoT 上限（66.8%），远超固定间隔策略（SR=60.1%）。
- **记忆机制有效性**：AT-Mem 在长程任务上显著优于均匀采样与全历史保留（49.8% vs 40.5% vs 42.4%）；移除STI后SR下降约4.2点，表明轻量时空token是维持长程空间记忆的关键。
- **两级GRPO有效性**：叠加局部优势显著缓解稀疏奖励问题，退火引导采样进一步加速收敛并将最终成功奖励提升至0.68（仅全局奖励基线为0.59）。
- **深度鲁棒性**：在σ=0.2（约16%相对误差）下SR仅下降2.8点，对中等程度深度扰动具备一定鲁棒性。
- **真实世界可行性**：零样本部署于 Unitree Go2 四足机器人，SR=60.0%，超越 StreamVLN（49.0%）与 DualVLN（53.0%）。

### 7. 优点与亮点

- **动作空间设计新颖且对齐预训练先验**：Pixel-to-3D 公式将VLM的角色简化为2D视觉指针，有效规避2D预训练模型与3D动作预测之间的表征鸿沟，是一个优雅的“解耦”思路。
- **推理调度实现“按需思考”**：通过RL奖励设计让模型自学何时需要深度思考，而非人工预设规则，展现出元认知能力涌现，兼具效率与性能。
- **记忆机制兼顾保真与压缩**：锚点+STI的异构设计在严格内存预算下同时保留关键视觉细节与完整时空拓扑，提供了清晰的长期状态表征方案。
- **奖励塑形系统化**：局部过程奖励与全局结果奖励的叠加、以及退火引导采样，在稀疏奖励长程任务中显著改善了信用分配问题，实验验证充分。
- **实验范围全面**：从标准benchmark到长程任务、深度噪声、消融、真实部署，层次分明；CoT监督来源对比还辅以人工质量评估，增加结论可信度。
- **数据与计算效率突出**：以远低于SOTA方法的训练数据与时延实现更高性能，具有实际部署价值。

---

### 8. 不足与局限

- **对深度信息与SLAM的强依赖**：TAMP-Nav 依赖深度相机数据、STI编码中的位姿估计及低层SLAM控制器。虽然受控噪声实验显示一定鲁棒性，但严重深度误差、累计里程漂移、定位失败或高动态环境仍会造成更大幅度的性能下降。
- **无法进行真机在线强化学习**：GRPO依赖仿真器提供的特权信号（进展、成功、SPL、碰撞等），当前系统不支持物理机器人的在线RL；计算完整奖励需端点标注、人类反馈或可靠学习验证器，因此真实部署仅限于仿真训练策略的零样本迁移。
- **关键节点挖掘启发式的局限**：Spatiotemporal Key Node Mining 基于 CLIP 语义相似度与视觉特征差异选择CoT监督，可能在决策点视觉不显著或指令风格与R2R-CE/RxR-CE差异较大时漏选关键状态，需额外训练样本或学习型触发准则。
- **STI缺少高度维度**：当前STI仅编码平面位姿（x, y, yaw），不含高度，无法显式区分楼层；任务进度描述只能部分补偿，在多楼层或崎岖地形中可能受限。

#### （续）8. 不足与局限

- **推理密度阈值的固定约束**：论文在全局轨迹奖励中引入推理密度奖励，将CoT比例硬性限制在约26%附近（接近人工标注的30%分布），这一固定阈值虽然带来了可观的效率收益，但可能并非全局最优。不同任务、不同场景复杂度下的“最优推理预算”理应是动态变化的——例如长走廊短任务几乎不需要推理，而复杂多岔路口任务可能需要远超30%的深度思考。固定阈值设计可能导致模型在分布外复杂任务上“不敢多思考”，或在简单任务上“被迫浪费计算”，从而限制了其泛化边界。
- **上下文窗口对超长任务的可扩展性隐忧**：尽管AT-Mem通过锚点+STI压缩机制显著缓解了记忆膨胀，但模型上下文窗口仍固定为4096 tokens。对于极端长程任务（如仓库、医院、多楼层大平面场景，路径长度数十米甚至上百米），锚点数量会随关键节点增多而线性增长，STI序列同样累积；若超过上下文上限，仍需依赖截断策略，仍可能丢失早期关键时空信息。
- **CoT监督标注质量的高度依赖**：SFT阶段依赖Gemini生成的伪CoT标注配合基于CLIP的启发式关键节点筛选，并通过人工抽检保证质量。但Gemini作为闭源模型，其CoT风格与推理习惯可能并非VLM导航任务的最优教师；且在指令分布、场景分布偏离R2R-RxR风格时，标注质量缺乏保障。RL阶段若继承了此类偏置，会对下游性能产生隐性约束。
- **缺乏跨领域泛化验证**：训练与评测均集中于MP3D场景（VLN-CE）。未在Gibson、HM3D、多楼层建筑、室外大尺度或动态行人环境中进行测试，其“锚点+STI”记忆与“关键节点触发推理”机制在结构化程度较低的真实非结构化环境中是否依然成立，仍属开放问题。

### 9. 综合评述与展望

- **总体判断**：TAMP-Nav 在具身导航“性能–效率–数据”三角中取得了当前最优平衡。其核心贡献不在于堆砌模型容量，而在于系统性地重新审视了VLM落地具身任务时必须面对的三类根本性错配：**预训练表征（2D）与动作空间（3D）的错配**、**深度推理与实时控制之间的时延错配**、**流式感知与长程记忆之间的容量错配**。通过 Pixel-to-3D 动作解耦、两级GRPO奖励驱动的按需推理涌现，以及锚点-时空流异构记忆，三个错配分别得到了针对性的工程化解法，且彼此之间形成了有机闭环：记忆模块为推理提供上下文，推理模块为记忆提供锚点，动作模块则统一将推理结果转化为控制指令。
- **学术价值与范式意义**：该工作展示了“为VLM设计合适的任务接口”比“让VLM直接学习人类式动作输出”更具潜力。选择性推理的涌现结果（RL后模型自主学会在十字路口“思考”）是值得关注的科学现象，为后续研究“如何通过过程奖励塑造语言模型的认知习惯”提供了实证范式。两级GRPO中将局部过程奖励与全局结果奖励解耦并叠加的做法，也为长时延、高风险、弱监督的机器人RL任务提供了可借鉴的奖励设计模板。
- **局限性提示**：其强依赖深度传感器、SLAM位姿与离线仿真特权信号的设定，决定了当前系统更适于结构化、可感知、可定位的室内环境；在无先验地图、无可靠深度、无里程计反馈的开放场景中需重新设计感知与记忆模块。固定推理密度阈值与缺乏高度维度的问题，也让其在多楼层与极高复杂度任务中留有提升空间。
- **未来方向**：结合本文框架，最自然的三条演进路径是：(1) 将推理预算从固定约束改为模型可自适应调节的软约束，使推理密度成为上下文条件化的输出；(2) 为STI引入高度/楼层维度并扩展至3D拓扑记忆，以支持垂直空间导航；(3) 引入真机在线RL（通过人工远端干预或任务完成信号替代特权奖励），缩小仿真到真实的策略迁移差距。此外，将当前方案与端到端可微SLAM或视觉里程计结合，以摆脱对成熟SLAM系统的依赖，也是重要落地方向。
- **最终评价**：整体而言，TAMP-Nav 设计逻辑清晰、实验证据充分、性能表现亮眼，并通过对效率与数据预算的控制显著提升了实用价值；上述局限多为框架边界而非设计缺陷，不影响其作为当前基于VLM的具身导航代表性工作的地位。对于后续研究者，它既是一个强基线，也是一个值得深入拓展的方法论起点。
