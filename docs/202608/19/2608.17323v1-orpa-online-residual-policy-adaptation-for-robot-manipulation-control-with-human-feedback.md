## 摘要
采用模仿学习训练的操作策略（如基于Transformer的动作分块，ACT）在理想条件下能取得良好性能，但通常对小的执行误差和分布偏移敏感。纠正这些失败通常需要数据集聚合和完整策略重新训练，这在计算上代价高昂且不适合实时部署。在这项工作中，我们提出了在线残差策略自适应（ORPA），该框架能够在无需修改底层策略参数的情况下，实现即时、反馈驱动的机器人动作纠正。ORPA为预训练控制策略增加了一个轻量级、以反馈为条件的模块，该模块直接在关节空间预测残差调整，使系统能够在运行时调整其行为。我们在ALOHA平台上的一系列精度敏感操作任务上评估了ORPA，结果表明，与基线控制策略和基于规则的运动学逆解纠正相比，ORPA在成功率和从微小扰动中恢复方面均有提升。

## Abstract
Robotic manipulation policies trained via imitation learning, such as Action Chunking with Transformers (ACT), can achieve strong performance under ideal conditions but often remain sensitive to small execution errors and distribution shifts. Correcting these failures typically requires dataset aggregation and full-policy retraining, which is computationally expensive and unsuitable for real-time deployment. In this work, we propose Online Residual Policy Adaptation (ORPA), a framework that enables immediate, feedback-driven correction of robot actions without modifying the underlying policy parameters. ORPA augments a pretrained control policy with a lightweight, feedback-conditioned module that predicts residual adjustments directly in joint space, allowing the system to adapt its behavior at runtime. We evaluate ORPA on a set of precision-sensitive manipulation tasks using the ALOHA platform, demonstrating improvements in success rate and recovery from small perturbations compared to baseline control policies and rule-based inverse kinematics corrections.

## 2. 论文提出的方法论

### 2.1 核心思想

- 保持底层 ACT 策略**完全冻结**，不修改其参数；通过一个"反馈编码器 + 策略更新器"的轻量级模块，在关节空间为 ACT 的原始动作输出叠加**残差修正**。
- 最终动作：  
  **a_final(t:t+k) = â(t:t+k) + Δa(t)**  
  其中 â 为 ACT 的名义动作块预测，Δa 为反馈条件残差修正。
- 残差公式保留 ACT 学到的原始操作行为，同时允许局部修正；直接在关节空间操作，**无需显式正/逆运动学计算**。

### 2.2 架构组件

- **反馈编码器（Feedback Encoder, FE）**：将人类反馈（如 "too left"、"too right"、"too high"、"good"）编码为潜在表示：**r_t = f_ψ(f_t)**。反馈信号先作为离散 token，再映射为可学习的嵌入向量。
- **策略更新器（Policy Updater, PU）**：接收编码后的反馈、当前观测和 ACT 动作轨迹，预测残差：**Δa_t = g_ω(r_t, o_t, a(t:t+k))**。由于残差同时以反馈和操作为条件，可产生**依赖任务阶段和物体构型的上下文修正**（这是与规则式 IK 方法的本质区别）。
- 两个模块均为轻量级 Transformer 结构（PU 含 6 个注意力头、2 层 Transformer）。

### 2.3 合成数据生成

- 为避免昂贵的人工纠错示范采集，ORPA 从**成功的示范轨迹**自动生成纠错训练数据：
  1. 通过遥操作采集成功轨迹并训练 ACT；
  2. 在目标物体位姿上引入**受控扰动**（如左右、上下平移或旋转），模拟部署时的执行误差；
  3. 按扰动方向自动分配反馈标签（如左移 → "too left"）；
  4. 残差修正目标为参考动作与扰动动作之差：**Δa\*_t = a_ref_t − a_perturbed_t**。

### 2.4 训练目标与流程

- 训练时 ACT 固定；仅优化 FE 与 PU，损失为最终修正动作与参考动作的均方误差：  
  **L_ORPA = (1/N) Σ‖a_final_i − a_ref_i‖²**
- Algorithm 2 流程：采样 (o_t, f_t, a) → 用冻结的 πθ 预测 ACT 动作块 → f_ψ 编码反馈 → g_ω 预测残差 → 叠加残差得到最终动作 → 计算 MSE 损失 → 用 ADAM 更新 ψ、ω。
- 关键超参数：批大小 8、chunk size 100、KL 权重 10、学习率 1e-5、训练 2000 个 epoch；FE 嵌入维度 32、隐藏层 128；PU 隐藏层 128、6 头注意力、2 层 Transformer。

- 对**策略微调研究**提出新视角：与微调全部参数或附加适配器（Adapter）不同，ORPA 的情绪条件是"即时语义反馈"而非"静态任务标签"，将策略调整从训练期延伸到了推理期，可能启发后续"可在线询问/可在线纠错"的具身智能体设计。

ORPA 是一篇方法动机清晰、实验设计扎实、工程可践性强的研究工作。其最大亮点在于**以极低的开销（冻结主策略 + 轻量残差模块）解决了实际部署中棘手的在线纠错问题**，并在仿真与真实世界任务中取得了明显优于规则式基线的结果。尽管在任务覆盖广度、消融分析与统计严谨性上仍有提升空间，但它所提出的"反馈条件残差学习"范式具有较强的通用性与实用价值，对后续机器人策略快速适配、人类在线干预、轻量化策略修整等方向具有较好的参考意义。
