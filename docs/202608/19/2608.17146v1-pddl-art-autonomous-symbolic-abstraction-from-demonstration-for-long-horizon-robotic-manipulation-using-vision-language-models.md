## 摘要
使用PDDL进行符号规划为长时程机器人操作提供了原则性框架，但构建准确的PDDL领域和问题描述仍然是一个重大瓶颈，通常需要大量的领域专业知识。我们提出了一种基于视觉语言模型（VLM）的方法，称为PDDL-ART，该框架能够从单个专家演示、自然语言任务描述以及可用高层动作名称库中自主生成特定任务的PDDL领域和问题描述。PDDL-ART不需要任何领域模板、动作签名或微调。为确保生成的描述不仅在语法上有效，而且在语义上与演示任务一致，PDDL-ART引入了一个在语法、语义和执行层面运行的多阶段校正流水线。执行引导校正的一个关键组成部分是符号谓词接地。PDDL-ART并非仅依赖视觉观察，而是利用现代VLM的工具使用能力，结合几何和时间推理来评估那些无法仅从图像直接辨别的关系谓词。关键的是，模型自主决定何时调用这些工具以及如何解释其输出。我们在发动机维护和家庭领域的具有挑战性的操作任务上评估了PDDL-ART，这些任务包括需要记忆、抽象谓词推理以及目标状态与初始状态在视觉上无法区分的任务。PDDL-ART的平均成功率达到93.3%，而基线基于VLM的规划器为78.3%。

## Abstract
Symbolic planning with PDDL offers a principled framework for long-horizon robot manipulation, but constructing accurate PDDL domain and problem descriptions remains a significant bottleneck, typically requiring substantial domain expertise. We present a Vision-Language Model (VLM)-based approach called PDDL-ART, a framework that autonomously generates task-specific PDDL domain and problem descriptions from a single expert demonstration, a natural language task description, and a library of available high-level action names. PDDL-ART does not require any domain templates, action signatures, or fine-tuning. To ensure the generated descriptions are not only syntactically valid but semantically aligned with the demonstrated task, PDDL-ART introduces a multi-stage correction pipeline operating at syntactic, semantic, and execution levels. A key component of execution-guided correction is symbolic predicate grounding. Instead of relying solely on visual observations, PDDL-ART leverages the tool-use capabilities of modern VLMs to incorporate geometric and temporal reasoning for evaluating relational predicates that are not directly discernible from images alone. Critically, the model autonomously determines when to invoke these tools and how to interpret their outputs. We evaluate PDDL-ART on challenging manipulation tasks in engine maintenance and household domains, including tasks that require memory, abstract predicate inference, and goal states that are visually indistinguishable from the initial state. PDDL-ART achieves an average success rate of 93.3%, compared to 78.3% for a baseline VLM-based planner.

## 1. 核心问题与整体含义（研究动机与背景）

- 符号规划（尤其是基于 PDDL 的规划）为长时程机器人操作提供了结构化的推理框架，能够显式建模动作、对象与因果依赖关系。
- 然而，手工构建准确、可用的 PDDL 领域（domain）和问题（problem）描述需要大量领域专业知识，且任务、对象、环境或机器人能力变化时往往需要重新修改，成本高、效率低。
- 已有的从数据中学习符号抽象的方法虽然减少手工指定，但学习到的抽象难以检查和修正，错误来源（谓词、接地、动作序列）不透明。
- 近年来 LLM/VLM 被尝试用于生成规划表示，但直接生成的 PDDL 往往存在语法错误、语义不匹配、规划不可行或与演示不一致等问题。
- 论文提出 **PDDL-ART**，目标是从**单个专家演示**、**自然语言任务描述**和**高层动作名称库**中自动生成并经多阶段验证的 PDDL 领域与问题文件，无需领域模板、动作签名或微调，从而实现“自主符号抽象”。

## 2. 方法论

### 2.1 整体框架
- 输入：
  - 专家演示 \(D\)：状态轨迹 \(\zeta\)（末端位姿、夹爪状态、对象位姿）和 RGB 图像序列 \(V\)；
  - 自然语言任务描述 \(d\)；
  - 高层动作名称库 \(A\)（仅动作名，不包含参数类型、前提/效果）；
  - 任务相关对象集合 \(O_{task}\)。
- 输出：经验证的 PDDL 领域 \(D\) 与问题 \(P\)，以及下游经典规划器可求解的、与演示语义一致的动作序列。

### 2.2 两个核心 VLM 组件
- **PDDLGen**：负责生成 PDDL 领域/问题文件，并在阶段 1 中进行语法、语义检查与修正。
- **PredicateEvalVLM**：负责阶段 2 中基于执行的修正，尤其是符号谓词的接地与评估。

### 2.3 Stage 1：语法与语义修正
- 通过近邻启发式从演示中抽取关键帧，减少输入 VLMs 的冗余图像。
- 依次执行：
  1. **语法检查**：使用 VAL 解析器验证 PDDL 是否符合语法；失败则把解析器错误反馈给 PDDLGen 进行最小化修正。
  2. **规划可行性检查**：使用 Fast Downward 求解器；若规划失败（找不到计划）或返回空计划（目标被初始状态平凡满足），则把规划器输出反馈修正。
  3. **初始状态交叉检查**：将演示初始帧与生成的问题文件初始状态对照，由 VLM 判定不一致之处并修正。
  4. **计划语义检查**：将生成计划与任务描述 \(d\) 对照，由 VLM 识别语义漂移并进行最后一轮阶段 1 修正。

### 2.4 Stage 2：执行引导的修正
- 将阶段 1 生成的计划通过细化函数 \(\Lambda\) 映射为机器人实际可执行动作序列。
- 若某个动作 \(a_j\) 执行失败，则将失败动作、已成功执行前缀、当前 PDDL 文件等反馈给 VLM，修改 PDDL 并重新规划。
- 对计划中的每个动作，通过 **DTW 子序列匹配**在演示轨迹中定位对应片段，以获得动作前后的关键帧：
  \[
  e^{o_j,0}_{[a:b]} = \mathrm{SubsequenceDTW}\left(e^{o_j,0}_{[0:T]}, \hat{e}^{o_j,0}_{[a':b']}\right)
  \]
- **谓词评估**：PredicateEvalVLM 分别对演示和执行关键帧上的前提/效果谓词求值，并交叉验证。工具包括：
  - **接近度检查工具（Proximity Inspection Tool）**：用于几何/关系谓词，模型自主判断阈值和参数；
  - **时间工具（Temporal Tool）**：用于需要记忆的历史状态，取回某谓词最近的取值。
- 模型自主决定是否调用工具、调用哪个工具、如何设置工具参数。
- 若演示与执行之间的谓词评估不一致，则把不匹配信息返回 PDDLGen 做最终修正；否则直接输出当前 PDDL。

### 2.5 算法流程
- 初始化 PDDL 生成 → Stage 1 各检查/修正 → 规划 → Stage 2 执行与谓词交叉验证 → 输出最终 PDDL 与计划。
- 修正均采用“最小化修改”方式，尽量避免破坏已有正确结构。

## 5. 主要结论与发现

- PDDL-ART 能够从单次演示和最小自然语言描述中自动生成**语法有效、语义对齐、计划可行且可执行**的 PDDL 领域与问题描述。
- 多阶段修正流水线有效提升生成质量：
  - Stage 1 提升语法正确性和规划可行性；

## 6. 优点

- **无需领域专业知识**：不需要模板、动作签名、候选谓词或微调，显著降低使用门槛。

- **面向困难任务**：在需要记忆、抽象谓词推理和目标状态视觉不可区分的情况下仍保持高成功率。
