## 摘要
开发能够理解和操作物体的机器人需要紧凑、可解释且可泛化的表示。本研究提出一种基于强化学习的机器人抓取细化框架，将基于关键点的物体表示与深度Q网络（DQN）相结合。利用模拟环境中捕获的二维俯视图图像，一种基于几何的算法生成初始抓取候选，然后通过所提出的框架进行迭代细化，将失败的抓取转化为成功的抓取。在UR5机械臂上对Dex-Net数据集中的300个物体进行的实验证明了该框架的有效性，在先前被几何方法判定为不可抓取的物体上达到了100%的成功率。该框架的仿真到现实迁移能力进一步通过Delta并联机器人的物理实验得到验证，其中细化后的抓取成功操纵了先前无法抓取的物体。研究结果强调了强化学习在解决机器人抓取挑战中的有效性，为接触丰富的操作任务提供了一种可扩展且适应性强的解决方案。

## Abstract
Developing robots capable of understanding and manipulating objects requires compact, interpretable, and generalizable representations. This work proposes a reinforcement learning-based framework for robotic grasp refinement, integrating keypoint-based object representations with a Deep Q-Network (DQN). Using 2D overhead images captured in a simulated environment, a geometric-based algorithm generates initial grasp candidates, which are iteratively refined by the proposed framework, transforming failed grasps into successful ones. Experiments conducted on 300 objects from the Dex-Net dataset using a UR5 manipulator demonstrate the framework's effectiveness, achieving a 100% success rate on objects previously deemed ungraspable by geometrical methods. The framework's sim-to-real transferability is further validated through physical experiments on a Delta parallel robot, where a refined grasp successfully manipulates an object that was previously ungraspable. The findings underscore the effectiveness of reinforcement learning in addressing challenges in robotic grasping, offering a scalable and adaptable solution for contact-rich manipulation tasks.

- **研究意义**：该工作探索了将传统几何方法与数据驱动学习**互补结合**的路径，不是取代几何算法，而是修复其盲区，实现更鲁棒的自动化抓取系统。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想

论文提出一个**两阶段抓取框架**：

- **第一阶段（初始抓取生成）**：使用 Sabzejou 等人 [22] 提出的基于几何的骨架关键点算法，从2D俯视图像生成初始抓取候选。
- **第二阶段（抓取细化）**：使用 Deep Q-Network (DQN) 对初始抓取候选进行**迭代微小调整**，将失败的抓取转化为成功的抓取。

每个抓取姿态用矩形表示，包含4个连续参数：中心坐标 $(x, y)$、平面内旋转角 $\theta$、夹爪宽度 $w$，即状态空间为 $s_t = (x, y, \theta, w)$。

### 2.2 评分系统与奖励设计

评分基于抓取前后物体姿态的旋转滑移（倾斜量）来衡量稳定性：

$$\text{Score} = \begin{cases} 1 - \frac{|\Delta\theta|}{\pi} & \text{成功抓取} \\ -1 + \frac{|\Delta\theta|}{\pi} & \text{失败抓取} \end{cases}$$

- 成功抓取：完全无倾斜得 +1，有旋转滑移则分数降低
- 失败抓取：完全未接触物体得 -1，有接触或物体移动则分数趋近于0

### 2.3 动作空间

动作空间为9个离散动作，每个动作对应 (Δx, Δy, Δθ, Δw) 的微小调整，包括：X/Y像素偏移（±1）、旋转调整（±2°）、宽度调整（±2）、以及无操作（No-op，用于当前状态已最优的情况）。

### 2.4 DQN实现细节

- **网络结构**：三层全连接网络（256→128→64个神经元），ReLU激活 + Layer Normalization
- **优化器**：Adam，学习率 0.005
- **强化学习参数**：折扣因子 γ=0.9，批次大小 32，ϵ-greedy 探索（ϵ 从 1.0 衰减至 0.01，衰减因子 0.999/步）
- **训练设置**：每个物体训练 E=25 个episode，每个episode最多 T=120 步
- **经验回放**：从经验回放缓冲区采样小批量，最小化 MSE 损失 $L(\phi) = \mathbb{E}\left[(Q(s,a|\phi) - y)^2\right]$，其中目标值 $y = r + \gamma \max_{a'} Q(s', a'|\phi)$

### 2.5 训练流程（Algorithm 1）

算法以初始失败抓取 $s_{init}$ 为起点，逐episode、逐步地执行模拟抓取，获取即时奖励（稳定性分数），存入经验回放；周期性更新Q网络和目标网络；记录历史最高分对应的抓取姿态 $s_{best}$ 作为最终输出。若奖励达到满分1.0则提前终止。每个抓取候选取平均值（执行N次取平均分数）以提升鲁棒性。
