## 摘要
强化学习通过评估从当前策略采样的轨迹来改进自动驾驶视觉-语言-动作（VLA）模型。组相对策略优化（GRPO）利用每次 rollout 组内的奖励差异进行学习。当所有采样轨迹都较差时，这种相对信号可以对失败进行排序，但无法识别失败区域之外的行为。我们提出 FIRE-VLA，一种失败知情自进化框架，将此类未解决的失败转化为下一策略的特权监督。低奖励、低多样性组触发从同一模型的冻结轮次起始副本进行自蒸馏。教师和学生具有相同的参数规模，但只有教师能观察隐藏的未来轨迹。监督遵循学生生成的前缀，并仅限于答案令牌，而 GRPO 对每个组保持激活。更新后的策略为下一轮提供教师，使路由失败分布随策略变化，而无需更大的外部教师。从相同的 Qwen2.5-VL-3B SFT 检查点开始，比较匹配了学生的 rollout 和策略更新次数。在来自 150 个保留的 nuScenes 场景的 6,019 个示例上，FIRE-VLA 保持了可比的单样本规划，将 G=4 平均 L2 从 1.848 降至 1.500 米，并将评估持续失败率从 13.03% 降至 11.20%。平均误差的减少主要源于罕见的高偏差 rollout，而非普通轨迹的均匀改进。

## Abstract
Reinforcement learning improves autonomous-driving vision-language-action (VLA) models by evaluating trajectories sampled from the current policy. Group relative policy optimization (GRPO) learns from reward differences within each rollout group. When all sampled trajectories are poor, this relative signal can rank failures without identifying behavior outside the failed region. We introduce FIRE-VLA, a failure-informed self-evolution framework that converts such unresolved failures into privileged supervision for the next policy. Low-reward, low-diversity groups trigger self-distillation from a frozen round-start copy of the same model. Teacher and student have the same parameter scale, but only the teacher observes the hidden future trajectory. Supervision follows the student's generated prefix and is restricted to answer tokens, while GRPO remains active for every group. The updated policy supplies the teacher for the next round, allowing the routed failure distribution to change with the policy without requiring a larger external teacher. Starting from the same Qwen2.5-VL-3B SFT checkpoint, the comparison matches student rollout and policy-update counts. On 6,019 examples from 150 held-out nuScenes scenes, FIRE-VLA retains comparable single-sample planning, reduces G=4 mean L2 from 1.848 to 1.500 m, and lowers evaluation-persistent failure prevalence from 13.03% to 11.20%. The reduction in mean error arises mainly from rare severe rollouts rather than uniform improvement across ordinary trajectories.

## 1. 论文的核心问题与整体含义

**研究动机与背景**
- 视觉-语言-动作（VLA）模型将视觉感知与语言推理相结合，用于生成自动驾驶轨迹。SFT提供驾驶先验，RL（特别是GRPO）通过评估当前策略采样的轨迹来进一步优化策略。
- GRPO的核心信号来自同一提示下多个响应之间的**奖励对比**。当组内同时包含成功与失败轨迹时，这种相对排序可以提供有用的学习信号。
- 但在**未解决失败组**中，所有采样轨迹都较差且奖励相近，GRPO只能对失败程度排序，无法提供如何**逃出失败区域**的纠正性信息——问题在于纠正信息不足，而非GRPO梯度消失。
- FIRE-VLA的核心命题是：**能否让同一个VLA模型将自身未解决的失败转化为对后继策略的特权监督，而不引入更大的外部教师模型？**

**整体含义**
- 提出一种失败知情的自进化（Failure-Informed Self-Evolution）框架，将"低奖励+低多样性"的未解决失败组转化为下一轮策略的特权自蒸馏信号，从而在不依赖外部大模型的前提下改善自动驾驶规划的可靠性与安全性。

## 2. 论文提出的方法论

**核心思想**
- 以GRPO为所有组的基底目标；对未解决失败组额外地加入**特权自蒸馏（Privileged Self-Distillation, PSD）**。
- 教师是轮次起始策略的冻结副本，**与学生参数规模相同、初始权重相同**，唯一区别是教师能看到隐藏的未来真实轨迹。
- 监督沿学生生成的前缀分布进行，只约束答案token，避免离策略偏差。
- 每轮更新后，新策略成为下一轮的教师，使失败分布随策略演化而自适应改变。

**关键流程（四阶段）**

1. **失败知情路由（Failure-Informed Routing）**：
   - 对每个在线策略组计算奖励均值 r̄ᵢ、奖励标准差 σᵢ、有效响应比例 vᵢ。
   - 若满足 r̄ᵢ ≤ 批次第30百分位 ∧ σᵢ ≤ 批次第30百分位 ∧ vᵢ ≥ 0.5，则判定为"未解决失败组"，触发额外PSD。
   - **注意**：训练时路由是批相对、在线动态的；评估用检测器则是冻结的、在独立SFT校准集上一次性确定固定阈值（r̄ᵢ ≤ 0.4458，σᵢ ≤ 0.0748，vᵢ ≥ 0.5）。

2. **构造双上下文**：
   - 学生上下文：c_S =（图像，历史，学生生成前缀）
   - 教师上下文：c_T =（图像，历史，⟨priv⟩隐藏未来轨迹⟨/priv⟩，学生生成前缀）
   - 教师冻结、无梯度，学生输入检查无特权token，因果掩码防止访问未来学生token。

3. **同策略答案token蒸馏**：
   - 在教师top-16 token加上1个残差桶上计算Jensen-Shannon散度（β=0.5），单个token散度上限设为0.05。
   - 按答案token数加权聚合（确保非均匀加权）；仅对已路由组激活。
   - 每个轨迹若含唯一的<answer>span即参与，缺失/多个标签或空span则掩码为零。

4. **策略更新（轮次式自进化）**：
   - 总损失：L = L_GRPO + λ·z·L_PSD，其中λ = 0.1，所有组保留GRPO。
   - 采用K=2轮，每轮75次策略更新；更新后的π_{k+1}初始化下一轮的教师和学生，失败分布随策略共同演化。

**核心公式**
- 轨迹奖励（有界倒数形式，对极大误差饱和）：

## 3. 实验设计

**数据集与场景**
- **nuScenes数据集**，最终保留评估集：**6,019个样本，来自150个场景**，与RL/SFT训练场景无重叠，且与SFT训练图像无重叠。
- RL训练提示集：1,200个唯一提示；FIRE-VLA将它们按位置拆分为两个不相交的600提示子集（Round 1/2各用一份），GRPO使用同一1,200提示集。

**基准与方法**
- 起点：同一个**Qwen2.5-VL-3B SFT检查点**。
- 对比对象：**标准GRPO**（连续150次策略更新）。
- 匹配变量：同样的1,200个提示、4,800次学生rollout（每提示4个响应）、150次策略更新。
- 未匹配变量：minibatch顺序；FIRE-VLA额外教师前向计算；第二轮重启优化器与调度器状态。

**评估协议（关键设计）**
- 单样本低温评估：温度0.2，每样本1个响应（n=1），非确定性但低随机性。
- G=4随机评估：温度0.8，每样本4个随机响应，候选指标先样本内平均再跨样本平均。
- 持久失败检测器：**冻结的**SFT衍生判据（独立256样本/37场景校准，与最终评估无样本和场景重叠）。
- 所有GRPO-FIRE对比按样本配对，置信区间采用**10,000次场景聚类bootstrap**。

## 6. 论文的主要结论与发现

1. **单样本名义规划性能可比**：FIRE-VLA与GRPO在低温单样本下的Avg L2差异无统计显著性（CI跨零），数值上略有改善。
2. **随机评估下显著更好**：G=4平均L2降低18.8%（1.848→1.500 m），评估持续失败率降低1.83个百分点。
3. **改进主要来自稀有严重轨迹**：FIRE-VLA通过减少极端rollout（Any>10m、CVaR₉₅/₉₉）来降低均值误差，但这以普通轨迹区域的微小退化为代价——并非均匀改善。
4. **自进化机制有效**：轮次式教师提升使失败分布与策略共同演化，无需更大外部模型即可提供特权纠正信息。
5. **未建立对所有SFT原始失败的一致恢复优势**：恢复率差异（25.21% vs 23.35%）不具统计显著性。

## 7. 优点

**方法设计上的亮点**
- **无需外部大模型**：冻结的轮次起始副本即教师，同参数规模、同初始化，仅通过隐藏未来轨迹的上下文差异形成特权，部署时仅保留学生分支，无额外推理开销。
- **GRPO与PSD互补而非竞争**：保持GRPO对所有组激活，仅在未解决失败组（低奖励+低多样性+有效比例足够）上叠加PSD，逻辑清晰、机制明确。
- **在线批相对路由 + 冻结评估检测器分离**：训练时用批相对统计自适应路由；评估时用独立校准的冻结检测器，避免评估偏倚。
- **答案token级、前缀对齐的蒸馏**：监督沿学生生成前缀分布施加，避免离策略偏移；权重按答案token数非均匀聚合，对齐轨迹质量。

**实验设计的亮点**
- **严格匹配对照组**：相同初始化、相同提示集（但FIRE第2轮子集不同）、相同rollout和更新数。
- **极为细致的统计分析**：场景聚类bootstrap、配对比较、Winsorized分析、CVaR尾部度量、奖励-L2关系诊断（Spearman vs Pearson）。
- **诚实的负面结果报告**：明确承认单样本优势不显著、GRPO在普通区域和中位数分位数上更好、不是等计算比较、不证明超越2轮的单调改进。

## 8. 不足与局限

**实验覆盖方面的局限**
- **单一训练种子**：无法评估训练随机性对结论的影响。
- **仅2轮自进化**：不建立多轮单调改进的证据。
- **无组件消融**：未隔离失败路由、特权蒸馏、教师轮换各自的独立贡献。
- **跨轮次提示不一致**：两轮使用不相交的提示子集，未纵向追踪同一批提示的演化。
- **开环评估**：仅前视相机、单帧开放环路规划，未测量闭环安全性、交通规则遵循、舒适性或复合状态偏移。

**偏差与公平性风险**
- **非等计算比较**：FIRE-VLA额外教师前向，第二轮重启优化器/调度器；如果按计算量严格对比，结论可能变化。
- **奖励饱和效应**：训练与评估使用有界倒数奖励，GRPO标量奖励更高可能误导；虽已诊断（Spearman高/Pearson低），但训练目标本身对极端误差不敏感。
- **恢复率不显著**：不能声称对所有SFT持久失败都有更好的恢复能力。
- **未恢复SFT随机鲁棒性**：两种RL均比SFT在G=4随机误差上更差，FIRE只是缓解了GRPO的退化，未恢复SFT级鲁棒性。
- **普通轨迹轻微退化**：FIRE在Winsorized截断均值和中位数/P90/P95上比GRPO略差，改进集中于尾部，可能不满足所有安全指标。

**应用限制**
- 前视单目、开环评估体系下验证，实际部署价值需闭环和多传感器验证支撑。
- 阈值选择（第30百分位、0.5有效比例、λ=0.1、token cap=0.05）在单一任务上固定，迁移泛化性未验证。
