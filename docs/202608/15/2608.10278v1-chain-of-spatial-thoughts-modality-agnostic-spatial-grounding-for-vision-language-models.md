## 摘要
空间理解是具身智能的基础，支撑着机器人操作、具身导航和自动驾驶等应用。尽管近期的视觉语言模型（VLM）在空间推理基准上取得了令人瞩目的性能，但最先进的方法通常在推理阶段依赖额外的空间编码器或架构修改，增加了计算成本。我们引入了Space Tokens，一种轻量级、架构无关的框架，使VLM具备显式的连续空间表示，而无需额外的推理时模块。通过将场景级3D几何和以对象为中心的空间属性蒸馏为连续潜在标记，我们的方法使这些模态能够直接融入思维链推理过程，从而提升VLM的空间推理能力。同时，学习到的表示可以被显式解码，以验证其编码了有意义的几何信息，而统一的标记接口仍可扩展到其他模态。在VSI-Bench上的实验将Qwen3-VL-8B提升了4.3%，SenseNova-SI-1.3提升了1.3%，并在物体大小估计（79.2%）和房间大小估计（75.7%）上达到了最先进性能。这些结果表明，连续空间标记为将几何推理集成到大型视觉语言模型中提供了一种有效、可解释且计算高效的机制。

## Abstract
Spatial understanding is fundamental to embodied intelligence, underpinning applications such as robotic manipulation, embodied navigation, and autonomous driving. Although recent vision-language models (VLMs) have achieved impressive performance on spatial reasoning benchmarks, state-of-the-art approaches typically rely on additional spatial encoders or architectural modifications during inference, increasing computational cost. We introduce Space Tokens, a lightweight, architecture-agnostic framework that equips VLMs with explicit continuous spatial representations without requiring additional inference-time modules. By distilling scene-level 3D geometry and object-centric spatial attributes into continuous latent tokens, our method enables these modalities to be directly incorporated into a chain-of-thought reasoning process, thereby improving the VLM's spatial reasoning capabilities. At the same time, the learned representations can be explicitly decoded to verify that they encode meaningful geometric information, while the unified token interface remains extensible to additional modalities. Experiments on VSI-Bench improve Qwen3-VL-8B by 4.3% and SenseNova-SI-1.3 by 1.3%, while achieving state-of-the-art performance on object size (79.2%) and room size estimation (75.7%). These results demonstrate that continuous spatial tokens provide an effective, interpretable, and computationally efficient mechanism for integrating geometric reasoning into large vision-language models.

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想

- **Space Tokens**：通过预留词汇表中一部分特殊 token，在自回归生成过程中，提取这些 token 在 VLM 最终层的隐藏状态作为连续空间表示，并用任务特定目标进行监督。
- **与 Chain-of-Thought 结合**：空间 token 被嵌入到思维链式的推理文本中，与原始视觉和文本信息一起参与多模态推理。
- **统一接口**：不同空间模态（3D 重建、3D 边界框）共用同一套 Token 范式，可扩展至深度、法线、语义等更多模态。

### 2.2 关键技术细节

- **3D 表示 Token（场景级几何）** ：
  - 以 VGGT-Omega 为教师模型，对齐 VLM 潜在表示与教师的 3D 几何特征。
  - 损失函数包括四部分：
    - 潜在空间对齐损失：`L_sim = 1 - (ẑ ⊤ z) / (||ẑ|| ||z||)`（余弦距离）
    - 相机参数重建损失：`L_cam = Σ|ĝ - g|`（ℓ1 损失）
    - 深度图重建损失（含回归项、梯度一致性项和异方差不确定性加权）
    - 3D 点图重建损失（将深度反投影到相机坐标后监督）
  - 综合目标：`L_3D = λ_sim L_sim + λ_cam L_cam + λ_dpt L_dpt + λ_pt L_pt`，实验中所有 λ 均设为 1。
- **3D 边界框 Token（物体级空间属性）** ：
  - 每个边界框用 12 维向量表示（相机空间中心 + 尺寸 + 6D 旋转表示）。
  - 使用匈牙利匹配（Hungarian Assignment）将预测匹配到真值框，背景槽位向零回归。
  - 损失包括 Smooth ℓ1 损失（β=0.1）加上背景回归损失。
  - 解码时融合 VLM 视觉骨干特征和归一化 2D 边界框特征（后者仅训练时使用）。

### 2.3 三阶段训练流程

- **Stage 1（表示学习）** ：将空间 token 手动注入提示词中的思维链语句中，仅回传重建/对齐损失，学习将 VLM 隐藏状态映射到空间特征空间。
- **Stage 2（空间 token 推理）** ：冻结投影层，保留空间 token 在提示词中，通过标准交叉熵损失（teacher forcing）训练 VLM 在推理过程中使用空间 token。
  - 经验发现：对输入帧的子集进行推理比使用全部帧更有效。
- **Stage 3（空间强化学习）** ：采用 GRPO（Group Relative Policy Optimization）进一步优化模型利用空间表示进行推理的能力。
  - 奖励基于 VSI-Bench 指标设计：多项选择题用模糊匹配给 1/0 奖励；数值题使用平均相对精度（MRA）。

- **总体性能提升**：
  - Qwen3-VL-8B 应用 Space Tokens 后 VSI-Bench 平均分提升 4.3 个百分点（59.8→64.1），房间大小任务提升最大（+15.8）。

  - 场景级 3D 重建 token 和物体级 3D 边界框 token 都对推理有积极贡献。

## 7. 优点

### 7.1 方法设计上的亮点

- **架构无关且轻量**：无需修改 VLM 架构、无需额外的推理时模块，仅通过预留词汇表和 LoRA 微调实现，具有较高便携性。
- **统一 token 接口**：场景级几何和物体级空间属性共享同一套机制，可自然推广到更多模态（深度、法线等）。
- **可解释性与可验证性**：学到的空间表示可以显式解码为 3D 场景和物体边界框进行可视化验证，避免了“黑盒”推理。
- **训练效率**：通过知识蒸馏将 VGGT-Omega 等重模型的几何能力压缩到 VLM 的轻量表示中，推理时不需要携带重模块。
- **两阶段式监督设计**：Stage 1 单独学习表示，Stage 2 再学习使用表示，避免了多任务竞争导致的表示漂移。
- **GRPO 强化学习**：用任务指标作为奖励进一步优化空间推理行为。

### 7.2 实验设计上的亮点

- 控制变量实验（同数据不加 Space Tokens）很好地隔离了“数据效应”与“方法效应”。
- 注意力掩码实验比 token 替换测试更能直接验证表示有效性，是对伦理/评估方法论的有益补充。

## 8. 不足与局限

- **基准覆盖单一**：主要在 VSI-Bench 上优化与评测，聚焦室内场景，对室外场景、动态场景、大规模开放世界空间理解缺乏实验验证。
- **推理帧选择策略受限**：6 帧的选定依赖 CLIP 相似度和训练模型的使用频率统计，该方法是否可泛化到未见数据集/任务值得存疑。
- **空间模态有限**：只集成了 3D 重建和 3D 边界框，未覆盖深度图、表面法线、场景图等可能互补的空间信息。
- **CV-Bench 下降**：OOD 评测中 CV-Bench 约有 1.5 点下降，说明空间 token 训练对部分空间感知能力有小幅负面影响。
- **TRT 测试不适配**：token 替换实验对多帧模型解释力有限，注意力掩码实验又受 Flash Attention 2 限制需用 eager attention 执行，绝对性能略有下降，评价方法本身仍有探索空间。
- **算力与工程细节未公开**：未报告 GPU 型号/数量/训练时长等资源信息，复现难度较大；32 帧输入的内存压力未提供完整的显存优化方案。
- **依赖教师模型的偏差风险**：3D 表示的监督来源于 VGGT-Omega，教师模型的缺陷可能被继承；若教师在某场景失效，学生模型可能会学到有偏差的表示。
- **GRPO 奖励与测试任务绑定**：Stage 3 的奖励函数直接针对 VSI-Bench 指标设计，有对特定基准过拟合的风险，可能削弱在更广泛空间任务上的泛化能力。
