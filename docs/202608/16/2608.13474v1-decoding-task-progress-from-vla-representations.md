## 摘要
视觉-语言-动作模型（VLA）正快速走向部署，作为通用操作策略，但我们目前缺乏基本工具来理解这些模型内部表征的内容或在运行时对其进行监控。借鉴机械可解释性的思想，我们探测了π_{0.5}的残差流，发现任务进度——轨迹中归一化的剩余时间——可以从激活中线性读取。我们发现，该信号在预训练的PaliGemma主干中就已存在，早于任何机器人特定数据的训练。当在多提示数据上训练时，单个线性探针可以泛化到未见任务，并在语言反事实下变化，但无法实现有意义的策略引导。这些性质使得该信号直接可用于检测已部署的VLA。我们将该探针用作一种简单的无标签OOD检测器，用于检测停滞的任务进度，并发现它与最先进的方法具有竞争力。我们的结果表明，VLA具有丰富、可线性读取的内部表征，涵盖了如任务进度等语义量，而学习读取这些信号为监控部署的视觉运动策略提供了一条轻量级、可解释的路径。

## Abstract
Vision-language-action models (VLAs) are moving rapidly towards deployment as general-purpose manipulation policies, but we currently lack basic tools for understanding what these models represent internally or for monitoring them at runtime. Leveraging ideas from mechanistic interpretability, we probe the residual stream of $π_{0.5}$ and find that task progress, the normalized time remaining in a trajectory, is linearly readable from the activations. We find that this signal is present in the pretrained PaliGemma backbone prior to training on any robot-specific data. A single linear probe generalizes to unseen tasks and varies under language counterfactuals when trained on multi-prompt data, but does not enable meaningful steering of the policy. These properties make the signal directly useful for instrumenting deployed VLAs. We use the probe as a simple label-free OOD detector, which detects stalled task progress, and find it competitive with state-of-the-art methods. Our results suggest that VLAs have rich, linearly readable internal representations of semantic quantities like task progress, and that learning to read these signals offers a lightweight, interpretable path toward monitoring deployed visuomotor policies.

### 二、方法论：核心思想、关键技术细节与公式

1. **核心思想**：利用线性探针（linear probing）技术，将任务进度定义为监督目标，在π0.5各层嵌入上训练线性映射，以检测该特征是否线性编码在残差流中。同时引入三种递进的定义体系，区分信号可提取、泛化与因果可控的区别。

2. **三种核心定义**（论文的主要方法论贡献）：
   - **弱可解码性**：在训练分布内，存在线性探针能从激活中低误差地解码特征。对应公式为 \(R(\phi; D_{val})\) 验证集风险最小化。
   - **强可解码性**：给定一个对输入的反事实变换 \(T: X \to X\)（如替换语言指令中的目标名词），同一探针无需重训练即可在变换后输入上正确解码特征，排除由偶然相关性导致的表面解码。对应数据集 \(D_T = \{(z_i(T(x_k)), \zeta(T(x_k)))\}\)。
   - **可引导性**：沿探针方向注入激活偏移，使探针读出目标反事实值，并检验模型的动作分布是否与真实反事实输入下的动作分布接近。对应注入公式：
     \[
     \tilde{z}_i(x) = z_i(x) + \frac{\zeta(T(x)) - \zeta(x)}{\|w\|^2}w
     \]
     以及引导风险 \(R_S(\phi; D, T)\)。

3. **任务进度定义**：给定轨迹 \(\xi = (x_0, x_1, \dots, x_T)\)，任务进度为归一化剩余时间：
   \[
   \tau(x_t) = 1 - \frac{t}{T} \in [0, 1]
   \]
   该定义无需人工标注（可从离线数据中直接生成），满足单调递减、跨任务泛化等可监测性要求。

4. **OOD检测流程**：
   - 预先估计每类任务预期完成时间 \(E[T | \ell]\)。
   - 运行时用探针解码当前进度 \(\tau_{\text{pred}}\)。
   - 计算残差 \(V_\tau(t) = \tau_{\text{pred}} - \left(1 - \frac{t}{E[T|\ell]}\right)\)。
   - 当 \(V_\tau(t) > \delta\) 时判定为OOD状态（即任务进度停滞）。该方法**无需任何OOD标签**，完全基于ID数据训练探针。

5. **对比学习探针**：针对语言反事实训练，采用成对hinge损失使同一时刻原指令与交换名词后的激活输出分离，并以BCE锚定损失保持进度信号的单调性，从而恢复探针的语言敏感性。

### 三、实验设计

- **数据集/场景**：VLABench基准（10个操作任务，500条轨迹/任务，共5000条轨迹），涵盖放置水果、插花、取饮料、加调味品、推书、选玩具等多样化操作场景。模拟器提供前、侧、腕部三视角相机图像、本体感觉与语言指令。
- **目标模型**：π0.5（PaliGemma视觉-语言骨干 + 动作专家），同时对比PaliGemma（纯VLM骨干）、π0（另一VLA架构）和基础版π0.5（微调前）。
- **对比方法**：OOD检测实验中对比了马氏距离（Mahalanobis）、变分自编码器（VAE）、SAFE-MLP与SAFE-LSTM（监督训练方法）。
- **实验维度**：
  - 弱可解码性（逐层探测）；

  - 强可解码性（语言反事实测试）；

### 六、主要结论与发现

1. **任务进度可线性解码**：π0.5各层（尤其是视觉骨干早期层与Gemma前几层）的残差流激活中线性编码了任务进度，且该信号**早于微调即已存在**——主要源于大规模机器人预训练，而非特定任务微调，PaliGemma预训练骨干中也存在较弱但可检测的信号。
2. **弱可解码不等于强可解码**：朴素训练的探针在ID数据上R²达到0.95，但对语言替换不敏感（输出几乎不变）；通过对比学习训练后，探针在保持ID跟踪能力的同时，能在反事实下正确推向τ≈1.0。
3. **信号可观测但不可引导**：沿探针方向注入进度偏移不会改变后续层的读出值，也不会使动作输出向真实未来动作靠拢。说明模型“知道”进度但未将其作为决策的因果输入，暴露了表征与行为之间的间隙。
4. **可作为有效的无标签OOD检测器**：Vτ在跨未见任务和跨未见扰动类型测试中，与监督训练的SAFE方法表现相当甚至更好（尤其在episode级聚合下），且无需任何OOD标签。
5. **任务进度不能从原始观测直接线性解码**：对照实验显示，在原始像素和本体感觉上训练的探针OOD后完全崩溃（R² = -2627.7），而基于VLA嵌入的探针保持稳健（R² = 0.807），说明该信号是模型内部表征的产物。

### 七、优点与亮点

- **定义体系清晰且严谨**：弱/强可解码性与可引导性的三层区分，为解释性研究提供了规范性框架，避免将“相关信号”误认为“因果信号”。
- **OOD检测方法新颖实用**：使用任务进度——策略自身表征中的内在信号——作为OOD指示器，无需任何OOD标注，跨任务与跨扰动鲁棒性强，适合实际部署。
- **控制实验设计合理**：标签打乱的容量扫描、轨迹级数据划分、多种子统计等方法有效保证了结论的可信度。
- **指出语言敏感性下降的量化诊断路径**：通过探针在语言反事实下的响应差异，为评估微调VLA的语言接地退化提供了直接工具。
- **发现问题并诚实报告**：明确报告了“可观测但不可引导”这一负面结果，对领域的实际期望管理有重要参考价值。

### 八、不足与局限

- **外部效度有限**：所有实验仅基于π0.x模型族和仿真环境（VLABench），未验证其他VLA架构（如OpenVLA）或真实物理机器人上的可迁移性。
- **任务进度定义的语义局限**：以归一化时间而非语义完成度定义进度，可能将“等待”或“绕路”错误编码为进度；强解码实验提供了部分反证，但不完全排除纯时间解释。
- **反事实标签存在代理偏差**：语言替换实验中对交换指令的进度设置为人为的1.0（零进度），并非真实语义进度，可能削弱对比训练的有效性。
- **引导性测试覆盖窄**：仅测了单层、单方向、固定步长的注入，未系统探索多方向联合编辑或不同层组合的引导效果，引导性负面结论的普适性有限。
- **OOD检测依赖预期完成时间**：Vτ需要预先估计 \(E[T|\ell]\)，跨任务迁移时该估计可能不准确，影响长时任务中的检测可靠性。
- **缺少真实部署验证**：OOD检测在真实机器人上可能面临更多未知扰动（动态光照、传感器噪声、物理接触异常等），论文未覆盖这些场景。
