## 摘要
移动操作要求机器人预测移动和手臂运动如何共同改变未来的观测和控制。现有的世界动作模型主要针对固定基座平台开发，没有明确区分相机自我运动与基座和手臂动作。在此，我们介绍了DECOWAM，一种通过专用条件接口分离这些因素的全身世界动作模型。DECOWAM冻结了适应后的FastWAM骨干网络，并训练残差适配器、从特权观测中提取的动作等价未来瓶颈、对抗性分离的基座和手臂潜变量，以及用于视频预测的基座速度条件。我们进一步介绍了ARMDOG，一个真实机器人数据集，同步了视频、全身状态和动作以及语言。在固定的回放协议上，DECOWAM相比FastWAM在未来视频和动作预测上都有所改进，以25.95M可训练自适应参数将动作均方误差降低了21.7%。每种方法进行79次闭环试验，它在所比较的系统中取得了最高的全身协调性和基座位移鲁棒性，同时任务完成率与最强基线相当。这些结果表明，具身感知分解可以在移动视点下支持参数高效的联合视觉预测和全身控制。

## Abstract
Mobile manipulation requires a robot to predict how locomotion and arm motion jointly alter future observations and control. Existing world-action models, developed largely for fixed-base platforms, do not explicitly distinguish camera ego-motion from base and arm actions. Here we introduce DECOWAM, a whole-body world-action model that separates these factors through dedicated conditional interfaces. DECOWAM freezes an adapted FastWAM backbone and trains residual adapters, an action-equivalent future bottleneck distilled from privileged observations, adversarially separated base and arm latents, and base-velocity conditioning for video prediction. We further introduce ARMDOG, a real-robot dataset that synchronizes video, whole-body state and action, and language. On a fixed replay protocol, DECOWAM improved both future-video and action prediction over FastWAM, reducing action MSE by 21.7% with 25.95M trainable adaptation parameters. Across 79 closed-loop trials per method, it achieved the highest observed whole-body coordination and base-displacement robustness among the compared systems, while task completion remained comparable to the strongest baseline. These results show that embodiment-aware factorization can support parameter-efficient joint visual prediction and whole-body control under moving viewpoints.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：移动操作（mobile manipulation）要求机器人同时预测“本体运动”与“手臂运动”如何共同影响未来观测与控制。然而，现有的视觉-语言-动作（VLA）模型和世界-动作模型（如 Aloha、RT-1/2、OpenVLA、π0、RDT-2 等）主要针对**固定基座**的双臂平台设计，其相机几何固定、动作空间仅限于手臂轨迹，难以直接推广到腿式移动操作机器人。
- **核心问题**：腿式移动操作平台带来了三个结构性困难：
  1. **动态视点**：机载相机随移动基座运动，图像流混合了场景动态、手臂运动和相机自运动（ego-motion），模型需要显式表达相机运动，而不能将所有像素位移都当作场景动态。
  2. **多速率动作耦合**：手臂关节需要高频控制（15–30 Hz），而基座速度指令通常低频（3–5 Hz），将两者拼接进统一动作块，要求单一表示同时覆盖导航级速度和操作级关节修正。
  3. **层次化意图**：真实任务同时包含“去哪里”和“如何操作”两种决策，单一隐变量难以同时表达导航尺度决策与操作尺度修正。
- **整体意义**：论文提出了一种“解耦”建模范式——把基座移动、手臂操作、相机自运动作为显式因子分别建模，从而在移动视点下实现**参数高效的联合视觉预测与全身控制**。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
DECOWAM 在 FastWAM（基于 Wan-2.2 视频扩散骨干 + ActionDiT 动作分支）基础上，引入四个“解耦”机制：
- 参数空间解耦：冻结预训练骨干，只训练残差适配器；
- 未来信息解耦：通过“动作等价未来瓶颈”从特权未来潜在变量中蒸馏因果训练信号；
- 动作因子解耦：用对抗性分离（GRL）区分基座速度与手臂动作隐变量；
- 自运动条件解耦：用基座速度 token 显式条件化视频预测，使视频分支不必仅从像素中推断相机运动。

### 2.2 问题形式化
模型学习条件联合分布：

\[
p_\theta(x_{1:T}, a_{1:K} | x_0, s_0, \ell)
\]

其中 \(x_{1:T}\) 为未来视频（T=8），\(a_{1:K}\) 为动作块（K=48，14维），每个动作分解为：

\[
a_k = [a^{\text{arm}}_k, a^{\text{grip}}_k, a^{\text{base}}_k, a^{\text{pad}}_k], \quad a^{\text{base}}_k \in \mathbb{R}^3
\]

通道 [0:7] 为手臂+夹爪，[7:10] 为基座速度，[10:14] 为 loader 填充。基座速度既是控制目标，又是相机自运动的来源。

### 2.3 分阶段参数高效适配
- **Stage 1（域对齐）**：全部 FastWAM 参数在 ARMDOG 数据上训练 50k 步，最小化视频+动作损失。
- **Stage 2（结构化适配）**：冻结 FastWAM 全部参数，只优化四组参数：
  \[
  \Phi = \{\phi_{\text{adp}}, \phi_q, \phi_{\text{ba}}, \phi_{\text{ego}}\}
  \]
  即残差适配器、动作等价未来瓶颈、基座/手臂分解、自运动条件。可训练参数从 6020.75M 降至 **25.95M**，约减少 232 倍。

残差适配器形式：

\[
h^+_l = h_l + \alpha_l W_{\text{up}}^{(l)} \sigma(W_{\text{down}}^{(l)} \mathrm{LN}(h_l))
\]

其中 \(W_{\text{down}}\) 投影到 128 维瓶颈，\(W_{\text{up}}\) 恢复隐藏维度，σ 为 SiLU。

### 2.4 动作等价未来瓶颈（Future Bottleneck）
- 教师网络观察当前与未来视觉潜在变量的统计摘要（均值+标准差），学生网络仅观察当前摘要和状态：
  \[
  c = \rho(e_0), \quad f = \rho(e_{1:T})
  \]
  \[
  z_t = q_t([c, f, s_0]), \quad z_s = q_s([c, s_0])
  \]
- 学生隐变量条件化动作专家：\(\tilde{u}_a = u_a + \eta_q B_q z_s\)。
- 训练损失包括动作重构、师生蒸馏（stop-gradient）和几何保持（geometry preservation）：
  \[
  L_q = \lambda_{q}^{\text{act}} L_q^{\text{rec}} + \lambda_{q}^{\text{dist}} \|z_s - \mathrm{sg}(z_t)\|_2^2 + \lambda_{q}^{\text{geom}} L_{\text{geom}}
  \]
  几何项保证动作轨迹相似时，特权隐空间也接近。

### 2.5 基座–手臂对抗性分解
- 从动作上下文池化得到两个 16 维因子：\(z_{\text{base}} = b_\phi(u_a)\)、\(z_{\text{arm}} = m_\phi(u_a)\)，拼接后条件化动作专家。
- 通过 **梯度反转层（GRL）** 进行交叉解耦：
  - 直接预测头保留本因子对应动作；
  - 交叉预测头经 GRL 反向传播，抑制相反因子信息。
- 损失函数 \(L_{\text{disent}}\) 包含四项重构项，目标是使每个隐变量只保留自身控制因子、丢弃对方信息。

### 2.6 自运动感知的视频条件化
- 当前归一化基座速度 \(v_0 = \Pi_{\text{base}}(s_0) = (v_x, v_y, \omega_z)\) 被投影到 WAN 隐藏维度，并加到每个视频 token 上：
  \[
  \tilde{h}_{v_i} = h_{v_i} + \beta B_v v_0
  \]
- 该 token 不做几何扭曲，只提供显式的相机帧运动解释变量。

### 2.7 训练与部署
- 使用条件流匹配（conditional flow matching），目标为速度场 \(v^\star(y_\tau, \tau) = y - \epsilon\)。
- 总损失：
  \[
  L = \lambda_v L_{\text{video}} + \lambda_a L_{\text{action}} + \gamma_q \lambda_q L_q + \gamma_{\text{ba}} \lambda_{\text{ba}} L_{\text{disent}}
  \]
  其中 \(\lambda_v = \lambda_a = 1.0, \lambda_q = 0.2, \lambda_{\text{ba}} = 0.1\)。
- 部署时移除教师网络和辅助预测头，严格因果，只依赖 \((x_0, s_0, \ell)\)。

## 6. 论文的主要结论与发现

1. **预测性能全面领先**：在固定回放协议下，DECOWAM 相比 FastWAM（50k）将帧 MSE 降低 15.03%、动作 MSE 降低 21.71%、PSNR 提升 0.222 dB。
2. **消融验证各模块有效性**：移除未来瓶颈、基座速度条件或全部结构化路径都会同时恶化视频和动作指标；完整模型比 adapter-only 控制的帧 MSE 降低 4.6%、动作 MSE 降低 15.7%、动作 MAE 降低 16.1%。
3. **兼具 VLA 级动作质量与未来预测能力**：DECOWAM 的动作误差低于 π0.5（A-MSE 降低 69.9%、A-L2 降低 21.1%），虽不及 X-VLA 的纯动作精度，但额外输出 8 帧未来视频。
4. **真实机器人全身协调与鲁棒性最佳**：在 79 次试验中，DECOWAM 达到最高全身协调成功率（44.3%）和基座位移鲁棒性（30.4%），任务成功率 58.2%，与最强基线 FastWAM（57.0%）相当，且平均完成时间比 FastWAM 快 16 秒。
5. **参数高效性显著**：Stage-2 仅需 25.95M 可训练参数（约为全量微调的 1/232），同时改进视频和动作预测，推理开销仅增加 11.4%。

- **数据覆盖有限**：ARMDOG 主线任务集中在物体取放（56% Bottle Pick&Place、39% Place Block），Climb Slope 仅 1%，对复杂地形、长距离导航等移动操作场景覆盖不足。
- **回放基准较窄**：所有回放结果基于单一 23-episode 固定切片，缺乏跨切片、跨任务家族的泛化验证。
- **评估公平性存疑**：VLA/WAM 参考模型未经过同等数据量的适配训练，其性能可能未达最优；跨模型比较时分辨率/帧数不一致（如 X-WAM 为 4 帧 160p），可能引入偏差。
- **统计显著性缺失**：真实机器人实验只报告点估计成功率，未提供置信区间或显著性检验；79 次试验中部分成功率差异（如 58.2% vs 57.0%）未必具有统计意义。
- **训练资源信息缺失**：全文未报告 GPU 型号、数量、训练耗时等算力信息，影响复现和成本评估。
- **理论分析有限**：对“解耦”为何有效的理论解释较弱——主要依赖消融实验的实证结果，缺少对隐变量可辨识性、解耦程度的量化分析（如互信息、干预实验等）。
- **应用限制**：仅验证了单一四足平台（轮式四足）和 14 维动作空间，对足式（非轮式）地形适应、双臂操作、多机协作等场景的可推广性未作探讨。
