## 摘要
本文介绍了具身场景重排规划（ESRP），这是一项新颖的任务，要求具身智能体仅使用以自我为中心的观察和俯视目标布局，在3D场景中重新排列家具以匹配目标配置。与之前的重排任务不同，ESRP排除了全局状态访问，并引入了物体之间的相互遮挡，反映了现实世界机器人部署的实际限制。这些因素使得将部分自我中心观察与全局目标布局对齐对于长视距规划尤为具有挑战性。为促进研究，我们基于OmniGibson构建了ESRP-Bench，一个包含超过5400个场景对和8200个物体的综合基准。我们定义了三个多层级指标来评估重排质量，并提供了四种基线方法：一种层次化任务与运动规划方法、一种基于视觉语言模型的方法，以及两种基于学习的方法（IL和RL）。实验结果表明，当前方法难以高效完成该任务，突显了ESRP作为具身智能体在场景理解和长视距任务规划方面的一个具有挑战性的前沿方向。这项工作为在现实场景中部署智能体迈出了重要一步。项目页面：https://pie-lab.cn/ESRP/。

## Abstract
This paper introduces Embodied Scene Rearrangement Planning (ESRP), a novel task requiring embodied agents to rearrange furniture in 3D scenes to match a target configuration using only egocentric observations and a top-down target layout. Unlike prior rearrangement tasks, ESRP precludes global state access and introduces mutual object occlusions, reflecting the practical constraints of real-world robotic deployment. These factors make aligning partial egocentric observations with the global target layout particularly challenging for long-horizon planning. To facilitate research, we present ESRP-Bench, a comprehensive benchmark built on OmniGibson featuring over 5,400 scene pairs and 8,200 objects. We define three multi-level metrics to evaluate rearrangement quality and provide four baselines: a hierarchical task-and-motion planning method, a vision-language-model-based method, and two learning-based approaches (IL and RL). Experimental results demonstrate that current methods struggle to complete the task efficiently, highlighting ESRP as a challenging frontier for embodied agents in scene understanding and long-horizon task planning. This work serves as a stepping stone toward deploying intelligent agents in real-world scenarios. Project page: https://pie-lab.cn/ESRP/.

## 1. 核心问题与研究动机

- **研究背景**：现有场景重排（Scene Rearrangement）研究主要分为两类：
  - **桌面级重排**：在受限工作空间内操作小物体，难以扩展到房间级、长时序的真实场景。
  - **场景级重排**：通常依赖全局状态访问，并在简化的 2D 平面中抽象环境，忽略了真实 3D 空间中的几何约束、物体间遮挡和部分可观测性。
- **核心问题**：真实机器人部署中，智能体只能获得第一视角（egocentric）的局部观测，无法访问全局状态；同时家具之间相互遮挡、场景随操作动态变化，使得长时程规划极其困难。现有任务设定与基准无法覆盖这一实际需求。
- **核心贡献**：本文提出 **ESRP（Embodied Scene Rearrangement Planning，具身场景重排规划）** 任务，要求仅凭第一视角 RGB 观测和一张俯视目标布局图，在 3D 场景中重新摆放家具以匹配目标配置，并构建了配套基准 **ESRP-Bench**。

## 2. 方法论

### 2.1 任务定义

- **输入观测**：每个时间步包含：
  - 第一视角 RGB 图像 \(I_{ego}\)（128×128）；
  - 目标布局俯视 RGB 图像 \(I_g\)（128×128）；
  - 二值夹爪状态 \(g \in \{0,1\}\)。
- **动作空间**：\(A = \{move\_forward, move\_backward, turn\_left, turn\_right, fetch, release\}\)。旋转步长为 22.5°，平移步长为 0.25m。
- **成功条件**：所有可重排物体被放置到目标位置。单个物体正确放置判定为：其当前 2D 包围盒与目标包围盒的水平面 IoU > 0.3。
- **终止条件**：超过最大时间步 \(L\)（超时失败）或所有物体成功放置。

### 2.2 数据集构建流程

- 基于 **3D-FRONT** 数据集，选取专业设计布局作为目标布局；
- 通过规则化的“逆向扰动”生成初始布局：从目标布局出发，机器人迭代随机移动每个物体，直至到达不重叠、无碰撞的位置，从而**保证可解性**；
- 逆向轨迹同时被保存为**专家示范**，用于模仿学习；
- 场景按可重排物体数量分为三档难度：Easy（1 个）、Medium（2–3 个）、Hard（4–6 个）。

### 2.3 评估指标

| 指标 | 公式 | 含义 |
|------|------|------|
| 成功率 SR | \(SR = \frac{1}{N}\sum_{i=1}^N S_i\) | 整集成功比例（所有物体均放置正确） |
| 物体成功率 OSR | \(OSR = \frac{1}{N}\sum_{i=1}^N M_i^{succ}/M_i\) | 正确放置物体占需重排物体总数的比例 |
| 剩余距离比 RDR | \(RDR = \frac{1}{N}\sum_{i=1}^N D_i^{end}/D_i^{start}\) | 结束与开始时所有物体到目标位置 L2 距离之和的比值，越低越好 |

### 2.4 四种基线方法

1. **ESRP-BC（模仿学习）**：基于条件扩散策略（Diffusion Policy），预测长度为 \(h=8\) 的未来动作序列；观测经两个 ResNet-50 编码后与夹爪状态拼接作为条件，使用条件 1D U-Net 去噪，损失为扩散噪声预测误差与离散动作交叉熵的加权和。
2. **ESRP-PPO（强化学习）**：使用 PPO 算法，视觉编码器为 CNN，结合单层 LSTM 维持时序记忆，MLP 输出动作；设计了密集奖励（成功奖励 +10、到达/离开 ±1、势函数项、抓取奖励等）。
3. **ESRP-VLM（视觉语言模型）**：基于 Qwen3-VL-2B-Instruct，采用 ReAct 模式的上下文提示，每步交替输出推理和动作，无需任务微调。另在实验中用 Gemini 2.5 Flash-Lite 替换骨干以测试模型能力影响。
4. **ESRP-PLAN（规划方法）**：利用全局信息的层次化 TAMP（任务与运动规划）框架——任务规划器决定物体移动顺序；运动规划器对每个物体执行 BFS（导航至物体）、fetch、A*（导航至目标）、release 四阶段流程，具备完美感知假设。

## 6. 主要结论与发现

1. **ESRP-PLAN 最优**：SR 30.20%、OSR 36.59%、RDR 0.6916，明显优于学习类方法，得益于全局状态访问带来的显式规划能力。
2. **RL 优于 IL**：ESRP-PPO 在三个指标上均优于 ESRP-BC；BC 的 RDR 较差（1.0170），说明长时程执行中误差累积放大。
3. **VLM 泛化不足**：ESRP-VLM（Qwen3-VL）仅达到 17.64% SR，与 BC 相当但未超过 PPO——预训练基础模型的先验不足以单独支撑长时程空间推理；骨干替换为 Gemini 2.5 Flash-Lite 后提升至 23.01% SR，说明骨干强度是关键影响因素之一。
4. **主要瓶颈是放置而非导航**：失败模式分解显示，无论哪种范式，约 60%–67% 的失败发生在 Stage 3（抓取后未能正确放置到目标），而导航和抓取阶段失败占比仅 4%–13%——精确放置是 ESRP 的核心难点。
5. **任务难度随物体数量急剧上升**：在 Hard 场景中，学习类方法 SR 全部为 0%，ESRP-PLAN 也降至 0% SR（仅 OSR 22%），说明多物体重排的组合复杂性和长程依赖是独立于感知的挑战。

## 7. 优点

- **任务定义具有真实感**：首次提出仅依赖第一视角观察的 3D 室内家具重排任务，排除了全局状态访问，贴近真实机器人部署约束。
- **基准构建完善**：5,400+ 场景对、8,000+ 物体，覆盖 24 种房型和多种家具类别，按难度分层；逆向生成初始布局保证任务可行性。
- **指标设计合理**：SR / OSR / RDR 三指标分别衡量整集成功、物体级成功和接近程度，层次清晰。
- **基线覆盖全面**：同时提供 RL、IL、VLM、TAMP 四种范式，且 TAMP 作为拥有全局信息的规划上界，便于诊断感知与规划各自的贡献。
- **失败模式分解很有价值**：将失败归类为导航/抓取/放置阶段，直接指明未来研究应聚焦于“在局部观察下精确放置”这一核心能力。
- **明确的现实部署讨论**：讨论了任务抽象合理性、仿真到现实的迁移前景以及俯视目标布局在真实世界的获取方式（如 MagicPlan 等扫描-编辑流程）。

## 8. 不足与局限

- **缺乏消融实验**：未对奖励设计、网络结构、扩散策略超参数、观测历史长度等进行消融，无法确定各设计选择的贡献。
- **统计稳健性不足**：未报告多次随机种子的均值与方差；VLM 结果基于单次运行，RL/IL 的随机性未充分刻画。
- **仅在仿真中验证**：无真实机器人实验，尽管作者说明了硬件限制（商用平台难以操控家具级物体），但 sim-to-real 转移效果仍未得到实证。
- **任务抽象简化了底层操作**：抓取采用“瞬时吸附”机制，忽略了真实抓取、抬升、放置等物理交互细节，可能弱化对操作能力的评估。
- **碰撞处理方式**：碰撞动作在仿真层面被拒绝，不产生惩罚，这简化了避障难度，与真实物理不一致。
- **观测模态单一**：仅使用 RGB 第一视角，未考虑深度、全景相机或 LiDAR 等多模态信息，限制了任务对感知全面性的考察。
- **Hard 场景下几乎所有方法失效**：虽然这证明了任务挑战性，但也意味着基准在最难层级上的区分度有限（多方法同为 0%），不利于算法比较与进展追踪。
