## 摘要
拆解报废电动汽车（EV）电池组是一项枯燥且危险的工作，几乎完全由人类完成。我们提出了GOLEM（通用开放具身模块库），一种用于电动汽车电池拆解的端到端开源系统架构，基于Unitree H1-2人形机器人。在该架构中，行走、操作、动态稳定性、导航和空间记忆是带有抽象接口的独立模块，从而便于方法的开发、互换和比较。GOLEM部署为基于Docker的ROS 2抽象，其中MuJoCo和IsaacLab数字孪生暴露与物理机器人匹配的接口。GOLEM的可组合性和逐模块定制能力支持从仿真到现实的人形电动汽车电池拆解开发与演示。GOLEM在人形模块之间提供公平比较，支持将其作为能力阶梯进行评估，即一次表征一个模块并将其添加为一级台阶：LiDAR-惯性导航将机器人定位在距6米目标13.0厘米以内；学习的站立控制器能够从基于采样的下肢MPC无法恢复的外部扰动中恢复；从真实现代Ioniq 5电池组抓取松动紧固件的成功率在系留状态下为97%，独立站立时为87%，在导航引起的位姿变化下降至37%。源代码可在项目页面 https://golem-humanoid.github.io 获取。

## Abstract
Disassembling end-of-life electric vehicle (EV) battery packs is dull and dangerous work, performed almost entirely by humans. We present GOLEM (Generalized Open Library of Embodied Modules), an end-to-end, open-source system architecture for EV battery disassembly with the Unitree H1-2 humanoid robot in which walking, manipulation, dynamic stability, navigation, and spatial memory are independent modules with abstract interfaces, so that methods are easily developed, interchanged, and compared. GOLEM is deployed as a Docker-based ROS 2 abstraction in which MuJoCo and IsaacLab digital twins expose interfaces matching the physical robot. GOLEM's composability and per-module customization enable development and demonstration of humanoid EV battery disassembly, from simulation to reality. GOLEM provides fair comparison between humanoid modules, enabling evaluation as a capability ladder, in which one module is characterized at a time and added as a rung: LiDAR-inertial navigation places the robot within 13.0cm of a 6m goal; a learned standing controller recovers from external disturbances that sampling-based lower-body MPC does not; and grasping loosened fasteners from a real Hyundai Ioniq 5 pack degrades from 97% tethered to 87% free-standing to 37% under navigation-induced pose variance. Source code is available at the project page https://golem-humanoid.github.io

## 6. 论文的主要结论与发现

1. **导航精度**：LiDAR惯性导航 + Nav2在6m目标距离上平均径向误差仅13.0cm（σ_x=6.83cm，σ_y=11.43cm），95%成功率——这是下游操作必须容忍的基座放置误差。
2. **控制策略对比**：学习型ALMI控制器在抗扰恢复方面显著优于采样型MPC——MJPC在扰动后单调失稳（CoM margin降至−0.166m）需人工急停，而ALMI在93%试验中恢复正CoM margin。
3. **抓取成功率三级递减（关键发现）**：真实Ioniq 5螺丝抓取从系留97%→站立87%→导航位姿变化后37%，**失败根源主要在于导航定位误差**（尤其远距离位姿超出机器人操作可达空间），而非抓取或拔除操作本身。
4. **视觉伺服（C-VS）是关键**：开环质心抓取在真实环境中完全失败（0%）——仿真低估了分割误差和标定误差；闭环视觉伺服（C-VS）恢复近完美性能。
5. **仿真与现实的巨大鸿沟**：仿真中基座摆动仅0.10mm，真实中达4.6mm RMS（≈46×差距）；接触丰富的任务（螺丝啮合）在仿真中不可信。
6. **GOLEM的架构价值**：模块化设计使失败可精确定位到具体组件（如"失败归于站立位姿而非抓取精度"），这对安全问责至关重要。

## 7. 优点

- **模块化架构设计优秀**：以标准化ROS 2接口解耦六大能力，真正做到即插即用，显著降低集成工程负担；仿真/硬件切换只需改DDS域，极大便利了开发迭代。
- **"能力阶梯"评估范式新颖**：每次只新增一个模块并量化其误差贡献，实现了组件级归因——这是大多数机器人系统评估所缺乏的。
- **开源性**：完整开源代码、硬件设计（MAGPIE手爪）和数字孪生，推动学术可复现性和社区协作。
- **方法公平对比**：所有控制器/抓取器通过同一接口在相同条件下部署，MMPC vs ALMI的对比尤具参考价值。
- **真实任务验证**：在真实商业EV电池组（Ioniq 5）上验证而非仅停留在仿真，且系统与现有RAPID拆解单元协同工作，具有实际工业意义。

## 8. 不足与局限

- **接触丰富任务的仿真预测力不足**：论文坦诚指出仿真无法复现螺丝啮合等接触交互的动态行为，导致仿真结果（如GGX在仿真中0%但在原理上可能有效）无法为真实部署提供可靠依据。仿真在这一关键任务上的价值存疑。

- **实验覆盖有限**：仅一个电池组型号（Ioniq 5）、单一操作（螺丝拔除，未含螺丝旋出）、单台机器人。缺少对不同电池组、不同操作类型（如切割、连接器断开）的泛化验证。
- **部分报告不够量化**：ALMI用于导航时的失败、厂商策略站立不稳等均仅定性描述；导航位姿分布采样仅6个位姿点（5次抓取），样本量偏小。
- **计算资源的透明度不足**：未报告训练/推理的具体GPU型号、数量、能耗，对可复现性和社区复现构成障碍。
