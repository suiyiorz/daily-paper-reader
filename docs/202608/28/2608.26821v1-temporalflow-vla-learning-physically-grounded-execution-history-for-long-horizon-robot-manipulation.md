## 摘要
视觉-语言-动作（VLA）模型利用预训练的视觉-语言表示进行机器人控制，但简单添加历史帧并不能可靠地捕捉近期的物理变化。这在多阶段操作中尤其成问题，因为视觉上相似的状态可能需要根据先前的执行采取不同的动作。为了应对这一挑战，我们提出了TemporalFlow-VLA，通过物理 grounded 的时间监督学习紧凑的执行历史。利用记录的机器人状态、机器人几何和标定相机，我们构建了机器人-表面时间流作为仅训练目标，并监督两个执行对齐的时间查询，为动作专家提供结构化的历史信息。几何监督路径在部署时不进行评估。TemporalFlow-VLA在LIBERO上实现了97.63 ± 0.26%的平均成功率，包括LIBERO Long上的96.60 ± 0.87%，以及在12个RoboTwin任务上Clean/Randomized成功率分别为85.5%/84.2%。在更长视野、多阶段操作中，它显示出相对于先前方法最明显的优势。受控的历史干预表明，动作预测依赖于历史内容和时间顺序。通过异步特征缓存，时间条件保持单帧级别的服务器端采样延迟，无需额外的历史编码开销。总体而言，TemporalFlow-VLA提供了一种紧凑、物理 grounded 的接口，用于利用有序执行历史，而无需在部署时进行显式运动估计或几何处理。

## Abstract
Vision-language-action (VLA) models leverage pretrained vision-language representations for robot control, yet simply adding historical frames does not reliably capture recent physical change. This is especially problematic in multi-stage manipulation, where visually similar states may require different actions depending on prior execution. To address this challenge, we present TemporalFlow-VLA, which learns compact execution history through physically grounded temporal supervision. Using recorded robot states, robot geometry, and calibrated cameras, we construct robot-surface temporal flow as a training-only target and supervise two execution-aligned temporal queries that provide structured history to the action expert. The geometric supervision path is not evaluated at deployment. TemporalFlow-VLA achieves 97.63 +/- 0.26% average success on LIBERO, including 96.60 +/- 0.87% on LIBERO Long, and 85.5%/84.2% Clean/Randomized success across 12 RoboTwin tasks. It shows its clearest advantage over prior methods on longer-horizon, multi-stage manipulation. Controlled history interventions show that action prediction depends on both historical content and temporal order. With asynchronous feature caching, temporal conditioning maintains single-frame-level server-side sampling latency without additional historical-encoding overhead. Overall, TemporalFlow-VLA provides a compact, physically grounded interface for exploiting ordered execution history without explicit motion estimation or geometric processing at deployment.

# TemporalFlow-VLA 论文详细中文总结

## 一、核心问题与研究动机

- **问题背景**：视觉-语言-动作（VLA）模型将预训练的视觉-语言表示迁移到机器人控制中表现出色，但大多数主流 VLA 在生成动作时主要依赖当前 RGB 观测、语言指令和机器人状态，缺乏对**近期执行历史（execution history）**的有效利用。
- **核心难题**：在多阶段（multi-stage）操作中，**视觉上相似的状态可能因不同的执行历史而需要不同动作**——例如，一次失败的抓取可能与抓取前的状态高度相似，相同的末端位姿可能对应接近、携带或恢复等不同阶段。仅简单叠加历史帧（multi-frame）无法可靠捕捉这种物理变化。
- **已有方法的不足**：
  - 多帧输入基线对历史帧的**时间顺序不敏感**（作者诊断实验显示：打乱历史帧顺序后离线动作损失几乎不变，而移除历史则损失增加约 4.6%）——说明历史信息虽有用，但原始帧的表示形式欠佳。
  - 现有外部记忆方法（如 TempoFit、MemER、MEM）侧重于组织或检索历史上下文，但未为潜在历史表示指定明确的物理目标。
  - 显式运动类方法（如 TraceVLA、MotionVLA、HiF-VLA、FlowVLA）在部署时仍需要运动估计或轨迹提示等额外计算和几何处理。
- **核心目标**：探索一种**紧凑、物理 grounded** 的执行历史表示方式，使策略在长时程、多阶段操作中能准确利用有序历史信息，同时不增加部署时的几何处理开销。

## 二、方法论

### 1. 核心思想

> 用物理 grounded 的运动作为训练监督，而非推理时的额外提示——历史信息被压缩为受监督的、与动作块对齐的时间查询（temporal queries），仅通过注意力机制暴露给动作专家。

### 2. 总体架构

- 在标准 π0.5（流匹配 VLA）基础上加入**并行时间通路**，保留原始当前观测动作生成路径。
- 输入：当前观测 `V0` + 语言指令 `L` + 机器人状态 `s` + 历史头戴相机观测（t-15、t-8 时刻的 RGB）。
- 两个可学习时间查询 `q8`、`q15` 追加到 prefix 序列，是动作专家**唯一能访问历史信息**的接口。

### 3. 关键技术细节

- **机器人表面时间流（Robot-Surface Temporal Flow）**：
  - 利用记录关节状态、URDF 几何、标定相机参数，离线生成训练标签。
  - 流程：对源时刻的图像可见机器人像素 → 通过正运动学反算到连杆坐标系 → 用目标时刻的正运动学变换 → 投影到目标图像 → 计算位移并经 224 归一化 → 聚合成 16×16×2 的流标签。
  - 可见性校验：目标投影须在界内、属于同一连杆、三维残差 ≤5mm，才保留对应关系。
  - 这是**训练专用标签**：无需手动流标注，部署时几何监督路径完全移除。
- **分层时间查询（Hierarchical Temporal Queries）**：
  - `q8`：表征 t-8 到 t 的近期运动，只可读语言、t-8 帧、当前帧和自身。
  - `q15`：表征 t-15 到 t 的完整演化，额外可读 t-15 帧和 `q8`，形成单向 `Q8 → Q15` 的层级抽象。
  - 通过**联合掩码注意力**，动作 token 仅能访问两个查询，不能直接访问历史图像 patch。
- **流重建解码器**：
  - 每个间隔使用独立的查询条件解码器（FiLM 调制 + 两层 MLP），对查询源的 VLM 空间特征进行调制并预测每个 patch 的流。
  - 损失仅在有效支持度（≥10% 可见机器人像素的 patch）上计算 Huber 损失。
- **最终损失**：`L = L_action + λ_temp · L_temp`，λ_temp=1.0。
- **异步历史特征缓存**：
  - 历史帧在机器人执行当前动作块期间异步编码（后台进程），存入时间戳特征缓存。
  - 重规划时直接检索缓存的历史特征，仅当前帧同步编码。
  - 延迟从 `3T_vision + T_joint + T_action` 降至约 `T_vision + T_joint + T_action`，保持单帧级采样延迟。

## 三、实验设计

### 1. 数据集 / 场景 / Benchmark

| Benchmark | 内容 | 特点 |
|---|---|---|
| **LIBERO** | Spatial / Object / Goal / Long 四套件 | 标准长时操作基准，含多阶段任务 |
| **RoboTwin 2.0** | 12 个双臂操作任务 | 强域随机化，按执行步数分组 H1/H2/H3 |
| **真机 AgiBot A3** | Three-Cup Stacking、Two-Bottle Packing | 三个阶段的物理操作任务，每任务 280 条演示 |

### 2. 对比方法

- LIBERO：π0.5、GR00T N1.7、CronusVLA、HAMLET、MotionVLA
- RoboTwin：π0、π0.5、X-VLA†、GigaWorld-Policy（后两者引用其他论文重评估结果）
- 消融：Multi-frame（原始历史帧）、2Q w/o Flow（无流监督的双查询）、Q8-only、Q15-only

### 3. 主要结果

- **LIBERO**：平均成功率 **97.63 ± 0.26%**（三种子），LIBERO Long 达 **96.60 ± 0.87%**，比最强 prior 平均高 2.1 个百分点。
- **RoboTwin 2.0**：**85.5% / 84.2%**（Clean/Randomized），比最强基线分别高 6.5（Clean，对 π0.5 79.0）和 8.0（Randomized，对 π0.5 72.3）个百分点。优势随任务时长增大而增强：H2 比 runner-up 高 5.5 点、H3 高 14.5 点，但 H1 并非最优。
- **真机**：Three-Cup Stacking 成功率 57.8%→77.8%（+20.0 点），Two-Bottle Packing 86.7%→97.8%（+11.1 点）。
- **推理效率**：异步缓存将平均采样延迟从 68.10ms 降至 62.78ms（每重规划节省 5.32ms），累计节省 79.8ms（7.8%）。

- **Batch size**：每 GPU 32。
- **训练步数**：LIBERO 联合训练 30k 步；RoboTwin 联合训练 60k 步（50 clean + 500 randomized 演示/任务）；真机任务各 60k 步。

- **部署**：几何标签生成管线完全移除，仅保留时间查询和动作生成计算；辅助流解码器不求值。文中未提及总训练时长（小时数）。

## 五、实验数量与充分性

### 数量

- 仿真评估：LIBERO 4 套件 + RoboTwin 12 任务（各 100-500 次 rollout、3 种随机种子）。
- 消融实验：2 个维度的系统消融——①历史内容/顺序扰动诊断（6 个 RoboTwin 任务）；②在线消融表（5 种变体 × 2 个条件，按 H1/H2/H3 分层报告）。

### 充分性评价

- **优点**：消融设计较细致（原始历史 vs 查询瓶颈 vs 流监督 vs 时间尺度分离），且将流监督与其他变量（查询数量、历史窗口）隔离，能较干净地分离贡献来源。
- **局限**：LIBERO 上各方法已接近饱和（97% 上下），差异幅度较小；RoboTwin 对比中 X-VLA† 和 GigaWorld 条目来自其他论文的表格，可能存在实验条件不完全对齐的问题；真机仅 2 个任务、且每任务 45 次试验总量偏小；历史扰动诊断是离线动作损失而非在线端到端成功率，文中也明确承认这一点。

## 六、主要结论与发现

1. **物理 grounded 的时间查询有效**：显式监督两个时间查询重建机器人表面时间流，比直接多帧 conditioning 显著提升长时、多阶段操作成功率。
2. **时序层次有价值**：Q8→Q15 的分层设计优于单独用任一查询，说明在近期摘要之上整合更长程上下文有互补效果。
3. **动作预测对历史内容与顺序均敏感**：受控扰动实验证明，正确的时间赋值是动作预测的必要条件，且模型对历史内容的完整性也很敏感（移除 vs 打乱各有代价）。
4. **部署开销可控**：异步特征缓存使历史条件化不增加同步编码负担，维持单帧级延迟。

## 七、优点与亮点

- **方法论新颖性**：将"机器人表面时间流"作为训练监督而非推理提示，这一设计在现有文献中具有差异化贡献，既获得了物理 grounded 的语义，又不引入部署时几何依赖。
- **信息瓶颈设计**：通过掩码注意力强制历史信息流经两个紧凑查询，压缩表示、降低过拟合风险，且避免了额外的跨注意力模块或历史专用残差门控。
- **层级时间抽象**：Q8/Q15 的设计将"近端细节 + 远端概述"的层次结构与动作块自然对齐，逻辑清晰。
- **异步缓存的工程落地**：将延迟优化从模型层面扩展到系统层面，贴近真机部署需求。
- **结论一致性**：性能优势随任务视野增长而增强（H1<H2<H3）的模式，与论文核心假设高度自洽，增强了结论可信度。
- **已公开工程实现细节**：给出注意力掩码矩阵的具体公式、监控覆盖率的定义（cρ(k)）、缓存一致性规则等，可复现性好。

## 八、不足与局限

1. **历史时间尺度固定**：仅使用 t-15 和 t-8 两个固定间隔，未系统研究最优历史深度/采样密度——作者在结论中亦承认此局限。
2. **LIBERO 上优势有限**：在饱和的 LIBERO 套件上，相对 HAMLET、GR00T N1.7 等优势较小（总体上甚至与 HAMLET 的 97.7% 基本持平），显著性说服力主要依赖 Long 套件的 2.1 点差异。
3. **H1 短时任务并非最优**：在 RoboTwin H=1 类别上，本文方法清洁设定下（84.0%）低于 GigaWorld（92.5%）和 X-VLA（90.3%），说明增加历史表示对简单任务可能引入不必要的复杂度或噪声。
4. **真实世界证据有限**：两个真机任务、45 次试验/方法/任务的规模偏小，且未报告方差或统计显著性检验。
5. **标签依赖**：时间流标签依赖 URDF 几何、关节状态和相机标定质量；对模型未知物体的操作、变形机器人、或标定误差大的场景，监督信号质量可能退化。
6. **训练开销**：20% 的额外训练时间在计算受限场景下可能成为采用障碍。
7. **与现有方法的对比公平性**：部分对比方法（如 X-VLA†、GigaWorld）的 RoboTwin 条目来自第三方报告，不同训练数据、随机种子和回合计数的差异性可能影响严格可比性。
