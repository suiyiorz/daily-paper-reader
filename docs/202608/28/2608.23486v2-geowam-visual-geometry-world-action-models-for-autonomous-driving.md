## 摘要
世界动作模型（WAMs）近来作为自动驾驶中联合建模场景演化与自我动作的框架而日益受到关注。现有的大多数WAMs在像素空间中学习场景动态，将用于未来观测预测的视频生成骨干网与用于自我轨迹预测的动作头相结合。然而，像素仅提供了这些动态的间接表示：它们将几何与运动同外观、纹理和光照纠缠在一起，迫使模型从二维观测中推断三维变换。我们认为，由点云表示的几何为驾驶提供了更自然的状态空间，因为它显式地捕捉了空间结构以及支配场景演化的刚性与非刚性变换，同时直接与执行驾驶动作的空间对齐。基于这一见解，我们提出了\textbf{GeoWAM}，一种用于自动驾驶的视觉几何世界动作模型。GeoWAM并非预测未来图像，而是被预训练以预测未来场景几何，从而产生联合编码空间结构与时间演化的表示。随后，一个几何条件动作头利用这些学习到的几何动态来预测未来的自我轨迹。广泛的开环与闭环评估表明，与基于图像的替代方法相比，视觉几何世界建模能产生显著更强的驾驶策略，从而确立未来几何预测作为自动驾驶的有效预训练目标。

## Abstract
World action models (WAMs) have recently gained increasing attention as a framework for jointly modeling scene evolution and ego actions in autonomous driving. Most existing WAMs learn scene dynamics in pixel space by combining a video-generation backbone for future-observation prediction with an action head for ego-trajectory prediction. Pixels, however, provide only an indirect representation of these dynamics: they entangle geometry and motion with appearance, texture, and illumination, forcing the model to infer three-dimensional transformations from two-dimensional observations. We argue that geometry, represented by point clouds, offers a more natural state space for driving because it explicitly captures spatial structure and the rigid and non-rigid transformations that govern scene evolution while directly aligning with the space in which driving actions are executed. Building on this insight, we introduce \textbf{GeoWAM}, a visual geometry world action model for autonomous driving. Rather than predicting future images, GeoWAM is pretrained to forecast future scene geometry, yielding representations that jointly encode spatial structure and temporal evolution. A geometry-conditioned action head then leverages these learned geometric dynamics to predict future ego trajectories. Extensive open-loop and closed-loop evaluations show that visual geometry world modeling yields substantially stronger driving policies than image-based alternatives, establishing future-geometry prediction as an effective pretraining objective for autonomous driving.

  - 像素空间与驾驶动作执行所依赖的三维坐标空间不对齐。
- **核心主张**：**几何（点云）**是驾驶的更自然状态空间——它显式编码三维空间结构与刚体/非刚体变换，且与规划动作处于同一三维坐标系。

## 2. 论文提出的方法论

### 2.1 核心思想

GeoWAM 不预测未来图像，而是**预训练预测未来场景的密集点图（point map）**，再通过**几何条件动作头**（geometry-conditioned action head）将学习到的几何动态转化为未来自我轨迹。训练分为两阶段：

### 2.2 阶段一：视觉几何世界模型预训练

- **多视图几何编码**：采用 DVGT-2 作为几何编码器，将 K 帧多视图历史图像编码为多层级历史记忆 Zₜ，包含几何 token X 和自车/位姿 token E。
- **未来几何解码**：
  - 使用可学习的未来几何查询（queries），加上时间/视角/二维位置嵌入；
  - 解码器内的注意力机制分两步：**因果时序自注意力**建模未来时间演化，**交叉注意力**从历史记忆中检索相关上下文；
  - 多层级输出通过共享的几何头（基于 Point DPT）解码为**稠密未来点图**（每个像素对应一个三维点）和逐像素置信度图。
- **监督信号**：使用特征级余弦距离损失（特征目标来自同一编码器的目标分支，带 stop-gradient）+ 稠密点图回归损失（包括欧氏距离回归、置信度感知回归、多尺度表面法向一致性）+ 当前帧点图锚定损失。

### 2.3 阶段二：GeoWAM 世界动作模型

- **逆动力学式设计**：先从预测的场景演化中推断未来自车运动，再将运动表示映射为轨迹。
- **未来自车 token 解码**：learned ego-query seeds 经过因果时序自注意力后，**交叉注意力同时关注历史记忆和预测的未来几何 token**（后者带 stop-gradient），以确保轨迹损失不回传重塑几何预测能力——这是一种单向连接，体现“运动从场景演化中推断”的设计哲学。
- **轨迹解码**：将历史自车 token 与预测的未来自车 token 拼接，经因果时序 transformer 精炼后，由轨迹查询交叉注意力聚合特征，回归头直接输出未来轨迹（无需轨迹锚点、模式分类或迭代采样）。
- **联合微调目标**：保留几何预训练损失 + 轨迹 ℓ1 回归损失 + 历史帧间相对位姿辅助损失。

## 7. 优点

- **问题视角新颖且动机充分**：清晰地论证了像素空间作为世界模型状态表示的局限性，提出几何是驾驶的“原生状态空间”，论点逻辑完整。
- **方法设计简洁优雅**：采用逆动力学式设计——从预测场景演化推断自车运动；stop-gradient 单向连接在几何预测与轨迹规划之间建立清晰的层次关系，保护预训练能力。
- **无需占用标注**：与 OccWorld 等占用世界模型不同，GeoWAM 无需地面真值占用标注，仅需 RGB 图像即可训练（点图目标来自现成几何基础模型）。

- **实验验证较全面**：从几何预测到开环规划到闭环评估，验证链条完整；navtest 对标大量最新方法，结果具有说服力。
- **实际部署潜力**：确定性轨迹解码器（无锚点、无采样）推理方式简单高效。

- **缺少消融实验**：未量化各设计选择（如 stop-gradient、特征级损失、点图损失、多层级特征）的独立贡献，削弱了方法设计的可解释性。
