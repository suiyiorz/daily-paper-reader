## 摘要
长时程机器人操作从根本上依赖于持久的空间记忆。然而，现有的三维记忆系统仅作为被动记录器：它们使用固定的、手工设计的规则存储观察结果，对每个场景元素——无论是关键抓取目标还是无关的背景墙——都给予同等的重视。在本文中，我们提出了一种从被动存储到主动的、任务驱动的空间记忆的范式转变。我们认为，机器人的记忆不应仅仅记录所见，而应主动学习如何记忆——发现哪些物体需要精确跟踪、如何激进地更新它们、以及丢弃什么，所有这些都以端到端方式学习，无需手工设计规则。关键在于，这一主动范式通过将记忆更新和读取统一为同一认知过程的两个方面来实现，使得任务需求塑造更新策略、反之亦然的双向流动成为可能。为了实例化这一愿景，我们引入了GaussMemory，它利用三维高斯泼溅作为持久的几何基板。在LIBERO上，GaussMemory在Goal和Long-10任务上优于MemoryVLA；在VLABench上，它超过π_0-FAST +5.2%（Track 1）和+6.0%（Track 6）。

## Abstract
Long-horizon robotic manipulation fundamentally relies on persistent spatial memory. However, existing 3D memory systems function merely as passive recorders: they store observations using fixed, hand-crafted rules, treating every scene element--whether a critical grasp target or an irrelevant background wall--with equal importance. In this paper, we propose a paradigm shift from passive storage to active, task-driven spatial memory. We argue that a robot's memory should not simply record what it sees, but actively learn how to remember--discovering which objects to track precisely, how aggressively to update them, and what to discard, all learned end-to-end without hand-designed rules. Crucially, this active paradigm is realized by unifying memory update and readout as two sides of the same cognitive process, enabling bidirectional flow where task needs shape update strategies and vice versa. To instantiate this vision, we introduce GaussMemory, which leverages 3D Gaussian Splatting as a persistent geometric substrate. On LIBERO, GaussMemory outperforms MemoryVLA on Goal and Long-10; on VLABench, it surpasses $π_0$-FAST by +5.2% (Track 1) and +6.0% (Track 6).

## 1. 核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型（如OpenVLA、π0）已成为机器人操作的主流范式，但**无记忆的VLA系统**仅能根据当前感官观测推断下一步动作，在长时程任务中面临根本性局限。
- **具体困境**：当物体被放入外表相同的抽屉并关闭后，当前RGB观测无法辨别正确抽屉；物体被遮挡、离开视野或经历中间子任务后，位置信息丢失。
- **现有方案不足**：
  - **2D记忆（MemoryVLA）**：感知-认知记忆库效果出色，但本质是2D，无法回答"盘子在杯子的哪个位置"等空间查询；
  - **语言记忆（SayPlan）**：文本描述牺牲了几何精度；
  - **3D结构记忆（ConceptGraphs）**：虽有显式几何，但依赖**手工设计的更新规则**（阈值匹配、固定速率平均、硬剪枝），与任务表现完全脱钩。
- **核心诊断**：所有现有系统都是**被动记录器**——用固定规则将所有场景元素同等对待，且记忆更新与读取被割裂为两个独立、不可微的阶段。
- **论文主张**：实现范式转变——从**被动存储**走向**主动、任务驱动的空间记忆**。记忆不应仅记录所见，而应**主动学习如何记忆**（跟踪什么、更新多激进、丢弃什么），并统一记忆更新与读取为同一认知过程的两个侧面，实现双向信息流动。

## 2. 方法论

### 2.1 核心思想
- **"主动记忆"范式**：记忆系统应学习如何记忆，评判标准只有一个——"这种记忆方式是否帮助机器人完成任务"。任务损失通过梯度直接塑造记忆行为。
- **更新-读取统一**：读取时对某物体的高注意力应回流偏置更新策略（更精确追踪该物体）；反过来，物体刚被移动的更新事件应告知读取端更信任其新位置——即"测试效应"（Testing Effect）的认知科学启发。

### 2.2 Temporal Gaussian Scene Memory（时间高斯场景记忆）
- **增强型高斯原语**：每个高斯携带标准3DGS属性（位置μ、协方差Σ、不透明度α、颜色c、球谐特征h）+ 时间元数据（创建/修改时间戳t_c/t_m、子任务索引τ、对象ID o、存在概率e）。
- **时间特征编码**：通过MLP编码器结合3D傅里叶位置编码PE_3D和相对时间编码PE_T(t−t_m)（使用对数间隔频率），支持长度泛化。
- **对象中心组织**：通过Gaussian Grouping + DINO特征将高斯按对象实例分组，形成对象级token。

### 2.3 Unified Memory Attention (UMA)——统一记忆注意力
- **核心机制**：观测token与任务条件读取查询拼接后，通过共享交叉注意力同时完成记忆读取（为动作预测提供上下文）和写入（产生更新信号），使整个记忆生命周期端到端可微分。
- **四阶段流程**：
  1. **构建统一查询**：观测token（Q_obs，由FF-3DGS生成M=8192个实时高斯后按对象池化为约20个token）+ 读取查询（Q_read，K=64个可学习token，经语言指令和子任务索引条件化）；
  2. **自注意力交换**：读取查询关注观测token（"高亮"任务相关物体），观测token将读取查询锚定在当前场景状态，产生上下文化统一查询；
  3. **交叉注意力**：统一查询查询高斯记忆库（键/值来自记忆高斯，最多32K），注意力权重含**时间相对偏置B_T**调制；
  4. **读写分流**：读取流Z_mem送LLM做动作预测；写入流利用观测行交叉注意力产生的软对应矩阵A_match驱动整个记忆生命周期。
- **记忆生命周期更新规则（文字描述）**：
  - **证据聚合**：对每个记忆条目k，汇总所有观测token的匹配强度w_k；
  - **位置估计**：通过注意力加权聚合观测3D位置得到μ_obs；
  - **学习更新门**：η_k = σ(MLP_η([注意力加权观测特征; 证据强度; 相对时间编码]))，位置按 μ_new = (1−η_k)·μ_mem + η_k·μ_obs更新；
  - **存在性管理**：存在概率e_k经证据强度对数更新，低于阈值θ_e=0.1的高斯被剪枝；
  - **新物体插入**：与所有记忆条目匹配度低的观测以学习概率p_new被插入记忆。
- **统一读写的关键优势**：共享自注意力使读取→写入耦合（更新偏向任务相关物体）和写入→读取耦合（LLM加权新旧信息）成为可能；梯度路径L_action → Z_mem → UMA → A_match, η_k, e_k使任务损失直接塑造记忆行为。

- **动作序列未建模**：3DGS记忆仅保存空间状态信息，对"物体移动轨迹的历史"（即物体如何到达当前位置）不敏感，而部分长时程任务需要理解"发生了什么"而非仅"在哪里"，这可能是Track 6成功率仍偏低（24.0%）的原因之一；
- **评估指标的单维度性**：主要报告成功率/进度分数，缺少对失败模式、任务内部分阶段错误率、记忆错误类型（误更新/漏更新/错误剪枝）的细粒度量化分析。

## 9. 总体评价与学术定位

- **整体判断**：这是一篇动机清晰、机制设计新颖、实验论证较扎实的工作。它将3D场景记忆从"手工几何规则驱动"提升至"任务损失驱动、端到端可学习"的层级，在方法论上具有开创性意义。尽管存在真实世界验证缺失等明显短板，但其所提出的**主动记忆范式**与**统一读写架构**，为后续VLA记忆研究提供了重要的概念框架与基线参照。
- **可复现性**：方法描述总体详尽（含公式级更新规则、损失项、训练配置、超参数表），且骨干网络与对比方法均采用公开实现，但多视图渲染、虚拟视角生成、Gaussian Grouping依赖的预处理管线未开源（论文未明确承诺开源计划），是复现的主要障碍。
- **理论贡献的延展性**："测试效应"（读取强化写入）与"更新门控"（写入强化读取）的统一，实际上指向了一个更一般的**记忆与推理协同优化**原则——这一思想不仅适用于机器人操作，也可迁移至具身导航、主动感知、开放世界持续学习等相邻领域。
