## 摘要
从现实世界数据中学习具身城市导航策略受到特定任务数据收集成本以及罕见但关键安全场景覆盖有限的制约。为应对这些挑战，我们提出了一个可扩展框架，用于从网络规模的野外自我中心视频中学习点目标城市导航，同时系统地暴露其长尾分布。该框架自动为未整理的网络视频标注度量轨迹和结构化导航语义，然后用于训练视觉-语言-动作策略，以实现可解释的导航规划。我们基于模型性能和感知-运动模式的分布来刻画长尾，并采用基于反思的分析来诊断重复出现的失败模式。在网络视频数据和真实城市导航任务上的实验表明，从无约束视频中实现了有效的知识迁移，并揭示了超越聚合导航性能的连贯长尾结构。

## Abstract
Learning embodied urban navigation policies from real-world data is constrained by the cost of task-specific data collection and the limited coverage of rare yet safety-critical scenarios. To address these challenges, we present a scalable framework for learning point-goal urban navigation from web-scale in-the-wild egocentric videos while systematically exposing its long tail. The framework automatically annotates uncurated web videos with metric trajectories and structured navigation semantics, which are then used to train a vision-language-action policy for interpretable navigation planning. We characterize the long tail based on model performance and the distribution of perception-motion patterns, and employ reflection-based analysis to diagnose recurring failure modes. Experiments on web-video data and real-world urban navigation tasks demonstrate effective knowledge transfer from unconstrained videos and reveal coherent long-tail structures beyond aggregate navigation performance.

## 2. 论文提出的方法论

### 2.1 核心思想

构建一个从网络规模的野外自我中心视频学习点目标城市导航的可扩展框架，包括**自动化数据标注管线**、**推理感知的 VLA（视觉-语言-动作）模型训练**与**基于反思的长尾刻画与失败归因**三个阶段。

### 2.2 关键技术细节

**① 数据采集与过滤**
- 收集约 500 小时的街道行走视频，覆盖 15 个国家 30 个城市。
- 使用视觉语言模型识别并过滤视频剪切、主体聚焦片段及门、楼梯、电梯等特殊事件，保留符合地面平面导航设定的片段。

**② 轨迹重建**
- 采用 LoGeR 长上下文几何重建框架，结合 Pi3X 视觉几何骨干，估计参考系无关的相机位姿与度量深度。
- 将重建的相机中心对齐到稳定的初始参考系并投影到地面平面，形成连续行走轨迹。
- 以 1 Hz 采样、按 10 帧（5 历史 + 5 未来）切分为导航片段，并通过时间块分组避免相邻片段跨数据划分造成泄露。

**③ 结构化导航推理标注**
- 使用 GroundingDINO 检测导航相关物体，将检测坐标与重建深度映射为类别、图像平面位置与深度标签。
- 使用 Qwen3.6VL-27B 作为教师 VLM，按照“感知–分析–规划”模式生成结构化导航推理链（CoT）：感知字段包含接地检测结果；分析字段描述场景演化、目标位置、可行区域、交互规则与碰撞风险；规划字段给出 meta-action 与轨迹的理由。
- **特权验证机制**：教师模型额外接收未来观测与规则推导的 meta-action，但仅用于验证和修正最终答案，不允许将未来信息写入感知、分析或规划字段，防止训练标注中的未来信息泄漏。

**④ WILD-Nav 模型结构**
- 基于 Qwen3.5VL-4B 视觉语言模型，视觉编码器冻结，融合时序观测、历史轨迹与点目标的文本表示。
- 引入特殊 `<PLAN_QUERY>` token，其最终隐藏状态经过动作专家模块解码为连续轨迹。
- 动作专家包含两个轻量输出头：meta-action 头为线性分类器：

$$\hat{a}_t = \text{softmax}(W_a h_q + b_a)$$

轨迹头为 4 层 MLP（3 层 512 维隐藏层 + GELU 激活）：

$$\hat{\tau}^{\text{plan}}_t = f_{\text{mlp}}(h_q)$$

- 两种推理变体：**WILD-Nav-inst**（直接由指令特征计算规划输出）与 **WILD-Nav-think**（先生成完整 CoT 推理再计算规划输出，规划 token 可关注完整推理文本）。

**⑤ 多任务监督损失**

$$\mathcal{L} = \lambda_{\text{cot}}\mathcal{L}_{\text{cot}} + \lambda_{\text{act}}\mathcal{L}_{\text{act}} + \lambda_{\text{traj}}\mathcal{L}_{\text{traj}}$$

- L_cot：自回归语言建模损失，监督结构化分析与规划推理；
- L_act：meta-action 交叉熵损失；
- L_traj：未来 5 个航点上的均方误差（MSE）损失。

**⑥ 长尾刻画与失败归因**
- 将每个片段表示为感知–运动联合模式 z，平均风险分解为 R(f) = Σ_z p(z) r_f(z)（p(z) 为模式出现概率，r_f(z) 为条件规划风险），从而区分低频但与高错误率相关的长尾样本。
- **罕见度**：对开放词汇物体描述进行词汇规范化，用平滑逆文档频率（IDF）计算联合感知–运动特征的罕见度分数。
- **难度**：用平均位移误差（ADE）与终点位移误差（FDE）衡量模型依赖难度，取各自 top 3% 的并集作为困难集。
- **特权反思**：仅对困难集使用教师 VLM，接收历史观测、模型输出、未来观测与参考轨迹，检查场景分析是否被历史观测支持、规划理由是否与目标一致、轨迹与 meta-action 是否一致，并输出结构化失败归因标签。
- 使用 SVD + UMAP + HDBSCAN 对困难样本聚类，将各簇与反思失败模式关联，揭示场景相关的失败结构。

## 6. 论文的主要结论与发现

- WILD-Nav 在视频测试集上全面优于 UrbanNav 与 SocialNav；其中 WILD-Nav-think 相比 WILD-Nav-inst 进一步降低 ADE 和 FDE，说明结构化 CoT 推理为连续航点生成提供了有效的上下文。
- 从视频直接迁移到真实世界存在显著领域差距（如 WILD-Nav-think 的 ADE 从 0.086 m 升至 0.619 m），微调后虽有明显改善（FDE 降至 0.127 m），但未完全消除差距。
- 长尾分布具有内部结构：困难样本中仅 24.18% 同时是罕见样本，说明"数据覆盖不足"与"模型系统性弱点"两类问题在很大程度上相互独立、需要分别处理。
- 失败模式是场景相关的：密集行人停止场景（C18）以规划与轨迹形状错误为主；踏板车–标识背景（C47）呈现规则与动作错误；交通标志场景（C60）放大规则违规；踏板车/骑行者交互（C105/C141）主要暴露预测与碰撞风险失败。
- 硬样本微调能有效降低固定尾部误差，但会损害整体性能；加入随机回放数据可实现最优权衡（测试集整体 ADE 0.093、尾部 ADE 0.217）。

## 7. 优点

- **数据规模化与自动化**：构建了完全自动化的标注管线（轨迹重建 + 接地检测 + 结构化 CoT 生成），无需人工标注即可从原始网络视频产出超过 50 万个训练样本。
- **数据地理多样性**：覆盖 30 城市、15 国，远超市面现有城市导航数据集，具备跨文化、跨场景的感知多样性。
- **可解释性设计**："感知–分析–规划"结构化推理与 meta-action 中间表示使得端到端规划具有一定可解释性，且特权验证机制有效防止了标注过程的未来信息泄漏。
- **长尾刻画方法论创新**：从"分布罕见度"和"模型依赖难度"双维度联合刻画长尾，不依赖预定义场景分类学；通过特权反思将失败归因到具体推理阶段，揭示了场景相关的失败结构。
- **数据增效结论实用**：证明了"硬样本微调 + 随机回放"的增量数据策略可同时改善尾部与整体性能，对实际数据采集与训练策略具有直接指导意义。

WILD-Nav 在数据规模化、自动标注与长尾失败分析三个方面做出了可观的贡献。其数据管线极具工程价值，能够在无人工干预条件下获得 50 万个带结构化推理的导航样本，为社区提供了一条低成本的算法学习路径。文中“罕见度 × 难度”联合刻画长尾的思路突破了传统基于场景分类学的人工先验，结合特权反思与聚类归因，使失败模式从“统计噪声”升华为“可理解的场景叙事”。尽管存在算力细节缺失、统计严谨性不足、教师模型偏好等局限，该工作仍为开放城市导航的端到端学习提供了新的视角和可行的技术路线，也为后续在数据增信、困难样本挖掘与可解释规划方面的研究奠定了坚实基础。
