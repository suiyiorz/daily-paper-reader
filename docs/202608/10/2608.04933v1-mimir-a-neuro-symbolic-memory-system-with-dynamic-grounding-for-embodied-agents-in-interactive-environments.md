## 摘要
长时程具身任务要求智能体在部分可观测条件下行动，同时保持场景信念和执行进度。扁平历史或隐式策略状态可能包含过去的观察，但它们没有为决定哪些世界事实支持当前活动目标提供显式接口。我们引入了Mimir，一种神经符号记忆，它将世界记忆与任务记忆分开，并在每次行动之前动态地将它们接地。世界记忆维护物体位置、物体状态和感知证据，而任务记忆维护有序的目标议程、进度状态、手部状态、失败和执行约束。一个接地模块将当前活动目标绑定到召回的世界候选项，填补缺失的源位置，并在规划和具身特定执行之前附加证据。在测试的各种骨干网络上，Mimir在不同的EB-ALFRED和EB-Habitat任务上持续改进，最大增益分别为42.5%和平均增益23.0%。与在同一骨干下评估的先前智能体和记忆系统中的最佳结果相比，Mimir将总体平均成功率提高了8.5%。最后，在EB-Habitat长时程子集上，Mimir达到了86.0%的成功率，大幅超越了当前的闭源模型。我们的代码将很快发布。

## Abstract
Long-horizon embodied task requires agents to act under partial observability while preserving both scene belief and execution progress. Flat histories or implicit policy states may contain past observations, but they do not provide an explicit interface for deciding which world facts support the currently active goal. We introduce Mimir, a neuro-symbolic memory that separates world memory from task memory and dynamically grounds them before each action. World memory maintains object locations, object states, and perceptual evidence, while task memory maintains an ordered goal agenda, progress state, hand state, failures, and execution constraints. A grounding module binds the active goal to recalled world candidates, fills missing source locations, and attaches evidence before planning and embodiment-specific execution. Across tested backbones, Mimir consistently improves on different EB-ALFRED and EB-Habitat tasks, with maximum gains of 42.5% and average gains of 23.0%, respectively. Compared with the best results among prior agent and memory systems evaluated under the same backbone, Mimir improves the overall average success rate by 8.5%. Finally, on the EB-Habitat Long-horizon subset, Mimir achieves 86.0% success rate, substantially outperforming current closed-source models. Our code will be released soon.

## 2. 论文提出的方法论

**核心思想**：

- 提出 **Mimir**，一种**神经符号记忆系统**，将记忆分为两个独立且可更新的部分，并在每次行动前进行**动态接地（Dynamic Grounding）**：

```
Mt = (Tt, Wt)
```

- **任务记忆（Task Memory）**记录执行进度，**世界记忆（World Memory）**记录当前场景信念。两者因证据来源不同而分离，并通过接地操作相互连接。

**关键技术细节：**

### 2.1 任务记忆（Task Memory）

任务记忆的形式化定义：

```
Tt = (G, ⪯, st, ht, Ft, Ct)
```

| 字段 | 含义 |
|---|---|
| G | 符号化目标集合 |
| ⪯ | 议程顺序（前置目标先于依赖目标，任务顺序作为确定性打破平局） |
| st | 目标状态映射（pending / completed / blocked） |
| ht | 当前手部状态（持物体状态） |
| Ft | 失败的物体–源假设集合 |
| Ct | 支持已完成目标的证据 |

- 活动目标由待处理目标集合中按议程顺序选取：`gt = min⪯ Pt`。
- 任务记忆更新依赖执行反馈 `yt = (σt, ∆t)`（行动结果 + 支持的物体关系/状态/手状态变化）。
- 目标完成条件采用**后置条件验证**：`st+1(gt) = completed ⇐⇒ Post(gt, ∆t) = 1`。行动成功（如导航到位、打开容器）不直接等于目标完成，而是要求反馈真正建立了对应后置条件。

### 2.2 世界记忆（World Memory）

世界记忆的形式化定义：

```
Wt = (Vt, Et, r, ℓt, ϕt)
```

- 实体集 Vt、父关系 Et、场景根 r、标签函数 ℓt、属性与证据存储 ϕt。
- 每个非根实体有唯一活动父节点（房间、支撑面、容器或手），不确定的替代项作为独立假设保留。
- **两个独立更新算子**：
  - 观测更新：`W⁺t = U_obs(Wt, ot)`，添加新实体或在身份与关系上下文一致时细化假设；
  - 行动更新：`Wt+1 = U_act(W⁺t, at, yt)`，仅写入由 ∆t 支持的关系/状态变化（如 pick 将物体关联到手）。

### 2.3 动态接地与执行闭环

- **目标条件召回**：`Rt = R(W⁺t, Q(gt))`，为活动目标检索有界数量的候选实体及其父位置、证据分数，生成紧凑的目标条件化世界视图。
- **接地操作** `Ĝ = G(gt, Rt, Ft, Ae, x, ot)`：
  - 移除违反行动约束、与显式源/目标矛盾、或已被失败记录反驳的候选；
  - 选择当前观测与召回证据支持度最高的候选；
  - **补齐缺失的源位置**（从选中实体的记忆父节点推断）并附加证据。
- **失败关闭（fail-closed）**：若无合格候选则返回 ⊥grd，不构造无依据的绑定。
- **执行适配**：规划器在体无关抽象动作空间生成 āt，再通过适配器 ρe 映射到具体具身动作，不合适则触发重规划或探索。
- **闭环推理完整算法**（Algorithm 1）：观测更新世界记忆 → 选取活动目标 → 召回 → 接地失败则探索；接地成功则规划并执行 → 反馈分别更新世界和任务记忆 → 循环直到所有目标完成或终止。

## 6. 论文的主要结论与发现

1. **一致性提升**：Mimir 在 12 个测试骨干上均显著提升 EB-ALFRED 与 EB-Habitat 的成功率与目标完成率，**最大单点提升 42.5 SR 点**（InternVL3-8B × EB-ALFRED）、**平均提升 23.0 SR 点**；GC 最大提升 42.6 点。
2. **弱骨干增幅更大**：基础能力弱的模型（如 InternVL3-8B、Gemma-3-12B）获得最大收益，说明**显式状态管理可补偿骨干容量不足**——InternVL3-8B 加 Mimir 后达到 60.5 SR，超过其 38B 和 78B 同类对照。
3. **超越现有记忆系统**：同骨干（Qwen2.5-VL-72B）比较下，Mimir 在 EB-ALFRED 上 SR 达 68.0（对比 RoboMemory 67.0），在 EB-Habitat 上 SR 达 90.0、GC 达 94.6（对比 RoboMemory 74.0/81.0），**平均成功率总体提高 8.5%**，EB-Habitat 的显著优势验证了世界记忆在位置/物体证据接地中的关键作用。
4. **超越闭源模型**：仅用开源 32B 骨干（Qwen3-VL-32B）+ Mimir，在 EB-Habitat Long-horizon 上达到 **86.0 SR / 93.0 GC**，超过最强闭源基线（Claude-Sonnet-4-6 的 82.0/86.8），分别高出 4.0 与 6.2 个百分点，表明**长时程表现更取决于任务–世界证据的组织方式而非单纯骨干规模**。
5. **记忆分工明确**：移除世界记忆在 EB-Habitat 上导致 SR 从 65.0/71.5 骤降至 12.5；移除任务记忆在 EB-ALFRED 上导致 SR 降低 23.0/37.5 点——**世界记忆提供目标实例化的空间证据，任务记忆维护有序进度与约束**。
6. **外部记忆优于内部推理**：加 Mimir 后 Instruct 模式全面优于 Thinking 模式（EB-ALFRED 68.0 vs 61.5 SR；EB-Habitat 71.5 vs 67.5 SR），说明任务进度与世界证据外部化后，内部额外推理不再提供额外优势。

## 7. 优点

### 8.2 方法层面的局限

- **对感知与 LLM 能力的依赖**：世界记忆的正确更新完全依赖观测解析的准确性。若多模态大模型在复杂视觉场景中产生错误实体识别或关系幻觉，错误会以“事实”形式写入世界记忆并持续影响后续接地决策。论文虽设计了失败关闭机制，但未深入分析**错误传播路径**及相应的自纠错能力。
- **单任务生命周期假设**：Mimir 的记忆结构是为单个长时程 episode 设计的，任务完成后记忆即重置。论文未讨论跨 episode 的经验积累、技能复用或语义知识的长期持久化问题，限制了其在持续学习场景中的适用性。
- **目标后置条件需人工先验**：任务记忆中的目标完成条件（后置条件验证）需要预定义符号规则。在开放式任务中，符号化后置条件的构建成本较高，且难以覆盖所有可能的完成方式。
- **未与多步规划器深度融合**：Mimir 的接地结果仅作为规划器的输入，规划本身仍依赖骨干模型的内隐推理能力。论文未探讨接地信息如何显式约束搜索空间或指导子目标分解，记忆系统与规划器之间仍是“松耦合”关系。

### 8.3 评测覆盖面有限

- **场景与任务类型局限**：评测集中于家居操作场景的四个任务类别，未涵盖移动导航中的动态障碍规避、多智能体协作、非刚体物体操作（如布料、液体）等更具挑战性的具身任务，结论外推需谨慎。
- **物理逼真度边界**：EB-Habitat 等仿真环境与真实世界在传感器噪声、执行不确定性、物体物理属性等方面仍有差距，Mimir 在真实机器人上的表现尚未验证。

## 9. 总结与个人评价

### 9.1 核心贡献评估

Mimir 的核心贡献不在于提出新的感知模型或规划算法，而在于**重新定义了具身智能体中“记忆”的语义角色**：从被动的信息仓库转变为主动的决策状态载体。其最有价值的洞见是——**将“世界知识”（场景现在是什么样）与“任务知识”（目标需要什么条件）显式分离，并在两者之间建立动态接地操作**。这一设计直击长时程具身操作的核心痛点：智能体往往“知道”足够多的信息，却无法在决策时刻迅速定位“哪条信息与当前目标最相关、最可信”。

### 9.2 方法论评价

- **形式化严谨度**：任务记忆与世界记忆的元组定义清晰，更新算子（观测更新 vs 行动更新）的分工体现了对感知不确定性与执行确定性的深刻理解，是本领域少见的形式化程度较高的记忆系统工作。
- **工程实现的可迁移性**：体无关抽象动作空间 + 适配器的设计使得 Mimir 可以较容易地嵌入不同具身系统，这一架构选择提升了方法的实用价值。
- **实验设计的标杆意义**：12 骨干 × 2 基准的评测矩阵、同骨干公平对比、闭源模型对标三重证据链，为后续记忆系统研究树立了实验规范。

### 9.3 展望与建议

未来研究可从以下方向深化 Mimir 的思路：

1. **引入置信度与记忆老化机制**：为世界记忆中的每个事实附加置信度分数并随时间衰减，结合重复观测的贝叶斯更新，增强对感知噪声的鲁棒性；
2. **跨 episode 记忆持久化**：将任务完成后的稳定世界知识抽象为长期语义记忆，支持零样本迁移到新任务；
3. **记忆驱动的规划反馈**：将接地结果中的证据链（如“杯子在柜子里”的推理依据）回传给规划器，用于冲突消解和替代路径生成；
4. **真实机器人验证**：在真实操作平台上评估记忆更新算子在执行噪声下的表现，补充 sim-to-real 的适配策略。

### 9.4 总体定位

总体而言，这是一篇**方法设计清晰、实验充分、结论可信**的高质量具身智能记忆系统论文。它用一个简洁而深刻的架构改进（世界记忆与任务记忆的动态接地）在多个骨干模型上取得了普遍且显著的性能提升，并提供了充分的消融证据支撑其设计决策。虽然存在算力披露不足、统计验证薄弱等瑕疵，但瑕不掩瑜，Mimir 提出的“以目标为中心、以证据为基础”的记忆组织原则，有望成为长时程具身操作任务中记忆系统设计的重要参考范式。
