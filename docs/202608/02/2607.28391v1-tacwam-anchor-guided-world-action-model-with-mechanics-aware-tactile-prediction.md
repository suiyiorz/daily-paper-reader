## 摘要
世界动作模型（WAM）将未来状态预测与机器人动作生成相结合，但现有方法主要依赖视觉未来状态。视觉预测能够捕捉场景结构和物体运动，但在接触丰富的操作任务中，对力、形变、剪切和滑移的监督信号有限。这引出了两个设计需求：触觉未来状态应携带有意义的物理信息，同时不应成为动作生成的privileged线索。我们提出TacWAM，一种基于力觉感知的触觉世界动作模型，通过三个步骤解决这一挑战。首先，空间对齐融合（SAF）触觉编码器将触觉外观、密集力场和形变流映射到共享的潜在预测空间，并通过双向力和力矩重建保留全局接触信息。其次，触觉历史编码器提供时间上下文，使未来触觉预测能够反映超越当前触觉观测的力和形变变化。第三，锚定引导三模态（AGT）注意力机制分离当前视觉与触觉锚点、未来预测令牌和动作令牌，使未来触觉状态能够监督训练，而动作分支无法直接读取。我们在四个真实世界的接触丰富操作任务上评估TacWAM，涵盖易碎物抓取、持续表面接触和动态手内操作。TacWAM平均成功率达到75.0%，比最强基线高出37.5个百分点。分阶段消融实验显示，移除触觉历史或放宽对未来预测目标的访问会导致性能持续下降。这些结果表明，结合信息丰富的触觉表示和部署一致性信息约束时，未来触觉监督能够改善接触感知的动作学习。

## Abstract
World Action Models (WAMs) combine future-state prediction with robot action generation, but existing approaches largely rely on visual futures. Visual prediction captures scene structure and object motion, yet provides limited supervision for force, deformation, shear, and slip during contact-rich manipulation. This creates two design requirements: tactile futures should carry meaningful physical information, and they should not become privileged cues for action generation. We present TacWAM, a mechanics-aware tactile WAM that addresses this challenge in three steps. First, a Spatially Aligned Fusion (SAF) Tactile Encoder maps tactile appearance, dense force fields, and deformation flow into a shared latent prediction space, with bilateral force and torque reconstruction preserving global contact information. Second, a tactile history encoder provides temporal context so future tactile prediction reflects how force and deformation change beyond the current tactile observation. Third, Anchor-Guided Tri-Modal (AGT) Attention separates current visual and tactile anchors, future prediction tokens, and action tokens, allowing future tactile states to supervise training without being directly read by the action branch. We evaluate TacWAM on four real-world contact-rich manipulation tasks covering fragile grasping, sustained surface contact, and dynamic in-hand manipulation. TacWAM achieves an average success rate of 75.0%, exceeding the strongest evaluated baseline by 37.5 percentage points. Staged ablations show consistent degradation when tactile history is removed and access to future prediction targets is relaxed. These results indicate that future tactile supervision can improve contact-aware action learning when combined with informative tactile representations and deployment-consistent information constraints.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 问题形式化

- 在时刻 *t*，机器人观测为：

  *oₜ* = (*oᵥₜ*, *oᵗᵃᶜₜ*, *qₜ*, *l*)

  其中 *oᵥₜ* 为视觉观测，*oᵗᵃᶜₜ* 为触觉观测，*qₜ* 为本体感觉，*l* 为任务/语言条件。
- 原始触觉读数通过 SAF 编码器映射为学习到的触觉表示：*zᵗᵃᶜₜ* = *E_SAF*(*oᵗᵃᶜₜ*)。

### 2.2 空间对齐融合（SAF）触觉编码器

- 输入三种空间对齐的触觉信号：
  - 校正后的触觉图像 *I_rect*
  - 密集局部力场 *F*
  - 网格形变流 *M_flow*
- 每个触觉传感器侧分别用对应分支（外观、力、形变）编码，再通过**双侧融合**结合两个传感器侧信息。
- 解码器 *R_tac* 从潜在表示中重建密集力场、网格形变流以及**双侧合力/力矩（global wrench）**，作为全局力学监督。
- 编码器为单帧结构，保证观测触觉状态和预测触觉状态共享同一潜在空间。

### 2.3 触觉历史编码器

- 单帧触觉信息存在歧义（相同力幅可能对应稳定接触、压力增大、滑移恢复或损伤风险等不同阶段）。
- 历史编码器 *E_hist* 将当前块之前的触觉潜在序列 *z*ₜ₀₋Tₕᵢₛₜ₊₁ : t₀ 汇总为紧凑的块级触觉上下文 *c*ᵗᵃᶜₜ₀。
- 该上下文通过**自适应归一化**调制触觉专家，而非作为额外记忆 token 插入。
- 附带轻量级接触事件辅助损失 *L_contact*，标注来自历史窗口中的二进制接触序列（接触开始、释放、稳定接触状态）。

### 2.4 锚点引导三模态注意力（AGT）

- 在块起始时刻 *t₀*，当前触觉状态作为干净锚点 *T₀* = *z*ᵗᵃᶜₜ₀；未来触觉序列为 *T₁:H*。
- Token 排列形式：[V₀, V₁:H | T₀, T₁:H | A]。
- AGT 可见性规则（表 1）：

| 查询流 | 允许的键/值流 |
|--------|----------------|
| 视觉 | V₀ 和 V₁:H（视频首帧因果掩码） |
| 触觉未来 | V₀、T₀ 和 T₁:H（触觉首帧因果掩码） |
| 动作 | V₀、T₀ 和动作 tokens |

- **核心约束**：动作 tokens 不能读取未来视觉或触觉预测 tokens；视频 tokens 不能读取 T₁:H；未来触觉 tokens 不读取动作 tokens。
- 目的：未来状态仅作为训练预测目标，动作生成只依赖部署可用信息。

### 2.5 训练与推理

- 两阶段训练：
  1. **触觉表示预训练**：优化 *L_SAF* = *λ_F L_F* + *λ_R L_wrench* + *λ_M L_flow*，学习 SAF 编码器和解码器，随后冻结。
  2. **联合生成训练**：优化复合损失 *L_TacWAM* = *λ_v L_video* + *λ_a L_action* + *λ_z L_tac-latent* + *λ_sem L_tac-decoded* + *λ_c L_contact*，使用流匹配目标；冻结但可微分的解码器将预测触觉状态解码为力场和扳矩，作为语义一致性正则化器。
- 推理阶段：以块为粒度闭环执行，模型从当前视觉/触觉锚点输出动作序列，执行后接收新观测再推断下一块。未来触觉预测可用于离线力/形变分析，但不作为在线修正信号。

## 6. 主要结论与发现

- **主结果**：TacWAM 在全部 4 个任务上优于所有基线，平均成功率 75.0%，超过最强基线（VT-WAM，37.5%）**37.5 个百分点**。单任务上比最强基线提升 10~40 个百分点。
- **分任务表现**：在白板擦拭和双笔旋转（最需持续接触和双侧接触推理的任务）上提升最大，分别提高了 40 和 30 个百分点。
- **消融结果**：
  - 移除触觉历史：平均成功率从 82.5% 降至 55.0%（−27.5 点），薯片抓取下降最明显（90% → 50%）。

  - 完全放开视觉-触觉双向交互：仅 7.5%，接近崩溃。
- **力预测质量**：TacWAM 预测的合力幅值时间趋势比 w/o History 更贴近地面真实；w/o History 在接触阶段转换时出现明显滞后，说明触觉历史有助于及时推断当前接触阶段。
