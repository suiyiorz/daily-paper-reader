## 摘要
在不确定环境中确保可靠性对于长时程机器人操作仍然困难。端到端的VLA模型数据需求大且不透明，使得诊断和验证困难。分层流程更具可解释性，但它们的计划往往弱依赖于观察，与低级动作对齐较弱，并且没有在线反馈计算，导致开环行为和幻觉。为了解决这些问题，我们引入了Triplet-to-Track系统（TTS），一种闭环的长时程模仿学习系统，利用人类视频减少对机器人采集数据的依赖。TTS将高级子目标表示为实例锚定的三元组，将它们转换为用于执行的连续轨道先验，并从观察中监控任务进度以进行在线重规划。在多样化的真实世界长时程任务中，TTS实现了74.8%的平均成功率，并支持对象级和组合泛化。

## Abstract
Ensuring reliability in uncertain environments remains difficult for long-horizon robotic manipulation. End-to-end VLA models are data-heavy and opaque, making diagnosis and verification difficult. Hierarchical pipelines are more interpretable, but their plans are often weakly grounded in observations, weakly aligned with low-level actions, and computed without online feedback, leading to open-loop behavior and hallucinations. To address these issues, we introduce the Triplet-to-Track System (TTS), a closed-loop long-horizon imitation learning system that uses human videos to reduce reliance on robot-collected data. TTS represents high-level subgoals as instance-grounded triplets, translates them into continuous track priors for execution, and monitors task progress from observations for online replanning. Across diverse real-world long-horizon tasks, TTS achieves a 74.8\% average success rate and supports object-level and compositional generalization.

- **核心问题**：长时程机器人操作在真实不确定环境中的可靠性。任务目标往往只在初始观测中部分指定，需要在长时间交互中通过中间步骤逐步验证和完成。
- **现有方法缺陷**：
  - **端到端 VLA 模型**：数据需求大、推理过程不透明，难以诊断和验证，且在多步长任务中数据采集成本高昂。
  - **分层管线**：更可解释，但高层计划常与具体观测弱关联（缺乏实例级空间约束），与低级动作接口不匹配，且缺少在线反馈，导致开环行为和规划幻觉（如虚构物体、错误关系）。
- **解决思路**：提出 **Triplet-to-Track System (TTS)**，一种闭环、层次化、利用人类视频的模仿学习系统，通过“实例锚定的三元组”进行高层规划，通过“连续点轨迹”作为底层执行先验，同时在线监控任务进度并重新规划，以提高可靠性、可解释性和数据效率。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **整体架构**：TTS 组织为三层：**Task Planner**（任务规划器）、**Track Predictor**（轨迹预测器）、**Action Policy**（动作策略），形成闭环执行。
- **高层表示——三元组空间**：`c = (x, r, y)`，其中 x 和 y 为具体物体实例，r 为关系谓词（如 on、over、grasped）。该表示与具体物体实例和空间关系绑定，可直接从图像观测验证，减少了幻觉。`hold(ot, c)` 判断当前场景是否满足关系。
- **低层表示——轨迹空间**：实体对齐的连续点轨迹（如 DINO/SAM2 特征）作为运动先验，可被底层策略消费，并可在动作无关视频上预训练，降低对机器人标注数据的依赖。
- **任务规划器细节**：
  - **关系预测器**：由轻量 Transformer 预测器（LTP）和 LoRA 微调的 VLM 验证器组成。LTP 使用 SAM2 解码器的实例 token 预测有序物体对关系；VLM 作为高精度验证器，仅在检测到关系变化时被触发（事件触发），以减少抖动和计算开销。两者级联可实现高召回 + 高精度。
  - **图保护的下一三元组生成器**：从人类视频中自动构建时序图 `G=(V,E)`，节点为任务相关三元组，边为观测到的可行变换。推理时用邻接矩阵行作为掩码，让 VLM 在候选集中选择下一个子目标，抑制幻觉和非法转换。
  - **闭环守卫**：在每个步骤检查当前子目标是否达成，若守卫失败则重新定位到初始节点并重新规划。
- **轨迹预测器**：
  - 将三元组变迁 `(x,r,y)→(x,r',y)` 编码为条件信号，结合视觉观测、实例掩码、当前点位置，预测下一时刻的点位置，实现从离散三元组到连续轨迹的转换。
  - 采用多模态掩码预测（类似 ATM），并加入两个辅助目标：掩码 patch 重建和关系变化识别。
- **动作策略**：
  - 使用 Transformer 骨干 + 可学习动作 token，结合观测特征、三元组条件、轨迹先验，回归末端执行器位姿和夹爪宽度。
  - 采用滚动时域（receding-horizon）推理：每 5 步检查一次子目标是否完成，未完成则继续，已完成则切换下一子目标。
- **形式化规则**（见论文）：`ck+1 = VLM(...) if Gk=1 else c0`，表示若所有守卫成立则生成下一子目标，否则重新规划。

### 3. 实验设计：数据集 / 场景、Benchmark 和对比方法

- **任务与场景**（真实世界，7-DoF Franka 机器人，两个 RealSense D435i 相机）：
  - **Dynamic Scale Balancing (DSB)**：动态天平平衡，测试在线重规划和闭环决策。
  - **Sequential Stacking (SS)**：顺序堆叠，测试多步逻辑排序和泛化到未见顺序。
  - **Diverse Pick-and-Place (DPP)**：多样化拾取放置，测试目标理解和物体级泛化（包括跨类别泛化）。
- **数据**：每个任务采集 30 条机器人示范和 50 条人类视频，仅少量标注（每个任务仅需 5 条轨迹标注用于关系预测器训练）。
- **基线方法**：
  - **FT-Pi0.5**：端到端 VLA 模型（微调）。
  - **SeeDo**：VLM 生成 QA 式文本计划 + 代码即策略。
  - **PALO**：VLM 在语义空间中递归分解任务。
- **评估设置**：每个任务分 Seen / Unseen / Perturbed 等条件，覆盖物体级泛化、组合泛化、扰动鲁棒性。任务最长包含 9–12 个子目标。
- **主要结果**：TTS 平均成功率 74.8%，显著优于最佳基线 SeeDo 的 30.4%。在扰动条件下 TTS 仍保持 60%–80% 成功率，而基线多为 0%。

- **架构合理**：将高层离散规划与低层连续控制解耦，避免端到端模型的不透明性，同时避免了纯分层方法的接口不匹配。
