## 摘要
四足移动操作需要两种紧密耦合的能力：达到可操作的构型，以及在关节物体交互过程中保持稳定接触。然而，现有方法通常在目标附近终止导航，导致可达性与操作就绪性之间存在差距，同时跟踪滞后、运动抖动和接触不稳定限制了连续交互。为解决这些挑战，我们提出了TONAV，一个将任务导向导航与动作-速度块学习相结合的统一框架。首先，我们引入了一个位置-速度耦合的遥操作框架，显式捕获运动动力学以提高主从一致性，并收集平滑、时间上一致的演示。接着，任务导向导航利用视觉-语言推理将高级指令分解为可执行的子目标，并自适应地调整机器人基座朝向操作就绪配置。最后，动作-速度块学习在速度监督下联合建模关节位置及其时间转换，实现平滑且稳定的持续接触操作。在多样化的关节物体任务上的真实世界实验表明，TONAV在任务导向导航和完整移动操作方面均取得了更高的成功率，缓解了导航-操作差距并改善了持续接触交互。项目页面位于https://haochen611.github.io/TONAV。

## Abstract
Quadruped mobile manipulation requires two tightly coupled capabilities: reaching manipulation-ready configurations and maintaining stable contact throughout articulated-object interaction. However, existing methods often terminate navigation near the target, leaving a gap between reachability and manipulation readiness, while tracking lag, motion jitter, and contact instability limit continuous interaction. To address these challenges, we present TONAV, a unified framework integrating task-oriented navigation with action-velocity chunk learning. First, we introduce a position-velocity-coupled teleoperation framework that explicitly captures motion dynamics to improve master-follower consistency and collect smooth, temporally consistent demonstrations. Next, task-oriented navigation leverages vision-language reasoning to decompose high-level instructions into executable subgoals and adaptively refine the robot base toward a manipulation-ready configuration. Finally, action-velocity chunk learning jointly models joint positions and their temporal transitions under velocity supervision, enabling smooth and stable sustained-contact manipulation. Real-world experiments across diverse articulated-object tasks demonstrate that TONAV achieves higher success rates in both task-oriented navigation and complete mobile manipulation, mitigating the navigation-manipulation gap and improving continuous-contact interaction. The project page is at https://haochen611.github.io/TONAV.

## 1. 核心问题与整体含义（研究动机和背景）

- 四足移动操作需要两个紧密耦合的能力：一是使机器人基座达到“操作就绪”的构型，二是在与铰接物体（关节物体）交互过程中保持稳定持续接触。
- 现有方法主要存在两个不足：
  - **导航与操作之间存在间隙**：传统目标导航往往在目标附近 1–2 米处终止，难以保证操作臂可到达且姿态合适；
  - **持续接触操作不稳定**：现有动作块（action chunk）策略多以关节位置为主，没有显式建模速度，导致跟踪延迟、运动抖动、接触不稳定。
- 论文针对这两个挑战提出 **TONAV**（Task-Oriented Navigation and Action-Velocity Chunk Learning）统一框架，旨在弥合“导航终点”与“操作就绪位形”之间的鸿沟，并提升对铰接物体持续接触操作的光滑性和稳定性。

## 2. 论文提出的方法论

### 核心思想

TONAV 将任务导向导航与动作-速度块学习集成在一个框架中：
- 导航侧：通过视觉-语言推理将高层指令分解为可执行子目标，并自适应细化机器人基座位姿；
- 操作侧：通过位置-速度耦合遥操作采集高质量演示，再使用动作-速度块策略联合预测关节位置与速度。

### 关键技术细节

1. **位置-速度耦合遥操作框架（AVTF）**
   - 传统遥操作只传送主臂关节位置；AVTF 同时传送关节位置和关节速度参考。
   - 主臂关节速度通过后向差分估计并限幅：
     - 速度估计：`q_dot = (q_t - q_{t-1}) / Δt`
     - 限幅：`clip(q_dot, -q_dot_max, q_dot_max)`
   - 从臂采用阻抗控制：
     - `τ = Kp (q_m - q_f) + Kd (q_dot_m_ref - q_dot_f) + τ_ff`
   - 控制环与记录环分离，记录每个演示帧 `D_k = {o_k, q_f_k, q_m_k, q_dot_m_k}`，保证演示数据时间一致性。

2. **感知-规划思维链（PP-CoT）**
   - 两阶段 MLLM 推理：
     - 任务条件感知：从全局图像和指令中提取目标、候选地标和可通行区域；
     - 感知引导的路线规划：将感知结果转化为以地标为基础的导航子指令。
   - 公式表达：`P = fθ(I, T; p_per)`，`Y = fθ(I, T, P; p_plan)`。

3. **自适应接近模块（AAM）**
   - 使用开放词汇检测器定位目标，并用 SAM2 分割、传播掩码，计算中值点并反投影为 3D 点。
   - 使用基于自身运动的卡尔曼滤波器补偿异步感知延迟，将历史时刻的观测转换到当前相机坐标系。
   - 根据水平对齐误差和站立距离误差进行混合控制：对齐误差调节转向，距离误差调节前进，最终停在操作工作空间内的安全距离。

4. **动作-速度块学习（Action-Velocity Chunk Policy）**
   - 在 ACT 风格 CVAE 中，解码器并行输出位置块 `q_hat` 和速度块 `q_dot_hat`。
   - 损失函数包含四项：
     - `L_pos`：位置模仿损失（L1）
     - `L_vel`：速度监督损失（L1）
     - `L_con`：位置变化与速度的一致性约束，显式规范化块内运动演化
     - `L_KL`：CVAE 隐空间正则化
   - 总损失：`L = L_pos + λv L_vel + λc L_con + β L_KL`。

- **统一框架**：把遥操作数据采集、任务分解、自适应接近、动作块学习整合成一个端到端可学习的流程。
- **遥操作方案实用**：位置-速度耦合可显著降低主从跟踪延迟，提升演示质量，且实现简单、不依赖昂贵硬件。

## 9. 总体评价

- TONAV 的核心贡献在于将“任务导向导航”和“动作-速度块学习”统一到同一个移动操作框架中，既解决了导航终点与操作就绪位形之间的语义鸿沟，又通过显式速度建模改善了持续接触操作的运动平滑性和稳定性。
- 从工程实现角度看，论文的模块划分清晰、真实平台验证完整，尤其是位置-速度耦合遥操作方案简单实用，具有较好的可复现性。
- 从学术贡献角度看，该工作属于“真实系统 + 模块化融合”类型，创新点明确，实验方向全面，但受限于实验规模和场景广度，当前结论更多是“可行性验证”而非“通用性证明”。
- 论文仍存在对 MLLM 推理能力较强依赖、端到端错误传播评估不完整、损失项消融不彻底等问题，距离大规模实际应用还有明显距离。

## 10. 未来研究方向

- 扩大真实世界任务种类和场景布局，增加每项任务的测试次数，并引入统计显著性检验以增强结论可信度。
- 探索轻量化视觉-语言模型或使用蒸馏/量化手段降低推理时延，缓解 PP-CoT 在实时导航中的延迟瓶颈。
- 将位置-速度联合预测思想推广到扩散策略、强化学习等其他操作策略中，进一步验证其通用性。
- 在操作过程中引入在线视觉反馈闭环校正，使机器人能在接触偏移、物体滑动等意外情况下自适应调整基座姿态和操作力。
- 在仿真环境中构建大规模基线测试集，系统评估导航误差传播、感知噪声和动态障碍物对完整任务成功率的影响。
