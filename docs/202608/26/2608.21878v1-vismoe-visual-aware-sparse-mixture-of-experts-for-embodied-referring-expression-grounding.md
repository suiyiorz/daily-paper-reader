## 摘要
具身指代表达式定位是一项任务，旨在使智能体能够在真实环境中导航，并根据自然语言指令定位远处的目标物体。在此场景中，智能体需要在每一步选择一个视图进行导航，并在目的地从所有候选对象中识别出特定对象。然而，以往的大多数方法未能区分视图和对象，而是使用普通的视觉编码器处理它们，导致视图和对象的表示模糊不清。为解决上述问题，我们提出了ViSMoE，它为具身智能体配备了一种视觉感知路由策略的稀疏混合专家模型。该框架专门处理不同类型的视觉信息，从而为视图和对象产生有区分度的视觉表示。在REVERIE和SOON数据集上的实验结果表明，ViSMoE超越了先前最先进的方法，展示了我们提出的方法的优越性。

## Abstract
Embodied Referring Expression Grounding is the task of enabling an agent to navigate in real environments and to localize a remote object based on natural language instructions. In this scenario, the agent needs to select one view for navigation at each step and identify a specific object among all candidate objects at the destination. However, most of the previous approaches fail to distinguish between views and objects, instead processing them using the vanilla vision encoder, which results in ambiguous representations of both views and objects. To address the above issues, we propose ViSMoE, which equips sparse Mixture-of-Experts with a visual-aware routing policy for the embodied agent. This framework processes different types of visual information specifically, resulting in discriminative visual representations for both views and objects. Experimental results on REVERIE and SOON datasets demonstrate that ViSMoE outperforms the previous state-of-the-art methods, showing the superiority of our proposed method.

## 1. 论文的核心问题与整体含义（研究动机和背景）

具身指代表达式定位（Embodied Referring Expression Grounding）要求智能体在真实室内环境中，依据高层自然语言指令完成两件事：一是逐步导航至目标物体所在的远端位置；二是在目的地从候选物体中准确识别出指令所指的目标物体。该任务同时涉及语言引导导航与指代表达式定位两个子问题，是视觉-语言导航（VLN）领域中更具挑战性的目标导向型任务，对应 REVERIE 和 SOON 两个数据集。

现有方法（如 DUET）通常将离散视图（discrete views）和候选物体（candidate objects）直接拼接后，输入同一个普通的视觉编码器进行处理。然而，论文指出这两类视觉信息存在本质差异：

- 离散视图提供房间布局、空间关系等全局场景信息，服务于导航决策；
- 候选物体提供场景中具体物品的细节信息，服务于物体定位。

两者不仅数据分布不同，而且分别对应不同的子任务。使用统一编码器处理会混淆两类输入，导致视图和物体的表示都缺乏判别性，最终影响导航和定位性能。因此，论文的核心动机是：设计一种能够区分并专门处理不同视觉输入的建模框架，以提升具身智能体对异构视觉信息的表征能力。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想

论文提出 ViSMoE（Visual-aware Sparse Mixture-of-Experts），将稀疏混合专家机制引入视觉编码环节，通过视觉感知路由策略，使不同的专家分别专门处理视图和物体两类视觉输入，从而获得更有区分度的视觉表示。

### 关键技术细节

1. **基础模型框架**：基于 DUET 的 dual-scale（局部-全局）推理架构，包含语言编码器、视觉编码器、全景编码器和双尺度跨模态编码器。离散视图和候选物体分别加入相对角度特征、边界框特征和导航类型嵌入后，经过全景编码器与跨模态编码器得到上下文表示。

2. **稀疏混合专家（SMoE）替换 FFN**：在视觉编码器的 FFN 层中引入 SMoE 层。给定输入 token x，路由器 G(·) 计算分配给 N 个专家的概率，选择 top-k 个专家进行加权求和：

   - G(x) = top-k(softmax(Wg · x))
   - 输出 = Σ_{i=1}^{k} G(x)_i · FFN_i(x)

3. **视觉感知路由策略（Visual-Aware Routing）**：这是论文的核心贡献。与标准 SMoE 不同，ViSMoE 在路由网络输入中显式加入视觉类型嵌入（type embedding），使路由器能够感知当前 token 是视图还是物体：

   - G(x) = top-k(softmax(Wg · (x + b_t)))
   - 其中 b_t 为可学习的类型嵌入：视图用 b_v，物体用 b_o。

   这样，路由网络可以依据“输入 token 本身”和“其视觉类型”共同决定激活哪些专家，从而实现视图和物体分别由不同的专家子集处理。

4. **辅助负载均衡损失（Auxiliary Loss）**：为避免路由失衡，引入 Load-Balancing Loss，公式为：

   - L_Aux = α · N · Σ_{i=1}^{N} p_i × f_i

   其中 α = 0.001，p_i 为第 i 个专家的平均路由权重，f_i 为分配给第 i 个专家的 token 比例。

5. **训练流程**：
   - 预训练：使用掩码语言建模（MLM）、掩码区域分类（MRC）、单步动作预测（SAP）和物体定位（OG）四个任务联合优化；
   - 微调：使用 DAgger 算法训练导航策略，加上 SAP、OG 和辅助损失共同优化。

整体上，ViSMoE 在预训练和微调阶段均将前馈网络替换为视觉感知 SMoE，使模型从训练一开始就能针对视图和物体学习差异化的专家分配模式。

## 3. 实验设计：数据集、基准与对比方法

### 数据集与基准

### 评估指标

### 对比方法

- REVERIE：CKR、SIA、HAMT、TD-STP、FDA、DUET；
- SOON：GBE、KERM、GridMM、DUET。

### 主要结果
