## 摘要
从原始像素导航大型、逼真的3D公寓通常被认为对于纯强化学习是不可行的。我们构建了一个能够做到这一点的智能体，仅从相机估计自身的位姿。该智能体必须依次到达多个目标物体，并且它们的位置在不同回合之间会变化，因此它必须进行探索以找到它们。它基于我们早期的以物体为中心的拓扑控制器，该控制器仍然从模拟器中读取智能体的真实位姿及其物体检测。在这里，我们用一种机载的、以物体为中心的估计来替代真实位姿。对于每个物体，我们保留一个ORB特征库，当再次看到该物体时，会产生一个粗略的位姿测量，一个最小扩展卡尔曼滤波器（EKF）将其与运动模型融合。如同在真实机器人上一样，执行的运动是有噪声的。估计会漂移，但智能体和附近的物体会一起漂移，因此局部一致的位姿足以跟随每个短边，然后在视觉上锁定目标，这使我们能够用更小的模型替代完整的SLAM，更接近生物导航的工作方式。在逼真的Habitat模拟器中，智能体仅凭视觉就能到达目标物体，其位姿只需局部一致即可。

## Abstract
Navigating large, photorealistic 3D apartments from raw pixels is widely considered infeasible for plain reinforcement learning. We build an agent that does it anyway, estimating its own pose from the camera alone. The agent has to reach several target objects in sequence, and their positions change between episodes, so it must explore to find them. It builds on our earlier object-centric topological controller, which still read the agent's true pose and its object detections from the simulator. Here we replace that true pose with an onboard, object-centric estimate. For each object we keep a bank of ORB features that, when the object is seen again, yield a rough pose measurement, which a minimal Extended Kalman Filter (EKF) fuses with a motion model. As on a real robot, the executed motions are noisy. The estimate drifts, but the agent and the nearby objects drift together, so a locally consistent pose is enough to follow each short edge and then home in visually on the target, which lets us replace full SLAM with a much smaller model, closer to how biological navigation appears to work. In the photorealistic Habitat simulator, the agent reaches its target objects from vision alone, with a pose that only needs to be locally consistent.

## 1. 核心问题与整体含义（研究动机与背景）

- **基本问题**：在大型、逼真的 3D 室内场景中，从原始像素出发进行纯强化学习（RL）导航通常被认为是不可行的。本文研究的是在**没有真实位姿（ground-truth pose）**的情况下，智能体能否仅凭视觉完成多目标顺序导航任务。
- **此前工作的缺陷**：作者在之前的工作中构建了基于对象中心拓扑地图的宏动作导航系统，能够在大型场景中成功导航，但该系统严重依赖模拟器提供的**真实位姿信息**（位置和朝向），这在真实机器人上是不现实的。
- **核心研究问题**：将真实位姿替换为**有噪声的、仅局部一致的位姿估计**后，原有的宏动作拓扑导航框架是否依然奏效？
- **生物启发**：人类和动物导航并不依赖全局精确的度量地图，而是依托地标和粗略的拓扑关系，仅需局部一致的位姿即可做出正确的转向和前进决策。本文以此为主要动机，尝试用更轻量的模型替代完整的 SLAM 系统。

## 2. 方法论：核心思想、关键技术细节

### 2.1 整体架构：两层设计

系统分为两个层次（如图 1 所示）：

- **决策层（继承自此前工作）**：一个基于对象中心宏动作的 DQN（Deep Q-Network）。它将导航任务分解为一系列"前往某个已知对象"的语义决策。智能体每次选择一个已存入地图的对象作为目标（宏动作），一个宏动作直到执行 `Found` 动作才结束。
- **导航与定位层（本文新增核心）**：将选定的对象转化为实际运动。包含拓扑地图上的最短路径规划、低层控制器（前进/转向），以及新加入的**定位栈**。

### 2.2 拓扑地图表示

- 地图是带权无向图 $G_t = (V_t, E_t)$，其中节点 $V_t = B_t \cup O_t$：
  - **骨干节点（Backbone nodes）**：智能体实际访问过的位姿点，作为内部导航航路点。
  - **对象节点（Object nodes）**：语义对象的表示，存储对象 ID、估计 3D 位置和图像补丁，是 DQN 可选用的宏动作。
- 地图在回合开始时为空，智能体需要**在线探索构建地图**，并在地图增长的同时进行导航。

### 2.3 DQN 架构

- 采用 DRRN（Deep Reinforcement Relevance Network）风格的**逐对象 Q 值评估**：$Q_\theta(F_v, g_t)$，其中 $F_v$ 是对象的图像补丁，$g_t$ 是任务进度 one-hot 向量。
- 由于地图动态增长，动作集不固定，无法用经典 DQN 的输出层直接表示。该网络对每个已知对象分别计算 Q 值，使用 Boltzmann 策略进行探索。

### 2.4 定位栈（本文核心贡献）

定位栈由三部分组成：

**（1）ORB 对象特征库（Landmark Bank）**
- 对语义掩码内的像素提取 ORB 特征（仅在对象掩码内部检测，确保特征与对象一一对应）。
- 首次看到某特征时，将其描述子与反投影得到的 3D 锚点（anchor）一起存储。
- 对象再次出现时，当前帧特征与库中锚点匹配。

**（2）Kabsch 位姿测量**
- 匹配的特征对给出两组地面平面点：当前观测点 $p_i$（智能体坐标系下的反投影）和存储锚点 $q_i$（地图坐标）。
- 通过加权 Kabsch 算法求解 SE(2) 刚体变换（2D 平移 + 绕竖直轴旋转），得到位姿测量值。
- 权重 $w_i$ 与逆距离成正比，避免远距离（更嘈杂）的锚点影响过大。
- 关键公式：旋转矩阵由加权互协方差矩阵 $C = \sum_i w_i (p_i-\bar{p})(q_i-\bar{q})^\top = USV^\top$ 的 SVD 分解得到，$R = V\operatorname{diag}(1, \det(VU^\top))U^\top$，平移 $t = \bar{q} - R\bar{p}$。

**（3）扩展卡尔曼滤波器（EKF）**
- 状态为 SE(2) 位姿 $s_t = [x_t, z_t, \psi_t]^\top$。
- 预测步由指令动作的运动学模型决定：

```text
前进 d 距离:  x_{t+1} = x_t - d·sin(ψ_t)
             z_{t+1} = z_t - d·cos(ψ_t)
             ψ_{t+1} = ψ_t
```

- 向左/右转：位置不变，偏航角按已知转角变化。
- **执行噪声建模**：添加零均值高斯噪声——转角标准差 1°、前进步长 0.01 m、侧滑 0.005 m，模拟真实机器人的执行不确定性。
- Kabsch 测量作为直接测量输入 EKF；当匹配一致性差（残差大）时增大测量噪声，明显不一致的测量被拒绝。
- EKF 在无可匹配对象时依靠运动模型"惯性滑行"。

**（4）地图写入门控（Map-Write Gating）**

- 新增机制：当定位置信度不足（如匹配特征少、EKF 不确定度高）时，**拒绝将对象写入地图**，避免错误地标污染后续规划。

**（5）视觉归巢（Visual Homing）**

- 接近目标对象时，控制器切换到视觉归巢模式：根据目标在相机图像中的位置（来自语义掩码和深度），左/右转对准目标，居中则前进，足够近则发出 `Found`。
- 视觉归巢依赖实时图像而非全局位姿估计，因此即使全局位姿漂移数米，最终关头仍能准确到达目标。

### 2.5 与完整 SLAM 的关键区别

| 维度 | 完整 SLAM | 本文方法 |
|---|---|---|
| 全局一致性 | 需要（通过回环检测和捆绑调整） | 不需要，局部一致即可 |
| 复杂度 | 高 | 低（仅 ORB + EKF） |
| 模型规模 | 大 | 小 |
| 生物合理性 | 较弱 | 更接近动物认知地图 |

## 3. 实验设计

### 3.1 场景与任务

- **模拟器**：Habitat，逼真的多房间公寓环境。
- **任务**：顺序多对象导航——每回合智能体从未知位置出发、地图为空，必须按固定顺序到达若干目标物体。目标物体位置每回合变化，无法记忆固定路线。
- **目标数量**：1 个、2 个、3 个。
- **奖励设置**：
  - **立即奖励**：每次到达当前顺序中的下一目标即获得奖励；
  - **终末奖励**：仅当完成整个序列时获得一次奖励（更难的信用分配问题）。
- **对象检测**：语义掩码和对象 ID 由模拟器提供（对象检测不是本文研究内容）。

### 3.2 对比条件（5 种）

| 条件 | 定位 | 宏动作策略 | 说明 |
|---|---|---|---|
| GT-Pose（oracle） | 真实位姿、无执行噪声 | DQN | 复现此前工作的上界 |
| **Full（本文）** | ORB+Kabsch+EKF 完整定位栈 | DQN | 完整系统 |
| No-EKF | 仅原始 Kabsch 测量，无运动模型/滤波 | DQN | 消融：验证 EKF 的作用 |
| Motion-Only | 仅 EKF 运动模型（纯航位推算） | DQN | 消融：验证视觉测量的作用 |
| Random-Macro | 完整定位栈 | 随机选择宏动作 | 验证策略的作用 |

- 每个条件和任务类型使用 **5 个独立随机种子** 训练。

### 3.3 评价指标

- **常规成功率**（conventional success）：按传统判据，只要宣布 `Found` 时落在目标小半径内即算成功（包括放弃后碰巧成功的样本）。
- **真实成功率**（genuine success）：仅统计真正到达目标并停止的情况，排除"放弃声明但碰巧在半径内"的次。
- **每回合基本动作数**（仅在成功回合上统计）。
- **位姿误差**：每回合中位 RMSE（位置，米；偏航角，度）。

## 6. 主要结论与发现

1. **核心结论成立**：仅具有局部一致的噪声位姿足以驱动宏动作拓扑导航。Full 系统在位置估计漂移数米、偏航误差 13–39° 的条件下仍能到达目标。
2. **EKF 不可或缺**：No-EKF 消融的偏航误差达 80–104°，导航基本失效，证明运动模型是位姿可用的关键；同时 Motion-Only 消融证明 Kabsch 测量防止位置无限漂移。**二者缺一不可**。
3. **性能差距**：Full 系统在单目标真实成功率 85.4%（GT-Pose 为 96.9%），差距随序列长度增大而扩大，说明噪声并非无害，但**局部一致性足够**是成立的。
4. **随机基线差距明显**：在真实成功率指标下，Random-Macro 相比训练过的策略大幅下降，说明学习到的策略确实在起作用（虽然低层控制器本身也贡献了相当鲁棒性）。
5. **深度信息可替代**：深度仅用于反投影锚点和视觉归巢测距，未来可用单目深度估计或三角化替代，有望去掉深度传感器。

## 7. 优点与亮点

- **概念新颖**：以"局部一致即可导航"为核心思想，将全局一致性的需求从导航系统中剥离，兼具理论价值和工程意义。
- **生物合理性**：与动物认知地图的构建方式呼应，为类脑导航提供了计算模型佐证。
- **轻量替换**：用 ORB 特征 + Kabsch 算法 + 最小 EKF 替代完整 SLAM，计算开销远小于主流方案，且避免了纹理稀疏场景中 SLAM 跟踪失败的脆弱性。
- **消融设计巧妙**："No-EKF"和"Motion-Only"互补消融，将定位栈两大组件的贡献清晰拆解，方法论严谨。
- **评估诚实**：区分常规成功率和真实成功率，有效识别"碰巧成功"的虚报问题，提升了实验结论的可信度。对随机基线的考察也增加了对比的公平性。

## 8. 不足与局限

### 8.1 实验覆盖方面

- **仅限模拟**：没有真实世界验证，执行噪声是人为添加的高斯噪声，与真实机器人动力学仍有差异。
- **对象检测未解决**：语义掩码和对象 ID 由模拟器直接提供，真实场景中的检测错误和漏检未纳入评估。
- **场景类型有限**：仅为公寓场景，未测试更开阔或更复杂的室内/室外环境。

### 8.2 偏差风险方面

- **成功率指标偏差**：即使采用"真实成功率"，将放弃后碰巧落在目标半径内的回合排除后，各条件的排名在部分任务类型（如 3 目标终末奖励）中仍存在较大置信区间重叠，结论的统计强度有限。
- **动作数统计偏差**：仅统计成功回合，失败多的条件（如 Motion-Only 在 3 目标时）动作数看似便宜，实为"幸存者偏差"。

### 8.3 应用限制方面

- **ORB 特征计算成本高**：在每个对象掩码内计算 ORB 特征是定位栈中最昂贵的部分，实时性存疑。
- **手工控制器依赖**：低层控制器（航点跟随、视觉归巢、失速恢复）靠大量人工调参，在不同环境下鲁棒性难以保证；Random-Macro 也表现不错的事实说明很多可靠性来自手工控制器而非学习策略。
- **可扩展性未知**：未报告训练算力资源和收敛曲线，无法评估该方法在更大场景或更多目标下所需的训练成本。
