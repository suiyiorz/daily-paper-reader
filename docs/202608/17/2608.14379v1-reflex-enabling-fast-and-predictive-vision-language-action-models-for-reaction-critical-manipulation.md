## 摘要
视觉-语言-动作（VLA）模型最近在机器人操作中取得了有前景的性能。然而，现有基准主要评估静态操作任务上的泛化能力，而很大程度上忽略了动态交互场景。为了解决这一差距，我们提出了 ReflexBench，一个用于反应关键操作的基准。ReflexBench 包含六个动态任务，并引入了一个评估框架，该框架将仿真器步进与机器人控制解耦，同时在同步和异步推理下支持可配置的延迟。基于 ReflexBench，我们提出了 ReflexVLA，一种高效 VLA 模型，专为反应关键操作设计，无需大规模机器人数据预训练。ReflexVLA 通过潜在未来预测和视觉主干中的多帧时间融合增强了时间推理能力，同时通过批量视觉编码和 CUDA Graph 重放减少了部署延迟。实验表明，ReflexVLA 在标准静态操作基准上保持竞争力的同时，持续提升了动态操作性能，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. ## 2. 论文提出的方法论

### 2.1 ReflexBench：延迟感知的动态操作基准

- **任务组成**：包含6个模拟动态任务，反映反应关键操作的代表性挑战：
  - 传送带抓取放置（Conveyor Belt Pick-and-Place）
  - 接球（Ball Catching）
  - 打地鼠（Whack-a-Mole）
  - 滚动球拦截（Rolling Ball Interception）
  - 抛球入桶（Ball Throwing）
  - 旋转销钉插入（Rotating Peg Insertion）
- **数据收集**：基于规划的流水线，将任务分解为顺序子目标（如预对齐、目标跟踪、定时插入），并利用物体实时位置和速度预测未来轨迹；对复杂交互动力学，额外训练任务特定的RL策略生成演示轨迹。
- **延迟感知评估协议**：
  - 解耦模拟器步进与机器人控制，使环境在策略推理期间持续演化，而非像传统基准那样暂停环境等待推理；
  - 显式建模**同步推理**（推理期间阻塞执行）与**异步推理**（推理与执行重叠，但动作可能过时）两种部署范式；
  - 支持手动指定延迟值，以可控方式分析延迟对性能的影响；
  - 引入**实时因子**（Real-Time Factor, RTF）将真实世界推理延迟转换为仿真延迟，RTF = t_sim / t_wall，使仿真评估更贴近实际部署。

### 2.2 ReflexVLA：快速且具有预测能力的VLA模型

基于紧凑VLA架构（融合ViT视觉编码器，即DINOv2+SigLIP，和Qwen2.5-0.5B语言骨干），提出三大核心设计：

- **① 潜在未来预测（Latent Future Prediction）**
  - 核心思想：让模型在训练时学习预测**未来视觉状态的特征**，而不是直接预测未来像素。
  - 实现方式：使用**冻结的DINOv3编码器**提取未来观测的语义特征作为目标（维度1024）；在输入序列中追加H个可学习的未来token（H等于动作块大小）；经过Transformer前向计算后，用投影头将对应时刻的隐藏状态映射到DINOv3特征空间，通过**掩码余弦相似度损失**进行监督。
  - 损失函数为：L = L_act + λ_future · L_future，其中L_future是预测特征与真实未来特征的余弦距离加权平均。
  - 优点：每个未来步仅用一个token，计算与内存开销可忽略；与动作块结构对齐，让预测直接服务控制；冻结目标提供稳定监督信号。

- **② 多帧时序融合（Multi-Frame Temporal Fusion）**
  - 动机：单帧观测无法捕捉运动信息，但简单拼接多帧视觉token会导致语言模型侧序列长度大幅增加，带来二次注意力复杂度。
  - 设计：在**视觉骨干的中间层**（而非最终层）执行时序融合，因为中间层保留更丰富的局部外观与运动线索；
  - 具体流程：对所有视角×历史帧提取中间和最终特征 → 对同一空间位置的跨帧特征做归一化、降维、添加时间位置编码 → 经**因果多头注意力**（防止信息泄漏）建模时序轨迹 → 上投影得到增量特征并与当前帧最终特征相加 → 融合后的当前帧token数量与单帧一致，再送入语言模型。
  - 优势：不增加语言模型侧视觉token数量，同时有效建模短时运动信息。

- **③ 推理延迟优化（Inference Latency Optimization）**
  - **批量视觉编码**：将多视角、多帧图像合并为一次视觉编码器前向传播，避免V×T次独立前向带来的框架开销；
  - **CUDA Graph 重放**：将整个推理流水线（视觉编码→时序融合→多模态投影→语言模型→动作预测）捕获为固定CUDA图，运行时仅将输入复制到预分配缓冲区并重放，省去重复内核调度与运行时分发开销；
  - 整体优化等价于执行 a_{t:t+H−1} = G(x_text, x_vision, x_state)，不改变模型结构和学习目标。

## 6. 主要结论与发现

- **最优反应关键操作的部署策略**（Q1）：较大chunk size + 较短action horizon + 高频异步推理组合效果最佳；低频异步推理因观测-动作失配而表现最差，

这一结果表明：异步推理中推理频率与动作执行周期必须匹配，否则过时的观测会严重损害成功率；而较大的动作块尺寸与较短的动作执行次数可缓解动作过时带来的负面影响。

- **ReflexVLA 在动态基准上全面领先**：在 ReflexBench 的 6 个任务上，ReflexVLA 的平均成功率显著超过所有基线（如 SmolVLA、VLA-Adapter、DynamicVLA、PUMA、π0.5、OpenVLA-OFT），同时端到端推理延迟最低（仅约 7–8 ms），展示了“既快又准”的优势。
- **未来预测与多帧时序融合均为有效模块**：消融实验显示，加入潜在未来预测后成功率明显提升，且使用冻结 DINOv3 目标比可训练目标更稳定；在视觉骨干中间层进行因果时序融合优于最终层融合，也优于交叉注意力方案，说明中间层特征保留了更丰富的运动线索。
- **系统级延迟优化效果显著**：批量视觉编码与 CUDA Graph 重放将端到端延迟大幅降低，且不改变模型输出，体现了工程优化对时敏操作的重要性。
- **静态任务泛化能力保持**：在 LIBERO 基准上，ReflexVLA 与 SmolVLA 等轻量模型性能相当，未因动态优化而牺牲静态任务能力。
- **真实世界验证可行**：在真实机械臂上，ReflexVLA 在三个代表性任务中均取得最高成功率，其中接球任务相比基线提升明显，验证了模拟到真实迁移的可行性。
