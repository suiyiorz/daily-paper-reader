## 摘要
自然语言为机器人提供了一种灵活的任务接口，但在具身环境中，目标歧义不仅源于用户意图，还可能源于当前观测中缺失与任务相关的物理证据。现有的交互式消歧方法主要通过询问用户来获取额外信息，而遮挡、受限视角、不可读文本以及未观察到的目标则要求机器人主动改变其观测。我们提出了一种用于具身目标消歧的主动感知框架，该框架以主动观测作为信息获取的基础，并利用视觉语言模型根据累积的视觉证据和交互信息来决定是继续观测、请求澄清还是完成目标选择。主动观测既能直接恢复缺失的判别性证据，也能揭示物体名称、标签和语义属性，从而在仍有必要的情况下改进用户澄清。真实机器人实验表明，该框架在统一的具身消歧过程中结合了物理信息获取和用户意图澄清。

## Abstract
Natural language provides robots with a flexible task interface, but target ambiguity in embodied environments arises not only from user intent; it can also result from missing taskrelevant physical evidence in the current observation. Existing interactive disambiguation methods primarily obtain additional information by asking the user, whereas occlusion, restricted viewpoints, unreadable text, and unobserved targets require the robot to actively change its observation. We propose an active-perception framework for embodied target disambiguation that uses active observation as the backbone for information acquisition and uses a vision-language model to decide, on the basis of accumulated visual evidence and interaction information, whether to continue observing, request clarification, or complete target selection. Active observation can both directly recover missing discriminative evidence and reveal object names, labels, and semantic attributes, thereby improving user clarification when it remains necessary. Real-robot experiments show that the framework combines physical information acquisition and userintent clarification within a unified embodied disambiguation process.

# 论文详细总结：Active Perception for Embodied Disambiguation（具身消歧中的主动感知）

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：自然语言已成为机器人任务接口的重要组成部分，视觉语言模型（VLM）和视觉-语言-动作模型使机器人能够理解指令并执行物理任务。然而，自然语言进入物理环境后，“理解指令”并不等于“唯一确定目标”。
- **核心问题**：具身环境中的目标歧义有两个来源：
  1. **观测不完整性（observation incompleteness）**：当前观测缺少任务相关的物理证据，例如物体表面被遮挡、视角受限导致的关键面不可见、文字过小无法辨认、目标根本不在当前视野中。
  2. **语义/意图歧义（semantic or intent ambiguity）**：场景已经足够可见，但用户的偏好或意图仍不明确，无法仅凭视觉确定目标。
- **现有不足**：已有交互式消歧方法（如 SeeAsk、KnowNo、CLARA 等）主要将“额外信息”的来源放在用户身上，通过提问获得澄清；这类方法忽略了“改变观测”这一物理信息获取渠道。VLM 只能对已有图像进行推理，无法“凭空生成”不存在的物理证据。
- **本文立场**：提出以**主动观察**为信息骨干的消歧框架，将“看”与“问”统一到一个连续的观察-交互-选择过程中，明确区分“缺失的信息是在物理世界中”还是“在用户意图中”，并根据信息源决定下一步动作。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：将主动感知（通过眼在手相机改变视角获取新 RGB-D 观测）作为信息获取的主干，而不是仅仅依赖用户提问。主动观察先改变机器人对物理场景的理解，再决定是否需要澄清，以及如何提出更具体的澄清问题。
- **高层决策**：VLM 根据用户指令 u、当前观测 o、历史观测和澄清对话，做出三类决策 α：
  - **O（Observe）**：继续获取新的物理观测——眼在手相机变换视角，采集新的 RGB-D 图像，返回给 VLM 重新评估；可多次迭代。
  - **Q（Query）**：询问用户澄清——基于已通过主动观察获得的名称、标签或视觉属性，生成更具体、更有区分度的问题。
  - **S（Select）**：完成目标选择——基于累积的视觉证据和必要时的用户反馈，承诺选定的物理目标。
- **关键机制**：
  - 主动观察可以：恢复被遮挡的判别性证据、使小文字可读、暴露标签或另一侧面、识别语义属性、检查桌面其他区域、发现之前未进入视野的目标。
  - 澄清问答不是独立动作：主动观察获得的新证据会改善后续澄清的语义基础。例如初始只能描述“右边有彩色图案的物体”，主动观察后可以问“左边粉色的‘盐酸左西替利嗪片’、中间白色的‘复方嗜酸乳杆菌片’、右边白色的‘健胃消食片’您需要哪一盒？”
  - 目标选择是累积证据上的终止决策；流程可能是“反复观察→选择”，也可能是“观察→澄清→选择”，用户回复后仍可能回到观察。
- **技术要点**：框架依赖 VLM（实验中为 Qwen3.7-Plus）进行多模态推理；不依赖训练或微调，而是利用模型对视觉场景与语言交互的综合理解，在每一步重新评估。

## 3. 实验设计：场景、基准与对比方法

- **机器人平台**：PiPER 六自由度机械臂 + DABAI DC1 RGB-D 相机（眼在手配置），在真实桌面场景中实验。
- **模型**：所有对照试验使用 Qwen3.7-Plus（通过阿里云百炼平台，中国北京区域）。
- **基准方法（baselines）**：
  - **Passive Direct Selection**：仅用初始观测，不提问、不移动相机，直接选择一个候选目标。
  - **Greedy Asking（SeeAsk 风格）**：不移动相机，针对当前偏好的一个候选进行确认式提问，根据用户回答推进。
  - **Static Asking（SeeAsk 风格）**：不移动相机，仅基于固定初始视图中可获得的属性构造候选划分问题。
- **实验场景**：共 9 个匹配场景（A1–A9），每个场景 4 种方法，共 36 次真实机器人试验。每个匹配比较使用相同的物理场景配置、相同初始观测条件、相同用户指令。
  - **RQ1（A1–A5）**：主动感知能否恢复初始局部观测中已存在目标的判别性视觉证据？涵盖顶面部分遮挡、小文字、同书名多卷书、书名相近、标签文字等场景。
  - **RQ2（A6–A7）**：主动感知能否为仍然必要的澄清提供更好的语义基础？涉及三盒药中用户偏好未指明、以及用户提供自由形式答案的情况。
  - **RQ3（A8–A9）**：主动感知能否在目标不在初始候选集中时扩展观测工作区？目标分别位于局部视野外和更远处。
- **评估维度**：
  - 目标是否解析成功；
  - 证据来源（新视觉证据 / 用户澄清 / 初始视图证据 / 无依据选择）；
  - 澄清交互次数（提问数量及对话记录）；
  - 主动观测次数（选择前获取的新视角数量）。

## 6. 主要结论与发现

- **主动观察可以直接解决观测不完整导致的歧义**：在 A1–A5 中，主动观察从新视角恢复了被遮挡的字母、小文字、卷号、书名等证据，使机器人无需提问即可正确选择目标；而固定视角的提问方法虽然也能通过用户澄清解决，但额外消耗了交互轮次。
- **主动观察能提升语言澄清的语义质量**：在 A6–A7 中，主动观察暴露了药品名称、颜色、条纹、图案等属性，使澄清问题从“右边带彩色图案的物体吗”变成“左边粉色包装的‘盐酸左西替利嗪片’、中间白色带绿条纹的‘复方嗜酸乳杆菌片’、右边印有‘健胃消食片’字样的，您需要哪一盒？”。用户更容易给出准确回答。
- **主动观察能扩展观测范围，发现初始候选集之外的目标**：在 A8–A9 中，固定视角方法只能在局部候选中选择，而主动搜索成功找到并读取了目标药名。
- **“看”与“问”是互补信息渠道**：世界回答“物理上有什么”，用户回答“我实际想要什么”；主动感知可以改善语言交互，但不一定完全消除提问需求。
- **并非所有歧义都应触发提问**：应根据缺失信息的来源决定下一步动作，观测不完整时优先改变视角，语义歧义时才提问。
