## 摘要
世界-动作建模已成为机器人控制的一种有前景的范式，它使模型能够超越对观测的反应，并预测场景将如何演变。然而，现有的WAM通常会产生大量的计算开销。像素空间方法通常将大量容量分配给可能与控制不直接相关的视觉细节，而一些潜在空间方法需要多阶段训练来构建推理空间。由此产生的训练成本使得这些方法在有限的计算预算下难以训练。在这项工作中，我们提出了LiLa-WAM，一种轻量级世界-动作模型，它在紧凑的潜在空间中推理未来，并且可以在单个24GB GPU上进行端到端训练。其核心设计是一个紧凑的潜在推理空间，由未来状态预测和动作生成共同塑造，使模型保持轻量级，同时与控制保持良好的对齐。对于任务规范，我们进一步提出了视觉转换标记（VTT），一种无语言任务表示，将每个任务编码为视觉特征空间中的一个方向。在RoboTwin 2.0、LIBERO和真实机器人任务上的实验证明了LiLa-WAM的有效性，在50个RoboTwin任务上实现了90.48%的成功率，且仅需单GPU训练。

## Abstract
World-action modeling has emerged as a promising paradigm for robotic control, as it empowers models to go beyond reacting to observations and anticipate how a scene will evolve. However, existing WAMs often incur substantial computational overhead. Pixel-space methods often allocate substantial capacity to visual details that may not be directly relevant to control, while some latent-space methods require multi-stage training to construct the reasoning space. The resulting training cost can make such methods difficult to train under modest computational budgets. In this work, we propose LiLa-WAM, a lightweight world-action model that reasons about the future in a compact latent space and can be trained end-to-end on a single 24GB GPU. Its core design is a compact latent reasoning space jointly shaped by future-state prediction and action generation, which keeps the model lightweight while remaining well aligned with control. For task specification, we further propose the Visual Transition Token(VTT), a language-free task representation that encodes each task as a direction in visual feature space. Experiments on RoboTwin~2.0, LIBERO, and real-robot tasks demonstrate LiLa-WAM's effectiveness, achieving 90.48\% success across 50 RoboTwin tasks with single-GPU training.

## 1. 论文的核心问题与整体含义（研究动机与背景）

近年来，**世界-动作模型（World-Action Model, WAM）** 成为机器人操作领域的新兴范式。与传统视觉-语言-动作（VLA）模型直接"反应式"地将观测映射为动作不同，WAM 通过显式建模"场景在机器人干预下将如何演变"来赋予策略**前瞻能力**，从而提升操作鲁棒性。然而，现有 WAM 普遍存在以下问题：

- **像素空间方法（Pixel-space）**：如视频生成类方案，需显式合成未来图像或视频帧，大量模型容量被分配给了与控制无关的视觉细节（纹理、光照、背景等），导致训练与推理的算力和显存开销巨大。
- **潜在空间方法（Latent-space）**：虽然避免了像素合成，但许多方法（如 WoG、LaWAM）需要**多阶段训练**——先单独训练未来预测模块或条件空间，再将其集成到策略中，训练负担并未真正降低。
- **骨干网络过重**：当前 WAM 多基于大规模预训练模型（如 VLM 或视频生成骨干），大量参数服务于语言建模或像素级动态，而非精细操控所需的细粒度空间与几何线索，造成严重的**能力-需求错配**。

**LiLa-WAM 的核心主张**：构建一个**轻量级、端到端、单 GPU 可训练**的世界-动作模型——在**紧凑潜在空间**中同时完成未来状态预测与动作生成，并由这两个目标**联合塑造**该潜在空间，使模型保持轻量的同时与控制目标紧密对齐。

## 2. 论文提出的方法论

### 2.1 总体框架

LiLa-WAM 学习如下条件分布：

```
pθ(at:t+H, ẑt+Δ | ot, qt, cτ)
```

其中 `ẑt+Δ` 是未来状态（前瞻间隔 Δ 后）的紧凑潜在表示，`cτ` 是**视觉任务提示**（Visual Task Cue），用来取代语言指令。未来状态不是用原始图像或像素重建来表示，而是在动作专家内部直接产生紧凑潜在码，因此无需任何重型生成骨干。

### 2.2 Foresight-Aware Action Expert（前瞻感知动作专家）

这是模型的核心组件，设计目标为**轻量且具备前瞻能力**：

- **视觉骨干**：采用**冻结的 DINOv3-ViT-L/16** 自监督视觉编码器。DINOv3 的密集自监督预训练可产生富含细粒度视觉细节的 patch 特征，比 VLM 骨干更适配精细操控需求。
- **多层级特征融合**：融合 DINOv3 第 17 层和第 21 层的 patch 特征（沿通道拼接后线性投影回专家宽度 D），以同时获取低层空间细节与高层语义。
- **查询式适配器（Query-based Adapter）**：采用 Nq=64 个可学习查询，通过交叉注意力将密集 patch 特征压缩为固定数量的紧凑视觉潜在标记 `Zv ∈ R^{Nq×D}`，将潜在大小与 patch 数解耦，限制后续注意力的计算量。
- **单流 Transformer 架构**：动作专家为 12 层 DiT（Diffusion Transformer）块，输入为一个统一的 token 序列：

```
[Za; Zq; cτ; Zv]
```

分别对应噪声动作块嵌入、本体感觉嵌入、VTT 任务令牌、压缩视觉潜在标记。经过 DiT 处理后：
  - **动作位置输出** → 线性头读出预测速度 `v̂s`（用于动作生成）；
  - **观测侧输出** → 形成预测的未来潜在状态 `ẑt+Δ`（用于未来预测）。

### 2.3 未来状态预测（Foresight Objective）

- 训练时，预测的未来潜在 `ẑt+Δ` 经一个轻量级 **Q-Former 风格解码器** 映射回冻结编码器的特征空间。
- 与真实未来观测 `ot+Δ` 经 DINOv3 提取的 patch 特征计算**逐 token 余弦损失**。
- 由于未来预测与动作速度从同一个 token 序列读出，**两个目标的梯度汇入同一共享表征**，迫使潜在空间保持紧凑且与控制相关。
- 推理时解码器被完全丢弃，**不引入任何额外测试时开销**。

### 2.4 Visual Transition Token（VTT，视觉转换标记）

这是论文提出的一种**无语言任务表示**：

- 对于任务 τ，收集其演示集 Eτ。对每个 episode e，取首帧和末帧的全局图像嵌入（来自同一冻结骨干），记为 `g0^e` 和 `gT^e`。
- VTT 定义为两者之差的平均值：

```
uτ = (1/|Eτ|) · Σ_{e∈Eτ} (gT^e − g0^e)
```

- VTT 本质上是**特征空间中的"过渡方向"**，编码"该任务改变了场景的什么"。它通过轻量 MLP 投影到专家宽度后注入 token 序列作为任务条件 `cτ`。
- VTT 是**离线计算、固定每任务向量**，在测试时**不需要文本、不需要目标图像**。

### 2.5 训练目标

总损失为：

```
L = Lfm + λff · Lff   （λff = 0.5）
```

- **动作预测**：采用**条件流匹配（Conditional Flow Matching）**。对噪声 `x0 ~ N(0,I)` 与真实动作块 `x1` 做线性插值 `xs = (1−s)x0 + sx1`，目标速度 `v* = x1 − x0`，训练模型预测该速度。
- **未来预测**：如上所述，在 DINOv3 特征空间上计算逐 token 余弦损失。

## 6. 论文的主要结论与发现

1. **轻量世界-动作模型可行**：在紧凑潜在空间中联合进行未来预测与动作生成，可以以远低于像素空间方法的成本获得有竞争力的操控性能，甚至超越参数规模大得多的模型。
2. **未来状态预测是有益的训练信号**：去除 Lff 后成功率下降 15.6 个百分点，说明前瞻监督对策略学习有显著贡献。
3. **VTT 是一种高效的任务表示**：它比 CLIP 语言指令更适用于该框架（+8.6 点），且测试时无需文本或目标图像；其注意力集中在任务相关物体上（如"放风扇"任务中同时关注风扇和目标垫）。
4. **轻量自监督骨干优于更大 VLM 骨干**：DINOv3（0.5B）在相同训练预算下优于 Qwen3VL-2B（2.2B，61.0 vs. 70.0），表明精细操控更需要**细粒度空间特征**而非高层语义表示。
5. **未来特征确实是动作条件化的**：动作扰动探针与注意力掩码实验表明，模型预测的未来状态编码了特定动作轨迹下的动态演变，而非仅由视觉上下文决定。
6. **跨域泛化能力**：在仿真（RoboTwin、LIBERO）与真实机器人上均验证了性能增益，说明该范式具有一定实操价值。

## 8. 不足与局限

- **泛化能力存疑**：VTT 是**离线计算的固定每任务向量**，新任务需重新收集演示并计算对应 VTT，无法像语言指令那样组合性地描述未见过的任务组合或零样本泛化。
- **数据集依赖**：训练使用了较大规模的演示数据（RoboTwin 每任务 500 条含域随机化演示；LIBERO 为每任务 50 条专家演示），对于真实世界中数据稀缺的场景，数据利用效率仍待

- **评估与对比公平性**：与其他 SOTA 方法（Motus、π0、GigaWorld-Policy 等）的对比基于各自原论文报告的结果，这些方法采用的演示数量、数据来源、骨干初始化及训练协议存在差异，因而跨论文比较存在一定的不可控变量。此外，LiLa-WAM 未与同实验条件下复现的其他方法进行公平同台对比。

- **对冻结编码器的强依赖**：模型成效高度依赖 DINOv3 冻结特征的表达质量。若目标环境与预训练数据分布差异较大，特征可能不再具有足够的判别性，而论文未提供针对此类分布外场景的量化分析。

- **任务粒度与动作表示上界**：VTT 基于首末帧全局特征之差，隐含假设任务可被表示为“初始状态→目标状态”的转换。对于涉及多阶段、长时序或需要中间状态约束的复杂任务，这种单步过渡描述可能不够充分，进而限制任务表达范围。

- **与动作流匹配的内在张力**：训练时动作与未来状态预测共用同一潜在序列，但论文未深入分析两者梯度冲突对训练稳定性的影响——尤其在去噪后期，动作 token 对视觉 token 的注意力需求与视觉一致性约束可能产生冲突，消融中 Nq 与层数选择虽提供了启发，但更精细的权衡分析仍有探索空间。

## 9. 综合评价

LiLa-WAM 的核心贡献在于表明了“**轻量、端到端、潜在空间中的世界-动作模型**”是一条可行且高效的路径。它以 0.5B 参数、单张 24 GB GPU、约 110 GPU 小时完成了在大量任务上的训练，并在 RoboTwin 2.0 与 LIBERO 以更少数据/算力超越或持平多代大规模 VLA 与 WAM 方法。VTT 作为一种免语言任务编码方式，是该工作最具原创性的设计之一——既规避了大型语言模型引入的参数开销，又稳定地提供了任务意图信息。

从学术价值看，该工作为“世界模型”的落地提供了一个新的轻量化范式参考：未来状态损失不必依赖像素生成，可在与动作共享的潜在空间中作为正则与监督信号而存在。它间接回应了近两年关于“大模型是否越大越好”的争论——在精细操控上下文下，**表征的细粒度与任务对齐程度往往比参数量更能决定性能上限**。

从工程价值看，LiLa-WAM 展示了在单张消费级显卡上训练世界-动作模型的可行性，对资源受限的机器人研究团队具有直接参考意义；其推理阶段的解码器移除设计也体现了对实用性（部署成本）的务实考量。

总体而言，该论文选题方向明确、方法设计简洁自洽、实验证据详实、分析有深度，是一项完成度高且具有启发性的工作。但其在跨域泛化、复杂任务扩展性上的验证仍待进一步深化——未来的工作或许可以沿“在线自适应 VTT 更新”“多任务共享潜在流形”或“与更强骨干的联合微调“等方向继续推进。
