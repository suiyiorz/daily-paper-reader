## 摘要
长期操作规划要求机器人不仅考虑当前任务的成功，还要考虑当前决策如何影响未来与环境的交互。在此背景下，家庭服务机器人可能需要在部分占用的货架上整理杂货，同时高效利用有限的存储空间，并保持后续放置的可访问性。本文考虑一种在线多物体货架放置场景，其中未来物体的到达是未知的。现有方法在连续货架填充过程中未同时处理语义组织、密集空间利用和机械臂可访问性。为解决这一空白，我们提出语义密度放置规划（SDPP），一种保持可访问性的方法，通过结合物体间语义相似性与空间邻近性的语义密度分数对候选位姿进行排序。可访问性地图（AM）进一步在运动规划之前过滤掉不可达的候选，并对减少剩余可访问工作空间的放置进行惩罚。仿真实验表明，SDPP在语义放置质量上显著优于最先进的基线方法，并实现了最高的平均货架密度，而AM大幅减少了识别可行放置位姿所需的时间。定性的真实世界实验证明了我们的流程在家庭货架存储场景中的适用性。

## Abstract
Long-term manipulation planning requires robots to reason not only about immediate task success but also about how current decisions affect future interactions with the environment. In this context, household service robots may need to organize groceries in partially occupied shelves while using limited storage space efficiently and preserving access for subsequent placements. In this paper, we consider an online multi-object shelf-placement setting in which future objects arrivals are unknown. Existing approaches do not jointly address semantic organization, dense space utilization, and manipulator accessibility during sequential shelf filling. To address this gap, we propose Semantic-Dense Placement Planning (SDPP), an accessibility-preserving approach that ranks candidate poses using a semantic-density score combining inter-object semantic similarity with spatial proximity. An Accessibility Map (AM) further filters candidates unlikely to be reachable before motion planning and penalizes placements that reduce the remaining accessible workspace. Simulation experiments show that SDPP significantly improves semantic placement quality over state-of-the-art baselines and achieves the highest average shelf density, while the AM substantially reduces the time required to identify feasible placement poses. A qualitative real-world experiment demonstrates the applicability of our pipeline in a domestic shelf-storage scenario.

## 2. 方法论

### 2.1 整体流程
SDPP的流程为：环境感知 → 构建每层货架的2D占用图 → 生成可访问性地图 → 采样候选放置位姿 → 用语义-密度分数和空间保持惩罚综合评分 → 按分数排序 → 对最高分候选执行IK和运动规划验证 → 执行最优可行抓取-放置对。该流程重复直至当前物体无法放置。

### 2.2 环境表示
- 将每个货架板建模为2D网格，存储物体的2D占据足迹、高度、中心位置和语义类别信息。

### 2.3 可访问性地图（AM）
- **地图生成**：将物体足迹和货架壁膨胀（dilation），并加入物体后方的锥形区域，表示候选物体中心不应放置的区域；随后用由夹爪宽度推导的椭圆形结构元素对占据掩膜进行形态学闭运算（morphological closing），以体现夹爪所需间隙。得到的黑色掩膜表示不可访问区域。
- **候选采样**：采用两种策略——
  - **Footprint-Constrained (FC)**：候选的完整足迹必须位于估计的可访问区域内（保守策略）；
  - **Center-Constrained (CC)**：仅要求足迹中心位于可访问区域内（宽松策略，支持更密集排列）；
  - 实际执行时，先尝试FC，若无可行放置则回退到CC，每个货架层采样至多250个有效候选。
- **空间保持惩罚**：对每个候选位姿，假设执行该放置后重新计算AM，衡量可访问区域面积的变化：

$$V_{AM} = \frac{|U(S_t^i)| - |U(S_t)|}{|S|}$$

其中 $|U(S_t)|$ 和 $|U(S_t^i)|$ 分别是放置前后的可达区域面积，$|S|$ 为货架面积。放置后残留可访问区域损失越大，惩罚越高。

### 2.4 局部语义-密度评分
- **相似度计算**：将物体标签拆分为语义词（如"mustard"）和形式词（如"bottle"），分别用GloVe词向量嵌入后加权组合：

$$s(o_i, o_j) = \alpha \cos(m_i, m_j) + (1 - \alpha) \cos(f_i, f_j)$$

其中 $\alpha=0.8$ 更重视语义内容；随后对语义相似度矩阵进行对比度归一化（减去对其它所有类别的平均相似度），增强区分度。
- **空间加权**：结合空间邻近性，使附近物体对评分影响更大，远处物体影响较小：

$$V_{SemDen}(x|\hat{o}) = \sum_{o_j \in O_t^l} \hat{s}(\hat{o}, o_j) \cdot \max\left(0, 1 - \frac{d(x, o_j)}{d_{max}}\right)$$

其中 $d(x, o_j)$ 为候选位置与已放置物体足迹的最短2D欧氏距离，$d_{max}$ 为最大影响半径。

### 2.5 综合放置评分
最终分数为语义-密度分数与空间保持惩罚的加权组合：

$$V_p(x|\hat{o}) = V_{SemDen}(x|\hat{o}) - w_2 V_{AM}(x|\hat{o})$$

其中 $w_2$ 权衡语义组织与可访问性保持两个目标。

### 2.6 执行模块
- 抓取位姿：基于GoalGrasp方法，先将物体点云投影到支撑平面，计算凸包的最小面积包围矩形后升回3D；所有抓取位姿在物体局部坐标系中表示，可直接变换到每个候选放置位姿。
- 运动规划：使用NVIDIA cuRobo路径规划器验证并执行抓取-放置对。

## 3. 实验设计

### 3.1 实验场景与配置
- **仿真平台**：PyBullet，Neobotix MMO-700移动机械臂（小型基座调整可访问3个货架层）。
- **真实平台**：固定式UR5e六自由度机械臂 + Robotiq 2F-85夹爪 + Orbbec Gemini 336 RGB-D相机，配套两层货架。
- **初始配置生成**：使用概率采样方法生成3层货架（每层4个物体，共12个初始物体），初始配置偏好在局部形成语义聚集但允许类别跨层分布（5%概率），所有方法使用相同初始配置和物体到达序列，实现配对比较。
- **实验协议**：每个trial从12个物体开始，每次放置随机选取评估集中的下一个物体；当当前物体找不到可行的放置位姿时trial终止。每种方法进行10次配对试验。

### 3.2 对比基线
1. **Semantic Proximity Sampling (SPS)**：复现Adeleye等人的方法，按语义相似度降序选取参考物体，放置在参考物体一侧固定距离处；
2. **SPS++**：SPS的扩展版本，保留SDPP的候选采样方式但根据半径 $d_{rad}=10\text{cm}$ 内最高语义相似度排序，用于隔离语义密度分数的效果；
3. **Density-driven placement**：基于间隙的评分方法，优先放置在现有物体附近但无显式语义或可访问性考量；
4. **Random placement**：随机分配分数，使用与SDPP相同的候选生成过滤器。

### 3.3 评估指标
- **额外放置物体数**（Additional objects placed）：在初始12个物体之外成功放置的物体数量；
- **语义总和**（Semantic sum）：最终货架配置中所有物体语义分数的总和；
- **语义分数**（Semantic score）：每个物体的邻近加权语义值（公式5）的均值；
- **邻近分数**（Proximity score）：每个物体在 $d_{rad}=10\text{cm}$ 半径内最高语义相似度的均值；
- **密度分数**（Density score）：所有货架层上物体投影足迹面积占总货架面积的比值。

## 6. 主要结论

1. **语义组织质量**：SDPP在语义分数和邻近分数上始终优于所有基线，且优势在货架逐渐填满时不断增大。SPS仅按最相关参考物体定位，过早耗尽可行候选；随机和密度基线即使货架变密后邻近分数有所升高，语义分数仍无明显提升。
2. **空间利用率**：SDPP实现了最高的平均货架密度（0.261），与密度驱动基线（0.248）相当且略优，但语义组织显著更强，证明语义优化无需牺牲空间效率。
3. **放置容量**：SDPP平均额外放置30.7个物体，显著高于所有基线（SPS为4.7，SPS++为28.2，Dengler为28.6，Random为19.9），表明可访问性保持有助于维持后续放置能力。
4. **可访问性地图效率**：AM过滤显著减少了识别可行放置所需的IK和运动规划时间。在分数排序下，FC→CC策略平均节省52.8秒（相对于无过滤）；在随机排序下节省7.4秒。随着货架占用的增加，过滤效益更加明显。
5. **消融分析**：去掉空间保持惩罚（$w_2=0$）后，SDPP的语义组织仍强但放置数量下降约1.5个；提高 $w_2=5$ 可提升放置容量但降低语义指标。两个分数项互补：语义密度项促进局部语义聚集，空间保持项保留未来可用空间。
6. **实际可行性**：真实世界实验（UR5e + 两层货架，初始9个物体 + 24个额外物体）验证了完整pipeline的适用性。

2. **实验覆盖不足**：

3. **基线对比存在局限**：
   - SPS是2022年较早期方法，未与较新的LLM/VLM驱动的语义放置方法（如TidyBot、AnyPlace等）对比；
   - 与最先进的在线装箱/装箱学习方法未有比较。
4. **语义表示受限**：

6. **可扩展性存疑**：
   - 方法未评估在更多货架层数、多机器人协作或更复杂操作约束（如动态障碍）下的表现；
   - 空间复杂度随物体数量增长，大规模场景（如仓库）下的性能未知。
7. **可访问性地图的保守性**：虽然FC→CC的回退策略缓解了过度剪枝问题，但AM对不可达区域的估计可能过于保守，在特定物体布局下仍可能丢失可行候选。
