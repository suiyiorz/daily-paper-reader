## 摘要
长时程具身任务要求大语言模型（LLM）智能体迭代地分解高层目标，根据环境反馈修正计划，并将叶级子目标落地为有效可执行动作。诸如ReCAP之类的递归上下文管理方法通过多级任务分解和父节点细化来提高规划稳定性，但仍然在叶节点反复调用LLM，将原子子任务落地为精确有效动作。我们将这一最终落地步骤称为“最后一英里落地冗余”，这种冗余在长时程执行过程中累积为大量的LLM调用和令牌开销。为缓解此问题，我们提出HaReCAP（习惯性动作落地ReCAP），一种用于ReCAP的低侵入性叶节点落地扩展。HaReCAP从成功轨迹中提取频繁的叶节点决策，并将其离线编译为可审计且可放弃的一步叶反射规则。在运行时，仅当规则能在当前有效动作集中唯一确定合法动作时，它才跳过叶节点LLM调用；否则，回退到原始ReCAP。这种设计避免了在常规叶动作落地时反复将完整递归上下文携带至LLM，同时保留了原始递归控制流。我们以Qwen3.5-27B作为主模型，在Robotouille和ALFWorld上评估HaReCAP。在ReCAP和HaReCAP均解决的任务上，HaReCAP在Robotouille同步、Robotouille异步和ALFWorld上分别将令牌消耗减少了14.67%、17.93%和20.08%。结果表明，HaReCAP可作为ReCAP风格递归上下文管理框架的低侵入性扩展，在常见成功轨迹上减少跨环境和模型的最后一英里落地冗余。

## Abstract
Long-horizon embodied tasks require LLM agents to iteratively decompose high-level goals, revise plans in response to environmental feedback, and ground leaf-level subgoals into valid executable actions. Recursive context-management methods such as ReCAP improve planning stability through multi-level task decomposition and parent-node refinement, but still repeatedly invoke the LLM at leaf nodes to ground atomic subtasks into exact valid actions. We refer to this final grounding step as last-mile grounding redundancy, which accumulates into substantial LLM-call and token overhead during long-horizon execution. To mitigate this issue, we propose HaReCAP (Habitual-action Grounded ReCAP), a low-intrusion leaf grounding extension for ReCAP. HaReCAP extracts frequent leaf decisions from successful trajectories and compiles them offline into auditable and abstainable one-step leaf-reflex rules. At runtime, it skips the leaf LLM call only when a rule can uniquely determine a legal action in the current valid-action set; otherwise, it falls back to the original ReCAP. This design avoids repeatedly carrying the full recursive context into the LLM for routine leaf action grounding, while preserving the original recursive control flow. We evaluate HaReCAP on Robotouille and ALFWorld with Qwen3.5-27B as the main model. On tasks solved by both ReCAP and HaReCAP, HaReCAP reduces token consumption by 14.67%, 17.93%, and 20.08% on Robotouille synchronous, Robotouille asynchronous, and ALFWorld, respectively. The results show that HaReCAP can serve as a low-intrusion extension to ReCAP-style recursive context-management frameworks, reducing last-mile grounding redundancy across environments and models on commonly successful trajectories.

# HaReCAP 论文总结

## 1. 核心问题与整体含义

- **背景**：长时程具身任务要求 LLM 智能体在持续交互中迭代地分解高层目标、根据环境反馈修正计划，并将叶级子目标落地为环境可执行的合法动作。此类任务对目标一致性和动作合法性要求很高。
- **现有方法的不足**：以 ReCAP 为代表的递归上下文管理方法通过多级任务分解、父节点回注入和记忆高效执行提升了规划稳定性，但在每个叶节点仍会反复调用 LLM 将原子子任务转换为精确动作字符串，例如将“拿起案板上的洋葱”重新生成“用机器人拿起案板上的洋葱”。
- **问题定义**：作者将这种递归规划末端的重复性动作落地调用称为 **“最后一英里接地冗余”（last-mile grounding redundancy）**。统计数据表明，在 Qwen3.5-27B 的成功 ReCAP 轨迹中，单纯的叶级/动作接地调用在 Robotouille 同步、Robotouille 异步和 ALFWorld 中分别占全部 LLM 调用的 23.67%、29.56% 和 45.73%，可见这是一项稳定且可观的推理成本。
- **论文含义**：提出 HaReCAP（Habitual-action Grounded ReCAP），以低侵入的方式将高频叶级决策离线编译为可审计、可放弃的“叶反射规则”（leaf-reflex rules），在不改变 ReCAP 原有递归控制流的前提下，跳过大部分冗余的叶级 LLM 调用，从而降低 token 消耗和 LLM 调用数。

## 2. 方法论

- **核心思想**：将 ReCAP 成功轨迹中已验证的“叶任务 → 合法动作”单步接地关系提取为规则，运行时仅在规则能**唯一确定**当前有效动作集中的合法动作时才触发，否则完全回退到原 ReCAP。它既不是多步宏技能库，也不是在线情节记忆系统，而是“末端推理蒸馏”。
- **离线规则库构建**：
  - 从成功的 ReCAP 轨迹中提取叶任务和实际执行的合法动作对。
  - 每条规则表示为 `s = (k_τ, k_a)`，其中 `k_τ` 和 `k_a` 分别是任务文本和动作文本的规范化键。
  - 规范化采用“动作类型无关的规范化”，保留词序，将对象 ID 归一化为类型占位符，如 `bread12 → bread#`。
  - 要求叶任务必须显式包含对象 ID，且这些 ID 必须被动作覆盖，即 `ids(τ) ≠ ∅` 且 `ids(τ) ⊆ ids(a)`，避免“准备食材”这类抽象任务被编译成反射。
  - 仅从成功轨迹提取；支持计数按任务去重，防止单个轨迹内循环膨胀置信度。
- **运行时触发机制**：
  - 在 ReCAP 的叶级 LLM 调用之前插入模块 `π_H(τ, A_t; L) → a∈A_t 或 ⊥`，其中 `τ` 为当前叶任务，`A_t` 为合法动作集，`L` 为规则库。
  - 触发条件包括：任务键匹配、支持度达到阈值 `m`、动作键可唯一实例化为当前合法动作、动作覆盖任务内对象 ID。
  - 冲突处理采用支持度派生得分 `ρ(s)`（单调递增，由置信度项和线性区分项组成）。当多个候选动作不同且最高分与次高分相差小于 1 时，视为歧义并放弃触发。
  - 整体流程见算法 1：若返回 `⊥`，则走原 ReCAP 叶级 LLM 调用；若返回动作，则直接与环境交互，之后仍回到 ReCAP 的父节点细化流程。

### 优点

- **实验设计较为完整**：覆盖两个具身环境（Robotouille 与 ALFWorld）及同步/异步两种交互模式，并在三个不同规模的模型上验证，能够从环境、模型规模、交互模式等维度考察方法的泛化性。

### 总结

HaReCAP 从“最后一英里接地冗余”这一具体且可量化的观察出发，提出将 ReCAP 成功轨迹中验证过的“叶任务→合法动作”映射离线编译为可触发的反射规则，以低侵入方式跳过大量冗余的叶级 LLM 调用。该方法思路清晰、工程实现简洁，且在不改变原递归控制流的前提下实现了可观的 token 消耗与调用次数降低，并在多个环境、多个模型上展示了稳定的成本收益。然而，论文在算力开销、规则库质量刻画、统计显著性检验以及动态环境适应性方面仍有明显缺失，其长期有效性和跨任务迁移能力也需更多实验支撑。整体而言，HaReCAP 为长程具身任务中的推理成本优化提供了一种成本低、易集成的补充方案，但作为一篇完整的方法论文，其报告完整性和对比广度仍有提升空间。
