## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署常常受到效率与性能权衡、跨形态泛化和执行平滑性的制约。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，优化计算资源和模块化设计。为弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的基于语言引导的动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束强制执行运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速约2.7倍。这种异步设计为实际机器人应用实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 一、核心问题与整体含义（研究动机与背景）

机器人操作领域正从模块化流水线向端到端学习范式转型，Vision-Language-Action (VLA) 模型通过将感知、语言和控制统一于单一架构，实现了自然语言指令跟随与复杂任务执行。然而，当代VLA模型在实际部署中面临三大核心瓶颈：

1. **效率-性能权衡困境**：单一同步架构采用统一时间分辨率，无法同时支持低频语义推理与高频电机控制的需求，导致计算资源分配僵化。

3. **执行平滑性挑战**：异步实时推理与动作块生成之间的时间错配常引发明显的抖动和执行不连续问题。

针对上述挑战，论文提出**NebulaVLA**——一种基于"快慢认知"范式的双频VLA模型，旨在系统性地解决效率与性能的平衡、跨实体动作表示统一以及轨迹平滑性三类核心问题。

## 二、方法论：核心技术思想与关键细节

### 2.1 核心架构：异构双频体系（Fast-Slow System）

NebulaVLA采用分层双频架构，将高层语义规划与低层动作控制解耦：

- **System 2（慢系统，10 Hz）** ：以Qwen3-VL作为视觉-语言骨干网络，处理自然语言指令和稀疏视觉输入，通过可学习Token提取隐藏层特征，输出抽象动作指导（abstract action guidance），承担"深思熟虑"式语义规划。
- **System 1（快系统，20 Hz）** ：以Diffusion Transformer（DiT）为核心，结合高频率视觉输入、动作历史和System 2的指导信号，通过去噪过程输出执行动作，承担"反应式"运动控制。

两系统通过显式数据流规范解耦，原生支持分布式部署，可分别部署于不同计算设备（如边缘计算场景），最小化交互延迟并最大化硬件吞吐量。

### 2.2 GESTURE-7：统一语言接地动作表示

GESTURE-7（Gesture Enumerated State Token for Unified Robot End-effector-7D）是一个7维连续末端执行器状态向量：

```
s = [x, y, z, r, p, w, g]
```

- (x, y, z) ∈ Z³：笛卡尔坐标位置（厘米，整数量化）
- (r, p, w) ∈ Z³：朝向角度，roll/pitch/yaw（整数度）
- g ∈ G：离散手势Token，来自预定义自然语言词汇表（如"grasp"、"push"、"rotate"、"release"）

**关键设计**：不同形态的机器人执行相同动作时共享相同关键词（如平行夹爪和灵巧手执行抓取均统一表示为"grasp"），从而统一异构平台的动作语义。该表示方法原生支持语言条件下的强化学习，并具有可扩展性（词汇表G可自由扩展）。

### 2.3 Guide Action：引导动作机制

受图像外推（Image Outpainting）启发，Guide Action将动作块连接直接嵌入生成流程：

- **问题**：朴素异步算法在推理结束后执行硬切换（hard switch），导致轨迹在块边界出现突变和机械抖动。
- **解决方案**：用前一动作块中未执行的动作点（如a₄–a₇）作为引导锚点，条件化下一块的生成，强制新块起始状态与先前轨迹对齐。
- **训练策略**：引导动作点数量适应推理延迟动态变化（训练时从0到3随机采样）。
- **数学表达**：去噪过程被重新表述为条件概率模型：pθ(Aᵗ⁻¹_full | Aᵗ_full, A_prior, τ)，其中A_prior为先前动作集（含已执行历史动作和待执行引导动作），τ为时间位置查询向量。

**掩码约束公式**：

```
Aᵗ⁻¹_full = M ⊙ Aᵗ⁻¹_prior + (1 - M) ⊙ Aᵗ⁻¹_noisy
```

其中M为二进制掩码：M[1..k]=1（锚定区域，严格保留），M[k+1..T]=0（生成区域，由模型预测）。

## 六、主要结论与发现

1. **性能领先**：NebulaVLA在LIBERO-Plus上实现85.5%平均成功率，超越InternVLA-M1（81.3%）4.2%、OpenVLA-OFT+（79.6%）5.9%、GR00T N1.5（59.0%）和π0.5（58.0%）。
2. **效率显著提升**：异构双频架构将平均步进延迟从115ms（同频变体）降至42ms，动作生成加速约2.7倍，同时提升成功率。
3. **平滑性改善**：Guide Action机制平均降低25.6%的关节加加速度（Joint 12和13分别降低41.2%和45.1%），有效消除动作块边界的不连续性。
4. **训练策略有效**：三阶段渐进式优化带来总体成功率的逐级提升（83.8%→83.0%→85.5%），其中S2的SFT显著改善Layout维度（+6.2%），RL进一步强化语言和布局相关的语义耦合维度。
5. **跨形态潜力**：GESTURE-7通过自然语言关键词映射统一异构机器人动作语义，为实现跨形态泛化提供基础。

## 七、优点与亮点

1. **创新架构设计**：快慢双频解耦是VLA架构的重要方向性贡献，以认知科学中的"系统1/系统2"为理论支撑，兼顾深度语义推理与高频运动控制，且原生支持分布式部署。
2. **统一动作表示**：GESTURE-7将连续运动学转化为带语义标签的7D向量，巧妙弥合了异构机器人平台间的语义鸿沟，且整数化量化降低了学习负担，并天然兼容RL训练。
3. **内化平滑性约束**：Guide Action将连续性约束嵌入扩散去噪过程本身，而非外挂后处理模块，从生成机制上消除块边界抖动，方法新颖且有效。
4. **训练与推理频率对齐**：三阶段训练流程严格保证训练-推理频率一致性（"训练-推理频率对齐"），避免了常见的不匹配问题。
5. **实际工程价值**：在真实工业场景的部署验证表明，异构频率设计在同等甚至更优成功率下大幅降低延迟，具有明确的落地价值。
6. **诚实的消融分析**：对Camera维度性能下降的归因分析（GESTURE-7建立固定视觉-空间映射导致对视角扰动敏感），体现了客观的研究态度。
