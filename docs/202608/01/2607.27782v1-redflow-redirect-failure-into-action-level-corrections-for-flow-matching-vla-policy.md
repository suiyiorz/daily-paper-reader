## 摘要
流匹配视觉-语言-动作（VLA）策略在机器人操作中显示出强大潜力，但常常因部署期间的分布偏移而遭受复合错误。虽然离线强化学习（RL）为使用回放数据改进已部署策略提供了一种实用方法，但现有方法要么忽略失败数据，要么仅在轨迹层面利用它，导致学习效率低下且错误持续存在。我们提出**RedFlow**，一个细粒度的离线RL框架，它将失败经验重定向为流匹配VLA策略的动作级纠正监督。RedFlow包含两个关键组件：（1）**上下文感知纠正匹配**机制，识别导致失败的动作，并从类似上下文中检索成功替代方案作为纠正目标；（2）**自适应重定向目标**，联合强化成功动作、抑制不良动作，并将可恢复的失败重定向到纠正目标。通过将成功和失败的经验都转化为密集监督，RedFlow实现了从混合质量数据中的鲁棒恢复学习。在LIBERO基准和三个真实世界操作任务上的实验表明，RedFlow持续优于最先进的离线RL基线，将真实世界成功率从56.7%提高到74.7%。它还与强在线策略方法（PPO、GRPO和DDPO）相匹配，同时所需的训练样本大约少一个数量级。

## Abstract
Flow-matching Vision-Language-Action (VLA) policies have shown strong potential for robotic manipulation but often suffer from compounding errors caused by distribution shifts during deployment. While offline reinforcement learning (RL) provides a practical way to improve deployed policies using rollout data, existing methods either ignore failure data or exploit it only at the trajectory level, resulting in low learning efficiency and persistent errors. We propose **RedFlow**, a fine-grained offline RL framework that redirects failure experiences into action-level corrective supervision for flow-matching VLA policies. RedFlow consists of two key components: (1) a **Context-Aware Corrective Matching** mechanism that identifies failure-inducing actions and retrieves successful alternatives from similar contexts as corrective targets, and (2) an **Adaptive Redirection Objective** that jointly reinforces successful actions, suppresses undesirable ones, and redirects recoverable failures toward corrective targets. By converting both successful and failed experiences into dense supervision, RedFlow enables robust recovery learning from mixed-quality data. Experiments on the LIBERO benchmark and three real-world manipulation tasks show that RedFlow consistently outperforms state-of-the-art offline RL baselines, improving the real-world success rate from 56.7% to 74.7%. It also matches strong on-policy methods (PPO, GRPO, and DDPO) while requiring roughly an order of magnitude fewer training samples.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：流匹配（Flow-matching）视觉-语言-动作（VLA）策略在机器人操作中表现出色，能够建模多模态动作分布，是通用操作策略的主流范式。
- **核心问题**：这类策略通常通过模仿学习（IL）训练，继承了行为克隆的根本缺陷——**部署时分布偏移导致复合错误**（compounding errors）。当机器人遇到偏离训练分布的少量状态时，预测误差逐步累积，最终导致不可恢复的失败。
- **现有方法的局限**：
  - 在线强化学习（如PPO、GRPO）虽然有效，但需要大量环境交互，在真实机器人上成本极高，难以扩展。
  - 经典离线RL方法（如AWR）只重加权或模仿成功行为，**忽略失败数据**，丢弃了大量诊断信息。
  - 偏好类方法（如DPO）虽利用失败数据，但只做**轨迹级比较**，缺乏动作级指引——只告诉策略"不要做什么"，不告诉"应该怎么做"。
  - 人在回路干预虽同时具备两种属性，但依赖专家人力，不可扩展。
- **核心研究问题**：如何在不依赖人工干预、不增加在线交互的前提下，从预收集的离线失败经验中提取高保真的**动作级纠正信号**，使其超越简单的"远离坏动作"，为策略改进提供明确的监督目标？
- **两大挑战**：（1）轨迹级失败标签与所需的动作级策略更新之间存在粒度错配；（2）如何将纠正信号严谨、精确地整合到流匹配策略的学习过程中，避免"均匀模仿"混合质量数据的陷阱。

## 2. 方法论

### 2.1 核心思想

RedFlow 是一种细粒度的离线强化学习框架，将失败轨迹系统地转化为**动作级别的纠正学习信号**，同时利用成功轨迹。核心目标是：通过将成功和失败经验都转化为密集、结构化的监督，使策略学会从混合质量数据中稳健恢复。

### 2.2 阶段 I：数据收集

- 使用预训练的基础流匹配 VLA 策略执行回放（rollout），收集成功与失败轨迹，存入离线缓冲区 D = D_exp ∪ D_roll。
- 每条轨迹带有二元结局标签 yτ ∈ {0, 1}，但轨迹级标签太粗糙，需要进一步细化到动作块（action chunk）级别。

### 2.3 阶段 II：上下文感知纠正匹配（Context-Aware Corrective Matching）

**此模块解决"粒度错配"挑战，包含以下关键步骤：**

**(1) 动作级优势估计：**
- 使用预训练的通用奖励模型（GRM）R(ot, l) ∈ [0,1] 估计任务进度；
- 用盒式滤波器对进度序列平滑：p̄_t = (1/(2W+1))·Σ R(o_j, l)；
- 将平滑后的进度转换为带符号的动作级分数：
  - Â_t = (p̄_{t+W} − p̄_{t−W}) + b·(2·1[yτ=1] − 1)
  - 第一项衡量局部进度变化，第二项注入轨迹结局偏差；
- 根据 Â_t 的符号将动作块标记为**正块**（Â_t > 0）或**负块**（Â_t < 0）。

**(2) 执行上下文聚类：**
- 定义执行上下文特征：f_t = [q̃_t; β·p̄_t]，结合归一化本体感觉状态和任务进度；
- 使用 **HDBSCAN** 对所有动作块进行聚类，同一簇内通常对应相同潜在子任务；
- 对每个簇 C_c，取正子集 C_c⁺ = {i ∈ C_c : Â_i > 0}。

**(3) 纠正目标构造：**
- 对每个负块 a_t（Â_t < 0），若其所在簇的正子集非空，构造质量加权动作质心：
  - α_i = exp(Â_i/κ) / Σ exp(Â_j/κ)
  - a*_t = Σ α_i·a_i
- 关键理解：a*_t 不是一对一的反事实替代，而是**经验正分布重心**，定义了局部传输方向，将概率质量从失败模式重定向出去。
- 若负块被 HDBSCAN 标记为离群点或所在簇无正块，则标记为**不可纠正**，仅做抑制处理。

### 2.4 阶段 III：自适应重定向目标（Adaptive Redirection Objective）

**此模块解决"如何精确整合纠正信号"的挑战，由三个互补项组成：**

**(1) 质量加权吸引（Quality-weighted Attraction）：**
- 将动作级分数转化为软权重：w_t = σ(Â_t / T_w) ∈ (0,1)；
- L_att = w_t · ‖v_θ(x_n, n, o_t, l) − u_n‖²
- 将策略吸引向高质量动作块，同时保持低质量块的弱数据支撑信号。

**(2) 失败抑制（Failure Suppression）：**
- 对低质量块增加**有限范围排斥铰链损失**：
  - e_t = ‖x̂₀ − a_t‖²，其中 x̂₀ = x_n − n·v_θ(x_n, n, o_t, l)
  - L_sup = λ_sup·(1 − w_t)·max(0, m − e_t)
- m 是自适应边距（stop-gradient 运行平均值）；
- 仅在预测与负块距离小于 m 时激活排斥，一旦超过边距即失效。

**(3) 目标引导纠正（Target-guided Correction）：**
- 对可纠正的失败块，加入朝向纠正目标的吸引项：
  - L_cor = c_t·λ_cor·(1 − w_t)·‖x̂₀ − a*_t‖²
- 提供有界端点级偏置，将概率质量移向局部正区域，而不是精确克隆目标动作。

**总目标：** L = E[L_att + L_sup + L_cor]

### 2.5 理论保证

- **定理1（有界端点重定向）**：在满足 λ_sup ≥ λ_cor 的条件下，端点能量 ϕ(h) = λ_cor‖h−b‖² + λ_sup[m − ‖h−a⁻‖²]₊ 的最小化器等价于将纠正目标 b 投影到障碍球 {h : ‖h−a⁻‖² < m} 的补集上。
- **定理2（Fréchet 均值性质）**：纠正目标是加权重正子集的经验平方代价重心。
- **定理3（推挽速度场）**：从 Wasserstein 梯度流视角证明目标的变分结构——正样本定义建设性的传输终点，负样本定义有限范围障碍。
- **定理5（能量耗散）**：理想化的 Wasserstein 梯度流保证能量非增并收敛到静止配置。

- **消融发现**：成功和失败数据互补；不可纠正失败分离至关重要（消融后性能大幅下降）；抑制和纠正是**互补而非冗余**的机制。

## 7. 优点

### 方法亮点

1. **细粒度失败利用**：超越了轨迹级别的偏好方法，真正定位到导致失败的**具体动作块**，并提供明确的纠正方向；
2. **无需额外交互**：纯离线策略改进，避免了在线RL的高交互成本，不需要人工标注或干预；
3. **上下文感知的纠正目标匹配**：利用"本体感觉状态 + GRM任务进度"构建执行上下文，避免了在视觉高维空间的直接聚类；同一上下文簇即使来自不同结局的轨迹也能对应相同子任务；
4. **理论完备性**：提供了 Wasserstein 梯度流视角的推-推-拉结构分析、端点重定向的闭式解以及能量耗散保证，增强了方法的可信度；
5. **有限范围抑制设计**：负块仅在其附近（m 范围内）产生排斥，不会形成全局排斥力，避免了连续动作空间中负证据的盲区问题；
6. **三机制互补**：吸引+抑制+纠正在流匹配速度场中实现互补功能，合理地避免了"均匀模仿"的陷阱；
7. **实验严谨性**：真实机器人评估使用100次rollout，统计可靠性优于常见做法；展示涌现修复行为的定性分析增加了经验说服力。

## 8. 不足与局限

### 方法局限

1. **依赖GRM质量**：纠正目标分配准确度依赖于任务进度估计的质量和进度-状态聚类的稳定性；不准确的进度信号或噪声聚类可能导致失败-成功匹配不完美；
2. **仅能纠正有近邻正支撑的失败**：对于离线缓冲区中缺乏成功对应物的新颖、分布外失败模式，只能抑制而无法明确纠正；
3. **纠正目标是经验质心而非反事实替代**：a*_t 是正块的平均，不一定是最优动作；在小簇中可能产生偏置的纠正方向；
4. **单次迭代离线过程**：不做迭代式改进，没有利用更新策略后再收集数据进行下一轮训练的可能性；
5. **轨迹级结局偏差的引入**：式(5)中的二值结局偏差对所有动作块统一施加，可能对中性或本质上合理的动作产生误判。

### 实验局限

1. **基准范围有限**：仅在 LIBERO（模拟）和三个真实任务上验证，未在更广泛的机器人形态、视觉条件、长时程任务上测试；
2. **固定具身设定**：所有真实实验在同一机器人平台（Agilex Cobot Magic）上完成；
3. **未报告统计显著性**：缺少方差、置信区间、多种子实验信息；
4. **消融覆盖不完整**：消融只在3个套件上运行，未覆盖 Long 套件；
5. **在线对比单一**：样本效率对比仅在 LIBERO-Spatial 一个套件上进行，代表性有限；
6. **未见跨方法超参敏感性分析**：对关键超参数（λ_sup、λ_cor、W、b、κ 等）的系统性鲁棒性研究不足。

作者在附录 F 中也承认了上述局限性，指出未来工作应关注不确定性感知的目标分配、更长时程任务、以及迭代式离线-在线改进的扩展。
