## 摘要
从人类视频中学习操作技能对于可扩展的机器人学习很有前景。然而，人类与机器人之间的具身差异使这一任务具有挑战性。一种有前景的解决方案是学习与具身无关的、以物体为中心的可操作可供性。在这项工作中，我们提出一个框架，利用以自我为中心的人类视频以及最先进的3D运动恢复结构和手部网格重建，来提取可操作的可供性，如视觉可供性、抓取可供性和轨迹可供性，这些可供性明确编码了在哪里交互、如何抓取以及如何移动。我们构建了EgoAffordance，一个大规模数据集，包含204K个片段，具有5.6M个视觉可供性和11.6M个抓取和轨迹可供性。在此基础上，我们引入了VLAff，一个基于大型视觉-语言模型的统一基础模型，学习所有可操作可供性之间的跨模态相关性。给定视觉观察和指令，VLAff生成视觉可供性热图、抓取姿态和轨迹，然后利用3D场景信息将其转换为可直接执行的行动。通过大量实验，我们证明VLAff不仅在视觉可供性预测上达到了最先进的性能，而且可以有效地应用于真实机器人应用，如零样本操作和可供性引导的机器人学习。

## Abstract
Learning manipulation skills from human videos is promising for scalable robot learning. However, the embodiment mismatch between humans and robots makes this challenging. One promising solution is to learn object-centric actionable affordances that are embodiment-agnostic. In this work, we propose a framework that leverages egocentric human videos with state-of-the-art 3D Structure-from-Motion and hand mesh reconstruction to extract actionable affordances such as visual, grasp, and trajectory affordances that explicitly encode where to interact, how to grasp, and how to move. We construct EgoAffordance, a large-scale dataset comprising 204K episodes with 5.6M visual affordances and 11.6M grasp and trajectory affordances. Building on this, we introduce VLAff, a large vision-language model-based unified foundation model that learns cross-modal correlations across all actionable affordances. Given a visual observation and instruction, VLAff generates visual affordance heatmaps, grasp poses, and trajectories, which are then converted into directly executable actions by utilizing 3D scene information. Through extensive experiments, we demonstrate that VLAff not only achieves state-of-the-art performance on visual affordance prediction, but can also be effectively applied to real robot applications such as zero-shot manipulation and affordance-guided robot learning.

## 2. 方法论

- **核心思想**：构建一个统一的Vision-Language-Affordance (VLAff)模型，将视觉、抓取和轨迹三类可供性在同一个大型视觉-语言模型框架下联合学习，利用它们之间的跨模态相关性，实现从语言指令和视觉观察直接生成完整的、可操作的行动方案。

- **数据提取流程**：从大规模第一人称视频中自动提取可供性数据。
    1.  **数据准备与交互信息提取**：利用预训练的LLM（如GPT-4）从视频片段中提取关键交互帧、动作标签、物体类别和交互手部等信息。
    2.  **手-物交互提取**：使用手-物检测器、分割模型（SAM 2）、2D手部关键点模型（ViTPose）和跟踪模型（CoTracker3）来识别接触区域，并利用3D手部网格重建模型（WiLoR）提取MANO手部参数作为抓取可供性。
    3.  **Ego-centric SfM与轨迹生成**：对去除手部遮挡的背景帧进行单目深度估计和相机位姿估计，结合3D手部轨迹跟踪（TAPIR3D），恢复出操作过程中手部（末端执行器）的3D运动和轨迹，形成轨迹可供性。

- **模型架构 (VLAff)**：基于大型视觉-语言模型（Qwen2.5-VL）构建，核心创新在于引入了三类**特殊Token**：
    - **视觉可供性Token (`<SEG>`)**：其嵌入向量通过一个分割解码器生成像素级的视觉可供性热图 `Av ∈ R^(HxW)`。
    - **抓取Token (`<GRASP>`)**：其嵌入向量通过一个抓取解码器解码为96维的MANO手部参数 `Ag ∈ R^96`（包括全局手腕旋转和15个局部关节旋转，用6D旋转表示）。
    - **轨迹Token (`<p_i>`)**：将6D轨迹空间（3D平移+3D旋转）离散化为量化箱，每个箱子对应一个Token，轨迹通过自回归方式生成。
    - **增强视觉编码器**：引入额外的DINOv2视觉编码器，以提供更精细的局部视觉特征，弥补VLM在细粒度空间定位上的不足。

- **训练目标**：采用多任务学习，总损失函数为三类损失的加权和 `L_total = λv·L_visual + λg·L_grasp + λt·L_traj`。
    - **视觉损失**：使用Soft Dice Loss处理热图预测的类别不平衡问题。
    - **抓取损失**：使用Smooth L1损失回归手部参数。
    - **轨迹损失**：使用标准的交叉熵损失进行自回归Token预测。

- **推理优化策略**：为提高3D轨迹的物理合理性，设计了两种采样策略：
    - **上下文轨迹引导**：利用VLM作为高级规划器，生成粗粒度的3D方向向量，用于约束第一个轨迹Token的采样分布。
    - **基于采样的轨迹选择**：生成K个候选轨迹，通过结合碰撞检测和方向对齐的复合目标函数，选择最优的一个作为最终输出。
