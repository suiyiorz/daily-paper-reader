## 摘要
作为具身智能的关键能力，三维视觉定位（3DVG）主要在以RGB-D或点云为输入的室内场景中研究，而现有的室外扩展则主要依赖单目图像。这两种设置都无法满足真实世界室外感知的需求，因为异构传感器捕捉到互补但不同的物理属性，如视觉纹理、三维几何和目标运动学，这些属性对于灵活且稳健的查询自适应定位不可或缺，但尚未被充分利用。为弥补这一差距，我们引入了Talk2Sensors，这是首个基于相机、激光雷达和4D雷达构建的多传感器三维视觉定位数据集。它包含8,682条语言指令和20,558个被引用目标，并提供与传感器特定物理线索明确对齐的多样化提示。此外，我们提出了TSFormer，一个基于Transformer的统一框架，用于自动驾驶中的语言引导三维视觉定位。TSFormer采用由粗到细的属性感知融合策略：语言路由属性采样器首先通过使用查询级语言线索调节传感器采样权重来执行粗略的文本条件特征检索，而后续的稀疏保持模态仲裁器模块则执行细粒度的模态仲裁和文本引导细化，以确定精确的被引用空间位置。这种设计使外观、几何和运动线索能够根据每个提示的语义需求进行动态路由，防止密集模态淹没稀疏但关键的传感器信号。大量实验表明，TSFormer在多个基准上达到最先进性能：在Talk2Sensors上，它比最强基线提高了8.05 mAP，并在单目Mono3DRefer基准上实现了53.05%的Acc@0.5。

## Abstract
As a key capability for embodied intelligence, 3D visual grounding (3DVG) has been predominantly studied in indoor scenes with RGB-D or point-cloud inputs, while existing outdoor extensions largely rely on monocular images alone. Both settings fall short of real-world outdoor perception, where heterogeneous sensors capture complementary yet distinct physical properties, such as visual texture, 3D geometry, and object kinematics, that are indispensable for flexible and robust query-adaptive grounding but remain under-exploited. To bridge this gap, we introduce Talk2Sensors, the first multi-sensor 3D visual grounding dataset built upon camera, LiDAR, and 4D radar. It contains 8,682 language instructions and 20,558 referred objects, with diverse prompts explicitly aligned with sensor-specific physical cues. Furthermore, we propose TSFormer, a unified Transformer-based framework for language-guided 3D visual grounding in autonomous driving. TSFormer adopts a coarse-to-fine property-aware fusion strategy: the Language-Routed Property Sampler first performs coarse text-conditioned feature retrieval by modulating sensor sampling weights with query-level linguistic cues, while the subsequent Sparse-Preserving Modality Arbiter module conducts fine-grained modality arbitration and text-guided refinement to determine the precise referred spatial location. This design enables dynamic routing of appearance, geometry, and motion cues according to the semantic requirements of each prompt, preventing dense modalities from overwhelming sparse but critical sensor signals. Extensive experiments demonstrate that TSFormer achieves state-of-the-art performance across multiple benchmarks: it improves over the strongest baseline by 8.05 mAP on Talk2Sensors, and transfers to the monocular Mono3DRefer benchmark with 53.05\% Acc@0.5.

### 2. 方法论：核心思想、关键技术细节

#### 2.1 总体框架

TSFormer是一个统一的端到端Transformer框架，采用**由粗到细的属性感知融合策略**，整体流程为：

1. 各传感器分支用独立骨干网络提取单模态特征（相机用ResNet-101+FPN，LiDAR用SparseEncoder-SECOND，雷达用RadarFeatureNet+PointPillarsScatter）；
2. 预训练CLIP文本编码器生成全局语义特征；
3. **Language-Routed Property Sampler (LRPS)** 做粗粒度语言条件化检索；
4. **Sparse-Preserving Modality Arbiter (SPMA)** 做细粒度模态仲裁与文本引导精化；
5. DETR式解码器迭代精化查询特征，输出3D边界框。

#### 2.2 Language-Routed Property Sampler（LRPS）——粗粒度语言条件化采样

LRPS解决了传统多传感器融合中依赖标定投影（BEV体素空间）、且对传感器子集泛化性差的问题。其核心思想是**将文本语义注入采样过程**，使特征采样变为查询驱动的过程：

- **文本映射**：将全局文本特征通过模态特定投影 $\phi_m$ 映射到各传感器语义空间：$t_m = \phi_m(t)$；
- **文本-传感器相似度计算**：沿通道维度对查询与投影后文本做逐元素乘加，生成查询级相似度图 $D_m$；
- **调制因子生成**：通过可学习的温度参数和Sigmoid函数将相似度转换为有界调制因子：$G_m = \sigma(\tau_m D_m)$；
- **加权采样注意力**：将查询级调制因子广播到注意力头与采样维度，在Softmax之前调制采样权重：$\tilde{A}_m = \text{Softmax}(A_m \odot G_m)$；
- **可变形采样**：参考点加归一化偏移得到采样位置，通过多尺度可变形注意力聚合约会感器特征。

这种方法使得采样过程显式具备语言感知能力：文本提示先产生查询级调制因子，再调整传感器采样权重，从而检索与语言描述物理属性（LiDAR几何、相机外观、雷达运动）一致的初步特征。

#### 2.3 Sparse-Preserving Modality Arbiter（SPMA）——细粒度模态仲裁

SPMA解决了两个关键问题：① 信息密集的相机特征会淹没稀疏但关键的雷达信号；② 现有融合方法缺乏语言引导的模态路由机制。其流程为：

- **全局文本摘要**：对文本token做平均池化并通过可学习投影得到全局语义向量 $t_g$；
- **模态门控网络**：轻量网络将 $t_g$ 映射为模态门控logits $\mathbf{z}$，可选Top-K稀疏选择掩码强制稀疏模态路由；
- **Softmax归一化**：得到样本级模态门控权重 $\boldsymbol{\alpha} = [\alpha_{cam}, \alpha_{lidar}, \alpha_{radar}]$；
- **加权融合**：各模态采样特征按门控权重加权求和得到融合特征 $F_s = \sum \alpha_m O_m$；
- **文本引导跨注意力**：以融合特征为Query、文本token为Key/Value，执行多头交叉注意力，将细粒度语言意图对准融合特征；
- **前馈网络精化**：残差连接+层归一化输出最终稀疏保持模态仲裁特征 $F_{SPMA}$。

这种设计让模型根据每个样本的文本语义动态决定强调哪些模态——外观、几何或运动——而不是无差别融合所有模态。

#### 2.4 解码器与训练目标

- **查询式集合预测**：900个对象查询，6层解码器，逐步精化；
- **预测头**：每个查询独立输出二值引用置信度 $\hat{\alpha}_i$ 和7维3D边界框 $(\hat{x},\hat{y},\hat{z},\hat{w},\hat{h},\hat{l},\hat{\theta})$（yaw角用正弦-余弦编码解决角度周期性）；
- **匈牙利匹配**：通过最优二分匹配在预测和真值之间建立对应，匹配代价结合引用置信度、L1框距离和3D GIoU；
- **损失函数**：包含二值交叉熵（引用置信度）、L1回归损失、3D GIoU损失，并在每个中间解码层施加辅助监督。

### 6. 主要结论与发现

1. **多传感器物理线索匹配显著有效**：TSFormer在EAA上达到51.000 mAP，比最强融合基线FUTR3D（42.949）提升8.05 mAP；DCA上达到66.499 vs 58.878，提升7.62；
2. **语言引导路由是核心**：无文本变体mAP崩至0.007，证明任务是真正的引用理解而非穷举检测；TSFormer随模态增加单调提升（46.18→48.28→51.00），而FUTR3D的三模态融合反而低于LiDAR单模态，说明语言引导路由能防止密集模态淹没稀疏关键信号；
3. **增益集中在雷达相关与三模态提示**：Radar Only（+8.03）、Camera+Radar（+8.16）、C+L+R（+10.83 mAP）增益最大，验证了属性路由的精确设计目标；
4. **鲁棒性与效率兼顾**：模态缺失下降更平缓，实时吞吐量（全三模态9.2 FPS）仍接近实时；
5. **跨数据集泛化能力**：在Mono3DRefer上无需任务特定调参即达53.05% Acc@0.5，超过专门方法Mono3DVG-TR（44.25%）近9个百分点；
6. **LRPS与SPMA互补而非重叠**：两者独立贡献相近但联合增益更大。

### 7. 优点

- **数据集首创性**：首个同时包含相机+LiDAR+4D雷达三种传感器、且文本提示显式对齐物理属性的3D视觉定位数据集，填补现有benchmark空白；
- **严谨的数据标注流程**：量化特征可视化（5米间隔同心圆、RCS/速度投影）消除了人工距离估计误差；“物理事实约束”的提示生成规则禁止主观推断；三段式专家评审确保语义-物理一致性；
- **方法设计动机清晰**：每一模块都对应一个明确的问题——LRPS解决标定依赖脆弱问题，SPMA解决模态不平衡问题——而非堆砌模块；
- **消融实验充分且互锁**：模块级、策略级、内部机制级三层消融体系完整，交叉验证结论可靠性；
- **跨数据集验证**：在完全不同来源的KITTI/Mono3DRefer上验证泛化性，增强了结论的普适性；
- **物理一致性验证**：BEV热力图（Fig. 10）显示仅视觉可感知的属性（颜色）在LiDAR/雷达热力图上几乎无响应，证明模型确实按物理线索路由而非全局融合。

### 8. 不足与局限

- **单一数据源局限**：Talk2Sensors完全基于View-of-Delft构建，该数据集规模有限（8,682条指令），场景和天气条件单一，可能限制模型的域泛化能力；
- **恶劣天气场景缺失**：论文自己指出雷达在恶劣天气的鲁棒优势，但数据集未覆盖雨、雪、雾、夜间场景，导致这一核心优势未被定量验证；
- **提示分布的类别偏差**：LiDAR-only提示占31.7%，而需要三模态融合的仅占2.9%，提示分布存在不平衡，可能影响模型对多模态协同的训练充分性；
- **计算效率有进一步提升空间**：全三模态FPS仅9.2，处于“接近实时”的水平，距离真正车载实时（>30 FPS）仍有差距；
- **门控机制粒度较粗**：SPMA门控是样本级（非逐查询），且Top-K强制稀疏可能对不同类别/空间位置的目标区分度不足；表IX也显示soft gating alone（50.628）与Top-K=2（51.000）差距很小，说明Top-K收益有限；
- **无真值传感器依赖标注**：数据集的提示基于传感器可观测物理属性标注，但未显式标注每条提示具体需要哪些传感器，评价时以分组统计替代，无法逐样本验证路由准确性。
