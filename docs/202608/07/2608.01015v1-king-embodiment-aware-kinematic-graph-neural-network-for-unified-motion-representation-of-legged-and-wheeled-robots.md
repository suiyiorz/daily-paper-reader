## 摘要
运动学模型为无特征环境中的里程计估计提供可靠的运动约束，在这些环境中，外部感知退化且 IMU 积分漂移。基于学习的运动学模型通过捕获非线性效应，能够比基于模型的方法实现更精确的里程计估计；然而，大多数现有的基于学习模型是在单一具身上训练的，并且对新具身的泛化能力较差。这种泛化是困难的，因为本体感觉测量的含义和结构在不同具身之间有所不同，包括关节和地面接触元素（例如轮子、脚）的数量。为了应对这一挑战，我们提出了 KING，一种基于图神经网络（GNN）的运动学模型，通过将机器人具身表示为公共图来显式地整合它们。我们展示了轮式和腿式运动学模型可以通过统一表示来表达，从而使得一个模型可以同时适用于轮式和腿式机器人。在涵盖多种具身的数据集上进行训练，KING 提供了轮式和腿式运动学的统一表示，并在真实环境中实现了高精度的里程计估计。KING 仅使用具身描述（例如 URDF 文件）和机载本体感觉（编码器和 IMU）即可估计准确的里程计，并且可以通过仅一分钟数据的少样本学习来适应新的机器人具身，从而避免为每个机器人从头开始在新数据集上重新训练。项目页面可在以下网址获取：https://smrg-aist.github.io/king_project_page/

## Abstract
Kinematic models provide reliable motion constraints for odometry estimation in featureless environments, where exteroceptive sensing degrades and IMU integration drifts. Learning-based kinematic models can achieve more accurate odometry estimation than model-based methods by capturing nonlinear effects; however, most existing learning-based models are trained on a single embodiment and generalize poorly to new embodiments. This generalization is difficult because the meanings and structures of proprioceptive measurements vary across embodiments, including the number of joints and ground-contact elements (e.g., wheels, feet). To address this challenge, we propose KING, a Graph Neural Network (GNN)-based kinematic model that explicitly incorporates robot embodiments by representing them as a common graph. We show that wheel and leg kinematic models can be expressed by a unified representation, enabling a single model for both wheeled and legged robots. Trained on datasets spanning diverse embodiments, KING provides a unified representation of wheeled and legged kinematics and achieves high-accuracy odometry estimation in real environments. KING estimates accurate odometry using only an embodiment description (e.g., a URDF file) and on-board proprioception (encoders and an IMU) and can be adapted to new robot embodiments through few-shot learning with only one minute of data, avoiding retraining from scratch on a new dataset for each robot. The project page is available at: https://smrg-aist.github.io/king_project_page/

## 论文详细总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：在无特征环境（featureless environment）中，基于外部传感器（LiDAR、相机）的里程计估计会因特征匹配失败而失效，IMU 积分则会因噪声累积而漂移。此时，基于运动学模型的里程计能提供可靠的运动约束，因为它主要依赖编码器测量（关节角、角速度等），积分量更少。
- **问题**：传统解析运动学模型难以精确建模轮/足打滑、地面变形等非线性效应；而现有学习式运动学模型通常只在单一机器人“具身”上训练，难以泛化到不同形态（morphology）或不同结构参数的机器人。跨具身泛化困难的根本原因在于本体感觉输入（关节数量、接触元件数量、每个传感器的物理含义）随机器人变化，输入维度和特征语义均不一致。
- **目标**：提出一种能够**统一表示轮式与腿式机器人运动学**的学习方法，使得一个模型即可服务于多种机器人形态，并可通过极少数据快速适配新机器人，从而避免为每个平台重新收集数据、重新训练。

### 2. 论文提出的方法论

**核心思想**：将机器人运动学统一建模为“操作臂运动学”，再把机器人的结构、本体感觉观测统一编码为图，用图神经网络（GNN）学习跨形态的运动学模型。

**关键技术细节**：

- **统一运动学表示**
  - 腿式机器人：第 *j* 条腿的足端速度满足 `^L v_B = -J_j θ̇_j`，其中 *J* 是雅可比矩阵，`θ̇_j` 为关节角速度，即足端速度决定身体速度。
  - 轮式机器人：车轮速度满足 `^W v_B = -r θ̇_j`，其中 *r* 为轮半径，`θ̇_j` 为轮角速度。
  - 作者证明轮式运动学可视为 1-DOF 操作臂的特例：当 1-DOF 臂的杆长 *l* 等于轮半径 *r*、关节角 *θ* = 0（接地）且持续接触时，其末端速度恰好退化为 `r θ̇`；因此轮和腿在操作臂运动学框架下具有统一表达。
- **图结构设计（Kinematic Graph）**
  - 节点类型：Base（机器人基座）、Joint（转动关节）、Contact（车轮或脚）。
  - 边：按机器人运动学连接关系构造，例如 Base 与相邻 Joint 连接、Joint 与 Contact 连接。
  - 节点特征：
    - Base：IMU 与基座相对位姿、IMU 加速度和角速度时间序列；
    - Joint：相邻关节间相对位姿、关节角/角速度的三维向量（显式编码旋转轴，避免 DH 约定偏差）；
    - Contact：关节到接触点的相对位姿、接触半径（轮半径或脚踝球半径）、接触状态（二进制）。
  - 为增强对传感器噪声的鲁棒性，所有传感器特征拼接当前及过去 *k* 个时刻（文中 *k*=2）。
- **GNN 架构（KING）**
  - 类型特定编码器（Base/Joint/Contact）将原始特征映射到 90 维隐空间。
  - 采用消息传递机制（Message Passing）沿图传播信息，各层更新公式如 `h_B^(l+1) = σ(W_B^(l) h_B^(l) + mean_{m∈N(B)} W_(J→B)^(l) h_J_m^(l))`，权重按节点类型与边方向区分。
  - 解码器分别从 Base 节点输出身体 twist `ξ_t ∈ R^3`，从 Contact 节点输出接触点相对基座的 6-DOF 位姿 `{^B T_C_n,t}`。
- **损失函数**
  - 由基座 twist 损失和接触位姿损失共同构成，采用不确定性加权（[Kendall et al. 2018]）平衡平移/旋转分量。
- **数据生成**
  - 在 Gazebo 物理仿真器中构建自动采集管线，覆盖六种形态：2WD/4WD 差速、3WD/4WD Ackermann、四足和六足机器人。
  - 对相同形态进行**领域随机化（domain randomization）**：改变轮径、连杆长度、IMU 位置等参数，以产生多样性具身。
  - 训练时对本体感觉数据做加噪数据增强以缩小 sim-to-real gap。

**训练流程**：多形态数据混合预训练 → 新形态测试时用极少量（约 1 分钟）目标数据微调（few-shot fine-tuning）。

### 3. 实验设计

**数据集与场景**：

- **仿真数据集**：使用 Gazebo 物理仿真器采集六个机器人形态的运动数据（直线、转弯、蛇形等轨迹，含加减速）。对每个形态随机化实施例参数（如两倍连杆差异、八倍轮径差异）。
- **真实场景**：两个测试平台——四轮差速机器人“Rover Mini”（Rover Robotics）和四足机器人“Unitree Go1”，在室内平坦地面上验证。参考轨迹由 Livox MID-360 的 LiDAR-IMU SLAM 提供，用于生成微调用的 twist 真值。

**基准与对比方法**：

- **模型基线（Model-based）**：解析运动学模型，其中平移速度由运动学公式（式 1/式 2）计算，旋转速度由 IMU 陀螺仪提供。该基线无法建模打滑等非线性效应。

**实验类型**：

1. **跨类迁移实验（Cross-class transfer）**：验证统一表示的有效性。分别以轮式类数据训练、腿式类数据测试，以及反向训练/测试，逐步增加源类数据比例（0%、10%、20%），观察目标类误差变化。
2. **留一形态交叉验证（Leave-one-morphology-out）**：每次将一种形态作为未见目标，其余五种形态预训练，再进行零样本（K=0%）和不同微调数据量（K=0.1%、0.5%、1%，对应约 1~10 分钟数据）下的测试。
3. **Sim-to-real 实验**：在两种真实机器人上执行少样本微调，评估里程计 twist 的 RMSE，并与模型基线对比。

**关键结果**：

- 跨类迁移：在轮→腿和腿→轮两种设置下，增加源类数据均显著降低目标类误差（如轮→腿平移 RMSE 从 0.206 降至 0.160 m/s），证明统一表示下两类运动学特征可互惠。
- 留一交叉验证：零样本下轮式机器人（2WD/4WD Ackermann）误差较低，腿式机器人误差较高；加入 0.1%（约 1 分钟）数据微调后，各形态误差大幅下降，接近“使用全形态”基准。
- 真实机器人：KING 的平移/旋转 RMSE 为 0.038 m/s 和 0.022 rad/s（四轮差速）、0.049 m/s 和 0.026 rad/s（四足），轨迹明显优于模型基线，且与仿真结果相当。

### 6. 论文的主要结论与发现

- 轮式和腿式运动学可统一为操作臂运动学，通过 1-DOF 关节模型等价推导得出。

### 7. 优点

- **理论创新**：给出了轮/腿运动学的统一代数推导，为跨形态学习提供了坚实的理论基础。
- **架构设计**：利用 GNN 处理可变图结构，输入特征显式包含结构参数（URDF）和本体感觉，避免固定维度限制，天然支持任意关节数和接触元件数。
- **数据高效性**：通过领域随机化仿真数据预训练 + 极短真实数据微调（1 分钟），大幅降低部署成本，实际应用价值高。

- **实验设计严谨**：跨类迁移和留一验证能较好分离“统一表示”和“结构泛化”两个层面的贡献。

### 8. 不足与局限

- **对比方法缺失**：没有与 AnyCar、Legolas、WHONet 等学习式运动学模型进行公平比较，难以评估相对 SOTA 的优势。

- **IMU 与基座外参**：网络需要 IMU-基座位姿作为输入，若该标定有误差，可能影响精度。
- **训练数据规模与算力未披露**：缺少模型参数量、推理时延、训练数据量（样本数/时长）等参数，影响复现性和工程评估。

- **未探索在线自适应**：作者在展望中提到未来会结合在线学习，说明当前方法对新环境仍需离线微调步骤。
