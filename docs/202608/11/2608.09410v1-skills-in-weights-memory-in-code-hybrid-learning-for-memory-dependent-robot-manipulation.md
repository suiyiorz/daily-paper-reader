## 摘要
现代视觉-语言-动作（VLA）策略已获得广泛的操作技能，但通常仅基于当前观察或短固定长度历史生成每个动作块。然而，真实世界的操作往往是非马尔可夫的，要求机器人从长时程交互历史中保留并推理任务相关信息以决定下一步动作。为应对这一挑战，我们提出HyMeS，一种混合学习框架，利用编码代理的推理与记忆管理能力来引导马尔可夫VLA完成记忆依赖型操作。具体而言，HyMeS通过基于梯度的模仿学习学习低级运动技能，同时通过启发式学习，从试运行反馈中迭代更新可执行启发式系统，使编码代理获得高级记忆管理策略。此外，我们通过多模态阶段完成验证来闭环引导与执行，利用本体感觉信号和多帧VLM判断更新记忆。与端到端记忆增强型VLA相比，HyMeS仅需可复用运动技能的演示数据，而无需为每个依赖历史的任务配置提供演示，从而实现数据高效的组合泛化。在RoboMemArena基准上，与pi0.5相比，HyMeS将平均累计成功率从52.5%提升至66.2%，平均任务成功率从41.3%提升至60.1%，同时累计成功率超越PrediMem 4.5个百分点，任务成功率超越14.5个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现代视觉-语言-动作（VLA）模型在机器人操作上取得了显著进展，但大多数 VLA 本质上是**马尔可夫（Markovian）**的——每次只基于当前观测或短固定长度历史生成动作块。然而，真实世界中的操作任务往往是**非马尔可夫（non-Markovian）**的，机器人需要从长时程交互历史中保留、推理任务相关信息（如起始阶段的提示卡片、已完成的操作次数、物体–位置关联等）才能决定下一步动作。这种历史依赖信息无法从当前观测中恢复，导致马尔可夫策略在记忆依赖型任务上表现不佳。
- **核心矛盾**：现有的记忆增强型 VLA 大多通过扩展观测上下文或增加可学习记忆模块，将历史条件化策略端到端地从机器人演示中学习。这种方法把“记忆获取”与“运动学习”纠缠在一起，当任务状态的组合空间很大时，需要覆盖各种组合配置的昂贵演示数据，即使这些配置并不涉及新的物理技能。
- **论文核心主张**：将**运动技能学习**与**记忆策略学习**分离——技能存于权重（梯度模仿学习），记忆存于代码（编码代理的启发式学习），以数据高效的方式实现组合泛化。

## 2. 论文提出的方法论

### 2.1 核心思想
HyMeS（**Hy**brid Learning for **Me**mory-**D**ependent Manipulation）是一个混合学习框架，由两部分组成：
- **权重空间中的运动技能**：使用流匹配（flow-matching）VLA（如 π0.5），通过梯度模仿学习微调，参数固定后不再改变。
- **代码空间中的记忆策略**：由编码代理（coding agent）通过启发式学习，从 rollout 反馈中迭代更新一个可执行的启发式程序 P = (C, V, U)，其中 C 为约束选择规则，V 为事件验证规则，U 为记忆更新规则。

### 2.2 关键流程公式与算法

**问题建模**：任务被建模为记忆依赖型策略
π\*(a_t | h_t, ℓ) = π\*(a_t | o_t, z_t, ℓ)，其中 z_t = ϕ(h_t) 是紧凑任务状态，无法从当前观测 o_t 单独恢复（观测别名化）。

**运动技能学习**：使用流匹配目标微调 VLA
θ\* = arg min E[‖v_θ(a_τ, τ | o, ℓ) − (a − ε)‖²]
其中 a_τ = (1−τ)ε + τa，最终 θ\* 固定不变。

**记忆策略学习**：编码代理根据 rollout 执行轨迹 ξ_n 和基准的阶段判定 b_n，迭代修订程序
P^(n+1) = Edit(P^(n), ξ_n, b_n)。

**记忆条件化动作引导**：每个阶段选择可微约束 R_ρt 注入流匹配速度场
v̂ = v_θ\*(a_τ, τ | o_t, ℓ) + λ_t ∇a_τ R_ρt(a_τ, o_t; s_t)
其中 λ_t 使用 sigmoid 衰减调度：靠近接触区域时引导衰减，让学到的运动策略主导接触丰富的执行。

**多模态阶段完成验证（PACE）**：
- 本体感觉证据（proprioceptive）：检测与动作相关的运动模式，通过符号锁存保留持续事件。
- 视觉证据：Qwen3-VL-8B 基于当前阶段和最近至多 5 帧 RGB 图像判断阶段是否完成。
- 两种信号融合：d_r = e_prop ∨ e_vlm，并在一滑动窗口（w=5, k=3）内投票：至少 k 个最近查询通过才触发阶段推进事件。

## 6. 论文的主要结论与发现

1. **记忆缺失是可补偿的**：在相同策略权重下，HyMeS 将 π0.5 的 CSR 从 52.5% 提升至 66.2%，TSR 从 41.3% 提升至 60.1%，证明可执行代码记忆可以弥补马尔可夫 VLA 的内建记忆缺失。
2. **优于端到端记忆增强**：HyMeS 相比 PrediMem 在 TSR 上高出 14.5 个百分点（60.1% vs. 45.6%），表明混合设计比端到端记忆学习更有效地将中间进展转化为完整任务成功。
3. **按任务类别的收益差异**：
   - 计数类 TSR 提升最大（+30.0 点），转移类 +26.6 点，顺序类 +22.5 点——显式计数器、物体–位置关联和阶段状态直接受益。
   - 遮挡类最困难：PrediMem 的 CSR 反而低于 π0.5（38.3% vs. 50.4%），表明不可靠的记忆会主动误导执行；HyMeS 在 CSR 上与 π0.5 持平（50.6%）但 TSR 提升 7.0 点，验证了阶段验证机制可限制错误绑定带来的损害。
4. **真实机器人验证**：SO-101 上 TSR 从 25.7% 提升至 57.1%，三种符号状态（提示保留、计数、源–位置关联）均有效。
5. **数据效率与可解释性**：只需一套微调权重即可支持所有任务，新记忆配置通过编辑代码而非收集演示实现；符号状态每步可读，失败可定位至记忆更新、运动执行或事件验证三个环节。
6. **消融结论**：rollout 经验将 CSR/TSR 提升 8.5/18.4 点；视觉+本体感觉双模态互补，任一单独使用都会显著降低性能（视觉-only 下降 16.0/21.7 点，本体感觉-only 下降 8.8/8.4 点）。

## 7. 优点

- **新颖的问题拆分视角**：将记忆依赖任务拆分为“技能（权重）+ 记忆（代码）”的混合学习问题，避开组合演示采集的数据瓶颈。
- **保留马尔可夫策略的简洁性**：VLA 权重固定，记忆机制完全外部化，避免了在权重空间中学习离散、组合式记忆逻辑带来的遗忘和不可解释问题。
- **记忆可编辑、可检查**：符号状态在每一步可读，失败可精确归因于记忆/执行/验证，便于调试和迭代。
- **双向闭环设计**：不仅有从记忆到策略的引导（steering），还有从执行反馈（本体感觉 + 视觉）回到记忆的更新（PACE），区别于单向的推理时引导方法。
- **实验设计公平性**：与 π0.5 共享完全相同权重和演示，隔离了记忆机制本身的效果；在相同 12 任务协议上重评估 PrediMem（而非照搬其公布的 26 任务结果）。
- **现实部署验证**：在真实 SO-101 机器人上验证，不局限于仿真。

## 8. 不足与局限

- **记忆表示能力受限**：当前仅支持可用紧凑符号状态表示的历史信息；更开放、更复杂的层级或多模态记忆（如长对话上下文、非结构化感知事件）尚不支持。
- **任务成功仍受限于底层能力**：正确的记忆状态和约束不保证接触丰富操作的成功（论文中 Missed Grasp、Extra Press 等失败案例表明运动执行仍可能失效）。
- **推理成本与延迟**：周期性 VLM 查询和编码代理调用增加了单 episode 的推理延迟与费用，论文未量化具体开销。
- **遮挡场景最脆弱**：视觉完成证据在目标隐藏时可靠性下降，HyMeS 在遮挡类 CSR 上仅与 π0.5 持平，说明该方法在视觉遮挡下仍有明显短板。
- **计数类早期阶段失败**：HyMeS 在计数类 CSR 上低于 PrediMem（60.3% vs. 72.2%），失败集中于早期执行阶段——可能源于冻结 VLA 的固有限制或偶发引导干扰，说明记忆机制与底层策略的协作仍有优化空间。
- **部分任务收益有限**：个别任务（如 Cookies + popcorn → microwave）TSR 仅从 20.0% 提升至 20.0%，没有任何改进——当底层运动技能本身不足时，记忆机制无法提高任务成功率。
- **算力信息缺失**：未报告 GPU 数量、训练时间、推理延迟等量化资源指标。
- **统计严谨性不足**：未报告多次随机种子的方差或显著性检验，RoboMemArena 上每任务 episode 数（10–20）相对有限。
