## 摘要
视觉-语言导航（VLN）使机器人能够在未见过的环境中遵循指令。最近出现了一种免训练范式：机器人查询多模态大语言模型以理解其观察并规划下一步行动。然而，基于图像流或密集地图的长时程导航不可避免地会引入不断增长的记忆和推理瓶颈。我们提出了HAM-VLN，一种决策耦合的、由智能体书写的记忆，赋予机器人一个持久的、基于深度感知的世界图。在与选择下一步行动相同的模型调用中，HAM-VLN还记录语义和反思信息——包括房间类型、物体、导航进度和失败记录。近期航点以逐字形式保留在有界窗口内，而较旧的历史仅通过按相关性、近因性和显著性评分的检索，以及一跳拓扑扩展重新进入上下文。该设计无需在每个航点决策之外增加额外的大语言模型调用。与先前方法相比，HAM-VLN不仅提升了各种导航指标，还将上下文长度减少了65%以上。具体而言，HAM-VLN在VLN-CE R2R上实现了61.0%的成功率（SR），在VLN-CE RxR上实现了52.7%的SR，在HM3D-v2 ObjectNav上实现了79.7%的SR，且无需任何训练。

## Abstract
Vision-and-language navigation (VLN) enables robots to follow instructions in previously unseen environments. Recently, a training-free paradigm has emerged: the robot queries a multimodal LLM to understand its observations and plan the next action. However, long-horizon navigation based on either image streams or dense map inevitably introduces a growing memory and reasoning bottleneck. We present HAM-VLN, a decision-coupled, agent-authored memory that equips the robot with a persistent, depth-grounded world graph. In the same model call used to select the next action, HAM-VLN also records semantic and reflective information---including room type, objects, navigation progress, and failure notes. Recent waypoints remain verbatim within a bounded window, while older history re-enters the context only through retrieval scored by relevance, recency, and salience, together with one-hop topological expansion. This design requires no additional LLM calls beyond the per-waypoint decision. Compared to previous methods, HAM-VLN not only improves various navigation metrics but also reduces the context length by more than 65%. Specifically, HAM-VLN achieves 61.0% Success Rate (SR) on VLN-CE R2R, 52.7% SR on VLN-CE RxR, and 79.7% SR on HM3D-v2 ObjectNav without any training.

# HAM-VLN 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉-语言导航（VLN）要求机器人在未见过环境中根据自然语言指令导航到目标位置。近年出现的零样本范式利用多模态大语言模型（MLLM）直接理解感知并规划动作，无需训练。
- **核心问题**：长时程导航中，无论使用**原始视觉历史**（按轨迹不断增长上下文）还是**稠密语义地图**（按面积增长存储），都会引入随轨迹持续增长的“记忆与推理瓶颈”——MLLM 每次调用只能处理有限上下文，而后续决策需要较早位置、指令进度、失败分支等信息。
- **整体含义**：导航系统需要一种**有选择性、任务相关、可回溯**的外部记忆机制，而不是简单堆叠历史或地图，以实现高效零样本长程导航。

## 2. 提出的方法论

### 核心思想
- 提出 **HAM-VLN**：一种“决策耦合、由智能体书写的记忆”系统，基于**深度支撑的世界图**（depth-grounded world graph）存储长期导航状态。
- 在同一 MLLM 调用中同时完成动作选择与记忆写入（语义、物体、进度、失败记录），**不增加额外 LLM 调用**。
- 近期观测保留在有限工作窗口内（verbatim），旧历史通过**子目标条件检索**和**一跳拓扑扩展**返回上下文。

### 双过程架构
- **System 2（慢速推理与规划）**：大 MLLM（Gemini-3.1-Pro），每个航点读取指令、当前观测、检索到的记忆上下文，输出高层决策（方向、回溯或停止），并生成结构化 JSON 记录（动作、语义进度、推理理由）。
- **System 1（快速策略/接地）**：轻量 MLLM（Qwen3.6-35B），将高层意图转化为像素空间目标框；控制器基于深度图和相机内参反投影到 3D，并通过快速行进法生成短程轨迹。
- 策略分解式：`At = πrobot(φ2(T, Ot, Mt), φ1(at, Ot), Dt, Pt, Kcam)`。

### 分层代理记忆
- 记忆状态：`Mt = Wt ⊕ Lt ⊕ R(Gt, qt)`
  - `Wt`：最近 K 个航点的原始帧流（工作记忆）
  - `Lt`：有序指令进度记录
  - `Gt`：长期世界图（地点-对象图）
  - `R`：子目标条件读取操作
- 世界图结构：地点节点、对象节点、地点-地点拓扑边、地点-对象语义边，由单链接聚类逐步构建。
- 四种功能视图：
  - **工作记忆**：最近帧流，逐字保留；
  - **情景记忆**：访问轨迹和时序元数据，提供近因性；
  - **语义记忆**：地点-对象内容与拓扑，提供相关性；
  - **反思记忆**：检索到地点时附带的失败证据，用于指导避免重复错误。
- 检索评分：`st(p) = α·rel(qt,p) + β·rect(p) + γ·sal(p)`，其中 rel 为查询-地点余弦相似度，rec 为近因性（指数衰减，ρ=0.85），sal 为显著性（地标和对象丰富度），权重 (α,β,γ)=(1.0,0.3,0.3)。
- 拓扑读出：种子数 Ks=3，最终地点数 Kp=5，种子扩展一跳并包含当前位置邻域。
- 失败回溯机制：当 System 2 决定回溯到旧航点时，将回溯路段对应地点附加决策理由作为失败证据；该证据是**建议性**的，不改变检索分数，只在地点被重新检索时返回上下文供重新解释。

## 6. 主要结论与发现

- **性能提升**：在 R2R-CE 上达到 61.0% SR / 48.1% SPL，NE 降至 3.92m；RxR-CE 上达到 52.7% SR / 35.7% SPL；HM3D-v2 ObjectNav 上达到 79.7% SR / 43.2% SPL，均超过此前最强的零样本方法，其中 ObjectNav 也超过表格中的监督方法。
- **记忆效率**：相比完整原始历史，上下文长度减少约 67%，同时 SR 和 SPL 更高（61.0 vs 53.3 SR，48.1 vs 38.1 SPL）。
- **组件重要性**：
  - 世界图是最关键组件：去掉后 NE 上升约 1.05m、SR 下降 9.3 点；

## 7. 优点

- **决策耦合式记忆写入**：动作选择和记忆更新在同一个 MLLM 调用中完成，没有额外推理开销。
- **分层记忆设计**：工作/情景/语义/反思四种视图分工明确，兼顾时序、语义和失败经验。
- **世界图表示高效**：图大小随发现的地点/对象增长，而不是随面积或轨迹增长，适合部分可观测环境。
- **可解释性与可回溯性**：失败证据以自然语言形式附着在具体地点上，回溯时返回上下文，行为可理解。
- **严格的可控实验**：主结果报告 3 次运行均值±标准差，消融覆盖充分，推理成本也做了量化。
- **零样本/免训练**：无需训练直接达到高分，并超越部分监督方法，展示了 MLLM 时代导航记忆设计潜力。
