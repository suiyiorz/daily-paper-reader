## 摘要
端到端（E2E）自动驾驶算法需要在提供高视觉保真度、强交互性和实时性能的仿真环境中进行严格的闭环验证。现有方法从游戏引擎到静态神经渲染，本质上在这些需求之间进行权衡，并难以应对E2E测试所必需的动态场景合成。为弥补这一差距，我们提出了一种专门针对大规模E2E评估的分离式3D高斯泼溅（3DGS）框架。我们利用以对象为中心的规范表示，将场景从根本上分解为高保真静态背景和可操控的动态代理。为解决由此产生的表示冲突，我们引入了三个针对性模块：（1）通过感知剪枝和向量量化的资产压缩，用于实时交通渲染；（2）利用语义拓扑进行地图引导的几何配准，以严格对齐轨迹；（3）基于代理的重光照，传递环境光照以实现无缝的光度集成。大量实验表明，DecoupleGS实现了保真度与效率的平衡权衡，改善了度量和光度一致性，并为E2E自动驾驶评估提供了一个实用的闭环传感器仿真平台。

## Abstract
End-to-end (E2E) autonomous driving algorithms require rigorous closed-loop validation in simulation environments offering high visual fidelity, strong interactivity, and real-time performance. Existing approaches, from game engines to static neural rendering, inherently trade off these requirements and struggle with the dynamic scene composition essential for E2E testing. To bridge this gap, we propose a novel decoupled 3D Gaussian Splatting (3DGS) framework tailored for large-scale E2E evaluation. We fundamentally decompose scenes into a high-fidelity static background and manipulable dynamic agents using an object-centric canonical representation. To resolve resulting representational conflicts, we introduce three targeted modules: (1) asset compression via perceptual pruning and vector quantization for real-time traffic rendering; (2) map-guided geometric registration leveraging semantic topology to strictly align trajectories; and (3) proxy-based relighting transferring ambient illumination for seamless photometric integration. Extensive experiments demonstrate that DecoupleGS achieves a balanced fidelity-efficiency trade-off, improves metric and photometric consistency, and provides a practical closed-loop sensor simulation platform for E2E autonomous driving evaluation.

## 2. 方法论

### 2.1 核心思想
提出 **DecoupleGS**，一种解耦式 3D Gaussian Splatting 框架：将场景分解为 **持久静态背景 + 可操控动态智能体**（对象中心规范表示），并在光栅化前数学融合两者，无需网络推理。整体流水线包含三个针对性模块（资产压缩、地图引导配准、代理重光照），分别解决效率、几何与光度冲突。

### 2.2 解耦表示与统一渲染
- **场景定义**：全局场景 Ω(t) = 静态背景 S_bg ∪ (K 个动态智能体的刚体变换 ∪)。
- **坐标变换**：对每个动态智能体的高斯均值 μ 和协方差 Σ，施加 6-DoF 刚体变换：
  - μ^(W) = R_k μ^(L) + t_k
  - Σ^(W) = R_k Σ^(L) R_k^T
- **SH 系数旋转**：使用 **Wigner D 矩阵** 对球谐系数进行旋转，以保持旋转后视相关反射的正确性。
- **统一光栅化**：所有高斯原语（背景+动态）合并为统一列表，按深度排序做 α 混合；采用保守视锥剔除、静态背景缓存复用、仅更新移动体积的批量空间变换等硬件级优化，保证交互帧率。

### 2.3 资产压缩（Asset Compression）
- **显式重要性评分**：对每个高斯原语计算标量重要性分数：
  \[
  s_i = w_{vis} V_i + w_{col} D_i + w_{ent} H_i
  \]
  其中 V_i 为可见性估计（训练视图中不透明度贡献），D_i 为颜色对比度（相对局部背景的感知显著性），H_i 为邻域纹理复杂度熵。低于阈值 τ_s=0.005 的原语被剪枝。
- **向量量化（VQ）**：将协方差 Σ_i 与 SH 颜色系数 c_i 分别映射到可学习码本（K_shape=512、K_color=1024），用 EMA（γ=0.99）更新码本，以紧凑整数索引替代浮点张量。

### 2.4 地图引导几何配准（Map-Guided Registration）
- **语义拓扑提取**：优先使用数据集提供的 HD map 车道中心线，缺失时用 MapTRv2 提取。
- **平面配准**：构建轨迹与车道几何的成本矩阵（欧氏距离+航向偏差），用**约束 DTW** 求最优弯折路径；再通过**正交 Procrustes 分析**求解最优 SE(2) 刚体变换，消除系统性横向漂移。
- **垂直接地**：3DGS 无连续表面网格，故用**不透明度加权深度累积**计算车辆底角锚点的高度，再最小二乘拟合局部地面平面，确定车辆 z 坐标与俯仰/侧倾姿态，保证车轮与地面物理接触。

### 2.5 代理重光照（Proxy-based Relighting）
- **局部探针采样**：将背景 SH 系数视为密集光照探针场，对车辆位置 x 聚合邻域背景高斯的 SH 系数（按可见性与距离加权），得到局部环境描述子 L(x)。
- **线性 SH 传递**：离线通过最小二乘回归在合成数据集上标定算子 T(·) 和 b(·)，在线端对车辆 SH 系数执行仿射调制：
  \[
  c_{out} = T(L(x)) \otimes c_{can} + b(L(x))
  \]
  完全避免在线 MLP 推理。
- **接触阴影**：在地面投影车辆足迹形状的超椭圆阴影掩码，并根据环境描述子的 DC 分量（主光强度）动态调节背景高斯强度，实现晴天阴影浓、阴天/夜晚阴影淡的效果。

## 6. 主要结论与发现

1. **保真度-效率平衡**：DecoupleGS 在所有流量密度下均保持 Top-2 的保真度与效率一致性，体现实用性优于单一指标最优。
2. **可扩展性**：在 50 个动态智能体的极端设置下，VRAM 近似线性增长且保持可用帧率，而 Vanilla 3DGS 在密集交通前即 OOM。
3. **几何与光度一致性**：地图引导配准显著降低轨迹漂移（对比无配准 ADE 从 0.05 m 升至 0.48 m）和地面穿透；代理重光照将 PAE 从 48.5° 降至 6.8°，插入车辆能自然继承环境光照和接触阴影。
4. **Sim-to-real 行为一致性**：在开环测试中，UniAD 在 DecoupleGS 渲染下的 mADE（0.82 m）和 minTTC（3.3 s）最接近真实输入（0.76 m / 3.5 s），优于 HUGSIM、RealEngine、OASim。
5. **闭环可用性**：DecoupleGS 在闭环测试中获得最高 Driving Score（0.884）和路线完成度（0.956），同时 45 FPS 的渲染速度远快于 HUGSIM（12 FPS）和 OASim（18 FPS）。
6. **难度分级压力测试有效**：从 Easy 到 Extreme，UniAD 和 VAD 的 DS/SR/RC/minTTC 均系统性下降，且 VAD 在 Hard/Extreme 下退化更明显，说明 DecoupleGS 能生成暴露规划器弱点的可控压力场景。
7. **模块即插即用**：将压缩、配准、重光照模块集成到现有仿真器中能提升渲染速度与光度一致性，验证了模块的求解器无关性。

## 8. 缺点与局限性

- **静态背景假设**：DecoupleGS 将背景视为“永久静态”并在光栅化前合并，因此无法处理背景中真实发生的长时变化（如树叶晃动、水渍反光、季节更替、道路施工）。虽通过代理重光照缓解了光照一致性问题，但背景本身的动态性缺失仍是场景真实感的天花板。
- **车辆资产域差距**：车辆模型取自 3DRealCar 合成数据集，其材质、几何细节与 nuScenes/PandaSet 中真实车辆仍存在差距。论文未量化“合成车辆资产嵌入重建场景”的感知级域差距（如下车身反光、车窗透明度），仅用 Masked PSNR 与 PAE 间接度量。
- **重光照模型的简化**：代理重光照本质是“SH 到 SH”的线性仿射映射，无法处理高光金属漆面的镜面反射、透明车窗的折射叠加，以及多光源（如路灯与车灯同时作用）的非线性光照场景。实验中的 PAE=6.8° 已说明误差不可忽略，在强逆光/多光源场景可能进一步恶化。
- **地图依赖与配准假设**：地图引导配准依赖 HD map 车道中心线（缺失时依赖 MapTRv2 的提取精度）。若车道拓扑错误或场景中车辆运动与车道无关（如停车场、越野工况），约束 DTW 的假设将失效，轨迹校正可能引入新的系统性偏差。
- **闭环评估的协议局限**：闭环测试中背景车辆使用 IDM+MOBIL 行为模型，其驾驶风格固定、不具学习能力，无法模拟激进、过激或非理性的人类驾驶行为；下游 E2E 策略也仅有 UniAD 与 VAD 两种，对更广泛的 E2E 架构（如 VLA 类模型）的适用性未验证。
- **安全问题未完全证明**：论文证明了渲染保真度与行为一致性，但“DecoupleGS 生成的仿真场景能系统性发现 E2E 规划器安全隐患”这一结论主要依赖 minTTC 与难度分级下的成功率下降，缺乏对失败案例（硬场景）的定性拆解与归因分析。
- **算力与实时性边界**：45 FPS 是在单卡 4090、特定场景规模下测得的；当背景高斯数量随场景扩大、或启用多传感器（多相机+雷达）同步渲染时，帧率可能显著下降。论文未给出 50 智能体压力测试在真实闭环（而非离线压力）中的 FPS 数据。

## 9. 总结与学术价值

DecoupleGS 的核心贡献在于：**将神经渲染从“静态重建工具”提升为“可交互、可编辑、实时闭环的仿真数据引擎”**。它通过解耦表示与三个针对性模块，系统性地平衡了 E2E 仿真中长期被忽视的三角张力——保真度、交互性与效率。与 HUGSIM、OASim 等具备完整闭环能力的仿真器相比，DecoupleGS 并不追求通用物理引擎或交通流模拟的全面性，而是专注解决“重建场景中可操控高保真智能体”这一具体问题，目标明确、工程完成度高。

论文在实验设计上表现出较强的说服力：既通过开环实验直接对比 sim-to-real 行为一致性，又通过闭环实验验证整体可用性，并辅以消融与压力测试，形成了较完整的证据链。但其方法边界同样清晰——静态背景假设、简化重光照、固定行为模型——这意味着它是“E2E 仿真的基础引擎”而非“终极仿真器”，后续工作可在此基础上扩展动态背景、物理交互与学习型驾驶者模型。

总体而言，该论文是神经渲染与自动驾驶闭环仿真交叉领域的一项扎实工作，具备方法创新性、工程完整性与实验严谨性，对希望构建高保真、可交互仿真数据引擎的研究者具有较高的参考价值。
