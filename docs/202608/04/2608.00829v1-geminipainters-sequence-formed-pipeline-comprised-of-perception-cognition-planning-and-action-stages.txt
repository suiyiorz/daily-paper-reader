# GeminiPainter: Real-Time AI-Guided Robotic Sketch Generation for Live Portraiture 

Miguel Altamirano Cabrera * Aleksey Fedoseev † Iana Zhura ‡ Dzmitry Tsetserukou §

ABSTRACT 

We present an autonomous robotic portrait-generation system com-bining real-time face detection, AI-based sketch generation, and robotic drawing. The system captures video frames, extracts facial regions, converts them into minimalist single-line sketches using the Gemini Vision API, optimizes stroke order through graph-based path planning, and executes smooth trajectories on a 6-DoF col-laborative manipulator. This perception-cognition-action pipeline integrates computer vision, neural artistic abstraction, motion opti-mization, and robot control. User ratings on a 5-point scale were high for sketch quality (4 .33), perceived execution (4 .53), and user experience (4 .65), indicating recognizable, appealing, and engag-ing robotic portraits. 

Index Terms: Human-Robot Interaction (HRI), Visual-Language Models (VLM), Collaborative Robotics, Trajectory Optimization, Immersive Analytics. 

1 INTRODUCTION 

The intersection of artificial intelligence, computer vision, and robotics has opened new possibilities for creative human-robot in-teraction. While robots have long been employed for manufactur-ing and precise manipulation, recent advances in deep learning and neural networks enable robots to engage in more nuanced, artis-tic tasks. Portrait drawing, in particular, is a compelling domain that requires simultaneous understanding of human facial features, artistic abstraction, and precise motor control. Prior work in robotic drawing has primarily focused on two paradigms: (1) reproducing pre-designed artwork through inverse kinematics and trajectory planning [10], and (2) generating draw-ings from predefined stylization algorithms [2]. Systems such as the drawing robot by Liu et al. [6] employed image processing pipelines (edge detection and edge thinning algorithms) to extract

Our contribution is focused into a real-time, interactive portrait-drawing system, together with an initial empir-ical characterization of that system. In contrast to robotic-drawing pipelines built on geometric edge detection, which produce rigid and noise-sensitive abstractions, we use a large multimodal model (Gemini) to reduce a face to a sparse single-line sketch that still preserves recognizable, expressive features. Finally, we report a user study ( N = 10) that quantifies the end-to-end latency of the pipeline and measures how users perceive the resulting portraits. 

2 METHODS 

2.1 System Architecture 

The designed pipeline of our system is presented in (Fig. 1). There, each stage is designed in a modular structure, where some steps may be replaced with a different method of trajectory gener-ation or executed by the robot of a different model. The system configuration utilized in this work consists of the following subsys-tems: 1. Live Face Detection: real-time video acquisition and facial region extraction. 2. Sketch Generation: AI-driven conversion of face image to single-line sketch via Gemini Vision API. 3. Trajectory Planning: extraction of stroke coordinates and optimal ordering. 4. Manipulator Execution: inverse kinematics, trajectory blending, and smooth arm motion. 

2.2 Live Face Detection 

We perform real-time face detection on standard USB camera input (30 FPS) using a Haar feature-based cascade classifier [12], which provides low-latency frontal-face detection without additional de-pendencies or GPU acceleration. We select the largest box, crop it with a small margin, and apply Contrast-Limited Adaptive His-togram Equalization (CLAHE) to normalize contrast under varying lighting. The enhanced face crop F is passed to sketch generation. 

2.3 AI-Driven Sketch Generation 

Traditional edge detection (Canny, Sobel) produces geometric, brit-tle abstractions sensitive to noise and lighting. Large vision models, trained on billions of diverse images and captions, implicitly learn to recognize semantically meaningful features and artistic conven-tions. Recent advances in diffusion models [4] have demonstrated remarkable capabilities in conditional image generation, which we leverage for sketch synthesis. We prompt the Gemini Vision API with a text prompt specifi-cally engineered to emphasize continuous lines: 

“Generate a minimalist, single-line portrait sketch of this face. Draw only essential features (eyes, nose, mouth, jawline). Use a single continuous or near-continuous line. Output should resemble a line drawing suitable for robotic drawing. Minimize the number of strokes.” 

This prompt serves to pinpoint desired output over two dimen-sions: semantic prioritization and physical simplicity. Firstly, re-stricting the output to ”essential features” encourages the model to focus on high-level facial geometry, discarding shading and tex-ture—a necessary simplification for real-time processing. Sec-ondly, demanding a ”continuous” or ”near-continuous” line with minimal strokes aims at the generated path that is topologically sim-ple, minimizing computational effort required for kinematic plan-ning and lowering the chance of abrupt joint movements. The model returns a PNG image of the generated sketch. We extract stroke coordinates via standard image processing:

2.4.2 Coordinate Mapping 

Face images are captured in pixel coordinates [u, v] with origin at image top-left. Whiteboard positions are defined in 3D robot coor-dinates (meters) relative to the robot base frame. We perform affine mapping which is calibrated via four-point correspondence (image corners to whiteboard corners). We maintain separate lift and draw-ing Z-offsets to ensure the tool (marker/pen) makes contact only during drawing. 

2.5 Manipulator Execution 

2.5.1 End-Effector Design and Marker Holder Mechanism 

The end-effector assembly consists of a marker holder equipped with a mechanical springer system. The springer mechanism pro-vides compliance in the vertical direction, allowing the marker to Figure 2: GeminiPainter generating and painting a human portrait in real time through VLM-based sketch retrieval and optimized path planning. 

move 1 .5 cm relative to the tool frame. This mechanical compli-ance serves multiple functions: (1) it accommodates minor vari-ations in whiteboard surface planarity, (2) it reduces impact forces during tool contact transitions, and (3) it enables uniform line width rendering by maintaining consistent contact pressure. The marker position within this compliance range is controlled via Z-axis tra-jectory commands relative to the whiteboard surface. The spring force is calibrated such that the marker maintains contact with the drawing surface under combined weight and spring force differen-tial. 

2.5.2 Trajectory Execution 

Trajectory execution is decomposed into two sequential phases: kinematic inversion to compute joint configurations from Cartesian poses, and temporal interpolation with blending to ensure smooth, continuous joint motion. This approach maintains continuous, high-speed motion while preserving geometric accuracy of stroke features. The execution protocol proceeds stroke by stroke. Starting from a retracted pose at the clearance Z-offset, the tool moves to the stroke’s start point via a blended trajectory, lowers to the drawing surface, and traces the stroke waypoints with trajectory blending. It then retracts to the clearance height and advances to the start of the next stroke, repeating until all strokes are drawn. Safety constraints include joint velocity/acceleration limits, sin-gularity avoidance, and emergency abort triggers. 

3 EXPERIMENTAL VALIDATION 

We report a user study ( N = 10 participants) that evaluates the sys-tem along two dimensions: (i) the real-time performance of the full perception–cognition–planning pipeline, and (ii) the user-perceived quality of the generated sketches, their robotic rendering, and the overall interactive experience. 

3.1 Experimental Design 

Participants and apparatus. Ten participants (3 women, 7 men; ages 23–37) of mixed background each completed one full session. For each session the system captured a live frame, detected and cropped the face, generated a single-line portrait via the Gemini Vi-sion API, extracted and ordered the strokes, mapped them to robot coordinates, and rendered the resulting drawing. 3.2 Results 

3.2.1 Real-Time Performance 

Table 1 reports the latency breakdown. Mean end-to-end latency was 8 .5 ± 2.1 s (range 6 .6–13 .8 s), satisfying the < 10 s interac-tivity target. The pipeline is overwhelmingly network-bound: the Gemini image-generation call accounted for 98 .5% of total latency (8 .38 ± 2.07 s), while all on-device computation—face detection (30 ms), stroke extraction (82 ms), path planning (9 ms), and inverse kinematics (6 ms)—together required only ≈ 127 ms (1 .5%). Local processing therefore imposes negligible overhead, and end-to-end responsiveness is determined almost entirely by the latency of the remote vision model. 

3.2.2 User Evaluation 

All ten survey items scored well above the neutral midpoint of 3 (Table 2). At the construct level, user experience was rated highest (mean 4 .65 ± 0.46), followed by perceived execution (4 .53 ± 0.63) and sketch quality (4 .33 ± 0.70). 3.3 Discussion 

The two results are complementary. The timing analysis shows that the engineered components of the pipeline, namely detection, abstraction-to-strokes, optimization, and kinematics, add negligible latency, so the system is already fast enough for interactive use and would benefit most from a faster or local generative model rather than further code optimization. The perceptual ratings show that, despite reducing a face to a sparse single-line drawing, the output is consistently recognized, judged aesthetically pleasing, and expe-rienced as engaging and autonomous. Together these support our central claim: a modern vision model coupled with a collaborative manipulator can perform a nuanced artistic task in real time and be perceived positively by non-expert users. In perspective of the ethical discussions, the authors consider it important to mention that the developed system is not architected to outperform or replace traditional artistic practice. The prompt is designed to output a stylized, single-line abstraction, and the cobot motion is grounded in kinematic optimization: with this, the robot explicitly vacates the territory of human artistic mastery and sub-jective touch. Thus, the GeminiPainter is deliberately positioning itself in a new niche where real-time computation and robotic actu-ation converge to produce interactive performative art, rather than imposing as a substitute for the painter’s studio. 

4 CONCLUSION 

We investigate an autonomous robotic portrait generation system that combines real-time computer vision, deep neural networks for sketch abstraction, path planning algorithms, and collaborative robotic control to enable autonomous portrait drawing. Key techni-cal contributions include: (1) the application of large vision mod-els (Gemini Vision) for semantically meaningful sketch generation, (2) efficient combinatorial optimization of stroke sequences to min-imize non-productive motion, and (3) trajectory blending strategies that enable smooth, continuous robot operation. Collectively, these techniques demonstrate that modern deep learning and collabora-tive manipulators can execute nuanced artistic tasks that tradition-ally required human skill. The system architecture integrates digital perception (face detec-tion), AI-driven abstraction (Gemini sketch generation), and phys-ical robotic execution ([model omitted for blind review] drawing) within a structured human-robot interaction context. The mechani-cal end-effector design—featuring a compliant marker holder with 1.5 cm vertical compliance—enables robust sketch rendering de-spite surface irregularities. Real-time feedback mechanisms and interactive user guidance establish a dynamic relationship between human subjects and robotic agents during collaborative artwork generation. Future work includes: (1) extending to multi-face collaborative drawing scenarios, (2) incorporating adaptive drawing speed and orientation strategies to achieve varied line weights and artistic ef-fects, (3) exploring alternative sketch models (fine-tuned diffusion models and user-provided style transfer), and (4) deploying the sys-tem in gallery and festival contexts to study long-term user engage-ment and feedback.
