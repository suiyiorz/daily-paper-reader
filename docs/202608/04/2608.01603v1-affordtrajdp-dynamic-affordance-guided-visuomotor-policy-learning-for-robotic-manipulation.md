## 摘要
可供性引导的模仿学习通过将视觉感知压缩为任务特定的几何约束（如固定接触点），在机器人操作任务中表现出令人印象深刻的表现。然而，常用的静态可供性在精度关键任务或物体位置扰动下可能变得不一致，导致接触后轨迹漂移。为解决这一问题，我们提出了AffordTrajDP，一种动态框架，通过以物体为中心的时序传播构建可供性轨迹，以指导渐进式操作过程。具体而言，给定RGB-D观测，我们的核心洞察是，检索到的锚定可供性（捕获末端执行器与目标物体之间期望接触点）可以通过可供性传播，利用物体的SE(3)姿态作为自然的传播媒介，向前传播，生成一个在整体执行过程中提供时间一致、状态感知指导的可供性轨迹。AffordTrajDP在ManiSkill3上达到70.0%的平均成功率，比强基线高出最多17.8%。在Galaxea A1和UR7e机械臂上的真实世界实验，涵盖StackCube、PickCup、AdapterInsertion、Ring-on-Peg、Put-in-Bowl和USB Insertion，进一步验证了在物体位置变化和外观变化下的鲁棒性，并在Galaxea A1上评估了已见和未见物体实例，消融实验确认了每个提出组件的贡献。

## Abstract
Affordance-guided imitation learning has shown impressive performance in robotic manipulation tasks by compressing visual perception into task-specific geometric constraints (e.g., fixed contact points). However, the commonly used static affordances can become inconsistent in precision-critical tasks or under object location perturbations, leading to post-contact trajectory drift. To address this issue, we propose AffordTrajDP, a dynamic framework that constructs affordance trajectories via object-centric temporal propagation to guide the progressive manipulation process. Specifically, given an RGB-D observation, our core insight is that a retrieved anchor affordance, which captures the desired contact point between the end-effector and the target object, can be propagated forward via affordance propagation, using the object's SE(3) pose as a natural propagation medium, to yield an affordance trajectory that provides temporally consistent, state-aware guidance throughout execution. AffordTrajDP achieves 70.0% average success rate on ManiSkill3, outperforming strong baselines by up to 17.8%. Real-world experiments on Galaxea A1 and UR7e robotic arms, covering StackCube, PickCup, AdapterInsertion, Ring-on-Peg, Put-in-Bowl, and USB Insertion, further validate robustness under object placement variations and appearance changes, with seen and unseen object instances evaluated on Galaxea A1, and ablations confirm the contribution of each proposed component.

- **核心缺口**：作者指出，已有方法要么只提供“**在哪里接触**”（静态接触点，如 AffordDP），要么只提供“**接触如何演化**”（物体位姿轨迹，如 SPOT/PRISM-DP），但没有单一信息同时保留两者。这是现有方法在精密操作中失败的根本原因。
- **整体意义**：该论文提出 `AffordTrajDP`，通过将检索到的锚点接触点沿预测的物体 SE(3) 位姿轨迹进行传播，生成**动态可供性轨迹**，为策略提供时间一致、状态感知的连续引导，从而提升操作精度与泛化能力。

## 2. 论文提出的方法论

### 核心思想
- 以物体为中心，利用物体的 SE(3) 位姿作为传播媒介，将静态接触点“动画化”为一条随时间变化的接触点轨迹。
- 该轨迹与预测的未来物体位姿对齐，能随物体运动而更新，克服静态先验的失配问题。

### 关键流程（Pipeline）
1. **锚点可供性生成（Anchor Affordance Generation）**
   - 从物体记忆中检索与当前目标最相似的源实例（通过 GroundedSAM 裁剪物体区域 + CLIP 特征余弦相似度）。
   - 将源实例的接触点通过**密集视觉对应**转移到目标实例，得到目标静态接触点 \(c^{tgt}\in\mathbb{R}^3\)。
2. **未来位姿轨迹预测（Future Pose Estimation）**
   - 用扩散模型（DDIM）预测目标物体未来 SE(3) 位姿轨迹 \(\{T_{t+k}\}_{k=0}^{H}\)。
   - 位姿用平移 \(t\) + 单位四元数 \(q\) 表示（7 维），并做归一化。
   - 训练时位姿轨迹表示为**源物体在目标物体坐标系下的相对位姿**，以消除绝对布局差异，提升跨实例泛化。
   - 训练目标为噪声预测 MSE。
3. **动态可供性传播（Affordance Propagation）**
   - 将静态锚点 \(c^{tgt}\) 沿预测位姿轨迹做刚性变换：
     \[
     p_{t+k}=T_{t+k}\tilde{c},\quad \tilde{c}=[c^{tgt\top},1]^\top
     \]
   - 得到动态可供性轨迹 \(\tau_{t:t+H}\)。
4. **动作生成（Action Generation）**
   - 静态接触点用 MLP 编码，动态轨迹用带 [CLS] 的 Transformer 编码，二者与点云观测融合为条件特征 \(f_t\)。
   - 动作生成网络为基于 DDIM 的扩散策略，从噪声迭代去噪得到动作序列，并采用 receding-horizon 执行（预测 16 步，执行前 8 步）。

### 关键技术细节
- 使用 DDIM 而非 DDPM，保证采样确定性，避免随机噪声传播到可供性轨迹中，同时减少采样步数，满足实时控制（10 Hz）。
- 策略主干基于 DP3（3D 点云条件扩散策略），在其上注入语义可供性先验。
