## 摘要
移动操控是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操控对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高质量全身演示的高效采集需要移动基座与机械臂的协调控制；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为应对这些挑战，我们开发了全身遥操作系统和全景感知VLA策略。该系统通过单一VR界面实现对轮式双臂机器人的协调控制，并支持采集包含5.5小时多模态演示的真实世界移动操控数据集。基于该数据集，我们提出PanoVLA，一种用于移动双臂操控的全景感知视觉-语言-动作策略。PanoVLA基于混合Transformer架构，通过专用的全景编码与融合模块引入全局空间上下文，实现全景观测与语言指令及机器人状态的有效集成以生成动作。在四个真实世界移动操控任务上的评估表明，PanoVLA实现了91.3%的平均阶段完成率和73.4%的端到端成功率，显著优于局部视图基线。这些结果表明，融入全景空间上下文可提升移动机器人的空间理解与闭环操控性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：移动操控（Mobile Manipulation）是具身智能的关键能力，但将VLA模型从桌面操控扩展到移动双臂机器人面临两大耦合挑战：
  - **数据层面**：采集高质量全身演示需要同时协调移动底盘、双臂与夹爪，传统分离式控制界面导致演示动作不流畅。
  - **模型层面**：现有VLA模型依赖前视/腕部局部相机，视野受限，在长时程任务中目标物体常因底盘移动、自遮挡而脱离视野，缺乏机器人中心（robot-centric）的全局空间理解。
- **整体含义**：论文提出一套从数据采集到策略学习的完整框架——全身遥操作系统 + 全景感知PanoVLA策略，以解决移动操控中全局空间理解缺失的问题。核心洞察是：**全景图像的自然全向视野能为VLA策略提供连续、一致的机器人中心空间上下文**。

### 2. 方法论

#### 2.1 全身遥操作系统（数据采集端）
- **硬件接口**：仅用一套VR设备——VR头显（6-DoF头部追踪）、双手柄（手部位姿+夹爪指令）、三个身体追踪器（腰部+双踝），稀疏人体运动追踪后实时重建SMPL人体状态。
- **运动重定向（GMR框架）**：
  - 将机器人配置参数化为 \( q = (x_b, y_b, \theta_b, q_L, q_R) \)，其中 \((x_b, y_b, \theta_b)\) 为平面底盘位姿，\(q_L\)、\(q_R\) 为左右臂关节配置。
  - 通过加权优化求解整身指令：\( q^* = \arg\min_q \lambda_{pos}L_{pos} + \lambda_{rot}L_{rot} + \lambda_{base}L_{base} + \lambda_{reg}L_{reg} \)，其中 \(L_{pos}\) 对齐手/夹爪位置，\(L_{rot}\) 对齐手/末端朝向，\(L_{base}\) 将底盘平面运动耦合至操作者骨盆位移与朝向，\(L_{reg}\) 约束关节极限与平滑性。
  - **关键设计**：将移动底盘建模为3-DoF平面虚拟浮动基座，与双臂联合优化，当目标末端位姿超出臂工作空间时，优化器可自动调整底盘平移与偏航，减少重定向误差，实现自然身体运动驱动的底盘-双臂协调控制。
- **底盘模式切换**：设计了成本驱动的模式切换策略，在每个控制周期评估三个运动模式（spin、acker-mann、diagonal-translation）与期望平移旋转的匹配成本，选择成本最低的模式执行，并周期性更新。

#### 2.2 PanoVLA模型（策略学习端）
- **总体架构**：基于Mixture-of-Transformers（MoT）架构，在π0.5的双专家（VLM专家+动作专家）基础上插入一个**全景专家**，形成三专家VLA策略。
- **全景编码器**：
  - 将双鱼眼图像通过球面重投影（spherical reprojection）转换为等距柱状投影（ERP）图像。
  - 使用MTPano（全景基础模型）提取分割分支与深度分支的中间特征，拼接得到统一的语义+几何密集表征。
  - 通过轻量级token适配器（自适应平均池化+MLP）将密集特征映射为固定数量的全景token序列。
- **全景专家**：执行任务条件下的空间编码——对全景token与VLM缓存（来自局部视图、语言指令、本体状态）进行联合自注意力，生成全景缓存供动作专家使用。动作专家基于拼接缓存 \([C^{vlm}_t; C^{pano}_t]\) 预测动作块。
- **训练目标**：采用条件流匹配（Conditional Flow Matching），最小化预测速度场与目标速度场的L2损失，预测32步连续动作块。

### 3. 实验设计

#### 3.1 数据集
- 使用自建数据集：四类任务共800条成功遥操作轨迹，约5.5小时，50万帧同步数据（25Hz），包括：
  - 局部RGB视图（1前视+2腕部相机）
  - 顶装360°全景相机（ERP格式）
  - 本体状态（双臂关节位置、夹爪开合状态、底盘位姿）
  - 17维全身动作（14维双臂+夹爪，3维底盘速度指令）
- **四类任务**（空间布局多样化）：
  - **Move Pen**：放笔入笔筒（目标方向前/左/右）
  - **Move Block**：转移积木至前方区域（左/右/双侧）
  - **Open Curtain**：打开双侧窗帘（左/右）
  - **Wipe Table**：沿长桌擦除污渍并归还毛巾

#### 3.2 对比方法
- **π0.5**：局部视图基线，不引入全景信息。
- **π0.5 w/ Pano**：将ERP全景直接作为额外图像输入，用SigLIP编码，无专属全景分支。
- **π0.5 w/ Stacked Pano**：将全景重投影为3个视角（光轴间隔120°）拼接成组合图输入。
- **PanoVLA**：完整模型（MTPano编码器+全景专家）。

#### 3.3 评估协议
- 每个任务15次闭环真实机器人试验，单次连续rollout，无人工重置。
- 两个指标：**SR**（端到端二值成功率）与**SCR**（阶段完成率，更细粒度）。

### 6. 主要结论与发现

- **PanoVLA总体最优**：平均SCR达91.3%，SR达73.4%，显著优于π0.5基线（58.6% SCR，30.0% SR）。
- **全景信息确实有效，但关键在于表示方式**：
  - 直接输入ERP全景（π0.5 w/ Pano）平均SR为56.7%，优于基线但仍不如PanoVLA。
  - 重投影拼接（Stacked Pano）平均SR仅38.3%，在部分任务上甚至低于原始全景输入，说明破坏跨视角连续性反而有害。
- **PanoVLA优势在多阶段、长时程任务中更显著**：Open Curtain和Wipe Table任务上优势最大（SR分别领先20%和26.7个百分点），这类任务需要持续的空间状态跟踪。
- **全景编码器选择关键**：MTPano相比SigLIP大幅提升性能（SR 86.7% vs 40.0%），说明全景专用预训练编码器能有效处理ERP的非透视畸变，而视角图像预训练的SigLIP存在显著领域差距。
- **全景专家容量有最优区间**：100M参数为最优，50M容量不足，200M/300M未带来一致提升（数据量有限可能是原因）。

### 7. 优点

- **实验覆盖范围有限**：仅4个任务、单一机器人平台（RANGER MINI + Piper双臂），缺少仿真实验、跨平台验证和未见过的物体/布局泛化测试。

### 9. 总结

论文系统性地解决了移动双臂操控中“数据采集难”和“全局感知缺失”两大核心问题，通过VR全身遥操作实现了自然协调的全身演示采集，并利用全景感知专用编码与融合模块有效弥补了局部视野的不足。PanoVLA的优势在需要跨视场搜索、多阶段状态跟踪和长程空间一致性的任务中表现突出，其全景编码器选择与专家容量消融实验为后续研究提供了有价值的设计依据。然而，实验规模有限、任务多样性不足、缺乏同领域方法对比等特点意味着该工作的结论需要在更大范围的评测中得到进一步验证。总体而言，这是一项系统完整、方法新颖、实验严谨的移动操控VLA研究，为该方向提供了可靠的数据采集方案与有效的模型设计范式。
