## 摘要
视觉-语言-动作（VLA）模型最近作为端到端自动驾驶的一种有前景的范式出现，能够在感知、语言和规划之间实现统一推理。然而，现有方法缺乏利用过去失败或适应分布偏移的机制，导致模型在先前失败的类似场景中持续表现不佳。在本文中，我们提出了DriveVLA-M0，一种具有失败感知潜在记忆的检索增强VLA模型。我们构建了一个存储失败案例及其结构场景表示和专家轨迹标签的潜在记忆池，并设计了一个专用的检索模型，该模型解耦了静态道路结构和动态智能体交互，以实现结构化的检索。在推理时，检索到的案例通过轻量级的解耦LoRA测试时训练（TTT）机制注入模型，从而无需修改主干网络即可进行有针对性的场景特定修正。在NAVSIMv1和NAVSIMv2基准上的大量实验表明，我们的方法始终优于先前方法，在Navtest上达到94.1 PDMS，在Navhard上达到47.0 EPDMS，且仅增加26.44毫秒的TTT反向传播延迟开销。此外，我们展示了DriveVLA-M0可通过额外记忆有效扩展，通过记忆扩展实现无训练的性能提升。代码可在https://github.com/ZebinX/DriveVLA-M0获取。

## Abstract
Vision-Language-Action (VLA) models have recently emerged as a promising paradigm for end-to-end autonomous driving by enabling unified reasoning across perception, language, and planning. However, existing approaches lack mechanisms to exploit past failures or adapt to distribution shifts, causing the model to persistently underperform on similar scenarios where it has previously failed. In this paper, we propose DriveVLA-M0, a retrieval-augmented VLA with failure-aware latent memory. We construct a latent memory pool that stores failure cases along with their structure scene representations and expert trajectory labels, and design a dedicated Retrieve Model that decouples static road structure and dynamic agent interactions to enable structurally grounded retrieval. At inference time, retrieved cases are injected into the model via a lightweight decoupled LoRA-based test-time training (TTT) mechanism, allowing targeted and scenario-specific correction without modifying the backbone. Extensive experiments on NAVSIMv1 and NAVSIMv2 benchmark demonstrate that our approach consistently outperforms prior methods, achieving 94.1 PDMS on Navtest and 47.0 EPDMS on Navhard with only 26.44 ms TTT backward latency overhead. Furthermore, we show that DriveVLA-M0 scales effectively with additional memory, enabling training-free performance gains through memory expansion. The code is available at https://github.com/ZebinX/DriveVLA-M0.

- **核心问题**：现有 VLA 驾驶模型缺乏对历史失败经验的利用能力，也无法有效适应分布偏移（distribution shift），导致模型在**相似的失败场景中反复犯错**——"在同一个地方跌倒两次"。
- **关键洞察**：
  - 人类在复杂决策中会依据过往错误经验评估当前情境的失败风险并调整行为（神经科学与心理学依据），而现有模型缺少这种联想式纠错机制；
  - 已有的记忆增强方法（如 MemoryVLA、EchoVLA）在具身智能中多为机器人操作设计，其检索基于视觉-语言特征，忽略了自动驾驶关键的**静态道路结构**（road topology）与**动态智能体交互**（agent layout）两类结构信息，检索结果可能在语义上相似但结构上不匹配。
- **整体含义**：本文提出通过**失败感知的潜在记忆 + 结构化检索 + 测试时训练（TTT）**，将历史失败经验以可检索、可注入的方式引入 VLA 驾驶策略中，从而针对性改善失败场景表现，且无需大规模重训模型。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 整体架构
- 采用两阶段设计：
  - **离线阶段 [M] Memory Generation（记忆生成）**：识别失败场景并写入潜在记忆库；
  - **在线阶段 [I] Inference with TTT（带 TTT 的推理）**：检索结构相似案例并通过解耦 LoRA 进行场景特定微调。

### 2.2 基座模型（Base Model）
- **VLM 骨干**：采用 InternVL3，在 RecogDrive 收集的大规模自动驾驶 QA 数据集（约 775K 高质量问答对）上微调，获得驾驶语义推理能力。
- **特征压缩**：由于 LLM 最后一层特征（2800×1536 tokens）内存开销过大，引入 Q-Former 风格压缩模块（16 个可学习查询，维度 256），通过交叉注意力将特征压缩至约 1/1050：
  \[
  F_{\text{lang}} = \text{Transformer}(Q_{\text{cmp}}, \text{Linear}(h_{-1}), \text{Linear}(h_{-1}))
  \]
- **动作解码器（Action Decoder）**：包含两个模块：
  - **轨迹头（Trajectory Head）**：融合语言嵌入与自车状态，解码出 M 条候选轨迹（M×8×3 的轨迹簇）；
  - **评分头（Score Head）**：对每条候选轨迹输出 K 个子分数（覆盖碰撞、可行驶区域等安全指标），取总分最高者为最终轨迹。

### 2.3 检索模型（Retrieve Model）
- **架构**：基于轻量预训练 DINOv2，使用 LoRA 微调，采用**解耦双分支设计**：
  - **Map 分支（静态）**：提取道路结构特征 \(F_{\text{map}}\)；
  - **Agent 分支（动态）**：提取智能体交互特征 \(F_{\text{agent}}\)。
- **训练**：遵循 TransFuser 的 occupancy grid 监督范式，用 BEV 占用网格真值进行二值交叉熵训练：
  \[
  L_{\text{Retrieve}} = \text{BCE}(\hat{M}_{\text{map}}, M_{\text{map}}) + \alpha \cdot \text{BCE}(\hat{M}_{\text{agent}}, M_{\text{agent}})
  \]
- 实验结果显示 Map 嵌入聚焦道路边界与车道线，Agent 嵌入聚焦前方车辆，验证了解耦检索的有效性。

### 2.4 记忆生成（Memory Generation）
- 记忆条目结构为三元组 \((\text{key}, \text{input}, \text{label})\)：
  - **检索键 \(k\)**：Map 特征 \(F_{\text{map}}\) 与 Agent 特征 \(F_{\text{agent}}\)；
  - **适应输入 \(x\)**：语言嵌入、自车状态嵌入、中间轨迹簇；
  - **监督标签 \(y\)**：专家轨迹 \(\tau\) 与 oracle 评分的轨迹簇分数 \(S\)。
- **失败判定**：通过 PDM（oracle scorer）对基座模型预测轨迹打分，当聚合分数 \(Q(\hat{\tau}) < \beta\)（\(\beta=0.5\)）时判定为失败场景，写入记忆库。
- 采用余弦相似度去重机制控制记忆库规模。

### 2.5 带 TTT 的推理（Inference with TTT）
- **检索与触发**：当前场景经检索模型提取 Map/Agent 特征，分别在两个层面检索 Top-K 相似案例；仅当相似度超过阈值 \(\lambda\)（最佳为 0.9）时触发 TTT：
  \[
  g = \begin{cases} 1, & \text{if } \cos(F, F^*) > \lambda \\ 0, & \text{otherwise} \end{cases}
  \]
- **解耦 LoRA TTT**：
  - Map 检索的案例用于微调静态 LoRA 分支，Agent 检索的案例用于微调动态 LoRA 分支；
  - LoRA 权重在每次测试时重新初始化，确保场景特定适应；
  - 优化目标为轨迹损失与评分损失之和。
- **路径感知分数融合**：可行驶区域合规等道路理解类子分数采用静态 LoRA 分支预测，碰撞避免等动态能力类子分数采用动态 LoRA 分支预测，组合选择最优轨迹。

- **问题定义清晰**：直击现有 VLA 驾驶模型"重复犯错"这一核心痛点，动机来自认知科学证据，有说服力；

## 8. 不足与局限

- **感知输入单一**：仅使用单目前视相机（Front Camera），未利用多相机环绕或 LiDAR 信息；与使用环绕相机（如 iPad、VADv2）或融合 LiDAR（如 GoalFlow）的方法对比时，在信息充分性上存在天然劣势；
- **仅在仿真环境验证**：NAVSIM 为非反应式/伪闭环仿真，与真实世界复杂交互仍有差距，缺乏真实道路测试或完全闭环仿真结果来验证实际部署可靠性；
- **记忆构建依赖离线评分器**：失败场景识别依赖于 PDM/PDMS oracle scorer，在无高保真仿真器的新场景中难以泛化；对合成数据（SimScale）的依赖说明记忆库扩展需要外部仿真资源支持；
