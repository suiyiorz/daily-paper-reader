## 摘要
通用机器人策略旨在将多模态观测和语言任务指令映射为跨多样任务的动作。然而，现有方法通常将未来表示为固定的短视频-动作块。这种短期未来捕获了用于动作执行的局部场景演化，但并未明确描述指定任务应如何从当前阶段推进到下一阶段的阶段级未来。因此，我们区分了机器人操作的两种互补未来：用于捕获局部场景演化的短期物理未来和用于表示任务进展的阶段级语义未来。我们引入了JEPA-WAM，它通过目标条件化的联合嵌入预测架构（JEPA）预测器Stage-JEPA，增强了基于Motus的世界动作模型（WAM）。给定当前观测和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净和随机化环境中的50个RoboTwin 2.0任务中，JEPA-WAM实现了90.25%的总体成功率，并相较于最强基线将成功轨迹中的平均执行步数减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

- **核心问题**：现有通用机器人策略（如 VLA、WAM）通常将“未来”建模为一个**固定、短期的视频-动作块**，只能捕获局部场景演化（短期物理未来），而**无法显式表达任务应如何从当前阶段推进到下一阶段**（阶段级语义未来）。论文断言：预测一个合理的视频-动作轨迹，并不等于策略理解了"任务当前应该到达什么状态"。
- **核心洞察**：未来应分为两个互补的层次：
  - **短期物理未来（short-term physical future）**：捕获局部场景演化（运动、接触、外观变化）；
  - **阶段级语义未来（stage-level semantic future）**：表示任务进展，编码与任务相关的对象状态/关系变化（如空间对齐、物-物关系转移），不承诺像素细节或转移时长。
- **研究意义**：为机器人操作中的“未来建模”提供了新的视角——**短期物理未来（如何做到）与阶段级语义未来（下一步做到什么）互补建模**，使策略既能理解任务进展，又能精细执行。

## 2. 论文提出的方法论

### 2.1 核心思想
提出 **JEPA-WAM**，通过一个目标条件化的 JEPA 预测器 **Stage-JEPA**，从当前观测和任务指令中预测下一任务阶段的**潜在表示（latent）**，并将此预测作为**内部任务进展目标**，通过门控接口注入 Motus 世界动作模型，从而**联合指导短时视频预测与动作生成**。

### 2.2 任务形式化（两种未来）
- 经典行为克隆策略：\( A_t = \pi(o_t, s_t, l) \)；
- WAM 建模：\( p_\phi(V^{\text{short}}_t, A_t \mid o_t, s_t, l) \)；
- JEPA-WAM 增加阶段级目标：\( \hat{Y}^{\text{stage}}_t = f_\theta(o_t, l) \)，并条件化 WAM：\( p_\phi(V^{\text{short}}_t, A_t \mid o_t, s_t, l, \hat{Y}^{\text{stage}}_t) \)。

### 2.3 两级训练流程

**Stage I：训练 JEPA 预测器（阶段语义目标）**
- **自动阶段对构建**：无需人工标注，利用冻结 V-JEPA2 特征在轨迹中的变化检测关键转移帧（keyframes）——具体为每 8 帧采样候选中心，编码 64 帧片段，计算 clip 级与 token 级特征距离得分，经时间非极大值抑制（NMS）选最多 5 个关键帧，形成阶段边界序列 \( B=(b_0,\dots,b_L) \)；
- **稠密配对**：每帧 \( t \) 与下一边界 \( b_{i+1} \) 配对，构成稠密训练对 \( (t, b_{i+1}) \)；
- **预测与损失**：冻结 V-JEPA2 编码当前切片和目标切片，可训练的 predictor（基于 V-JEPA2 predictor 初始化 + 指令交叉注意力适配器）输出预测的 next-stage 特征，与目标特征计算**余弦相似度损失**对齐。

**Stage II：训练阶段条件化 WAM（短期物理目标）**
- **WAM 骨干**：Motus（Mixture-of-Transformers），包含视频生成专家（初始化自 Wan2.2）、动作专家和视觉语言理解专家（Qwen3-VL），通过 Tri-modal Joint Attention 交换三流信息；
- **条件注入**：对 Stage-JEPA 输出的 256 个 target tokens 做 mean-pooling，经 MLP 投影到视频 token 维度，通过**门控标量** \( \alpha = 0.2\sigma(\beta) \) 加权后加到视频 token 上：
  \[
  \tilde{X}^v_t = X^v_t + \alpha h_t
  \]
- **正则化**：\( \mathcal{L} = \mathcal{L}_{\text{video}} + \mathcal{L}_{\text{action}} + \lambda_g \alpha^2 + \lambda_\rho(\rho - \rho_0)^2 \)，约束门控为小的残差更新、控制注入幅度比例；
- **两阶段互补**：Stage I 决定"应发生什么任务级变化"，Stage II 学习"如何通过细节视觉演化与动作实现它"。

### 2.4 推理流程
- 保持因果 64 帧观测缓冲区（不足时重复最早帧填充），无未来信息；
- 每个策略查询执行：① 冻结 Stage-JEPA 从观测缓冲区+指令预测阶段潜变量；② WAM 依据该条件预测视觉未来与动作块；③ 执行动作块、更新缓冲、重规划（滚动时域闭环）。

## 6. 论文的主要结论与发现

1. **性能提升**：在 50 个 RoboTwin 任务上，JEPA-WAM 总体成功率为 **90.25%**（clean 91.42%、randomized 89.08%），超过最强基线 Motus（88.66%/87.02%），并在 clean 下 5/7 类别、randomized 下 6/7 类别取得最优；
2. **执行效率提升**：全部 rollout 平均 episode 长度从 156.28 降至 132.80（-15.02%）；**成功 rollout** 平均长度从 79.57 降至 74.82（**-5.97%**），说明阶段引导减少了冗余纠正动作；
3. **消融结论**：移除 JEPA 分支降幅最大（→87.23%），证明阶段条件通路提供了超出短时 WAM 骨干的信息；将预测的阶段潜变量注入视频 token（而非仅用于当前观测）更有效；Stage-I 目标函数带来额外但较小的增益；门控正则化提供进一步稳定约束；
4. **定性分析**：JEPA-WAM 轨迹更直接地推进到任务完成阶段，而 Motus 出现多次目标物体的上下反复震荡和局部修正；
5. **真实场景**：LIFT2 上 JEPA-WAM 平均任务进展分 48.00，高于 π0.5 的 41.50；
6. **适用边界**：对依赖精确抓取几何/接触稳定的任务（如 acquisition & lifting）和需要严格机构运动学约束/精确计时的铰接/设备交互任务，增益较小。

## 7. 优点与亮点

- **概念创新清晰**：明确提出"短期物理未来"与"阶段级语义未来"的双尺度区分，并指出像素级未来预测与任务进展预测的根本错配，动机扎实；
