## 摘要
自主具身智能体必须维持一个涉及感知、行动、验证和自我纠正的长决策循环，该循环跨越多个步骤。当前系统通过特定任务的工作流或具身策略来维持这一循环。我们研究了第三种形式：智能体具身控制，其中通用智能体自己维持循环。以零样本导航作为受控测试平台，我们仅使用单目RGB摄像头和离散动作评估了三种软件工程智能体框架。在这种严格的最小条件下，复现的默认努力配置达到了70.7±3.5%的成功率（opus-5，三次运行的平均值），而fable-5在最大努力下达到了78%。当训练好的路径点工具作为可选能力与原始动作一起暴露时，混合fable-5智能体在默认努力下达到76.7±0.6%，使用的环境步数仅为最大努力原始运行的一半，运行时间不到四分之一。受控干预表明，能力主要是以模型为中心的：模型选择极大地改变了成功率，框架影响是描述性的，而强制路径点接口有助于较弱的模型但可能阻碍更强的模型。尽管如此，在更长视野的任务上性能急剧下降，同时延迟和上下文增长限制了持续操作。这些结果表明，智能体控制在零样本导航中已经具有竞争力，并且模型、框架和接口为自主具身智能体提供了互补的路径。

## Abstract
Autonomous embodied agents must sustain a long decision-making loop that involves perceiving, acting, verifying, and self-correcting over many steps. Current systems sustain this loop through task-specific workflows or embodied policies. We study a third form, agentic embodied control, in which a general-purpose agent holds the loop itself. Using zero-shot navigation as a controlled testbed, we evaluate three software-engineering agent harnesses given only a monocular RGB camera and discrete actions. Under this strictly minimal condition, replicated default-effort configurations reach 70.7$\pm$3.5% success (opus-5, mean over three runs), and fable-5 reaches 78% at maximum effort. When a trained waypoint tool is exposed alongside primitives as an optional capability, the hybrid fable-5 agent reaches 76.7$\pm$0.6% at default effort, using half the environment steps and less than one quarter of the wall time of the maximum-effort primitive run. Controlled interventions show that capability is primarily model-centered: model choice strongly changes success, harness effects are descriptive, and a forced waypoint interface helps weaker models but can hinder stronger ones. Performance nevertheless falls sharply on longer-horizon tasks, while latency and context growth limit sustained operation. These results show that agentic control is already competitive in zero-shot navigation and that models, harnesses, and interfaces offer complementary paths toward autonomous embodied agents.

- **上下文重要性**：随着前沿视觉语言模型（VLM）能力增强（空间推理、多轮工具使用、错误恢复等），传统由导航专用脚手架提供的功能可能已内化在模型中。因此，探索模型能否直接控制具身循环具有前瞻性意义。
- **整体含义**：该研究验证了在最小接口下（无导航专用训练、无地图、无搜索、无显式记忆），通用智能体已能达到与工业级训练策略相当的零样本导航性能，但离真正自主（长时间操作、资源受限管理）仍有距离。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：用通用软件工程智能体框架替代所有导航专用脚手架，仅提供极简感知-动作接口，让模型自主驱动观察、行动、恢复和终止的循环。不预设任何导航逻辑。
- **关键技术细节**：
  - **接口定义**：
    - `observe()`：返回单张 512×512 前向 RGB 图像（HFOV 90°），不推进环境。
    - `step(actions)`：执行最多 50 个离散原始动作序列，包括 FORWARD（0.25 m）、LEFT（15°）、RIGHT（15°）、STOP（终止）。返回执行的动作数和剩余预算，**无图像、无碰撞信号、无比对、无位姿**。
  - **智能体框架**：使用三个现成的软件工程智能体框架——`mini-swe-agent`（最小参考框架）、`Claude Agent SDK`、`Codex CLI`。它们均未针对导航设计，只提供通用工具调用和会话管理。
  - **混合接口**：在原始动作基础上，可选暴露一个训练好的深度基路径点预测器，输出最多 5 个候选路径点，由智能体决定是否调用。路径点模块从强制控制路径变为可选能力。
  - **控制循环**：每回合模型主动调用 `observe()` 或 `step()`，无外部策略或工作流预设顺序。历史由框架自动维护（无限制上下文增长）。
  - **零样本设置**：所有模型权重冻结，无导航领域微调，无演示示例，副本间不共享状态。

## 6. 论文的主要结论与发现

1. **最小接口下零样本导航性能出众**：`Fable-5` + `Claude SDK` 默认达到 68.3% SR（三次平均），最大努力达 78% SR，与工程化零样本（AgenticNav 55% SR）和训练策略（Qwen-RobotNav 72% SR，全景输入）处于同一水平。
2. **能力主体在模型本身**：固定框架和接口时，模型选择导致 SR 从 5% 到 72% 的跨度，远大于框架变化（2–7 SR）的影响。
3. **路径点接口的效果依赖模型能力**：强制路径点对弱模型（Qwen3.5-4B 从 5% 提升到 43%）帮助巨大，但强模型（Fable-5）仅提升 0.7 SR 且增加碰撞；作为可选工具时，混合接口使默认努力达到 76.7% SR，步数和时间减少一半以上。
4. **长视野和持续操作仍是瓶颈**：RxR-CE 上 SR 降至 26-39%，上下文无限制增长（中位数 49k tokens），延迟高（中位数 527 秒），无法支撑长时间自主。
5. **失败模式为沉默、自信、路线级**：92% 失败以自信的成功声明结尾；多数提前分支错误而非最终定位错误；模型常自我诊断但不纠正。
6. **物理机器人展示推理迁移**：逻辑条件判断、精细属性区分、多段路径保持等能力转移，但身体感知（未预留转向空间）、致动误差（报告成功但实际转向不足）和无持久空间记忆导致关键失败。

## 7. 优点：方法或实验设计上的亮点

- **清晰的分离研究**：首次将模型、框架、接口作为独立变量，在具身导航中进行系统消融，提供了对照基准。
- **最小接口设计**：消除了几乎所有导航专用脚手架，使能力归因明确，揭示了通用模型的内蕴导航能力。
- **混合接口概念**：展示智能体控制可作为组合性基底——训练好的模块从强制控制路径变为可选工具，效果显著提升。
- **物理机器人验证**：将模拟器结论推广到真实硬件，暴露了新维度的问题（身体意识、校准、空间记忆）并定位了未来方向。
