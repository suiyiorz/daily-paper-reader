## 摘要
视觉-语言-动作（VLA）模型作为一种可扩展的机器人操控方法引起了越来越多的关注。尽管这些模型是有效的动作预测器，但将它们部署为机器人代理时暴露了关键缺陷：缺乏故障恢复机制、在长时程任务中执行不一致，以及对观测、任务或本体变化的鲁棒性有限。现有解决方案通过模型重训练或环境特定模块单独解决这些局限性，但真正需要的是一个通用框架，能够系统性地将预训练的VLA转化为机器人代理。我们提出RoboBRIDGE，一个模块化框架，通过五个协调模块（即Monitor、Perceptor、Planner、Controller和Robot Interface）提供编排层，从而利用现成组件（包括预训练VLA）组合出稳健的机器人代理。Monitor将快速故障检测与分层恢复相结合，在错误级联之前纠正错误。当环境偏离当前计划时，Planner触发重新规划，同时Perceptor异步更新场景理解，避免执行停滞。在Controller内部，原始技能微调将操作分解为具有专用LoRA适配器的域不变原语，从而降低使用VLA时对域偏移的敏感性。在LIBERO、RoboCasa以及覆盖多种机器人平台和VLA骨干的真实世界案例研究中，RoboBRIDGE始终优于独立策略和先前的增强VLA部署。这些结果表明，可靠的机器人代理能力不仅来自扩展动作预测器，更来自围绕它们进行的结构化编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

## 2. 论文提出的方法论

### 总体架构

RoboBRIDGE提出一个模块化编排框架，由五个协调模块组成：**Monitor（监控）、Perceptor（感知）、Planner（规划）、Controller（控制）、Robot Interface（机器人接口）**。任何动作生成策略（包括但不限于VLA）都可放入Controller槽位，外围四类模块补充单体部署所缺失的能力。

### 三项核心技术机制

**（1）两阶段分层监控（Two-phase Monitoring）**
- **第一阶段：轻量成功检查**。使用VLM定期评估当前观测与计划上下文的匹配情况，输出二值成功标志和置信度，采用约束输出格式抑制冗长推理，减少延迟，可随执行持续运行而不阻塞。
- **第二阶段：失败诊断与恢复**。仅在检测到高置信度失败时触发（conf ≥ γ），调用诊断模型推断根因与恢复目标，选择四层分层恢复策略，按重计算范围从小到大排列：
  1. **重试（retry）**：重新执行当前原语；
  2. **重新生成（re-generate）**：保留当前计划和感知状态，重新生成轨迹；
  3. **重新规划（replan）**：基于最新异步感知结果重新规划；
  4. **重新感知（re-perceive）**：先强制完整感知再规划，用于对象状态不可靠的场景。
- 该层级结构确保以最小代价解决故障，避免不必要的重算，同时保留深度恢复能力。

**（2）反应式规划与异步感知（Reactive Planning with Asynchronous Perception）**
- 采用生产者-消费者架构：感知线程持续更新线程安全缓冲区（仅存最新检测结果），执行线程按顺序运行原语；感知延迟被执行过程掩盖。
- 每个原语完成后，比较当前规划所用感知结果 (¯o_plan) 与缓冲区中最新感知结果 (¯o_lat) 的差异，差异度量公式为：

  **Δ(¯o_a, ¯o_b) = max_i∈O_a∩O_b ‖p_a^(i) - p_b^(i)‖₂ + λ·|O_a △ O_b|**

  其中 p(i) 为对象 i 的三维位置，O 为检测对象集合，△ 为对称差，λ 权衡对象出现/消失相对于位置位移的权重。
- 当 Δ ≥ τ 时触发重新规划：保留高层动作序列（如 PICK → PLACE），仅重新生成当前及后续原语技能的空间参数，避免冗余的高层推理。

**（3）原始技能微调与控制器切换（Primitive Skill Fine-tuning）**
- 将操控分解为域不变原语集合：**P = {MOVE, GRIP, ROTATE, ...}**，每个原语由专属LoRA适配器（∆θ_k）在冻结的VLA骨干上执行。
- 控制器切换采用两层级解析器：存在对应适配器则选用，否则回退到所有LoRA适配器的平均：

  **RESOLVE(p_t) = ∆θ_pt（若存在适配器），否则 (1/|P|) Σ_p Δθ_p**

- 动作生成输出7自由度增量动作：**a_t = (δx, δφ, g)**，包括三自由度平移、三自由度旋转和夹爪指令。执行时可通过笛卡尔速度指令或IK求解器（将增量转化为绝对目标后求解关节位置）双路径执行，兼容不同运动学接口的机器人。

### 算法流程（简化文字描述）

1. 重置环境，执行初始感知，Planner生成高层计划；
2. 启动异步感知线程持续更新场景状态；
3. 对每个原语：解析对应LoRA适配器 → 循环执行动作生成与步进 → 每步进行轻量成功检查；
4. 若检测到失败且置信度足够：停止机器人，调用诊断模型，"重试/再生成/重规划/重新感知"四选一恢复；
5. 原语完成时比较当前感知与规划时感知的差异，超过阈值则触发重新规划并更新场景状态，继续执行下一原语。

## 6. 论文的主要结论与发现

1. **框架带来一致提升**：在LIBERO上，RoboBRIDGE将GR00T-N1.5的平均任务成功率从35.5%提升至39.7%；在更困难的RoboCasa上，提升更为显著，所有骨干的成功率均有所提高（平均从3.7%提升至7.5%，排除pick-and-place任务后从6.2%提升至11.4%）。
2. **监控有效性与LLM骨干推理能力强相关**：启用两阶段监控后，Claude Opus 4.6提升最大（+8.1%，达14.7%），而较小模型（Gemini-3 Flash、Claude Haiku 4.5）几乎无提升，说明有效的失败诊断需要足够推理能力。
3. **规划与监控缺一不可**：无监控时，所有LLM骨干的成功率仅落在1.8%–8.0%窄区间，说明仅靠规划质量不足以弥合VLA与可靠智能体之间的差距。
4. **LoRA微调+框架逼近全量微调**：LoRA微调结合RoboBRIDGE达到27.1%成功率，接近独立全量微调的31.9%，但参数更新量少得多；全量微调从框架中同样获益，提升至40.0%。
5. **框架策略无关性得到验证**：经典IK控制器在框架内也达到22.1%成功率，证明RoboBRIDGE的模块化设计适用于超越学习策略的控制器。
6. **外部编排优于模型内部自校正**：CycleVLA虽在VLA内部集成了回溯和自校正解码，但独立部署仅7.5%成功率，远低于RoboBRIDGE的外部监控与恢复机制。
7. **核心结论**：可靠的机器人智能体能力**不是来自单纯扩展动作预测器，而是来自结构化的模块编排**——长期来看，需要围绕策略构建监控、感知、规划与控制的协同架构。

## 7. 优点

- **通用性与政策无关设计**：框架不依赖特定VLA架构，可无缝包裹任意动作生成策略（包括经典控制器），具有高度的模块化和可组合性。
- **分层恢复策略精巧**："重试→再生成→重规划→重新感知"的层级结构在最小代价修正与深度恢复之间取得良好平衡，避免过度重算。
- **异步感知架构高效**：将感知与执行解耦为并发线程，用缓冲区隐藏推理延迟，仅在场景实质发散时触发重规划，不阻塞执行流。
- **参数高效的域适配方案**：将操控分解为域不变原语，配以专属LoRA适配器，显著减少域漂移敏感性，同时避免全量微调的高参数成本。
- **类比清晰、动机扎实**：以LLM从生成器到智能体的演进为类比，为VLA领域提出了一个具有启发性的结构化视角。
- **实验组合较全面**：仿真双基准+真实世界验证+多种VLA骨干+LLM骨干消融+控制器消融+失败模式分析，覆盖面在同领域中较为突出。
- **失败案例分析具有实践价值**：明确指出感知错误和不可恢复操控失败两类主要失效模式，为后续研究提供了针对性方向。

- **真实实验证据薄弱**：真实世界仅以案例展示形式呈现，缺乏系统的成功率统计、多次重复和定量对比，降低了结论的实证强度。
- **RoboCasa成功率整体偏低**：大量任务成功率接近0%，说明在困难场景下VLA策略能力本身仍是瓶颈，框架更多是"锦上添花"而非"雪中送炭"。
- **原语词汇有限**：当前原始技能集仅覆盖单臂桌面行为，无法处理接触丰富交互、可变形物体和双臂任务，泛化范围受限。
- **超参手工设定**：监控阈值（γ、τ）、恢复规则和发散度权重（λ）均为手工配置，未实现从交互数据中学习，部署时需要人工调参。
- **感知瓶颈突出**：在杂乱场景、遮挡和视觉相似物体情境下，Perceptor的误识别和误定位是主要失败源，框架未能完全解决感知层面的可靠性问题。
- **不可恢复失败处理不足**：对于接触丰富交互中永久改变环境状态的情况，重试机制失效，缺乏提前停止或切换替代策略的机制。
- **资源信息不透明**：未报告GPU型号、数量、总训练时长，算力评估与复现成本信息不完整。
- **统计功效有限**：部分实验每组仅17次rollout，成功率统计精度较低（±约5.9个百分点），对于小幅度提升的显著性没有报告置信区间或统计检验。
- **局限性中已自我承认**：论文在结论部分明确承认上述多项限制，并指出未来方向为学习监控阈值、添加显式验证与确认层、扩展状态表示以支持接触丰富和双臂操作。
